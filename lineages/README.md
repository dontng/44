## 怎么用

每条知识脉络独立成篇，阅读顺序自由，从任意一条开始都可以：
1. **先说明为什么捏合在一起**，再按逻辑逐个把知识点一次讲清（不反复绕弯、贴合 408 教材和真题原本的表达）；
2. **真题案例直接揉进正文推演**，讲到计算或易错点时顺手把真题里的数字算清楚；
3. **文末附关联真题归拢表**，直达 [sprint40/](../sprint40/README.md) 对应练习页，知识点看明白后，碎片时间随时点开做纯推演和复盘。
