# 408 全考纲自然知识脉络（Lineages）

> **本目录替代 [sprint40/](../sprint40/README.md) 的日历排期作为主作战入口。**
> 不设硬性天数配额、不做主观剪枝，完全按**“学科 → 章节 → 自然知识脉络”**串起全部知识点，由程序校验保证 **88/88 考纲专题**与 **329/329 近七年真题（2020–2026：280 选择 + 49 大题）**零遗漏覆盖（`python3 tools/check_lineages.py`）。

## 使用方式

每条知识脉络独立成篇，固定包含三部分：
1. **知识脉络复原**：按演化逻辑讲透这一支的全部概念、机制、对比与边界（融合 [outline/](../outline/README.md) 全部考点，不留盲区）；
2. **真题考点与计算拆解**：把 2020–2026 真题里在这一支上实际考过的切入点、公式与推演步骤抽出来讲清；
3. **关联真题归拢清单**：直达 [sprint40/](../sprint40/README.md) 对应真题与解析。知识点一复原，做题与日历彻底解耦——随时有空点进去只做纯推演和复盘。

```bash
python3 tools/check_lineages.py
```

确保 88 考纲专题、40 选择题组（280 题）、49 道大题（总计 329 题）全部闭环覆盖且无断链。
