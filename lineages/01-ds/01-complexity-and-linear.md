# 复杂度分析、顺序/链式线性表与特殊矩阵压缩

> 脉络编号：`ds-01` · 返回 [全科知识脉络总览](../README.md)

数据结构开篇要解决的其实就一件事：数据在内存里怎么摆，以及摆完之后算起来有多快。逻辑上最简单的一排数据叫线性表，放到内存里就分出“挨着放（顺序表）”和“散开放、靠指针串起来（链表）”两条路；而二维数组和各种特殊矩阵，本质上也是把格子压平塞进一维顺序数组里。把基本概念、复杂度计算、顺序表、链表和矩阵压缩放在一条线上，从“怎么衡量快慢”一路看到“连续数组和指针链表各自擅长什么”，整个线性部分就通了。

## 一、数据结构基本概念：分清“逻辑”和“存储”

408 开篇的术语其实很朴素：
- **数据**是计算机能处理的所有信息；**数据元素**是数据的基本单位（比如一张学生表里的一整条学生记录）；**数据项**是不可再分的最小单位（比如学生的学号、姓名）；**数据对象**是性质相同的数据元素的集合（整张学生表）。
- **数据结构三要素**：**逻辑结构**（元素之间谁跟谁有关系）、**存储结构**（在内存里实际怎么存）和**数据的运算**（支持哪些操作，比如查找、插入、删除）。运算的“定义”看逻辑结构，运算的“实现”看存储结构。

考试最爱考的一类概念题，是让你区分哪些词属于**逻辑结构**，哪些属于**存储结构**：
- **四大逻辑结构**：集合、线性结构（一对一）、树形结构（一对多）、图状结构（多对多）。只要只谈元素之间的关系、没说内存里怎么存，都是逻辑结构——比如线性表、栈、队列、树、图，以及**有序表**（只说了关键字按大小排好序，没规定用数组还是链表存）。
- **四大存储结构**：顺序存储、链式存储、索引存储、散列存储。名字里带“顺序”“单链”“双链”“循环链”“静态链表”“散列/哈希”的，都明确指定了内存里的存法，属于**存储结构**。千万别把“有序表（逻辑）”和“顺序表（存储）”搞混。

另外还有一个小计算叫**存储密度**：
$$\text{存储密度} = \frac{\text{结点中数据本身占的字节数}}{\text{结点总共占的字节数}}$$
顺序表只存数据、不存指针，存储密度最高（为 1）；链表每个结点都得带指针，存储密度小于 1。在 408 理论计算里，如果一个结点存 4 字节整数加 8 字节指针，存储密度按 $4 / (4+8) = 1/3$ 算；在真实 64 位 C 语言里，因为结构体还要做 8 字节对齐填充，`int` 后面会补 4 字节空位，总大小变成 16 字节，实际有效占比只有 25%。

## 二、算法复杂度：别靠猜，按实际执行次数算

时间复杂度看的是**输入规模 $n$ 变大时，基本操作执行次数的增长量级**，记号上 $O$ 表示上界、$\Omega$ 表示下界、$\Theta$ 表示同阶紧确界（408 里一般直接用大 $O$ 表示紧确复杂度）。常见量级从小到大排：
$$O(1) < O(\log n) < O(\sqrt{n}) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$$

### 1. 循环怎么算？重点看内层次数跟外层的关系

做复杂度选择题，最容易踩的坑是看到两层循环就直接把两层的最大范围相乘。正确的做法是把外层每一轮里、内层实际跑了多少次写出来求和：

- **外层线性递增 + 内层跑到 `i`**（`for(i=1; i<=n; i++) for(j=1; j<=i; j++)`）：
  总次数是 $1 + 2 + 3 + \dots + n = \frac{n(n+1)}{2}$，量级是 **$O(n^2)$**。
- **外层每次翻倍 + 内层跑到 `i`**（`for(i=1; i<=n; i*=2) for(j=1; j<=i; j++)`）：
  例如真题 `2022-01` 就考过这种写法。外层 $i$ 依次取 $1, 2, 4, \dots, 2^k$（$2^k \le n$），一共约 $\log_2 n$ 轮，很多人会误乘成 $O(n\log n)$。但把每轮内层次数加起来其实是等比数列：
  $$1 + 2 + 4 + \dots + 2^k = 2^{k+1} - 1 < 2n$$
  等比数列的和跟最后一项同阶，所以总复杂度其实是 **$O(n)$**，不是 $O(n\log n)$。
- **外层条件带平方 + 内层跑到 `i`**（`for(i=1; i*i<=n; i++) for(j=1; j<=i; j++)`）：
  例如真题 `2025-01` 就是这个套路。外层只跑到 $m = \lfloor\sqrt{n}\rfloor$，每轮内层跑 $i$ 次，合起来是等差数列：
  $$1 + 2 + \dots + m = \frac{m(m+1)}{2} \approx \frac{(\sqrt{n})^2}{2} = \frac{n}{2}$$
  量级同样是 **$O(n)$**。
- **内层步长等于外层变量**（`for(i=1; i<=n; i++) for(j=i; j<=n; j+=i)`）：
  每轮分别跑 $n, n/2, n/3, \dots, 1$ 次，总次数是 $n(1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n}) \approx n \ln n$，量级为 **$O(n\log n)$**。
- **内层变量不重置（双指针 / 滑动窗口）**：
  如果 `j` 定义在循环外面，外层 `i` 走完一遍的过程中 `j` 只往前走不回头，那么 `i` 最多走 $n$ 步、`j` 也最多走 $n$ 步，加起来是 **$O(n)$**。

### 2. 递归的时间和空间怎么算？

- **递归时间**：看递推式或画递归树，把所有结点的计算量加起来。
  - 单支递推 $T(n) = T(n-1) + O(1)$：一路调用 $n$ 层，每层常数工作量，总时间 $O(n)$。
  - 二分分治 $T(n) = 2T(n/2) + O(n)$（比如归并排序、理想快排）：一共 $\log_2 n$ 层，每层总工作量都是 $O(n)$，合起来 $O(n\log n)$。
  - 朴素斐波那契 $T(n) = T(n-1) + T(n-2) + O(1)$：每次裂成两支，总时间呈指数级增长（$O(2^n)$ 级别，精确为 $\Theta(1.618^n)$）。
- **递归空间**：只看**调用栈同时压着的最大层数**（也就是递归树的最大深度），**不是**递归函数总共被调用了多少次！因为一条分支返回后，它的栈帧就弹掉了，空间会被后面的分支复用。
  - 比如二叉树递归遍历，时间是 $O(n)$，空间是 $O(h)$（平衡时 $O(\log n)$，退化成一条链时 $O(n)$）。
  - 如果算法除了递归栈，还在堆上额外开了长度为 $n$ 的辅助数组（比如归并排序），总辅助空间取两者中更大的那个，即 $\max(O(\log n), O(n)) = O(n)$。

## 三、顺序表：查得快，但中间增删要挪人

顺序表就是用一段地址连续的内存（静态数组或 `malloc` 动态数组）依次存元素。在 408 考试模型里把这段空间直接看成连续的；在现代操作系统里，它保证的是虚拟地址连续，同一个页面内物理地址连续，对 CPU 缓存（Cache）非常友好。

### 1. 随机存取：为什么按下标取元素是 $O(1)$？

设第 1 个元素 $a_1$ 存在地址 $\text{LOC}(a_1)$，每个元素占 $L$ 字节，那么第 $i$ 个元素（逻辑位序从 1 开始，对应 C 数组下标 `i-1`）的地址直接靠一步乘法和加法就能算出来：
$$\text{LOC}(a_i) = \text{LOC}(a_1) + (i - 1) \times L$$
不用从头挨个找，这就是**随机存取**。例如真题 `2023-01` 考顺序表上哪种操作时间复杂度是 $O(1)$：答案就是**按位序（下标）存取**；而“按值查找”不知道元素在哪，无序表要顺序扫 $O(n)$，有序表折半查找也要 $O(\log n)$。

### 2. 插入、删除与平均移动次数

顺序表因为大家紧挨着坐，插队或退队就得挪动后面的人：
- **插入第 $i$ 个位置**（合法范围 $1 \le i \le n+1$，且表未满）：必须**从后往前**把 $a_n \sim a_i$ 依次往后挪一格（如果从前往后挪，会把后面的元素覆盖掉）。
  - 在第 $i$ 位插入需移动 $n - i + 1$ 个元素。
  - 表尾追加（$i = n+1$）移动 0 次；表头插入（$i = 1$）移动 $n$ 次。
  - 假设 $n+1$ 个位置等概率，平均移动次数为 $\frac{0 + 1 + \dots + n}{n+1} = \mathbf{\frac{n}{2}}$，复杂度 $O(n)$。
- **删除第 $i$ 个位置**（合法范围 $1 \le i \le n$，且表非空）：必须**从前往后**把 $a_{i+1} \sim a_n$ 依次往前挪一格填坑，最后表长减 1。
  - 删除第 $i$ 位需移动 $n - i$ 个元素。
  - 表尾删除（$i = n$）只需 `length--`，移动 0 次；表头删除（$i = 1$）移动 $n-1$ 次。
  - 假设 $n$ 个位置等概率，平均移动次数为 $\frac{0 + 1 + \dots + (n-1)}{n} = \mathbf{\frac{n-1}{2}}$，复杂度 $O(n)$。

例如真题 `2026-01` 就直接考：对长度为 $n \ge 3$ 的顺序表做表头插入、表头删除、表尾插入、表尾删除，哪些操作**一定**要移动多个元素？答案就是**表头插入**（移动 $n$ 次）和**表头删除**（移动 $n-1$ 次），表尾的插和删移动次数都是 0。

### 3. 动态顺序表为什么要“翻倍扩容”？

数组满了之后需要重新 `malloc` 一块更大的内存并把旧数据全搬过去。
- 如果每次容量**翻倍（$\times 2$）**：从容量 1 开始连续尾插 $n$ 个元素，搬迁次数是 $1 + 2 + 4 + \dots + 2^k < 2n$，平摊到 $n$ 次插入上，每次均摊只需 **$O(1)$**。
- 如果每次只增加一个固定常数 $C$（$+C$）：要扩容 $n/C$ 次，总搬迁次数是 $C + 2C + \dots + n = O(n^2)$，均摊到每次插入就退化成 $O(n)$ 了。

### 4. 顺手看三道 408 数组算法大题的常见思路

408 的第 41/42 题非常喜欢用顺序表/数组考线性时间算法，核心都是避免 $O(n^2)$ 暴力嵌套，用单趟扫描解决问题：
- **多指针单向推进**（真题 `2020-41`）：给三个升序数组 $A, B, C$，求三元组 $(a, b, c)$ 的最小距离 $D = |a-b| + |b-c| + |c-a|$。把三个数按大小排成 $\text{lo} \le \text{mid} \le \text{hi}$，化简一下发现 $D = 2(\text{hi} - \text{lo})$，跟中间那个数根本没关系！要想缩小 $\text{hi} - \text{lo}$，只能把当前**指向最小值的那个指针往后移一格**（移另外两个只会让差值变大或不变）。三个指针一路向右扫，时间 $O(m+n+p)$、空间 $O(1)$。
- **逆向扫描维护后缀极值**（真题 `2025-41`）：给数组 $A[0..n-1]$，对每个 $i$ 求 $\max_{j \ge i}(A[i] \times A[j])$。注意负数乘负数会变大！所以 $A[i] \ge 0$ 时要乘后缀最大值，$A[i] < 0$ 时要乘后缀最小值。如果从后往前扫，一边走一边用两个变量 `hi` 和 `lo` 记录当前后缀的最大、最小值，扫一趟就算出全部结果，时间 $O(n)$、空间 $O(1)$。
- **海量数据求最小 $k$ 个数**（真题 `2022-42`）：在超大数组里找最小的 10 个数，不需要把整个数组排序（$O(n\log n)$）。只需维护一个容量为 10 的**大根堆**：先拿前 10 个数建堆，堆顶就是这 10 个数里最大的门槛；后面每来一个数，只要比堆顶大或相等就直接丢掉，比堆顶小就换掉堆顶并向下调整。因为 $k=10$ 是常数，每次调整耗时 $O(\log 10) = O(1)$，总时间 $O(n)$、额外空间 $O(1)$。

## 四、链表：改指针很快，但找位置要从头走

链表把元素散放在内存各处，靠指针把逻辑上的前后关系串起来。因为没法用公式直接算地址，按位序找第 $i$ 个元素只能从头挨个走，时间是 $O(n)$；但如果**已经拿到了前驱结点的指针**，插入和删除只需改几条指针，时间是 $O(1)$。

### 1. 为什么要加“头结点”？常见链表类型怎么对比？

如果单链表不带头结点，在第 1 个位置插删要改外部指针 `head`，在后面插删要改前驱结点的 `next`，代码必须分情况写。加上一个不存有效数据的**头结点**后，第 1 个数据结点也有了前驱，所有位置的插删写法完全统一，判空也统一成 `L->next == NULL`。

几种常见链表的对比（408 选择题高频考点）：

| 链表类型 | 判空条件 | 访问表头 | 访问表尾 | 删除表尾 |
| :--- | :--- | :---: | :---: | :---: |
| **带头结点单链表** | `L->next == NULL` | $O(1)$ | $O(n)$ | $O(n)$ |
| **带头、尾指针的单链表** | `L->next == NULL` | $O(1)$ | $O(1)$ | **$O(n)$** |
| **仅设尾指针的循环单链表** | `rear->next == rear`（带头结点） | **$O(1)$** | **$O(1)$** | $O(n)$ |
| **双向循环链表** | `L->next == L` | $O(1)$ | $O(1)$ | **$O(1)$** |

这里有两个极容易掉坑的地方：
1. **单链表就算加了尾指针 `rear`，表尾删除依然是 $O(n)$**。因为删掉 `rear` 后，得把 `rear` 挪到倒数第二个结点，而单链表没有前驱指针，只能从头结点重新遍历一遍找前驱。
2. **静态链表**是用数组模拟链表：每个数组元素存 `data` 和下一个元素的数组下标 `next`（俗称游标），逻辑上还是链式存储，增删不用搬移数据，但整体容量固定、不支持随机存取。

### 2. 指针修改铁律与真题高频边界

改链表指针永远记住两句话：**“先连后断”**（先把新链子接好，再拆旧链子，防止后面的结点丢了找不到）和**“先判空再解引用”**。近几年真题考的全是这些细节：

- **删单链表首元结点时，别忘了维护尾指针**（真题 `2021-01`）：
  带头结点 `h`、尾指针 `p` 的单链表，删除首元结点 `q = h->next` 时，常规写完 `h->next = q->next` 后，**必须检查 `if (p == q) p = h;`**，最后再 `free(q)`。否则如果表里原本只有一个数据结点，删完后 `p` 还指着已释放的 `q`，变成悬空指针，下次尾插直接崩溃。
- **双链表插入的指针顺序**（真题 `2023-02`）：
  在结点 `p` 后插入 `s`，如果已经执行了 `s->next = p->next; p->next = s;`，此时原后继结点只能靠 `s->next` 找到，且原后继的 `prev` 仍然指着 `p`。接下来必须先写 **`s->prev = s->next->prev;`**（把 `p` 赋给 `s->prev`），再写 **`s->next->prev = s;`**。要是反过来先改了 `s->next->prev = s`，下一句就会把 `s->prev` 错赋成 `s` 自己。
- **把结点从后面摘下来头插到表头**（真题 `2024-01`）：
  设 `q` 是 `p` 的后继，要把 `q` 移到头结点 `h` 后面，分两步：先脱链 `p->next = q->next;`，再头插 `q->next = h->next; h->next = q;`。头插这两句绝对不能颠倒，否则原首元结点会丢失。
- **隔项跳跃赋值要防空指针**（真题 `2026-02`）：
  给每个结点设置 `p2` 指向它“后继的后继”（`p1->p1`），写循环时必须先判断 `cu->p1 != NULL && cu->p1->p1 != NULL`，不满足就安全置 `cu->p2 = NULL`，并且每个分支走完都要让游标 `cu = cu->p1` 往前走，既不能对空指针取 `->p1`，也不能漏掉游标推进导致死循环。

### 3. 链表的四个经典操作模型

- **单链表原地逆置**（时间 $O(n)$，空间 $O(1)$）：
  - **头插法**：把头结点摘空 `L->next = NULL`，然后把后面的结点挨个取下来头插到 `L` 后面（每次插之前先用 `nxt = p->next` 存下剩余链表）。
  - **三指针法**：用 `pre = NULL, cur = head`，循环里先 `nxt = cur->next`，再翻转 `cur->next = pre`，然后 `pre = cur; cur = nxt;` 同步往前挪，最后返回 `pre`。
- **仅设尾指针的两个循环单链表合并**（时间 $O(1)$）：
  记 `headA = rearA->next`，然后 `rearA->next = rearB->next->next`（A 尾接 B 首元），释放 B 的头结点，再 `rearB->next = headA` 闭合大环，返回 `rearB`。
- **两个有序单链表归并**（时间 $O(m+n)$）：
  每次比较两链当前结点，把小的摘下来尾插到结果链；等一条链空了，直接把另一条剩的整段挂在尾巴上。
- **快慢指针**（时间 $O(n)$，空间 $O(1)$）：
  - **找倒数第 $k$ 个结点**：`fast` 先走 $k$ 步（中途提前遇到 `NULL` 说明长度不够 $k$，直接返回失败），然后 `slow` 和 `fast` 一起每次走 1 步，当 `fast == NULL` 时 `slow` 就在倒数第 $k$ 个。
  - **找链表中点**：`slow` 走 1 步、`fast` 走 2 步。偶数个结点时，循环条件写 `fast->next != NULL && fast->next->next != NULL` 停在**左中点**，写 `fast != NULL && fast->next != NULL` 停在**右中点**。

## 五、多维数组与特殊矩阵压缩

内存是一维的，所以二维数组和特殊矩阵都得按一定顺序“拉直”存进一维数组。做这类题**千万别死背公式的正负号**，记住“数前面已经存了多少个元素”的方法，再用起点坐标代入验算一下，绝对不会错。

### 1. 二维数组地址计算

设二维数组行范围 $[l_1, u_1]$（共 $R = u_1 - l_1 + 1$ 行），列范围 $[l_2, u_2]$（共 $C = u_2 - l_2 + 1$ 列），每个元素占 $L$ 字节：
- **行优先**（C/C++ 标准，先存满一行再存下一行）：
  $$\text{LOC}(i, j) = \text{LOC}(l_1, l_2) + \big[(i - l_1) \times C + (j - l_2)\big] \times L$$
- **列优先**（先存满一列再存下一列）：
  $$\text{LOC}(i, j) = \text{LOC}(l_1, l_2) + \big[(j - l_2) \times R + (i - l_1)\big] \times L$$

例如真题 `2021-03`：二维数组按行优先存，每个元素占 1 个存储单元，`A[0][0]` 地址是 100，`A[3][3]` 地址是 220，问 `A[5][5]` 的地址。
算起来很直接：`A[3][3]` 相对 `A[0][0]` 偏移了 $220 - 100 = 120$ 个单元。按行优先，前面有 3 整行加第 3 行的前 3 个，即 $3C + 3 = 120$，解出每行 $C = 39$ 个元素。于是 `A[5][5]` 的地址是 $100 + (5 \times 39 + 5) \times 1 = \mathbf{300}$。

### 2. 对称矩阵与三角矩阵压缩

设 $n$ 阶方阵，行列号从 1 开始（$1 \le i, j \le n$），压缩到一维数组 `B[0..]`（下标从 0 开始）。只需要数“当前行/列前面已经存满的三角形或梯形有多少格，加上当前行/列内的偏移”：

| 存储区域与主序 | 前面完整行/列的元素个数 | 当前行/列内偏移 | 一维下标 $k$（从 0 开始） |
| :--- | :--- | :--- | :--- |
| **下三角（$i \ge j$）按行优先** | $1 + 2 + \dots + (i-1) = \frac{i(i-1)}{2}$ | $j - 1$ | $k = \frac{i(i-1)}{2} + j - 1$ |
| **上三角（$i \le j$）按列优先** | $1 + 2 + \dots + (j-1) = \frac{j(j-1)}{2}$ | $i - 1$ | $k = \frac{j(j-1)}{2} + i - 1$ |
| **上三角（$i \le j$）按行优先** | $n + (n-1) + \dots + (n-i+2) = \frac{(2n-i+2)(i-1)}{2}$ | $j - i$ | $k = \frac{(2n-i+2)(i-1)}{2} + j - i$ |
| **下三角（$i \ge j$）按列优先** | $n + (n-1) + \dots + (n-j+2) = \frac{(2n-j+2)(j-1)}{2}$ | $i - j$ | $k = \frac{(2n-j+2)(j-1)}{2} + i - j$ |

两个必须留神的细节：
- **对称矩阵（$a_{i,j} = a_{j,i}$）**：只存一半，共占 $\frac{n(n+1)}{2}$ 格。如果题目问的元素恰好落在没存的那一半，**先把行列号互换**再算！例如真题 `2020-01` 把对称矩阵的**上三角按列优先**存进下标从 0 开始的数组，问 $m_{7,2}$ 的下标。因为 $m_{7,2}$ 在下三角，先翻成 $m_{2,7}$；第 1 到第 6 列共有 $1+2+3+4+5+6 = 21$ 个元素，第 7 列从上往下第 2 个是 $m_{2,7}$，它是第 $21 + 2 = 23$ 个元素，下标从 0 开始就是 **$22$**。
- **三角矩阵**：另一半全是同一个常数 $c$，除了存有效三角区的 $\frac{n(n+1)}{2}$ 格外，还要在数组最后**多开 1 格**存这个常数 $c$（下标为 $\frac{n(n+1)}{2}$），总容量是 $\frac{n(n+1)}{2} + 1$。

### 3. 三对角矩阵（带状矩阵）

非零元素只允许出现在主对角线及其上下紧邻的两条次对角线上，即 $|i - j| \le 1$ 的区域（带外恒为 0 不存）。第 1 行和第 $n$ 行各存 2 个，中间 $n-2$ 行每行存 3 个，总共占 **$3n - 2$** 格。
- **已知 $(i, j)$（从 1 开始）求行优先下标 $k$（从 0 开始）**：
  前 $i-1$ 行共占 $2 + 3(i-2) = 3i - 4$ 格；第 $i$ 行最左边元素列号是 $i-1$，所以 $j$ 前面有 $j - (i-1)$ 个元素。合起来：
  $$k = (3i - 4) + (j - i + 1) = \mathbf{2i + j - 3}$$
  （若数组下标从 1 开始，则是 $k = 2i + j - 2$。考场代入 $(1,1)\to 0$、$(2,1)\to 2$ 立刻就能验证。）
- **已知 $k$（从 0 开始）反求 $(i, j)$**：
  第 1 行占 $[0, 1]$，第 2 行占 $[2, 4]$，第 3 行占 $[5, 7]$……把 $k+1$ 除以 3 向下取整再加 1 就刚好对齐行号：
  $$i = \left\lfloor \frac{k+1}{3} \right\rfloor + 1, \qquad j = k - 2i + 3$$

### 4. 稀疏矩阵：三元组表与十字链表

当矩阵里绝大多数元素都是 0、且非零元毫无规律时，上面的公式都不能用，改用：
- **三元组顺序表**：把每个非零元记成 `(行号, 列号, 值)` 存进顺序表。**注意**：除了所有非零元的三元组外，表头**必须额外保存矩阵的总行数和总列数**（真题 `2023-03` 考点），因为如果矩阵末尾几行或几列全是 0，光看三元组表根本还原不出矩阵原来的大小；而“含非零元的行数/列数”帮不上忙。
- **十字链表**：用链式结构把同一行的非零元串成行链表、同一列的非零元串成列链表，适合非零元位置经常增删变动的稀疏矩阵。
