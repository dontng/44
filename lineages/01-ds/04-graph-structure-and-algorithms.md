# 图的存储遍历、最小生成树、最短路与拓扑/关键路径

> 脉络编号：`ds-04` · 返回 [全科知识脉络总览](../README.md)

图把结点之间的关系放开到了“多对多”，而且允许有环。整章内容其实按一条很顺的线展开：先解决图在内存里怎么存（邻接矩阵、邻接表、十字链表、邻接多重表），再解决怎么走遍全图不绕死循环（BFS/DFS 与欧拉路径），最后落到图上最常用的三类工程问题——连成一棵最省钱的树（最小生成树）、找两点最省力的路（最短路径）、以及安排有先后依赖的工序与工期（拓扑排序与关键路径）。

---

## 一、图的四种存储结构

图的边数可能很多（稠密图，$|E| \approx |V|^2$），也可能很少（稀疏图，$|E| \ll |V|^2$），所以衍生出四种存储结构：

| 存储结构 | 适用图 | 空间复杂度 | 核心特点与常考细节 |
| :--- | :--- | :---: | :--- |
| **邻接矩阵** | 稠密图 | $O(\|V\|^2)$ | 查两点间是否有边 $O(1)$；遍历图需 $O(\|V\|^2)$；表示唯一（给定顶点编号） |
| **邻接表** | 稀疏图 | $O(\|V\| + \|E\|)$ | 找某顶点的出边很快；无向图边结点共 **$2\|E\|$** 个，有向图共 **$\|E\|$** 个；表示不唯一 |
| **十字链表** | 有向图 | $O(\|V\| + \|E\|)$ | 把邻接表（出边）和逆邻接表（入边）合二为一，查出度和入度都方便 |
| **邻接多重表** | 无向图 | $O(\|V\| + \|E\|)$ | 每条无向边只存 **1 个边结点**，删边或打边标记不用在两个链表里各找一次 |

几个选择题和大题反复考的细节：
1. **邻接矩阵算度数**：
   - 无权图（0/1 矩阵）：无向图第 $i$ 行（或列）非 0 个数是度数；有向图第 $i$ 行非 0 个数是**出度**，第 $i$ 列非 0 个数是**入度**（真题 `2023-41` 考找出度大于入度的顶点，直接双重循环扫第 $i$ 行和第 $i$ 列统计即可，时间 $O(n^2)$，若有自环在行列各加一次自动抵消）。
   - **带权网注意**：没边的地方填 $\infty$、主对角线填 0，但**有效边的权值也可能是 0**，所以带权网算度数要数“非对角线上非 $\infty$ 的元素个数”，不能说“非零元素个数”。
2. **邻接矩阵的幂次 $A^k$**：对于 0/1 邻接矩阵 $A$，$A^k[i][j]$ 等于从 $v_i$ 到 $v_j$ **长度为 $k$ 的通路（Walk）条数**，**不是**简单路径条数（允许重复走同一条边或同一个点，比如两点一条边 $0-1$，$A^2[0][0] = 1$ 对应 $0 \to 1 \to 0$）。
3. **邻接表求有向图某顶点的入度**（真题 `2026-06`）：邻接表只存出边，想知道谁指向顶点 $v$，必须把所有 $|V|$ 个顶点表头和全部 $|E|$ 个边结点全扫一遍，时间是 **$O(|V| + |E|)$**，也就是 **$O(\max(|V|, |E|))$**。不能写成 $O(|E|)$，因为如果 $|E| = 0$（完全没边），检查 $|V|$ 个空表头依然要花 $O(|V|)$。
4. **邻接多重表看度数**（真题 `2024-04`）：边结点存 `[mark | ivex | ilink | jvex | jlink]`，顶点 $v$ 的度数就等于全图里所有包含 $v$ 下标（不管是填在 `ivex` 还是 `jvex`）的边结点总数。

## 二、图的遍历、连通性与欧拉路径

因为图里有环，遍历必须配一个 `visited[]` 数组防止重复访问陷入死循环。

### 1. BFS 与 DFS 的核心机制

- **广度优先搜索（BFS）**：用**队列**按层向外扩，类似于树的层序遍历。
  - **必须入队时就打 `visited[w] = true` 标记**，绝不能等出队再标！反例是 4 个点的菱形图（0 连 1 和 2，1 和 2 都连 3）：如果出队才标，1 出队时把 3 入队，2 出队时看 3 还没出队就又把 3 入队一次，造成重复入队。
  - **无权图（或所有边权相等的图）求单源最短路径用 BFS**：队列按边数一层层推进，第一次碰到目标点就是边数最少的路径，时间 $O(|V|+|E|)$。注意真题 `2023-06` 考过：**所有边权都为 1 时，Prim/Kruskal 求出的最小生成树不能保证两点间路径最短**（因为任意生成树总权都是 $|V|-1$，都是 MST，比如四边形加一条对角线，MST 可能不选对角线导致绕远路）。
- **深度优先搜索（DFS）**：一条路走到黑再回溯，用递归（或显式栈）。
  - 邻接矩阵存储时，从固定起点出发的 BFS/DFS 序列**唯一**；邻接表因为边结点挂载顺序不同，序列**不唯一**。
  - 时间复杂度：邻接矩阵 $O(|V|^2)$，邻接表 $O(|V| + |E|)$。

### 2. 连通性与图论小结论（选择题高频）

- 外层循环调用 BFS/DFS 的次数 = 无向图的**连通分量个数**。从一点出发一次 DFS 访问完所有点，只能说明是**连通图**，不能说明是**完全图**（完全图任意两点都有直接边，边数 $\frac{|V|(|V|-1)}{2}$）。
- **连通必要条件**：无向连通图至少要有一棵生成树，即 $|E| \ge |V| - 1$。逆否命题是：**只要 $|V| > |E| + 1$，无向图一定不连通**（真题 `2022-06`）。注意反过来 $|E| \ge |V| - 1$ 不能保证连通（可能边全扎堆在某几个点里，外面还有孤立点）。
- **无向无环图必有度 $\le 1$ 的点**：一棵 $n$ 结点的树总度数 $2n - 2$，平均度小于 2。反过来：**如果无向图里每个顶点的度都 $\ge 2$，图里一定有环**（真题 `2025-06`）。
- **无环图最长简单路径上限**（真题 `2026-07`）：$n$ 个顶点的图，不含环的路径最多经过 $n$ 个顶点，即**最多 $n - 1$ 条边**。只要一条路径有 $n$ 条边，就经过了 $n + 1$ 个点，按抽屉原理必然有重复顶点，也就是一定含环。

### 3. 欧拉通路与欧拉回路

经过图中**每条边且只经过一次**的路径叫**欧拉通路（EL 路径）**；起点和终点重合的叫**欧拉回路**。
无向图存在欧拉通路的充要条件：所有非零度顶点连通，且**度为奇数的顶点个数只能是 0 或 2**（0 个时存在欧拉回路，任意点出发都行；2 个时存在欧拉通路，必须以这两个奇数度顶点为起点和终点）。
例如真题 `2021-41` 给定一个**无向连通图**的邻接矩阵，让你写函数判断是否存在 EL 路径：因为题目已经保证图是连通的，不需要再写 DFS 判连通，直接双重循环算每个顶点的度数，统计奇数度顶点个数 `oddCount`，最后返回 `oddCount == 0 || oddCount == 2` 即可，时间 $O(|V|^2)$，空间 $O(1)$。

## 三、最小生成树（MST）：Prim 与 Kruskal

在无向带权连通图里选 $|V| - 1$ 条边，把所有顶点连起来且总权值最小，这就是最小生成树。

### 1. MST 唯一性辨析

- **总权值之和永远唯一**（而且任意两棵 MST 的边权排序后也是完全一样的）。
- 如果图中**所有边权互不相等**，MST **一定唯一**；但这只是**充分条件，不是必要条件**——有重复边权时 MST 依然可能唯一（比如三角形三条边为 `1, 1, 5`，两条 `1` 都必选，MST 唯一）。
- **充要条件**：任意一条没被选中的非树边，其权值**严格大于**它在生成树中对应回路上的最大边权。

### 2. Prim（加点法）与 Kruskal（加边法）

- **Prim 算法（适合稠密图）**：
  - 维护已入树点集，用 `lowcost[v]` 记录未入树点 `v` 到**当前整棵树**的最小单边权值，`parent[v]` 记录连向树里哪个点。
  - 每轮从未入树点里挑 `lowcost` 最小的加入树，再用它的边去更新其它未入树点的 `lowcost`。
  - 如果还没加满 $|V|$ 个点，剩下的未入树点 `lowcost` 全是 $\infty$，说明原图**不连通**。
  - 普通数组实现时间 **$O(|V|^2)$**，跟边数无关，所以适合稠密图（堆优化可达 $O(|E|\log|V|)$）。
- **Kruskal 算法（适合稀疏图）**：
  - 把所有边按权值从小到大排序，配合**并查集**依次考察每条边：如果两端点不在同一连通分量（`Find(u) != Find(v)`），就选入并合并；否则会成环，跳过。选满 $|V| - 1$ 条边结束（如果扫完所有边还凑不够 $|V| - 1$ 条，说明原图不连通）。
  - 瓶颈在给边排序，时间 **$O(|E|\log|E|)$**，适合稀疏图。
  - 例如真题 `2020-07` 给 6 个顶点的图按 Kruskal 选边：把边按权值排成 `(b,f):5, (b,d):6, (d,f):7, (a,e):9, (c,e):10, (b,e):11...`，选 5 和 6 后，7 会和 `b-d-f` 成环必须跳过，接着选 9、10、11，凑齐 5 条边结束。

## 四、最短路径：Dijkstra 与 Floyd

### 1. Dijkstra 算法（单源，要求边权非负）

和 Prim 长得很像，但目标完全不同：Prim 里的 `lowcost[v]` 是到**当前树集合**的单边距离，Dijkstra 里的 `dist[v]` 是到**源点**的**累加路径总长**。
- 维护 `final[]`（是否已确定最短路）、`dist[]`（当前最短距离）、`path[]`（前驱顶点，用来倒推路径）。
- 每轮两步：① 从 `final[v] == false` 里选 `dist` 最小的顶点 $u$，置 `final[u] = true`；② 只拿 $u$ 的出边去松弛还没确定的邻居：若 `dist[u] + w(u, v) < dist[v]`，就更新 `dist[v]` 和 `path[v] = u`。
- 例如真题 `2021-08` 问从顶点 1 出发**求出第 2 条最短路径后** `dist` 数组的值：初始 `dist = [26, 3, ∞, 6]`（对应顶点 2,3,4,5）；第 1 轮锁定顶点 3（距离 3），用 $3\to 2(22)$ 松弛得 `[25, 3, ∞, 6]`；第 2 轮锁定顶点 5（距离 6），用 $5\to 2(15)$ 和 $5\to 4(8)$ 松弛得 **`[21, 3, 14, 6]`**。此时顶点 4 还没被锁定，千万不能提前用 $4\to 2$ 去把顶点 2 改成 15。
- **时间复杂度**：数组实现 **$O(|V|^2)$**，小根堆优化 **$O(|E|\log|V|)$**。
- **为什么不能有负权边？** Dijkstra 一旦锁定 `final[u] = true` 就不再回头改它。遇到负权边可能算错（但不是“一定算错”，而是**不能保证正确**）。反例：$S \to A = 2$，$S \to B = 5$，$B \to A = -4$。Dijkstra 第一步先锁定 `dist[A] = 2`，等后面锁定 $B$ 发现 $5 + (-4) = 1 < 2$ 时，已经不会去改 $A$ 了。
- **最短路径树（SPT）$\ne$ 最小生成树（MST）**：比如三角形 $(A,B)=3, (A,C)=3, (B,C)=1$，MST 选 `(B,C)` 和 `(A,B)` 总权 4，而以 $A$ 为源点的最短路径树必须选 `(A,B)` 和 `(A,C)` 总权 6。

### 2. Floyd 算法（全源，允许负权边但不能有负权环）

用动态规划求任意两点之间的最短路，三重循环非常短，但**中继点 `k` 必须放在最外层**：
```c
for (int k = 0; k < n; k++)
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (A[i][k] + A[k][j] < A[i][j]) {
                A[i][j] = A[i][k] + A[k][j];
                path[i][j] = k;
            }
```
外层 `k` 表示“当前允许借道前 `k` 个顶点中转”，每完成一轮外层循环，所有点对的最短路才基于新的中转集合收敛完毕；如果把 `k` 放内层，子问题还没算完就拿来拼，结果会错。
- 时间复杂度 **$O(|V|^3)$**，空间 $O(|V|^2)$。
- **负权环检测**：Floyd 可以处理普通负权边，但如果存在总权为负的回路（绕圈距离趋于 $-\infty$），算法结束后矩阵主对角线上会出现 **`A[i][i] < 0`**。

## 五、拓扑排序与关键路径

### 1. AOV 网与拓扑排序

**AOV 网**用顶点表示活动、有向边 $\langle u, v \rangle$ 表示 $u$ 必须在 $v$ 之前完成。
- **Kahn 算法（入度法）**：统计每个顶点的入度，把所有入度为 0 的顶点放进队列（或栈）；每次弹出一个顶点输出，把它指向的所有后继入度减 1，谁减到 0 就进队。
  - 输出顶点数 $= |V|$ $\iff$ 图是**有向无环图（DAG）**；
  - 输出顶点数 $< |V|$ $\iff$ 剩下的顶点里**有环**。
  - 时间复杂度：邻接表 $O(|V|+|E|)$，邻接矩阵 $O(|V|^2)$。
- **DFS 求逆拓扑序**（真题 `2020-06`）：在 DAG 上做 DFS，如果把 `print(u)` 放在**退出递归前**（后序位置），因为后继一定比前驱先结束递归并输出，得到的正好是**逆拓扑序列**（再倒过来就是拓扑序列）。
- **拓扑序列与上三角矩阵**：DAG 按拓扑序列给顶点重新编号后，邻接矩阵一定是**严格上三角矩阵**（主对角线及以下全为 0）；反之，邻接矩阵是严格上三角矩阵的有向图必为 DAG。
- **拓扑序列唯一性的充要条件**（真题 `2021-07`、`2024-41`）：**在拓扑排序的每一步，入度为 0 的候选顶点始终恰好只有 1 个**（也就是图中有一条串起所有顶点的有向链，跨越边只是加强约束不会增加分支）。如果某一步有 $\ge 2$ 个入度为 0 的点，它们谁先谁后都行，拓扑序列就不唯一；如果某一步为 0 个，则有环不存在。真题 `2024-41` 写 `uniquely(MGraph G)` 就是按 Kahn 算法写，每轮判断队列长度 `tail - head != 1` 就直接返回 0。
- **顺带区分操作系统死锁**：AOV 网里“有环 $\iff$ 无法拓扑排序”；但操作系统**多实例**资源分配图里，有环只是死锁的必要条件，不是充分条件（别的进程释放多余实例就能解开）。

### 2. AOE 网与关键路径

**AOE 网**用**顶点表示事件**（里程碑），用**带权有向边表示活动**（权值是持续时间）。从源点到汇点**路径长度（权值和）最长**的路径叫**关键路径**，它决定了整个工程的最短总工期（不是边数最多的路径）。

手算四个参数，记住口诀 **“顺推 $ve$ 取最大，逆推 $vl$ 取最小”**：
1. **事件最早发生时间 $ve$**：$ve(\text{源点}) = 0$，按拓扑序 $ve(j) = \max\big(ve(k) + w(k, j)\big)$（要等所有前驱活动都做完）。
2. **事件最迟发生时间 $vl$**：$vl(\text{汇点}) = ve(\text{汇点})$，按逆拓扑序 $vl(k) = \min\big(vl(j) - w(k, j)\big)$（不能耽误任何一条后继路线）。
3. **活动最早/最迟开始时间与时间余量**（对活动 $a_i = \langle k, j \rangle$，耗时 $w$）：
   $$e(i) = ve(k), \qquad l(i) = vl(j) - w, \qquad \text{时间余量 } d(i) = l(i) - e(i) = vl(j) - ve(k) - w$$
4. **$d(i) == 0$ 的活动就是关键活动**，连起来构成关键路径。

例如真题 `2025-42` 的 7 事件 AOE 网：顺推算得 $ve(1)=0, ve(3)=2, ve(4)=5, ve(6)=6, ve(7)=9, ve(2)=9, ve(5)=12$，最短工期就是 **12**；再从 $vl(5)=12$ 逆推 $vl$，挑出 $d(i)=0$ 的活动即可。再如真题 `2022-07` 让你找时间余量最大的活动，直接算完 $ve$ 和 $vl$，套公式 $vl(\text{弧头}) - ve(\text{弧尾}) - w$，算出活动 `g` 的余量 $12 - 5 - 1 = 6$ 最大。

**赶工期（压缩工期）的必考陷阱**（真题 `2020-08`）：
- 延长**任意一个**关键活动，总工期**一定**变长；
- 但缩短一个关键活动，总工期**不一定**缩短！如果工程有**多条并行的关键路径**，只缩短其中一条上的独有活动，别的并行关键路径还卡在原来的长度上，总工期纹丝不动。只有缩短**所有关键路径共有的关键活动**，或者**同时缩短每条关键路径上的活动**，总工期才会变短（而且不能无限缩短，缩到比原来的次关键路径还短时，次关键路径就会变成新的关键路径）。
