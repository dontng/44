# 二叉树形态遍历、线索化、森林互转、哈夫曼编码与堆/并查集

> 脉络编号：`ds-03` · 返回 [全科知识脉络总览](../README.md)

从线性表跨到树，核心变化是从“一对一”变成了“一对多”。为了在内存里好存好算，数据结构把一般多叉树和森林都通过“左孩子右兄弟”统一转成了二叉树；把遍历时闲置的空指针改造成线索，省掉了遍历栈；把带权路径压缩做成哈夫曼编码；而完全二叉树因为下标规整，直接用数组就能撑起堆，双亲数组则撑起了并查集。这一条脉络就是树形结构的全部基本功。

## 一、二叉树的性质与存储

408 里默认非空二叉树的根结点在第 1 层，树高 $h$ 是最大层数。

### 1. 必记的几条数量关系

- **叶子与度为 2 的结点**：任何二叉树都满足 **$n_0 = n_2 + 1$**。推导很简单：总结点数 $n = n_0 + n_1 + n_2$，总边数一方面等于 $n - 1$（除根外每人头顶 1 条边），另一方面等于 $n_1 + 2n_2$，联立一消就出来了。
- **空指针个数**：$n$ 个结点的二叉链表共有 $2n$ 个指针域，用了 $n - 1$ 个指向孩子，剩下的 **`n + 1` 个全是空指针**。
- **每层与全树上限**：二叉树第 $k$ 层最多 $2^{k-1}$ 个结点，高 $h$ 最多 $2^h - 1$ 个结点。推广到 **$m$ 叉树**，高 $h$ 最多有 $\frac{m^h - 1}{m - 1}$ 个结点。例如真题 `2022-04` 问 244 个结点的三叉树最小高度是多少：代入 $m = 3$，$h = 5$ 时最多放 $\frac{3^5 - 1}{2} = 121$ 个不够，$h = 6$ 时最多放 $\frac{3^6 - 1}{2} = 364 \ge 244$ 个，所以最小高度是 **6**。
- **满二叉树与完全二叉树**：
  - 满二叉树每层都塞满，总数正好 $2^h - 1$，没有度为 1 的结点。
  - 完全二叉树前 $h - 1$ 层满，最后一层从左往右连续排。高度为 $h = \lfloor \log_2 n \rfloor + 1 = \lceil \log_2(n + 1) \rceil$。
  - **完全二叉树的 $n_1$ 只有 0 或 1 两种可能**：把 $n_0 = n_2 + 1$ 代入 $n = n_0 + n_1 + n_2$ 得 $n = 2n_2 + n_1 + 1$。所以 **$n$ 是偶数时必有 $n_1 = 1$ 且 $n_0 = n/2$**；**$n$ 是奇数时必有 $n_1 = 0$ 且 $n_0 = (n+1)/2$**。

### 2. 顺序存储与二叉链表

完全二叉树最适合用一维数组存，靠下标就能算父子关系：

| 关系 | 1-based 下标（`1..n`，考场常见） | 0-based 下标（`0..n-1`，C 数组常见） |
| :--- | :---: | :---: |
| 根结点 | `1` | `0` |
| 结点 $i$ 的双亲 | $\lfloor i/2 \rfloor$ | $\lfloor (i-1)/2 \rfloor$ |
| 结点 $i$ 的左孩子 / 右孩子 | $2i$ / $2i+1$ | $2i+1$ / $2i+2$ |
| 最后一个非叶结点 | $\lfloor n/2 \rfloor$ | $\lfloor n/2 \rfloor - 1$ |

如果拿顺序数组去存**一般二叉树**，缺的结点必须用空位（比如 `-1`）占着，否则下标公式就乱了。这里有两个真题常考的点：
- **空间浪费极值**（真题 `2020-03`）：想用顺序数组存下“任意一棵”高为 5 的二叉树，至少要开多大数组？最坏情况是每层都只往右拐的右单支树，结点编号依次是 `1, 3, 7, 15, 31`，所以至少要开 **$2^5 - 1 = 31$** 格。
- **空位下面不能挂结点**（真题 `2025-03`）：用 1-based 数组存二叉树、`-1` 表示空结点时，如果下标 4 存的是 `-1`，那下标 8 和 9 就绝不能存有效结点（因为 $\lfloor 9/2 \rfloor = 4$，双亲都不存在，哪来的孩子）。
- 顺带一提，真题 `2022-41` 考的正是给一棵 0-based 顺序存储的二叉树（`-1` 表示空）判断它是不是二叉搜索树（BST）：不能只拿当前结点跟 `2*i+1`、`2*i+2` 比，而要从根开始自顶向下传允许范围 `(lo, hi)`，往左子树走把上界收紧成当前值，往右子树走把下界收紧成当前值，越界或遇到 `-1` 返回 `true`。

## 二、二叉树遍历与由序列还原树

四种遍历（先序 NLR、中序 LDR、后序 LRN、层序）本身很熟，408 重点考的是**非递归栈细节**和**已知序列反推树形**。

### 1. 非递归遍历的关键细节

- **中序非递归**：一路把左孩子压栈；走到底就弹栈顶访问，然后转向它的右孩子。
- **后序非递归**：一个结点必须等左右子树都访问完才能访问，所以需要一个指针 `r` 记录**刚刚访问过的结点**。看栈顶 `p`（先不弹）：如果 `p` 有右孩子且 `p->rchild != r`，说明右子树还没去过，转向右子树；否则弹出 `p` 访问，并更新 `r = p`。
  - **重要结论**：后序非递归访问到结点 $X$ 时，**栈里剩下的所有结点正好就是从根到 $X$ 的全部祖先**（常用来找最近公共祖先或输出根到叶的路径）。
- **中序序列里的相邻关系**（真题 `2022-03`）：在中序序列中，如果 $p$ 紧挨在 $q$ 前面，$q$ 可能是 $p$ 的双亲（$p$ 是左孩子且无右子树）、右孩子（$q$ 无左子树）或祖先（$p$ 是 $q$ 左子树的最右下结点），但 **$q$ 绝对不可能是 $p$ 的右兄弟**——因为左兄弟和右兄弟之间夹着它们的共同双亲，中序遍历一定先访问完左兄弟、再访问双亲、最后才轮到右兄弟。

### 2. 哪两个序列能唯一还原二叉树？

前提是所有结点值互不相同：
- **先序 + 中序**、**后序 + 中序**、**层序 + 中序**：只要带中序，**一定能唯一确定**。
  - 先/后序定根，中序按根切出左右子树。
  - **层序 + 中序**（如真题 `2026-03`：层序 `a,b,g,c,d,e,f`，中序 `b,e,d,f,c,a,g`）：层序第 1 个 `a` 是根，中序把左子树切为 `{b,e,d,f,c}`、右子树切为 `{g}`；接下来在左子树集合里看谁在层序里**最先出现**，最先出现的是 `b`，所以 `b` 是左子树的根；继续按中序切，层序里 `{e,d,f,c}` 最先出现 `c`，以此类推还原整棵树，再写出后序 `e,f,d,c,b,g,a`。
  - 如果题目直接给了**树的形状图**外加一个遍历序列（如真题 `2023-05` 给树形和后序 `f,d,b,e,c,a`），按左右根把字母往图的空圈里填回去，就能直接读出先序 `a,e,d,f,b,c`。
- **先序 + 后序**：
  - 对**一般二叉树不能唯一确定**。最简单的反例是 2 个结点 `A, B`：`B` 当 `A` 的左孩子和当 `A` 的右孩子，先序都是 `A, B`，后序都是 `B, A`。
  - 但如果是**正则二叉树（没有度为 1 的结点，$n_1 = 0$）**，先序 + 后序**可以唯一确定**：先序第 2 个元素必是左子树的根，在后序里找到它，它和它左边的部分就正好是整个左子树。
  - 另外记住一条小推论：**先序和后序恰好互为逆序 $\iff$ 整棵树是一条单支链**（每个结点度都 $\le 1$）。

## 三、线索二叉树：把空指针变成前后导航

$n$ 个结点的二叉链表白白浪费了 $n + 1$ 个空指针。线索二叉树给每个结点加两个 1 bit 标志位 `ltag`、`rtag`：
- `ltag == 0` 表示 `lchild` 指左孩子，`ltag == 1` 表示 `lchild` 指向该遍历下的**直接前驱**；
- `rtag == 0` 表示 `rchild` 指右孩子，`rtag == 1` 表示 `rchild` 指向该遍历下的**直接后继**。

### 1. 中序线索化的构造与查找

构造中序线索树时，按中序递归遍历，用全局指针 `pre` 记住上一个刚访问过的结点：
- 若当前结点 `p->lchild == NULL`，就令 `p->lchild = pre; p->ltag = 1;`；
- 若 `pre != NULL && pre->rchild == NULL`，就令 `pre->rchild = p; pre->rtag = 1;`；
- 更新 `pre = p`。
- **收尾别漏**：整棵树递归结束后，中序最后一个结点的右指针还没人帮它填，主函数里必须补一句 `pre->rchild = NULL; pre->rtag = 1;`。

在中序线索树里找结点 $v$ 的前驱和后继：
- **找中序后继 `Nextnode(v)`**：如果 `rtag == 1`，`rchild` 直接就是后继；如果 `rtag == 0`（有右子树），后继是**右子树里最左下**的结点（一路沿左孩子走到 `ltag == 1`）。
- **找中序前驱**：如果 `ltag == 1`，`lchild` 直接就是前驱；如果 `ltag == 0`（有左子树），前驱是**左子树里最右下**的结点（一路沿右孩子走到 `rtag == 1`）。
- 真题 `2024-03` 就考了这个几何位置：若结点 $v$ 既有左子树又有右子树，它的中序前驱 $p$ 是左子树的最右下结点，所以 **$p$ 一定没有右孩子**；它的中序后继 $q$ 是右子树的最左下结点，所以 **$q$ 一定没有左孩子**。

**复杂度辨析**：单步调用 `Nextnode(p)` 最坏要沿着子树走到底，时间是 $O(h)$；但用 `Firstnode` + `Nextnode` **遍历整棵树**时，每条边最多被走两遍，总时间严格是 **$O(n)$**，且不需要栈，空间复杂度 **$O(1)$**。

### 2. 先序和后序线索树的局限

- **先序线索树**：找后继很顺（有左孩子就是左孩子，没左有右就是右孩子，叶子走线索）；但**找前驱困难**——如果一个结点有左孩子，它的前驱是双亲或双亲左子树的最后一个结点，二叉链表没有父指针，回不去。
- **后序线索树**：找前驱很顺；但**找后继困难**——如果一个结点有右孩子，它的后继可能是双亲（或双亲右子树的起点），普通二叉链表没法向上找双亲，必须加父指针变成**三叉链表**或者借用栈才能完成遍历。

## 四、树、森林与二叉树的互相转换

一般树有三种存储方式：
- **双亲表示法**：一维数组，每个元素记 `(data, parent)`。找双亲 $O(1)$，找孩子要扫全表 $O(n)$，最适合**并查集**。
- **孩子表示法**：数组存顶点，每个顶点挂一条单链表存它的孩子。找孩子快，找双亲慢。
- **孩子兄弟表示法（二叉链表）**：每个结点存 `(firstchild, data, nextsibling)`，左指针指第一个孩子，右指针指紧邻的右兄弟。

用孩子兄弟表示法，**任何树或森林都能唯一、无损地转换成一棵二叉树**（真题 `2025-04` 考点）：
- **规则**：左指针认长子，右指针认右兄弟；森林里各棵树的根互为兄弟，从第 2 棵树开始依次挂在前一棵树根的右孩子上。
- **必考性质**：
  1. **森林有多少棵树** = 转换后二叉树从根出发、**沿着右孩子链一路数下去的结点总数**。例如真题 `2021-04` 给转换后二叉树的先序 `a,b,d,c,e,g,f` 和中序 `b,d,a,e,g,c,f`：根是 `a`，`a` 右子树先序首位是 `c`（`a` 的右孩子），`c` 右边只剩 `f`（`c` 的右孩子），右孩子链是 `a -> c -> f`，所以原森林有 **3 棵树**。
  2. **森林转二叉树的高度下界**（真题 `2026-04`）：森林有 5 棵树、每棵树至少 2 个结点，问转成二叉树后最小高度是多少？5 棵树的根串成一条长为 5 的右链，第 5 棵树的根已经在第 5 层；它至少还有 1 个孩子（转成左孩子）落在第 6 层，所以树高至少是 **$5 + 1 = 6$**。
  3. **叶子对应**：原树/森林的叶子结点没有孩子，所以转成二叉树后**没有左孩子（`lchild == NULL`）**；反过来也成立，**二叉树中 `lchild == NULL` 的结点数 = 原树/森林的叶子总数**。
- **遍历对应关系（只记两句）**：
  - **树先根 = 森林先序 = 二叉树先序**
  - **树后根 = 森林中序 = 二叉树中序**
  - 例如真题 `2020-04` 给森林的先根遍历 `a,b,c,d,e,f` 和中根遍历 `b,a,d,f,e,c`，它们直接就是对应二叉树的先序和中序，还原二叉树后再求后序，得到 `b,f,e,d,c,a`。

## 五、哈夫曼树与前缀编码

变长编码给高频字符分配短编码、低频字符分配长编码，为了让总编码长度最短，就要让**带权路径长度（WPL）**最小：
$$\text{WPL} = \sum_{i=1}^{n} w_i \cdot l_i$$
其中 $w_i$ 是叶子权值，$l_i$ 是叶子到根的**边数**（根深度为 0）。

### 1. 构造过程与 WPL 速算

哈夫曼树用贪心法构造：**每次从当前森林里选权值最小的两棵树合并，新根权值等于两者之和，放回森林重复，直到只剩 1 棵树**（用小根堆找最小，总时间 $O(n\log n)$）。

- **WPL 速算结论**：**$\text{WPL}$ 严格等于所有生成的非叶结点（分支结点）权值之和**，不用再一个个去数叶子深度！
  - 例如真题 `2021-05` 给权值 `{10, 12, 16, 21, 30}`：依次合并 `10+12=22`、`16+21=37`、`22+30=52`、`37+52=89`，直接把非叶结点加起来：$\text{WPL} = 22 + 37 + 52 + 89 = \mathbf{200}$。
  - 例如真题 `2023-04` 给频次 `{3, 4, 5, 6, 8, 10}`（总和 36）求加权平均长度：依次合并得非叶结点 `7, 11, 15, 21, 36`，和为 `90`，加权平均长度 = $\frac{\text{WPL}}{\sum w_i} = \frac{90}{36} = \mathbf{2.5}$（注意分母是频次总和 36，不是字符种数 6）。
  - 如果题目问具体哪些叶子深度相同（如真题 `2026-05` 给 `a:1, b:2, c:4, d:5, e:8, f:10, g:12`），照着合并过程画两笔：`1+2=3`，`3+4=7`，`5+7=12`，`8+10=18`，`12+12=24`，`18+24=42`，一眼看出 `e(8)`、`f(10)` 和 `g(12)` 都在深度 2。
- **几个常考的性质辨析**：
  - $n$ 个叶子的哈夫曼树**没有度为 1 的结点（$n_1 = 0$）**，共有 $n - 1$ 个非叶结点，总结点数 **$2n - 1$**。但这只是**必要条件，不是充分条件**（把大权值塞到底层的正则二叉树不是哈夫曼树）。
  - 遇到相同权值或左右分支互换时，**哈夫曼树的形态和具体编码不唯一，但最小 WPL 绝对唯一**。
  - **对比定长编码树**（真题 `2022-05`）：定长编码每个字符码长都是 $\lceil \log_2 n \rceil$，所以**所有叶子都在同一层**；哈夫曼树里频次不同的字符也可能落到同一层（比如 `{2, 3, 4, 5}` 里 `4` 和 `5` 深度都是 2）。

### 2. 前缀编码与解码校验

任何一个字符的编码都不是另一个字符编码的前缀，叫做**前缀编码**。把左分支记为 `0`、右分支记为 `1`，**所有字符都只放在叶子结点上**，天然就是前缀编码，解码时不会有歧义。

真题 `2020-42` 专门考了用二叉树实现前缀编码的解码与合法性检查：
- **解码**：指针从根出发，读 `0` 往左走、读 `1` 往右走；走到空指针说明码字非法；走到标了 `isEnd == true` 的字符结点就输出字符并把指针**重置回根**；读完整个串如果指针没回到根，说明末尾有残缺码字。
- **插入码字时怎么判断是否破坏前缀特性？** 两条冲突情况必须都查：
  1. 沿路径往下走的过程中，路过了某个已经标了 `isEnd == true` 的结点（说明已有的短码是当前码的前缀）；
  2. 走完当前码字落脚时，该结点**已经有孩子**（说明当前码是已有长码的前缀），或者该结点本身已经标了 `isEnd == true`（码字重复）。

### 3. $k$ 叉哈夫曼树补虚设结点

$k$ 叉哈夫曼树每次合并 $k$ 个结点，每轮净减少 $k - 1$ 个结点。要让最后刚好合并成 1 个根，必须满足 $(n_0 - 1)$ 能被 $(k - 1)$ 整除。
如果余数 $r = (n_0 - 1) \bmod (k - 1) \ne 0$，就要在合并前先补 **$u = (k - 1) - r$ 个权值为 0 的虚设叶子结点**，让它们在第一轮就跟最小的权值合并掉，避免最后根节点分支不满导致 WPL 变大。

## 六、并查集与堆

### 1. 并查集（Union-Find）

并查集用**双亲表示法数组 `S[]`** 维护互不相交的集合：`S[x] >= 0` 表示 `x` 的双亲下标；`S[x] < 0` 表示 `x` 是根，通常用 `|S[x]|` 存这棵树的结点个数（初始全为 `-1`）。
- **查（`Find`）+ 路径压缩**：顺着 `S[x]` 往上找到根，回溯时把**沿途经过的结点**直接挂到根下面：`if (S[x] < 0) return x; return S[x] = Find(S, S[x]);`。
  - **易错点**：一次 `Find(x)` **只压缩从 `x` 到根这条路径上的结点**，旁边的支路结点没被访问到，不会自动变扁。
- **并（`Union`）+ 按大小/按秩合并**：把小树（结点少/高度小）的根挂到大树的根下面，避免树退化成单链。
- 两者一起用时，$m$ 次操作总时间 $O(m \cdot \alpha(n))$，其中反阿克曼函数 $\alpha(n) \le 4$，均摊接近 $O(1)$。典型应用是 Kruskal 最小生成树判环。

### 2. 堆（Heap）

堆是存放在一维数组里的完全二叉树：
- **大根堆**：任意非叶结点都 $\ge$ 它的左右孩子（1-based：`A[i] >= A[2i]` 且 `A[i] >= A[2i+1]`），堆顶是最大值。
- **小根堆**：任意非叶结点都 $\le$ 它的左右孩子，堆顶是最小值。

三个核心操作：
1. **自底向上原地建堆（时间 $O(n)$）**：从最后一个非叶结点（1-based 是 $\lfloor n/2 \rfloor$，0-based 是 $\lfloor n/2 \rfloor - 1$）开始，倒着往根走，对每个结点做**向下调整（下沉）**——和左右孩子里较大（大根堆）或较小（小根堆）的那个换，换下去后要**顺着被换下去的位置一路查到底**。
   - 为什么建堆是 $O(n)$ 而不是 $O(n\log n)$？因为一半以上的结点在底层根本不用下沉，只有极少数靠上的结点需要走较长路径，加权求和收敛到线性 $O(n)$。（而逐个把 $n$ 个元素插入空堆建堆才是 $O(n\log n)$。）
2. **插入元素（时间 $O(\log n)$）**：放进数组末尾，然后不断跟父结点比较并**向上调整（上浮）**。
3. **删除堆顶（时间 $O(\log n)$）**：把**数组最后一个元素**搬到堆顶填坑，堆长减 1，再从堆顶执行一次**向下调整（下沉）**。
