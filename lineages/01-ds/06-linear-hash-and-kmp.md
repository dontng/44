# 顺序/折半判定树、散列表冲突与 ASL、KMP 串匹配

> 脉络编号：`ds-06` · 返回 [全科知识脉络总览](../README.md)

除了用平衡树动态查找，另一大块查找和匹配问题都在数组和字符串里完成：最基础的是顺序查找、折半查找和分块查找；想彻底跳出“两两比大小”的 $O(\log n)$ 下限，就靠散列表（哈希表）直接算地址；而在长文本里找子串，KMP 算法通过预处理模式串自己的前后缀，省掉了主串指针的无用回退。把它们放在一条脉络里，刚好把非树形查找和串匹配的计算套路一次理清。

## 一、顺序查找、折半查找与分块查找

衡量查找快慢的核心指标是**平均查找长度（ASL）**——把每个元素查找所需的比较次数按概率求平均，分**查找成功 $\text{ASL}_{\text{succ}}$** 和**查找失败 $\text{ASL}_{\text{unsucc}}$**。

### 1. 顺序查找

- **无序表**：从头扫到尾，等概率时 $\text{ASL}_{\text{succ}} = \frac{n+1}{2}$。
  - **带哨兵 vs 不带哨兵**：把待查值放进 `A[0]` 当哨兵，从 `n` 倒着扫到 `0`，省掉了循环里的越界检查；但查找失败时会跟 `A[0]` 自己多比一次，所以失败比较次数是 **$n + 1$**（无哨兵只比 $n$ 次）。
- **有序表**：查找成功一样是 $\frac{n+1}{2}$，但查找失败只要扫到比目标大的数就能提前停，平均失败长度降到约 $\frac{n}{2} + \frac{n}{n+1}$。
- **非等概率**：谁被查的概率高就把谁放前面，能减小 $\text{ASL}$。

### 2. 折半查找（二分查找）与判定树

折半查找必须同时满足两个条件：**① 关键字有序；② 支持 $O(1)$ 随机存取（顺序存储数组）**。例如真题 `2024-05` 考有序链表、无序数组、有序静态链表、无序静态链表哪些能直接折半查找——答案是**全都不行**！有序链表不能随机找中点；**有序静态链表**虽然底层是数组，但逻辑顺序靠游标 `next` 串着，数组中间下标根本不是逻辑中点，同样不能直接折半。

折半查找的过程可以画成一棵**二叉判定树**（408 默认 `mid = floor((low + high) / 2)`）：
- **结点数**：内部结点（圆形，代表查找成功）有 $n$ 个；外部失败结点（方形，代表查找失败的空区间）有 $n + 1$ 个。
- **最大比较次数（树高）**：$h = \lfloor \log_2 n \rfloor + 1 = \lceil \log_2(n + 1) \rceil$。例如真题 `2023-08` 问 600 个元素折半查找最坏比较几次：因为 $2^9 = 512 \le 600 < 1024 = 2^{10}$，所以 $h = \lfloor \log_2 600 \rfloor + 1 = 9 + 1 = \mathbf{10}$ 次。
- **精确算 ASL**：遇到具体较小的 $n$（比如 $n = 11$），直接画出判定树数层数，别套近似公式 $\log_2(n+1) - 1$。
  - 成功比较次数 = 内部结点所在的层数（根为第 1 层）；
  - **失败比较次数 = 外部失败结点所在层数减 1**（因为外部结点本身不存数据，只跟它上面的内部祖先比过）。
  - 比如 $n = 11$ 按向下取整画出来：第 1 层 1 个、第 2 层 2 个、第 3 层 4 个、第 4 层 4 个内部结点和 4 个外部结点、第 5 层 8 个外部结点。于是 $\text{ASL}_{\text{succ}} = \frac{1\times 1 + 2\times 2 + 3\times 4 + 4\times 4}{11} = 3$，$\text{ASL}_{\text{unsucc}} = \frac{3\times 4 + 4\times 8}{12} = \frac{11}{3}$。

顺带提一下和二分思想一脉相承的真题大题 `2026-41`：在一棵二叉搜索树里找和目标值 $k$ 差值最小的结点。不需要把整棵树中序遍历完，而是顺着根往下做二分剪枝：遇到 `p->data == k` 直接差 0 返回；若 `p->data < k`，记下 `lo = p`（左子树都比它更远，直接扔掉）往右走；若 `p->data > k`，记下 `hi = p`（右子树都比它更远，直接扔掉）往左走。走到空时，答案一定就在 `lo` 和 `hi` 两者之中，时间 $O(h)$、空间 $O(1)$。

### 3. 分块查找（索引顺序查找）

把表分成 $b$ 块，每块 $s$ 个元素（$n = b \cdot s$），要求**块间有序、块内可以无序**；再建一张按各块最大关键字排好序的索引表。
如果查索引表和查块内都用顺序查找，平均查找长度是：
$$\text{ASL} = \frac{b + 1}{2} + \frac{s + 1}{2} = \frac{1}{2}\left(\frac{n}{s} + s\right) + 1$$
由均值不等式，当 **$s = b = \sqrt{n}$** 时取得最小值 $\sqrt{n} + 1$。例如真题 `2025-07` 给 400 个元素做分块查找（顺序查索引表），每块选 $\sqrt{400} = \mathbf{20}$ 个元素时 ASL 最小（为 21）。

## 二、散列表（哈希表）：直接算地址与冲突处理

基于比较的查找最快也就 $O(\log n)$，散列表直接用散列函数 $H(\text{key})$ 算出存储位置，期望 $O(1)$ 命中。

### 1. 散列函数与影响 ASL 的三大因素

最常用的是**除留余数法**：$H(\text{key}) = \text{key} \bmod p$，其中 $p$ 通常取**不大于表长 $m$ 的最大质数**，避免关键字有公因子规律时扎堆冲突。
不同关键字算出同一个地址叫**冲突**，它们互称**同义词**。散列表的平均查找长度由三个因素共同决定（真题 `2022-09` 考点）：**① 装填因子 $\alpha = \frac{\text{已存元素数 } n}{\text{表长 } m}$**、**② 散列函数**、**③ 解决冲突的方法**，三者缺一不可。

### 2. 冲突处理方法与细节辨析

1. **开放定址法**：所有元素都挤在同一个数组里，冲突了就按增量序列 $d_i$ 往后找空位 $H_i = (H(\text{key}) + d_i) \bmod m$。
   - **线性探测法**：$d_i = 1, 2, 3, \dots, m - 1$。
     - 优点：**只要表还没满，一定能找到空位**（步长 1 遍历全表，真题 `2025-09` 考点）。
     - 缺点：容易产生**聚集（堆积）**——不同初始哈希值的非同义词也会撞到同一片拥堵区，所以开放定址法处理的冲突**既有同义词冲突，也有非同义词冲突**。
   - **二次探测法（平方探测法）**：$d_i = 1^2, -1^2, 2^2, -2^2, \dots$（或题目指定的单向 $+k^2$）。能缓解线性堆积，但**表没满也可能找不到空位**（即使表长是 $4k + 3$ 型质数，也只保证能探到至少一半的位置）。
   - **双散列法**：用第二个散列函数当步长 $H_i = (H_1(\text{key}) + i \cdot H_2(\text{key})) \bmod m$，要求 $H_2(\text{key}) \ne 0$ 且与表长 $m$ 互质。
2. **拉链法（链地址法）**：表里每个槽位是一个单链表头，同义词全挂在对应链表上。没有堆积问题，删除就是普通删链表结点，装填因子 $\alpha$ 可以大于 1。

### 3. 开放定址法的逻辑删除与 ASL 精算

在开放定址法里**删除元素时，绝对不能把槽位直接清空成 `EMPTY`**，否则会截断后面冲突元素的查找路径，导致本来在表里的数找不到了！必须打上**逻辑删除标记 `DEL`**（俗称墓碑）：
- **查找**遇到 `DEL` 时**不能停**，必须继续往后探，直到找到目标或者遇到真正的 `EMPTY` 才算失败；
- **插入**遇到 `DEL` 时可以先记下这个空位，继续往后查到 `EMPTY` 确认没有重复键后，再把新元素填回这个 `DEL` 槽位复用。

**算 ASL 一定要看清分母**：
- **$\text{ASL}_{\text{succ}}$**：把表里每个实际存着的元素查到它要比较的次数加起来，除以**实际元素个数 $n$**。
- **$\text{ASL}_{\text{unsucc}}$**：把散列函数**所有可能算出来的初始地址**（比如 $\text{key} \bmod p$ 就是 $0 \sim p - 1$ 共 **$p$** 个起点，**不是**表长 $m$！）逐个往后探测，一直数到碰到第一个 `EMPTY`（含这次比对 `EMPTY`），再除以 **$p$**。

拿真题 `2023-09` 演练一遍：表长 $m = 5$，散列函数 $H(k) = (k + 4) \bmod 5$，线性探测。依次插入 `2022`（落 1）、`12`（1 冲突，落 2）、`25`（落 4），再删除 `25`（槽位 4 打上 `DEL`）。此时 0～4 号槽位分别是 `[EMPTY, 2022, 12, EMPTY, DEL]`。算查找失败比较次数：
- 起点 0：看 0 是 `EMPTY` $\to$ 1 次；
- 起点 1：看 1, 2, 3(`EMPTY`) $\to$ 3 次；
- 起点 2：看 2, 3(`EMPTY`) $\to$ 2 次；
- 起点 3：看 3 是 `EMPTY` $\to$ 1 次；
- 起点 4：看 4 是 `DEL` 不能停，绕回看 0(`EMPTY`) $\to$ **2 次**。
所以 $\text{ASL}_{\text{unsucc}} = \frac{1 + 3 + 2 + 1 + 2}{5} = \mathbf{1.8}$。

再看一道二次探测综合大题 `2024-42`：表长 $m = 11$，散列函数 $H_0 = (\text{key} \times 3) \bmod 11$，冲突探测 $H_k = (H_0 + k^2) \bmod 11$，依次插入 `20, 3, 11, 18, 9, 14, 7`：
- `20 → 5`、`3 → 9`、`11 → 0`、`18 → 10` 直接落位；
- `9` 算得 `5`（冲突），$k=1$ 探 `(5+1) % 11 = 6` 落位；
- `14` 算得 `9`（冲突），$k=1$ 探 `10`（冲突），$k=2$ 探 `(9+4) % 11 = 2` 落位；
- `7` 算得 `10`（冲突），$k=1$ 探 `0`（冲突），$k=2$ 探 `(10+4) % 11 = 3` 落位。
- 装填因子 $\alpha = 7/11 \approx 0.636$；查找 `14` 的比较序列是 **`3, 18, 14`**（依次查下标 9、10、2）；查找不存在的关键字 `8`（$H_0 = 2$），依次探测下标 `2(14) → 3(7) → 6(9) → 0(11) → 7(空)`，遇到空单元确认失败，失败时的散列地址是 **7**。

## 三、字符串模式匹配与 KMP 算法

主串 $S$（长 $n$）里找模式串 $T$（长 $m$）：
- **朴素匹配（BF）**：失配时主串指针 $i$ 回退到本轮起点的下一位，模式串 $j$ 回 1。遇到 `S = "aaaaab", T = "aaab"` 这种串，每趟都在最后一位失败，最坏时间 **$O(n \times m)$**。
- **KMP 算法**：核心改进是**主串指针 $i$ 永远不回退**，只把模式串指针 $j$ 跳回 `next[j]`（或 `nextval[j]`）。预处理 `next` 花 $O(m)$，匹配时 `i` 最多走 $n$ 步、`j` 最多退 $n$ 步，总时间 **$O(n + m)$**，空间 $O(m)$。

### 1. 手算 `next` 数组（408 标准 1-based 口径）

408 默认字符串下标从 **1** 开始，`next[j]` 表示第 $j$ 位失配时，$j$ 下一步跳去哪一位：
1. 死记前两位：**`next[1] = 0`**，**`next[2] = 1`**；
2. 对 $j \ge 3$：**遮住第 $j$ 位和后面的字符，只看前面子串 $T[1..j-1]$**，找出它“既是真前缀又是真后缀”的最长公共子串长度 $L$，填 **`next[j] = L + 1`**。（如果题目用 0-based 下标，`next[0] = -1`，其余每一位正好是 1-based 结果减 1。）

### 2. 手算 `nextval` 与滑动距离

如果 $T[j] == T[\text{next}[j]]$，既然主串字符已经跟 $T[j]$ 对不上了，退回 `next[j]` 看到的还是同一个字符，肯定还会再失配一次。`nextval` 就是把这种白跑一趟的跳转直接一步跨过去：
- `nextval[1] = 0`；
- 从 $j = 2$ 到 $m$，设 $k = \text{next}[j]$：
  - 若 $T[j] == T[k]$，继承前面的优化值：**`nextval[j] = nextval[k]`**；
  - 若 $T[j] \ne T[k]$，保持不变：**`nextval[j] = k`**。
- 注意：`next` 和 `nextval` **都只跟模式串自己有关，和主串无关**。

当在第 $j$ 位失配、跳转到 `nextval[j]` 时，模式串向右滑动的字符距离是 **$\Delta = j - \text{nextval}[j]$**（`nextval[j] = 0` 时主串前进 1 格、模式串首字符对准下一格，正好滑了 $j$ 格）。

拿真题 `2024-06` 的模式串 `T = "aabaab"` 走一遍：

| 位序 $j$ | 1 | 2 | 3 | 4 | 5 | 6 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 字符 $T[j]$ | `a` | `a` | `b` | `a` | `a` | `b` |
| `next[j]` | `0` | `1` | `2` | `1` | `2` | `3` |
| `nextval[j]` | `0` | `0` | `2` | `0` | `0` | `2` |
| 滑动距离 $j - \text{nextval}[j]$ | 1 | 2 | 1 | 4 | **5** | 4 |

比如 $j = 5$ 时，`next[5] = 2`，因为 $T[5] = T[2] = \text{'a'}$，所以 `nextval[5] = nextval[2] = 0`，失配时一下向右滑动 $5 - 0 = \mathbf{5}$ 个字符，是整串里滑得最远的位置。
