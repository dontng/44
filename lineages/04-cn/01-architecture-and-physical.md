# 网络体系结构、时延交换与物理层传输

> 返回：[全科知识脉络总览](../README.md)

把「网络体系结构」「时延与数据交换」「物理层信道极限与编码复用」合在同一条脉络里，是因为它们回答的是同一个起点问题：一条数据要从一台计算机发到另一台计算机，在真正进入链路层组帧之前，协议栈要怎么分工、数据在网络里怎么跑、要花多少时间，以及底层的电信号或光信号最快能传多快。先搞清楚分层和性能指标，再落到物理层的带宽、噪声、编码和复用，后面的数据链路层、网络层和传输层就都有了落脚点。

## 一、计算机网络体系结构与分层模型

### 1. 为什么网络通信要分层？

让相距几千公里的两台主机上的程序互相通信，要同时处理电信号调制、传输误码、多台机器抢信道、跨网络选路、丢包重传、进程端口区分等一大堆事情。如果把这些功能全揉在一套代码里，哪怕只是把铜线换成光纤，上层软件就得跟着重写。

分层的好处在于**降低设计复杂度、方便各层独立升级、利于制定统一标准**，每层只做好自己的事，通过接口向上一层提供服务。但要注意：**分层并不会提高网络运行效率**（2026-33 就专门考了这个误区）。恰恰相反，每经过一层都要加上该层的控制首部、接收端再逐层解封装，层数越多，额外开销越大；分层是用一点运行开销换取系统的可维护性和扩展性。

### 2. 三种常见体系结构与各层协议数据单元（PDU）

408 考试里常见三种模型：OSI 七层参考模型、TCP/IP 四层模型，以及教材常用的五层教学体系。它们的对应关系和每层的数据单位（PDU）如下：

| 五层教学体系 | OSI 七层模型 | TCP/IP 四层模型 | 本层数据单位（PDU） | 核心职责 |
| :--- | :--- | :--- | :--- | :--- |
| 应用层 | 应用层 / 表示层 / 会话层 | 应用层 | 报文（Message） | 直接面向用户应用（HTTP、DNS、FTP、SMTP 等） |
| 传输层 | 传输层 | 传输层 | TCP 报文段 / UDP 用户数据报 | 进程到进程通信、复用与分用、可靠传输与拥塞控制 |
| 网络层 | 网络层 | 网际层（IP 层） | IP 数据报 / 分组（Packet） | 主机到主机路由选择与跨网转发 |
| 数据链路层 | 数据链路层 | 网络接口层 | 帧（Frame） | 相邻结点间的组帧、差错检测、介质访问控制 |
| 物理层 | 物理层 | 网络接口层 | 比特流（Bit Stream） | 在传输介质上透明传输 0/1 比特流 |

OSI 独有的两层在 TCP/IP 中合并进了应用层，考纲要求记住它们各自的职责：
- **表示层**：处理不同系统的数据格式差异，负责数据格式转换（如字符编码转换）、加密解密、压缩解压缩。
- **会话层**：负责建立、管理和终止会话，在长数据流中插入同步点（检查点），支持断线续传。

### 3. 协议三要素、服务与服务访问点（SAP）

体系结构里最容易混的是**协议**和**服务**：
- **协议是水平的**，规定通信双方**同一层对等实体**之间如何交流。协议包含三要素：
  1. **语法**：数据与控制信息的格式、各字段占多少位、怎么排列；
  2. **语义**：发出什么控制信息、完成什么动作、做出什么响应；
  3. **时序（同步）**：事件发生的先后顺序和速率匹配。
  - 例如 2020-33 给出一张双方消息交替收发的时序图，图里只画了谁先发、谁后回的顺序，没有画报文格式，也没有画动作含义，所以只体现了**时序**。
- **服务是垂直的**，是同一台主机内部**下层向上层**提供的功能（第 $N$ 层为第 $N+1$ 层提供服务，上层不必关心下层内部怎么实现）。2021-33 问“为传输层提供服务的那一层的功能是什么”，传输层正下方是**网络层**，所以答案是**路由选择**，而不是传输层自己的端到端传输，也不是上层的会话管理或下层的数据链路层流量控制。
- **服务访问点（SAP）**：相邻两层交界的逻辑接口，用来告诉接收端“拆掉本层首部后，里面的数据该交给上层哪个协议”。在 TCP/IP 协议栈里：
  - 数据链路层 SAP：以太网帧首部的 **类型字段（Type）**（如 `0x0800` 交 IPv4、`0x0806` 交 ARP；LLC 子层中是 DSAP/SSAP）；
  - 网络层 SAP：IP 首部的 **协议字段（Protocol）**（如 `6` 交 TCP、`17` 交 UDP、`1` 交 ICMP）；
  - 传输层 SAP：**端口号（Port）**（如 80 交 HTTP、53 交 DNS）。
- **服务分类**：按三个维度组合——面向连接 vs 无连接（如 TCP vs UDP/IP）、有确认 vs 无确认、可靠服务 vs 不可靠（尽最大努力交付）。注意下层不可靠（如 IP）不妨碍上层构建可靠服务（如 TCP）。

### 4. 封装、有效传输效率与各层互连设备

数据从应用层往下发，每层都套上自己的首部（以太网链路层还会加上 4 字节帧尾 FCS，物理层发射前还会加 8 字节前导码与帧开始定界符）。例如 1000B 应用载荷加上 200B HTTP 头、20B TCP 头、20B IP 头、14B 以太网帧头和 4B 帧尾 FCS，整帧长 1258B，帧层面的有效载荷传输效率就是 $1000 / 1258 \approx 79.49\%$。接收端则自下而上逐层拆封。

不同网络互连设备工作在不同层次，也决定了它们能否隔离冲突域和广播域：

| 设备 | 工作最高层次 | 转发依据 | 隔离冲突域 | 隔离广播域 |
| :--- | :---: | :--- | :---: | :---: |
| 中继器 / 集线器（Hub） | 物理层 | 无（仅放大整形、广播式转发电信号） | 否 | 否 |
| 网桥 / 以太网交换机（Switch） | 数据链路层 | MAC 地址表 | 是（每端口一个） | 否（划分 VLAN 后可隔离） |
| 路由器（Router） | 网络层 | IP 路由表 | 是 | 是 |
| 网关（Gateway） | 传输层及以上 | 协议转换、应用层字段 | 是 | 是 |

## 二、网络性能指标、四类时延与数据交换方式

### 1. 单位换算与带宽、吞吐量

408 计算题里最容易丢分的坑是**进制**：
- **速率 / 带宽**按十进制（$10^3$）：$1\text{ kb/s} = 10^3\text{ b/s}$，$1\text{ Mb/s} = 10^6\text{ b/s}$，$1\text{ Gb/s} = 10^9\text{ b/s}$。
- **文件大小 / 存储容量**默认按二进制（$2^{10}$）：$1\text{ B} = 8\text{ bit}$，$1\text{ KB} = 1024\text{ B}$，$1\text{ MB} = 2^{20}\text{ B}$（如果题干明确写“$1\text{ MB} = 10^6\text{ B}$”则按题干算）。

**吞吐量**是单位时间内实际通过网络的数据量。端到端最大吞吐量取决于整条路径上带宽最小的**瓶颈链路**（木桶效应）。例如 2024-33 的拓扑中，骨干网内部有 $100\text{ Mb/s}$ 甚至更高的链路，也有一条 $1\text{ Mb/s}$ 的支路可以绕开，但源主机 H1 和目的主机 H2 自己的接入链路都是 $10\text{ Mb/s}$，数据出不去也进不来，所以端到端最大吞吐量就是 **$10\text{ Mb/s}$**。

### 2. 四类时延与时延带宽积

一个分组从发出到送达，总时延由四部分组成：
1. **发送时延（传输时延）**：网卡把一整个分组的所有比特推上线缆的时间，$T_{\text{send}} = \frac{\text{分组长度 } L\text{ (bit)}}{\text{发送速率 } R\text{ (b/s)}}$。发生在发送端网卡内部，带宽翻倍缩短的是它。
2. **传播时延**：电磁波在线缆或空间中走完物理距离的时间，$T_{\text{prop}} = \frac{\text{链路长度 } D\text{ (m)}}{\text{传播速度 } V\text{ (m/s)}}$。光纤和一般有线介质通常取 $2 \times 10^8\text{ m/s}$，无线电和卫星信道取 $3 \times 10^8\text{ m/s}$。提高网卡带宽不会改变传播时延。
3. **处理时延**：主机或路由器检查首部、查转发表的时间。
4. **排队时延**：分组在路由器输入/输出队列等待转发的时间。当信道利用率 $U$ 逼近 100% 时，排队时延会急剧飙升甚至引发队列溢出丢包，因此骨干网通常把利用率控制在较低水平。

**时延带宽积（BDP）**要注意单向与往返的语境：
- **单向时延带宽积** $= T_{\text{prop}} \times R$：表示当第一个比特刚到达接收端时，这条单向链路上最多能“装下”多少个比特（管道容量）。
- **往返时延带宽积** $= \text{RTT} \times R \approx 2T_{\text{prop}} \times R$：表示从发出第一个比特到收到对应 ACK 期间，发送端能连续塞进管道的在途数据量，是设计滑动窗口大小的基准。

### 3. 三种数据交换方式与多跳存储转发计算

网络中间节点转发数据有三种方式：
- **电路交换**：先建立端到端专用物理通路（耗时 $T_{\text{setup}}$），通信期间独占带宽，数据直通传输无需存储转发，结束后拆链。适合持续大流量通信，突发小流量时带宽浪费严重。
- **报文交换**：不建链，整块报文在每个中间节点**存储转发**（完整收完再发往下一跳），中间节点缓存压力大、时延极长。
- **分组交换**：把大报文切成定长小分组，每个分组在中间节点存储转发，但多个分组可以在不同链路上**像流水线一样并行传输**。分组交换又分为**数据报**（无连接，各分组独立选路，可能失序）和**虚电路**（先建逻辑连接确定路径，分组只带虚电路号 VCID，按序到达）。
  - 特别注意 2020-34 的考点：**虚电路属于分组交换，不是电路交换**，它不需要为每条虚电路预分配独占的物理带宽，沿途链路依然是各连接统计复用共享的。

**多跳存储转发的计算模型**分两种情况：
1. **单个分组过 $k$ 段链路**（带宽 $R_i$、传播时延 $\tau_i$）：没有流水线，直接累加：
   $$T = \sum_{i=1}^{k} \frac{L}{R_i} + \sum_{i=1}^{k} \tau_i + \text{各跳处理与排队时延}$$
2. **大报文分成 $m$ 个等长分组，过 $k$ 段同构链路**（每段带宽 $R$、传播时延 $\tau$，忽略处理排队）：
   - 源端把全部 $m$ 个分组发完需要 $m \cdot \frac{L}{R}$；
   - 最后一个分组从源端发完后，还要在后面的 $k-1$ 个中间节点各经历 1 次发送时延，外加走完 $k$ 段链路的传播时延 $k\tau$；
   - 合起来就是流水线公式：
     $$T = (m + k - 1) \cdot \frac{L}{R} + k \cdot \tau$$

> **真题推演 1（2023-33 分组交换流水线）**
> 主机 H1 经 1 台路由器向 H2 发送 $1\text{ MB}$（按 $10^6\text{ B}$）文件，切成 $1000$ 个 $1000\text{ B}$ 的分组，两段链路带宽均为 $100\text{ Mb/s}$，每段传播时延 $10\,\mu\text{s}$。
> - 单分组发送时延：$\frac{1000 \times 8}{100 \times 10^6} = 80\,\mu\text{s}$。
> - 源端发完 1000 个分组耗时 $1000 \times 80\,\mu\text{s} = 80\text{ ms}$；最后一个分组在中间路由器再花 1 次发送时延 $80\,\mu\text{s}$；两段链路传播时延共 $20\,\mu\text{s}$。
> - 总时延 $= 80\text{ ms} + 0.08\text{ ms} + 0.02\text{ ms} = \mathbf{80.10\text{ ms}}$。如果忘加路由器对最后一个分组的发送时延，就会误算成 $80.02\text{ ms}$。

> **真题推演 2（2025-33 三种交换方式耗时比较）**
> 传 $16\text{ Mbit}$ 数据，经过三段速率不同的链路（$10\text{ Mb/s} \to 100\text{ Mb/s} \to 1000\text{ Mb/s}$），忽略传播时延。电路交换建链耗时极短，仅 $32\,\mu\text{s}$；分组交换单分组 $400\text{ B}$。
> - **报文交换 $T_{\text{ms}}$**：整份数据在三段链路上串行发送，$\frac{16\text{ M}}{10\text{ M}} + \frac{16\text{ M}}{100\text{ M}} + \frac{16\text{ M}}{1000\text{ M}} = 1.6 + 0.16 + 0.016 = 1.776\text{ s}$，最慢。
> - **电路交换 $T_{\text{cs}}$**：建链 $32\,\mu\text{s}$ + 按瓶颈速率 $10\text{ Mb/s}$ 直通发完 $1.6\text{ s}$ $= 1.6\text{ s} + 32\,\mu\text{s}$。
> - **分组交换 $T_{\text{ps}}$**：所有分组在最慢的第一段（$10\text{ Mb/s}$）发完占 $1.6\text{ s}$，最后一个分组（$3200\text{ bit}$）在后两段链路再花 $\frac{3200}{100\text{ M}} + \frac{3200}{1000\text{ M}} = 32\,\mu\text{s} + 3.2\,\mu\text{s} = 35.2\,\mu\text{s}$，总计 $1.6\text{ s} + 35.2\,\mu\text{s}$。
> - 因为 $32\,\mu\text{s} < 35.2\,\mu\text{s}$，本题反而是 $T_{\text{cs}} < T_{\text{ps}} < T_{\text{ms}}$。可见不能死背“分组交换一定比电路交换快”，要看建链时间和末分组多跳转发时间谁更小。

## 三、物理层基础：接口特性、传输介质与信道极限

### 1. 物理层四大特性与传输介质

物理层负责在传输介质上透明传输比特流，它的接口标准由四个特性定义：
- **机械特性**：接插件的形状、尺寸、引脚数目和排列（如 RJ-45 水晶头 8 针）。
- **电气特性**：电压范围、阻抗匹配、传输速率和距离限制。
- **功能特性**：某根引脚出现某种电平代表什么含义（如发送线 TxD、地线 GND）。
- **过程（规程）特性**：不同引脚信号交互的先后顺序和应答步骤。

传输介质分两类：
- **导引型（有线）**：
  - **双绞线（UTP 无屏蔽 / STP 屏蔽）**：两根铜线绞合，利用外部电磁干扰在两根线上感应出的电动势大小相等、方向相反来抵消串扰，局域网最常用。
  - **同轴电缆**：50Ω 基带同轴（早期以太网）与 75Ω 宽带同轴（有线电视）。
  - **光纤**：利用光的全反射传输。**单模光纤**纤芯极细（接近光波长），光直线传播无模间色散，用激光器，适合几十公里长途传输；**多模光纤**纤芯较粗，多条不同角度光线全反射传播，有模间色散，用发光二极管 LED，适合几百米到几公里短距传输。注意“单模”指单条传播路径，不等于只能传一种波长，单模光纤完全可以用波分复用（WDM）同时传多种波长的光。
- **非导引型（无线）**：无线电波（全向、穿透力强）、微波（直线视距传播，需中继站或卫星）、红外线与激光（强定向、无穿透）。

### 2. 波特率、比特率、奈奎斯特定理与香农公式

在信道上传输信号时，一段固定时长的基本波形叫一个**码元（Symbol）**。每秒传输的码元数叫**波特率（$B$，单位 Baud）**，每秒传输的二进制位数叫**比特率（$R_b$，单位 b/s）**。如果一个码元有 $V$ 种离散状态（电平、相位或幅度组合），每个码元就能携带 $\log_2 V$ 比特信息，因此：
$$R_b = B \times \log_2 V$$

信道速率不能无限提高，受两大定理限制：
1. **奈奎斯特定理（无噪声理想低通信道）**：
   发送太快会导致高频分量被滤除、前后波形拖尾粘连（码间串扰）。带宽为 $W\text{ (Hz)}$ 的理想低通信道，最高码元速率为 $B_{\max} = 2W\text{ Baud}$，最高数据传输速率为：
   $$C_{\text{Nyquist}} = 2W \log_2 V \quad (\text{b/s})$$
   *（注：408 统考与教材不细分低通与带通，奈氏准则统一按 $2W\log_2 V$ 计算。）*
2. **香农公式（存在高斯白噪声的现实信道）**：
   信噪比 $\frac{S}{N}$ 限制了能分辨的电平层级数。无论采用多复杂的调制，带宽为 $W\text{ (Hz)}$ 的有噪信道极限数据率都不可能超过：
   $$C_{\text{Shannon}} = W \log_2\left(1 + \frac{S}{N}\right) \quad (\text{b/s})$$
   如果题干给的是分贝数 $\text{SNR}_{\text{dB}}$，必须先按 $\text{SNR}_{\text{dB}} = 10\log_{10}(S/N)$ 换算成无量纲比值 $S/N = 10^{\text{SNR}_{\text{dB}}/10}$（如 $30\text{ dB} \to 1000$，$20\text{ dB} \to 100$，$10\text{ dB} \to 10$）；如果题干直接给 $S/N$（如 1023），则直接代入。
3. **双定理同时给出时**：实际极限速率取两者的**较小值** $\min(C_{\text{Nyquist}}, C_{\text{Shannon}})$。因为即使把调制状态数 $V$ 调得再高，一旦超过香农上限，噪声也会淹没相邻电平导致无法分辨。

> **真题推演 3（2022-34、2023-34、2026-34 信道极限计算）**
> - **正向用奈氏准则（2022-34）**：无噪声信道带宽 $W = 200\text{ kHz}$，采用 4 个幅值的 ASK（$V = 4$）。每个码元携 $\log_2 4 = 2\text{ bit}$，极限波特率 $2W = 400\text{ kBaud}$，所以最大数据率 $= 400\text{ k} \times 2 = \mathbf{800\text{ kbps}}$。（常见错解是漏乘 $\log_2 4$ 或直接乘以 4）。
> - **逆向求调制方案（2023-34）**：无噪声信道 $W = 4\text{ MHz}$，最大数据率 $C = 48\text{ Mbps}$。极限波特率 $B = 2W = 8\text{ MBaud}$，每码元比特数 $= 48 / 8 = 6\text{ bit}$，状态数 $V = 2^6 = 64$，故采用 **QAM-64**。
> - **香农公式结合发送时延（2026-34）**：信道带宽 $W = 200\text{ kHz}$，信噪比 $S/N = 1023$（直接是比值，不是 dB）。极限速率 $C = 200\text{ kHz} \times \log_2(1 + 1023) = 200\text{ k} \times 10 = 2\text{ Mbps}$。发送一个 $1500\text{ B}$ 分组的最短发送时延 $= \frac{1500 \times 8\text{ bit}}{2 \times 10^6\text{ b/s}} = \mathbf{6\text{ ms}}$。

## 四、数字编码、载波调制与信道复用

### 1. 基带编码：自同步问题与曼彻斯特波形判读

最简单的**不归零码（NRZ）**用高电平表示 1、低电平表示 0。一旦连续出现几百个 0 或 1，电平变成一条直线，接收端没法从中提取时钟信号，晶振稍有偏差就会数错位数。**反向不归零码（NRZI）**遇到 0 翻转、遇到 1 保持（或相反），依然无法解决连 1 无跳变的问题。

因此传统局域网引入了**自同步编码**：
- **曼彻斯特编码（Manchester）**：每个比特周期的**正中间必定有一次电平跳变**，既用来同步时钟，又表示数据。
  - 注意存在两套约定：IEEE 802.3 以太网标准规定 **低到高为 1，高到低为 0**；Tanenbaum 等教材常规定 **高到低为 1，低到高为 0**。做题时**先看题干给的图例**，若无图例且指明以太网标准则按 IEEE 802.3。
  - 代价：每个比特周期内最多两次跳变，波特率是比特率的 **2 倍**（例如 10 Mbps 数据需要 20 MBaud 调制速率，编码效率 50%）。
- **差分曼彻斯特编码（Differential Manchester）**：每个比特周期**正中间的跳变只用来同步时钟，不表示数据**；数据完全看**比特周期起始边界有没有跳变**：
  - **起始边界有跳变 $\to$ `0`**；
  - **起始边界无跳变 $\to$ `1`**。
  - 优点是抗线路反相，且波特率同样是比特率的 2 倍。

> **真题推演 4（2021-34 差分曼彻斯特波形还原）**
> 给定一段 8 比特的差分曼彻斯特波形，初始前导电平为高电平。逐位看每个码元周期的**左边界**（忽略周期中间的时钟跳变）：
> - 第 1 位左边界保持高电平（无跳变）$\to$ `1`；
> - 第 2 位左边界发生跳变 $\to$ `0`；
> - 第 3、4、5 位左边界均延续上一位末尾电平（无跳变）$\to$ `1, 1, 1`；
> - 第 6、7 位左边界均发生跳变 $\to$ `0, 0`；
> - 第 8 位左边界无跳变 $\to$ `1`。
> - 拼出完整比特串：`1011 1001`。记住“有跳为 0、无跳为 1”，只盯左边界就不会看花眼。

### 2. 频带传输调制（ASK / FSK / PSK / QAM）

要在模拟信道上传数字信号，需要用二进制数据去控制高频正弦载波 $s(t) = A\sin(2\pi ft + \varphi)$ 的参数：
- **ASK（振幅键控）**：单频率载波，改变振幅 $A$；抗干扰差。
- **FSK（频移键控）**：改变载波频率 $f$，用两个不同频率 $f_1, f_2$ 分别表示 0 和 1（2024-34 考的正是“需要 2 个不同频率载波”的调制方式是 FSK）；抗干扰好但占频带宽。
- **PSK（相移键控）**：单频率载波，改变绝对相位 $\varphi$（如 BPSK 用 $0, \pi$，QPSK 用 4 种相位每码元携 2 bit）；**DPSK（差分相移键控）**则用前后码元的相对相位差表示数据。
- **QAM（正交振幅调制）**：同时调制振幅和相位，组合出 $M$ 个星座点，每码元携带 $\log_2 M$ 比特（如 16-QAM 每码元 4 bit，64-QAM 每码元 6 bit）。

### 3. 信道复用技术与 CDMA 正交计算

多路信号共享一条物理信道，有五种典型复用方式：
- **频分复用（FDM）**：按频率切分，各路并行传输，子频带间需留保护频带。
- **波分复用（WDM）**：光纤里的频分复用，不同波长的光在同一根光纤里并行传输。
- **同步时分复用（TDM）**：按固定时间片轮流分配时隙，某用户无数据时该时隙空置浪费。
- **统计时分复用（STDM）**：按需动态分配时隙，提高突发流量下的利用率，但每个时隙必须带用户地址标识；注意如果所有用户持续 100% 满负荷发包，STDM 因为多了地址开销，净吞吐率反而低于同步 TDM。
- **码分多址（CDMA）**：所有站点在同一时间、同一频段同时发信号，靠互相正交的 $m$ 位码片序列区分。规定发比特 `1` 时发自身码片 $\mathbf{S}$，发比特 `0` 时发反码 $-\mathbf{S}$（码片中的 `1` 记为 $+1$，`0` 记为 $-1$）。不同站点的码片规格化内积 $\frac{1}{m}\mathbf{S}\cdot\mathbf{T} = 0$，自身与自身为 $+1$，与反码为 $-1$。
  - **解调示例**：设站点 A 码片 $\mathbf{A}=(-1,-1,-1,+1,+1,-1,+1,+1)$，信道叠加信号 $\mathbf{P}=(-1,+1,-3,+1,-1,-3,+1,+1)$。计算规格化内积：
    $$\mathbf{P}\cdot\mathbf{A} = \frac{1}{8}(1 - 1 + 3 + 1 - 1 + 3 + 1 + 1) = \frac{8}{8} = +1$$
    结果为 $+1$ 说明 A 发了 `1`；若为 $-1$ 说明发了 `0`；若为 $0$ 说明 A 未发送。
