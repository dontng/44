# 湖科大网络每日一题

这里管理“湖科大教书匠”按日发布的 408 计算机网络题，作为 [src/](../src/) 真题能力线的补充，不替代真题。

## 年份口径

| 目录 | 发布年份 | 通常面向 |
|---|---:|---|
| [2025/](2025/) | 2025 | 2026 考研 |
| [2026/](2026/) | 2026 | 2027 考研 |

目录按**视频发布年份**命名。这样不会把“2026考研系列”和“2026年发布系列”混为一谈。

## 保存方式

每题一个 Markdown：`YYYY/MMDD.md`。文件内同时放来源、题意、首次作答、讲解和验证，不拆成多份。

- 原题证据：保留 B 站视频链接、标题、发布日期和题目出现时间。
- 可检索内容：用自己的话写一两句题意与关键词，不逐字抄整段讲解。
- 图片：文字题不截图；拓扑图、表格等离图无法作答时，才放 `YYYY/assets/MMDD.png`，并只裁题目所需区域。
- 学习状态：只用 `未做 → 已作答 → 已讲 → 已验证` 四档。
- 讲解尺度：先给结论和唯一关键机制，再补一个最小的 i+1 变式。

本仓库公开。不要批量上传视频画面、字幕或老师的完整解析。

新增题目时复制 [TEMPLATE.md](TEMPLATE.md)，再在对应年份的索引中增加一行。
