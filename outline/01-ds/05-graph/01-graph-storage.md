## 2. 核心机理与五步推演

### (1) 为什么需要四种不同的图存储结构？

- **物理矛盾**：
  图是由顶点集合 $V$ 与边集合 $E$ 构成的非线性多对多拓扑。图的形态分布极其极端：
  - 可能是接近完全图的**稠密图**（$|E| \approx |V|^2$）；
  - 也可能是边数极少的**稀疏图**（$|E| \ll |V|^2$，如树状拓扑 $|E| = |V|-1$）。
  单一静态数组或单向链表无法兼顾“判断两点之间是否有边”的查询速度与“存储空闲稀疏图”的空间开销。

| 存储结构 | 适合图类型 | 空间复杂度 | 核心优势 | 关键局限 |
| :--- | :--- | :---: | :--- | :--- |
| **邻接矩阵** | 稠密图 | $O(\|V\|^2)$ | $O(1)$ 时间极速判断任意两点间是否有边；代数性质优异 | 稀疏图严重浪费空间；找某个顶点的全部邻居必须扫描整行 $O(\|V\|)$ |
| **邻接表** | 稀疏图 | $O(\|V\| + \|E\|)$ | 空间随边数线性增长；找某顶点的所有出边极快 | 找入边困难（有向图需扫描全表或增设逆邻接表）；判两点是否有边需遍历链表 |
| **十字链表** | 有向图 | $O(\|V\| + \|E\|)$ | 将每个顶点的出边表与入边表焊死在同一张链表中，**查出度与入度均达最优** | 仅适用于有向图；指针域较多，结构较复杂 |
| **邻接多重表** | 无向图 | $O(\|V\| + \|E\|)$ | **一条无向边仅占用一个唯一的物理边结点**，删除边无需在两端链表中分别寻删 | 仅适用于无向图 |

### (2) 邻接矩阵的度数与代数性质（幂次定理深度纠偏）

#### ① 顶点的度数计算判据与加权图边界
- **无权图（0/1 简单图）**：
  - 无向图：第 $i$ 行（或第 $i$ 列）中非零（值为 1）元素的个数，严格等于顶点 $v_i$ 的度 $TD(v_i)$；
  - 有向图：第 $i$ 行非零元素个数为出度 $OD(v_i)$；第 $i$ 列非零元素个数为入度 $ID(v_i)$。
- **加权图（带权网，Network）的重要边界修正**：
  - 在带权网中，不存在边的位置通常填充 $\infty$（表示无穷大，不可达），主对角线通常填充 $0$；
  - **关键陷阱**：在加权网中，**有效的边其权值完全可能为 0**！因此不能简单以“非零元素个数”判定度数，而必须表述为：**非对角线上非 $\infty$ 元素的个数**。

#### ② 邻接矩阵幂次定理：计算的是“通路（Walk）”而非“简单路径（Simple Path）”！
设无权有向或无向简单图的邻接矩阵为 $A$（$A[i][j] = 1$ 表示从 $v_i$ 到 $v_j$ 有直接边，否则为 0）：
$$\text{矩阵 } A^k \text{ 中第 } i \text{ 行第 } j \text{ 列的元素 } A^k[i][j]，\mathbf{严格等于从顶点 } v_i \mathbf{ 到顶点 } v_j \mathbf{ 长度为 } k \mathbf{ 的通路（Walk）总数目！}$$

> **核心认知红线（严防偷换概念）**：
> 很多初学者误将 $A^k[i][j]$ 当作“简单路径条数”。**这是错误的！**
> - **简单路径（Simple Path）**：序列中经过的顶点和边**严格互不重复**；
> - **通路 / 游走（Walk）**：允许在顶点和边之间**反复横跳、多次经过同一个顶点或同一条边**。
>
> **【最小反例证伪】**：
> 考虑只有 2 个顶点的无向图，顶点为 $0$ 和 $1$，边为 $(0, 1)$。其邻接矩阵为：
> $$A = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$$
> 计算平方矩阵 $A^2$：
> $$A^2 = A \times A = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$$
> 结果显示 $A^2[0][0] = 1$。
> - 物理含义：存在一条从顶点 0 到顶点 0、长度为 2 的通路：$0 \to 1 \to 0$；
> - 这条通路重复利用了边 $(0, 1)$，并且顶点 0 出现了两次，**根本不是简单路径**！

### (3) 十字链表（有向图）与邻接多重表（无向图）微架构深度推演

#### ① 十字链表（Orthogonal List —— 有向图专属）
十字链表是有向图的邻接表与逆邻接表的物理融合体。

```
顶点结点结构:
┌──────────┬──────────┬──────────┐
│   data   │ firstin  │ firstout │
└──────────┴──────────┴──────────┘
             (入边表头)  (出边表头)

弧结点结构:
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ tailvex  │ headvex  │  hlink   │  tlink   │   info   │
└──────────┴──────────┴──────────┴──────────┴──────────┘
  (弧尾/起点) (弧头/终点) (同弧头链)  (同弧尾链)  (权重权值)
```

- **同弧头链 `hlink`**：将所有指向相同终点（相同 `headvex`）的弧串联在一起，构成了该顶点的**逆邻接表（求入度）**；
- **同弧尾链 `tlink`**：将所有从相同起点（相同 `tailvex`）出发的弧串联在一起，构成了该顶点的**邻接表（求出度）**。
- **空间开销**：共有 $|V|$ 个顶点结点和 $|E|$ 个弧结点，空间复杂度为严格的 $O(|V| + |E|)$。

#### ② 邻接多重表（Adjacency Multilist —— 无向图专属）
在传统的无向图邻接表中，一条无向边 $(u, v)$ 必须被复制拆分为两个独立的边结点：一个挂在 $u$ 的链表下，另一个挂在 $v$ 的链表下。这导致删除一条边时，必须分别遍历查找并删除两个结点，效率低下。
邻接多重表彻底消除冗余：**每一条无向边在整个内存中仅分配一个唯一的边结点**！

```
顶点结点结构:
┌──────────┬──────────┐
│   data   │firstedge │
└──────────┴──────────┘

边结点结构 (一条无向边对应一个实体):
┌──────┬──────┬──────┬──────┬──────┬──────┐
│ mark │ ivex │ilink │ jvex │jlink │ info │
└──────┴──────┴──────┴──────┴──────┴──────┘
 (访问标记)(端点i) (依附i) (端点j) (依附j) (权值)
```

#### ③ 4 顶点无向图多重表编织与极速删边追踪

考虑 4 个顶点 $V = \{0, 1, 2, 3\}$，边集包含：$e_1(0, 1)$、$e_2(0, 2)$、$e_3(1, 2)$：

```
顶点表 (firstedge):
  0: firstedge ──► e1        (顶点 0 的关联边链: e1 ──ilink──► e2 ──ilink──► NULL)
  1: firstedge ──► e1        (顶点 1 的关联边链: e1 ──jlink──► e3 ──ilink──► NULL)
  2: firstedge ──► e2        (顶点 2 的关联边链: e2 ──jlink──► e3 ──jlink──► NULL)
  3: firstedge ──► NULL      (孤立顶点)

边结点物理表 (每条无向边唯一对应 1 个实体):
  e1 (边 0-1): [ ivex=0 | ilink=&e2 | jvex=1 | jlink=&e3 ]
  e2 (边 0-2): [ ivex=0 | ilink=NULL| jvex=2 | jlink=&e3 ]
  e3 (边 1-2): [ ivex=1 | ilink=NULL| jvex=2 | jlink=NULL]
```

- **双向依附编织**：
  边 $e_1(0, 1)$ 同时挂在顶点 0 的链上（作为 `ivex=0`，由 `ilink` 索引下一条依附于 0 的边 $e_2$），又挂在顶点 1 的链上（作为 `jvex=1`，由 `jlink` 索引下一条依附于 1 的边）；
- **极速删边机制**：
  若要删除无向边 $(0, 1)$：
  - 在普通邻接表中：需在顶点 0 的链表中搜寻删除结点 1，再到顶点 1 的链表中搜寻删除结点 0（两次遍历，释放两次内存）；
  - 在邻接多重表中：直接修改顶点 0 的 `firstedge` 指向 $e_1 \to ilink$（即 $e_2$），修改顶点 1 的 `firstedge` 指向 $e_1 \to jlink$，**只需释放一次 $e_1$ 结点的内存，即可瞬时完成该无向边的全局抹除**。

### (4) 典型反例证伪（常见认知陷阱）

1. **反例 1：“计算邻接矩阵的 $A^3[i][j]$，若结果为 2，说明从顶点 $i$ 到顶点 $j$ 恰好存在 2 条不同的简单路径。”**
   - **反例证伪**：错误。$A^3[i][j]$ 统计的是长度为 3 的所有通路（Walk）。例如在三角形环路 $A-B-C$ 中，从 $A$ 出发经 $A \to B \to A \to B$ 的往返序列长度为 3，会被矩阵幂次计入，但这根本不是简单路径。
2. **反例 2：“对于带权网，只要矩阵第 $i$ 行非零元素的个数大于 0，顶点 $i$ 的出度就一定不为 0。”**
   - **反例证伪**：错误。在带权图中，不可达由 $\infty$ 标示，但完全可能存在一条权重恰好为 $0$ 的合法边（例如某些零消耗网络跃点）。若整行除了一个权值为 0 的边外全部是 $\infty$，该行非零元素个数为 0，但该顶点的实际出度为 1。
3. **反例 3：“无向图的邻接表中，边结点的总个数严格等于边数 $|E|$。”**
   - **反例证伪**：错误。在无向图邻接表中，每条无向边被拆为两个方向的对称边结点，因此链表边结点总数严格等于 **$2|E|$**。只有在邻接多重表中，边结点总数才严格等于 $|E|$。

## 3. 408 考场标准模型 vs 现代工程实现边界

| 维度 | 408 考场标准模型（学理解题口径） | 现代工程实现边界（工业级图计算框架） |
| :--- | :--- | :--- |
| **稀疏图存储表示** | 优先考查标准指针链表形式的邻接表（`Node*` 指针分散动态分配） | 现代静态图计算与算子加速框架（如 PyTorch Geometric, GraphBLAS）通常以 **CSR（Compressed Sparse Row，压缩稀疏行）**或 **CSC** 替代分散指针链表：由两个整型密集数组直接紧凑排布边和偏移量，具备极致的 CPU Cache 命中率和向量化并行能力 |
| **邻接矩阵内存消耗** | 稠密图默认开辟二维静态数组 `int A[N][N]` | 节点规模突破百万级时，即便稠密图也无法放入连续内存，转为分布式切片分块矩阵（Block-partitioned Matrix） |
| **十字链表与多重表** | 强调作为指针网络在内存中手写构建 | 现代图数据库（如 Neo4j）将边设计为独立的一级实体，支持双向指针记录边属性（Property Graph 模型），机制在思想上源于多重表 |

## 4. 跨章节与跨学科关联

### 1. 本学科内跨章节关联
- $\to$ 关联 [图的遍历算法](02-graph-traversal.md)：
  - **共同机制**：图遍历的算法时间复杂度直接受存储结构决定。
  - **关键差异**：基于邻接矩阵遍历图的时间复杂度恒为 $O(|V|^2)$；基于邻接表遍历图的时间复杂度优化为 $O(|V| + |E|)$。
  - **不可直接迁移的判据**：对于同一个图，邻接矩阵表示形式唯一（给定顶点排列），DFS/BFS 遍历序唯一；邻接表的单链表结点插入顺序不同，DFS/BFS 遍历序不唯一。
- $\to$ 关联 [特殊矩阵的压缩存储](../03-stack-queue-array/03-matrix-compression.md)：
  - **共同机制**：无向图的邻接矩阵是对称矩阵，可采用对称矩阵上三角或下三角一维数组压缩技术，将空间开销从 $|V|^2$ 压缩至 $|V|(|V|+1)/2$。
  - **关键差异**：普通矩阵压缩仅关注按行/按列下标映射公式；图邻接矩阵压缩后还需保留主对角线（自环判断）与行和计算（度数计算）。
  - **不可直接迁移的判据**：有向图邻接矩阵通常非对称，不可直接套用对称矩阵的一维压缩公式。

### 2. 跨学科协同关联
- $\to$ 关联 [计算机组成原理 / 存储体系与局部性原理](../../02-co/03-memory-hierarchy/01-memory-types.md)：
  - **共同机制**：邻接矩阵二维数组在物理内存中按行连续存放，行扫描具有优异的空间局部性，易触发硬件预取（Hardware Prefetch）。
  - **关键差异**：指针链表式的邻接表结点在堆内存中离散分配，遍历邻居时频繁发生指针追逐（Pointer Chasing），导致高昂的 CPU Cache Miss。
  - **不可直接迁移的判据**：虽然邻接表渐进复杂度 $O(|V|+|E|)$ 在稀疏图上优于邻接矩阵 $O(|V|^2)$，但在边数适中的中等图上，邻接矩阵由于高 Cache 命中率，实际运行耗时可能反超邻接表。

## 5. 核心考点自查清单与闭环判据

1. **邻接矩阵幂次定理核心判据**：
   - $A^k[i][j]$ 计算的是从 $i$ 到 $j$ **长度为 $k$ 的通路（Walk）数量**，绝对不能直接断言为简单路径数。
2. **度数统计边界**：
   - 0/1 无权简单图：统计非零元素；
   - 带权网：统计非对角线、非 $\infty$ 元素。
3. **结点开销记忆公式**：
   - 邻接表：顶点表 $|V|$ 个结点，无向图边表 $2|E|$ 个结点，有向图边表 $|E|$ 个结点；
   - 邻接多重表：顶点表 $|V|$ 个结点，边表严格只有 $|E|$ 个结点（单边唯一实体）。
