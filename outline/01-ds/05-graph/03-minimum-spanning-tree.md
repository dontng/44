## 2. 核心机理与五步推演

<a id="mst-cut-and-uniqueness"></a>
### (1) 最小生成树的物理本质与割性质（Cut Property）

- **物理矛盾**：
  在工程网络建设中（如城市供水管网、通信光缆铺设），存在 $|V|$ 个节点与海量备选链路 $|E|$。
  目标是以最小的建设总代价（所有边权之和最小）将全域节点连通，同时杜绝任何冗余回路（无环且连通即为树，边数严格恒等于 $|V| - 1$）。
- **数学基石：割性质（Cut Property）**：
  将无向连通图的顶点集 $V$ 任意切分为两个不相交的非空子集 $S$ 与 $V - S$（称为一个“割”，Cut）。
  在所有横跨该割（即一端属于 $S$、另一端属于 $V - S$）的候选边集中，**权值最小的那条轻量边（Light Edge），必定属于该图的某棵最小生成树**。
  - **Prim 算法**：动态维护集合 $S$，每轮从横跨割的边中挑最小边把外部点拉入 $S$（加点法）；
  - **Kruskal 算法**：全局按权值由小到大排序候选边，利用并查集挑选连接不同树的轻量边（加边法）。

### (2) 最小生成树唯一性的充要条件与判定定理

#### ① 充分条件 vs 充要条件
- **充分非必要条件**：
  若无向连通图中**所有边的权值互不相等**，则图的最小生成树**必定唯一**。
  *(逆命题不成立：存在权值相等的边，生成树仍然完全可能是唯一的！)*
- **充要条件（严格判定法则）**：
  一棵生成树 $T$ 是图 $G$ 的**唯一最小生成树**，**当且仅当对于图 $G$ 中任意一条非树边 $e = (u, v) \notin T$，边 $e$ 的权值 $w(e)$ 严格大于树 $T$ 中连接 $u$ 与 $v$ 的唯一下属路径上的最大边权**：
  $$w(e) > \max_{e' \in \text{Path}_T(u, v)} w(e')$$
  *(证明：若存在某条非树边权值等于路径上的最大边权，用该非树边替换路径上的最大边，即可得到一棵总权值完全相等但拓扑结构不同的另一棵 MST，导致多解)*。

#### ② 重复权值下的唯一性对比算例

**【算例 1：边权重复，但 MST 严格唯一】**
考虑 4 顶点图 $V = \{A, B, C, D\}$：
- 边集：$(A, B) = 1, (B, C) = 1, (A, C) = 5, (C, D) = 2$。
- 边权集合为 $\{1, 1, 2, 5\}$，权值 $1$ 发生了重复。
- **MST 判定**：由于三角形 $A-B-C$ 中两条权为 1 的边互不冲突且权值极小，连通 $A, B, C$ 必须且只能选 $(A, B)$ 和 $(B, C)$；连通 $D$ 只能选 $(C, D)$。唯一生成的 MST 边集为 $\{(A,B), (B,C), (C,D)\}$，总权值 $1+1+2=4$。**该图存在重复权值，但 MST 严格唯一**。

**【算例 2：边权重复，导致 MST 不唯一】**
考虑 4 顶点图 $V = \{A, B, C, D\}$：
- 边集：$(A, B) = 2, (B, C) = 2, (A, C) = 1, (C, D) = 3$。
- 边权集合为 $\{1, 2, 2, 3\}$，权值 $2$ 发生重复。
- **MST 判定**：选定 $(A, C)=1$ 和 $(C, D)=3$ 之后，顶点 $B$ 既可以通过 $(A, B)=2$ 接入，也可以通过 $(B, C)=2$ 接入。
  - MST 方案 1：$\{(A, C), (C, D), (A, B)\}$，总权值 $1 + 3 + 2 = 6$；
  - MST 方案 2：$\{(A, C), (C, D), (B, C)\}$，总权值 $1 + 3 + 2 = 6$。
  - **总权值之和绝对唯一（均为 6），但树形拓扑结构多解**。

### (3) Prim 算法执行机理与完整状态追踪表

设 5 顶点无向加权图 $V = \{0, 1, 2, 3, 4\}$，其邻接矩阵如下（$\infty$ 表示无直接边）：
```
       0    1    2    3    4
  0 [  0,   4,   2,  INF, INF ]
  1 [  4,   0,   1,   5,  INF ]
  2 [  2,   1,   0,   8,  10  ]
  3 [ INF,  5,   8,   0,   2  ]
  4 [ INF, INF,  10,  2,   0  ]
```

维护三个一维辅助数组：
- `isJoin[v]`：顶点 $v$ 是否已并入生成树（`true` 或 `false`）；
- `lowcost[v]`：顶点 $v$ 到当前生成树顶点集合的最短横跨边权（已并入则置为 0）；
- `parent[v]`：顶点 $v$ 对应横跨边在树中的连接母节点。

从顶点 $0$ 出发，初始化：`isJoin[0]=true, isJoin[1..4]=false`；
初始 `lowcost = [0, 4, 2, INF, INF]`，`parent = [-1, 0, 0, -1, -1]`。

| 轮次 | 候选节点扫描（查未加入点的最小 `lowcost`） | 决策选入顶点与边 | 权值 | 状态更新（利用新入节点松弛其他各点的 `lowcost`） | 轮末 `lowcost[]` 数组状态 | 轮末 `parent[]` 数组 |
| :---: | :--- | :---: | :---: | :--- | :--- | :--- |
| **初始** | 节点 0 入树 | 顶点 0 | - | 用 0 的出边初始化 | `[0, 4, 2, INF, INF]` | `[-1, 0, 0, -1, -1]` |
| **第 1 轮** | 比较未加入点 $\{1, 2, 3, 4\}$：最小为 `lowcost[2]=2` | **并入顶点 2**<br>选中边 $(0, 2)$ | 2 | 考察 2 的出边：<br>- 到 1 权 1 < 4 $\to$ 更新 `lowcost[1]=1, parent[1]=2`<br>- 到 3 权 8 < INF $\to$ 更新 `lowcost[3]=8, parent[3]=2`<br>- 到 4 权 10 < INF $\to$ 更新 `lowcost[4]=10, parent[4]=2` | `[0, 1, 0, 8, 10]` | `[-1, 2, 0, 2, 2]` |
| **第 2 轮** | 比较未加入点 $\{1, 3, 4\}$：最小为 `lowcost[1]=1` | **并入顶点 1**<br>选中边 $(2, 1)$ | 1 | 考察 1 的出边：<br>- 到 3 权 5 < 8 $\to$ 更新 `lowcost[3]=5, parent[3]=1`<br>- 到 4 无直接边保持 10 | `[0, 0, 0, 5, 10]` | `[-1, 2, 0, 1, 2]` |
| **第 3 轮** | 比较未加入点 $\{3, 4\}$：最小为 `lowcost[3]=5` | **并入顶点 3**<br>选中边 $(1, 3)$ | 5 | 考察 3 的出边：<br>- 到 4 权 2 < 10 $\to$ 更新 `lowcost[4]=2, parent[4]=3` | `[0, 0, 0, 0, 2]` | `[-1, 2, 0, 1, 3]` |
| **第 4 轮** | 比较未加入点 $\{4\}$：最小为 `lowcost[4]=2` | **并入顶点 4**<br>选中边 $(3, 4)$ | 2 | 全节点均已加入，算法终止 | `[0, 0, 0, 0, 0]` | `[-1, 2, 0, 1, 3]` |

**生成树求解结果**：
- 依次选入的树边为：$(0, 2)$、$(2, 1)$、$(1, 3)$、$(3, 4)$；
- 最小生成树总权值之和：$2 + 1 + 5 + 2 = \mathbf{10}$。

<a id="kruskal"></a>
### (4) Kruskal 算法并查集协同与复杂度精解

#### ① 算法执行流
1. 将图中的所有 $|E|$ 条边提取为结构体数组，按权值升序快速排序（耗时 $O(|E| \log |E|)$）；
2. 建立含有 $|V|$ 个独立单元素集合的**并查集（Disjoint Set / Union-Find）**；
3. 从小到大遍历每条边 $(u, v, w)$：
   - 执行并查集查找：`root_u = Find(u)`, `root_v = Find(v)`；
   - 若 `root_u != root_v`：说明两端点不在同一个连通分量，将该边纳入生成树，并执行 `Union(root_u, root_v)`；
   - 若 `root_u == root_v`：两点已经处于同一连通分量，若加入该边将闭合形成回路，**直接丢弃**；
4. 累计选足 $|V|-1$ 条边后提前 break 退出。

#### ② 复杂度定论
- 采用路径压缩与按秩合并优化的高级并查集，单次 `Find/Union` 操作的均摊时间复杂度为反阿克曼函数 **$O(\alpha(|V|))$（近乎常数级）**；
- 整个 Kruskal 算法的时间瓶颈在于**边排序**，总时间复杂度为 **$O(|E| \log |E|)$**。

### (5) 非连通图的异常检测机制

若输入的无向图原本就处于非连通状态（存在多个连通分量，图本身根本无法形成一棵包含所有顶点的生成树）：
- **Prim 算法的检测判据**：
  在循环未达到 $|V|-1$ 次之前，如果在某一轮查找未加入集合的最小边时，**所有未加入顶点的 `lowcost[v]` 均为 $\infty$**，说明当前生成树所在连通分量与其他孤立节点之间没有任何横跨边相连，算法即可断定图非连通，提前异常终止。
- **Kruskal 算法的检测判据**：
  在遍历完全部 $|E|$ 条边后，**累计并入生成树的边数仍小于 $|V| - 1$**，说明全图无法连为一体，算法断定生成树不存在。

### (6) 典型命题辨析与反例证伪

1. **反例 1：“只要连通图中有权值相同的边，它的最小生成树就一定不唯一。”**
   - **反例证伪**：错误。在上文算例 1 中，边权集合为 $\{1, 1, 2, 5\}$，虽然权值 1 重复出现，但两边分别连接不同的关键端点，生成的 MST 拓扑是唯一确定的。重复权值只是多解的必要条件，绝非充分条件。
2. **命题 2：“最小生成树中所有边权之和是唯一的，所以无论求出哪一棵 MST，各条边的权值集合在排序后都是完全一样的。”**
   - **真伪判定**：正确。不仅总权值唯一，**所有最小生成树中出现的边权升序多重集合在数学上也是严格恒等的**。
3. **反例 3：“Prim 算法的时间复杂度为 $O(|V|^2)$，所以在任何场景下其执行耗时都必然慢于 Kruskal 算法。”**
   - **反例证伪**：错误。在完全图等稠密图中，$|E| \approx \frac{|V|^2}{2}$。Kruskal 的复杂度为 $O(|E|\log |E|) = O(|V|^2 \log |V|)$，其由于边排序和并查集常数，耗时显著大于 Prim 的纯 $O(|V|^2)$。

## 3. 408 考场标准模型 vs 现代工程实现边界

| 维度 | 408 考场标准模型（学理解题口径） | 现代工程实现边界（超大规模网络架构） |
| :--- | :--- | :--- |
| **Prim 堆优化** | 教材默认以简单一维数组存储 `lowcost`，遍历扫描取最小，时间固定为 $O(\|V\|^2)$ | 引入**斐波那契堆（Fibonacci Heap）**优化后，Prim 算法时间复杂度可压缩至 **$O(\|E\| + \|V\| \log \|V\|)$**，在极度稠密图中渐进性能达理论顶峰 |
| **Kruskal 边排序** | 默认采用基于比较的快速排序 $O(\|E\| \log \|E\|)$ | 若边权均为小整数（如跳数、网络时延微秒），工业界可采用**基数排序（Radix Sort）**或计数排序，将排序耗时降至线性 $O(\|E\|)$ |
| **动态增量 MST** | 静态图一次性离线全量求解 | 在实际数据中心拓扑震荡时，运行 **动态树（Link-Cut Tree / LCT）**，支持在 $O(\log V)$ 内动态增删边并在线维护当前 MST |

## 4. 跨章节与跨学科关联

### 1. 本学科内跨章节关联
- $\to$ 关联 [树与二叉树 / 树与森林的转换](../04-tree/04-forest-conversion.md)：
  - **共同机制**：Kruskal 算法的初始状态即为一个包含 $|V|$ 棵独立单节点树的森林，每加入一条合法边即进行一次树的合并。
  - **关键差异**：森林转换强调孩子兄弟链表树形转换；Kruskal 强调连通分支并查集合并。
  - **不可直接迁移的判据**：无向生成树无天然根节点；转化为孩子兄弟二叉树必须人为指定根节点。
- $\to$ 关联 [单源最短路径（Dijkstra）](04-shortest-path.md)：
  - **共同机制**：Prim 算法与 Dijkstra 算法的代码框架高度同构，均采用辅助数组记录最优值，每轮选最小入树并松弛邻居。
  - **关键差异**：Prim 的 `lowcost[v]` 记录顶点 $v$ 到**生成树集合 $U$ 的最近单边距离**；Dijkstra 的 `dist[v]` 记录顶点 $v$ 到**源点 $s$ 的整条路径累加距离**。
  - **不可直接迁移的判据**：MST 只保证全网总权值最小，不能保证任意两点间的单条路径距离最短；最短路径树只保证源点到各点最短，总权值之和往往大于 MST。

### 2. 跨学科协同关联
- $\to$ 关联 [计算机网络 / 数据链路层以太网交换机与生成树协议（STP）](../../04-cn/03-datalink/03-mac-and-ethernet.md)：
  - **共同机制**：交换机为了防止冗余链路引发广播风暴，必须在二层物理网状链路中破环，其计算的正是以交换机优先级和链路开销为权值的生成树。
  - **关键差异**：算法课在单机内存中集中式运行全局 Prim/Kruskal；STP（IEEE 802.1D）是交换机之间通过周期性收发 BPDU 报文进行的**完全分布式异步收敛算法**。
  - **不可直接迁移的判据**：STP 阻塞端口不代表物理光纤拔除，仅逻辑丢弃普通数据帧，保留控制协议交互。

## 5. 核心考点自查清单与闭环判据

1. **算法选型铁律**：
   - 稠密图（边多） $\implies$ **Prim 算法**（开销受 $|V|^2$ 控制，与边数无关）；
   - 稀疏图（边少） $\implies$ **Kruskal 算法**（开销受 $|E|\log |E|$ 控制）。
2. **唯一性充要判据**：
   - 非树边权值**严格大于**其在树中所对应回路的最大边权。
3. **拓扑属性基准**：
   - 任意包含 $n$ 个顶点的连通图，其生成树必有且仅有 $n-1$ 条边；
   - 最小生成树的总权值之和绝对唯一。
