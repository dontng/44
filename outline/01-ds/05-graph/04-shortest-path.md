## 2. 核心机理与五步推演

### (1) 最短路径的子结构最优性与松弛操作（Relaxation）

- **最优子结构定理**：
  若从源点 $s$ 到终点 $t$ 的某条最短路径途经中间节点 $u$，则该路径中从 $s$ 到 $u$ 的前缀子路径，必定也是从 $s$ 到 $u$ 的全局最短路径。
- **松弛方程（Relaxation）**：
  考察任意一条有向边 $(u, v)$，若借道 $u$ 前往 $v$ 的累计距离比已知的到 $v$ 的最短估计更小，则立即刷新距离并更新前驱指针：
  ```c
  if (dist[u] != INF && dist[u] + weight(u, v) < dist[v]) {
      dist[v] = dist[u] + weight(u, v);
      path[v] = u;    // 更新 v 的前驱节点为 u
  }
  ```
  *(注：必须加入 `dist[u] != INF` 的边界检查，防止数值溢出产生伪负数)*。

### (2) Dijkstra 算法：贪心策略与单源求解

#### ① 运行机理与三级状态数组
维护三个数组：
- `final[v]`：布尔值，指示源点到顶点 $v$ 的全局最短路径是否已确定收敛（加入集合 $S$）；
- `dist[v]`：记录当前从源点 $s$ 到顶点 $v$ 的最短估计距离；
- `path[v]`：记录最短路径上顶点 $v$ 的直接前驱顶点编号（用于倒推重构完整路径）。

#### ② 5 顶点无向/有向带权图 Dijkstra 算法执行轨迹追踪表

考虑 5 顶点有向带权图 $V = \{0, 1, 2, 3, 4\}$，以 **0 号顶点为源点**：
- 边集及权值：$(0, 1)=10, (0, 4)=5, (1, 2)=1, (1, 4)=2, (4, 1)=3, (4, 2)=9, (4, 3)=2, (3, 2)=6, (2, 3)=4$。

```
初始状态:
final = [ true, false, false, false, false ]
dist  = [  0,    10,    INF,   INF,    5   ]
path  = [ -1,     0,     -1,    -1,    0   ]
```

| 轮次 | 候选节点扫描（查 `!final[v]` 的最小 `dist`） | 锁定入集顶点 $u$ | 确定的最短距离 | 依据 $u$ 的出边执行松弛操作 | 轮末 `dist[]` 数组 | 轮末 `path[]` 数组 |
| :---: | :--- | :---: | :---: | :--- | :--- | :--- |
| **第 1 轮** | 未确定点中最小为 `dist[4] = 5` | **顶点 4** | 5 | 考察 4 的出边：<br>- $(4, 1)=3 \implies 5+3=8 < 10 \to \text{dist}[1]=8, \text{path}[1]=4$<br>- $(4, 2)=9 \implies 5+9=14 < \text{INF} \to \text{dist}[2]=14, \text{path}[2]=4$<br>- $(4, 3)=2 \implies 5+2=7 < \text{INF} \to \text{dist}[3]=7, \text{path}[3]=4$ | `[0, 8, 14, 7, 5]` | `[-1, 4, 4, 4, 0]` |
| **第 2 轮** | 未确定点 $\{1, 2, 3\}$ 中最小为 `dist[3] = 7` | **顶点 3** | 7 | 考察 3 的出边：<br>- $(3, 2)=6 \implies 7+6=13 < 14 \to \text{dist}[2]=13, \text{path}[2]=3$ | `[0, 8, 13, 7, 5]` | `[-1, 4, 3, 4, 0]` |
| **第 3 轮** | 未确定点 $\{1, 2\}$ 中最小为 `dist[1] = 8` | **顶点 1** | 8 | 考察 1 的出边：<br>- $(1, 2)=1 \implies 8+1=9 < 13 \to \text{dist}[2]=9, \text{path}[2]=1$ | `[0, 8, 9, 7, 5]` | `[-1, 4, 1, 4, 0]` |
| **第 4 轮** | 未确定点 $\{2\}$ 中最小为 `dist[2] = 9` | **顶点 2** | 9 | 考察 2 的出边：<br>- $(2, 3)=4 \implies 9+4=13 > 7$（不更新） | `[0, 8, 9, 7, 5]` | `[-1, 4, 1, 4, 0]` |

**最终最短路径倒推重构**：
- 到顶点 2 的最短路径：从 $2$ 查 `path[2]=1`，从 $1$ 查 `path[1]=4`，从 $4$ 查 `path[4]=0`，逆序翻转得到完整路径：**$0 \to 4 \to 1 \to 2$**，最短长度为 **9**。

### (3) Dijkstra 算法在负权边下的真实表现（失效机理与反例）

- **贪心锁定的物理假设**：
  Dijkstra 能够将 `dist[u]` 锁入集合 $S$ 且后续绝不复查的前提是：**边权全为非负数**。后续任何未确定的迂回路径其长度必然单调递增，绝不可能反超变短。
- **负权边出现时的两种分化表现**：

**【情况 1：存在负权边，但 Dijkstra 恰巧输出正确结果】**
- 拓扑：$S \to A = 2, \quad S \to B = 5, \quad A \to B = -1$。
- 执行流：
  1. 初始 `dist[A]=2, dist[B]=5`。锁定 $A$；
  2. 用 $A$ 松弛 $B$：$2 + (-1) = 1 < 5 \to \text{dist}[B] = 1$；
  3. 锁定 $B$。
- 最终结果 `dist[A]=2, dist[B]=1`，与真实最短路径完全吻合！
- **结论**：不能表述为“在含负权边的图上 Dijkstra 绝对必定算错”，而是**不能保证正确性（贪心前提被破坏，算法失效）**。

**【情况 2：经典失效反例（Dijkstra 彻底算错）】**
- 拓扑：$S \to A = 2, \quad S \to B = 5, \quad B \to A = -4$。
- 真实最短路径：$S \to B \to A$，距离为 $5 + (-4) = \mathbf{1}$。
- **Dijkstra 错误执行流**：
  1. 初始扫描未访问点：`dist[A]=2, dist[B]=5`；
  2. 贪心锁定较小者：**将顶点 $A$ 标记为 `final[A] = true`，将其最短路径永久锁定为 2**；
  3. 下一轮锁定顶点 $B$（`dist[B] = 5`）；
  4. 考察 $B$ 的出边 $(B, A)$：虽然 $5 + (-4) = 1 < 2$，但由于 **$A$ 已经出队锁定，算法绝不再度松弛更新已被收录的顶点 $A$**！
  5. 最终输出 `dist[A] = 2`（错误！正确值为 1）。

### (4) 最短路径树（SPT）与最短路径图的严格界定

- **最短路径树（Shortest Path Tree, SPT）**：
  若源点到每个可达顶点的最短路径唯一，或者在存在多条等长最短路径时每个节点仅记录单一的前驱指针 `path[v]`，则从源点出发经由这组前驱边展开的子图，构成一棵**以源点为根的最短路径树（包含 $|V|-1$ 条边且无环）**。
- **最短路径图（DAG）**：
  若将从源点出发到达各顶点的**所有等长最短路径全部保留并取并集**，所构成的子图是一个**有向无环图（DAG）**，而非单一树形。

### (5) Floyd 算法：全源动态规划与外层循环必然性

#### ① 状态转移方程与物理意义
定义 $A^{(k)}[i][j]$ 为：**仅允许使用顶点集合 $\{0, 1, \dots, k\}$ 作为中继候选跳板时，从顶点 $i$ 到顶点 $j$ 的最短路径长度**。
$$A^{(k)}[i][j] = \min\Big( A^{(k-1)}[i][j], \quad A^{(k-1)}[i][k] + A^{(k-1)}[k][j] \Big)$$

#### ② 为什么中继节点 $k$ 必须置于最外层循环？
```c
for (int k = 0; k < n; k++) {          // 【阶段推进】中继节点 k 必须在最外层
    for (int i = 0; i < n; i++) {      // 起点
        for (int j = 0; j < n; j++) {  // 终点
            if (A[i][k] + A[k][j] < A[i][j]) {
                A[i][j] = A[i][k] + A[k][j];
                path[i][j] = k;        // 记录中继节点
            }
        }
    }
}
```
- **动态规划阶段依赖**：
  外层循环 $k$ 代表动态规划的“阶段”。每完成一轮外层 $k$ 循环，代表允许借道的中继节点集合从 $\{0 \dots k-1\}$ 扩充到了 $\{0 \dots k\}$。
  若将 $k$ 置于内层，意味着在尝试中继时，其他节点对的最优子路径尚未形成阶段收敛，状态依赖严重倒置，导致算出的路径并非全局最优。

#### ③ 4 顶点图 Floyd 算法矩阵迭代全流程追踪

考虑 4 顶点带权有向图 $V = \{0, 1, 2, 3\}$：
初始邻接矩阵 $A^{(-1)}$：
```
       0    1    2    3
  0 [  0,   5,  INF,  7 ]
  1 [ INF,  0,   4,   2 ]
  2 [  3,  INF,  0,   1 ]
  3 [ INF, INF, INF,  0 ]
```

- **第 1 阶段（允许借道 0，即 $k = 0$）**：
  考察能否通过 0 缩短其他路径。由于入 0 的边只有 $(2, 0)=3$：
  - $A[2][1] = \min(\text{INF}, A[2][0] + A[0][1]) = \min(\text{INF}, 3+5) = \mathbf{8}$
  - $A[2][3] = \min(1, A[2][0] + A[0][3]) = \min(1, 3+7) = 1$
  其余不变，生成矩阵 $A^{(0)}$。
- **第 2 阶段（允许借道 0 和 1，即 $k = 1$）**：
  考察能否借道 1：出边有 $(1, 2)=4, (1, 3)=2$。
  - $A[0][2] = \min(\text{INF}, A[0][1] + A[1][2]) = \min(\text{INF}, 5+4) = \mathbf{9}$
  - $A[0][3] = \min(7, A[0][1] + A[1][3]) = \min(7, 5+2) = 7$
  - $A[2][2] = \min(0, A[2][1] + A[1][2]) = \min(0, 8+4) = 0$
  其余更新生成矩阵 $A^{(1)}$。
- **第 3 阶段（$k=2$）**：可由 2 中转，新增 $A[1][0]=4+3=7$；例如 $A[0][3]=\min(7,9+1)=7$ 保持不变。
- **第 4 阶段（$k=3$）**：顶点 3 没有指向其他顶点的可达边，不会缩短其他点对距离。四个阶段完成后停止。

| 阶段 | 第 0 行 | 第 1 行 | 第 2 行 | 第 3 行 |
| :---: | :--- | :--- | :--- | :--- |
| $k=0$ | `[0,5,INF,7]` | `[INF,0,4,2]` | `[3,8,0,1]` | `[INF,INF,INF,0]` |
| $k=1$ | `[0,5,9,7]` | `[INF,0,4,2]` | `[3,8,0,1]` | `[INF,INF,INF,0]` |
| $k=2$ | `[0,5,9,7]` | `[7,0,4,2]` | `[3,8,0,1]` | `[INF,INF,INF,0]` |
| $k=3$（最终） | `[0,5,9,7]` | `[7,0,4,2]` | `[3,8,0,1]` | `[INF,INF,INF,0]` |

**路径与停止判定**：从 1 到 0 的最短路为 $1\to2\to0$，长度 7；从 0 到 3 的直接边长 7 与经 1 的路径 $0\to1\to3$ 同长，选任一条即可，不能因出现平局就覆盖成错误路径。所有对角线仍为 0，本例没有负权回路；实现中先检查两个子路径有限，再做加法，避免整数 INF 溢出。

#### ④ 负权回路与 Floyd 检测
- Floyd 算法**完全允许边权为负数**（能正确求解含负权边图的最短路径）；
- **致命限制**：图中绝不能存在**总权重为负数的回路（负权环）**。若存在负权环，绕环旋转一圈距离就会无底线减小，导致最短路径趋于 $-\infty$；
- **负环检测铁律**：Floyd 运行结束后，检查矩阵主对角线：
  $$\mathbf{若存在某个顶点 } i \mathbf{ 满足 } A[i][i] < 0 \iff \mathbf{图中必定存在经过顶点 } i \mathbf{ 的负权回路！}$$

### (5) 典型反例证伪（常见认知陷阱）

1. **反例 1：“只要图中包含负权边，Dijkstra 算法计算出的所有顶点的最短路径就一定全错。”**
   - **反例证伪**：错误。若负权边处于较深的汇聚层，或者负权值不足以逆转已锁定的拓扑顺序，Dijkstra 完全可能侥幸算出正确结果。科学表述应为：Dijkstra 算法在含负权边图上无法保证贪心策略的正确性。
2. **反例 2：“Floyd 算法三重循环中，外层控制起点 $i$，中层控制终点 $j$，内层控制中继点 $k$ 也能算出正确结果。”**
   - **反例证伪**：错误。若中继 $k$ 放在最内层，当计算 $A[i][j]$ 尝试中继 $k$ 时，$A[i][k]$ 和 $A[k][j]$ 自身可能还没尝试过后续的中继点进行松弛，破坏了动态规划的拓扑无后效性。
3. **反例 3：“Dijkstra 算法求出的最短路径树（SPT）和 Prim 算法求出的最小生成树（MST）在任何加权图上都是同一棵树。”**
   - **反例证伪**：错误。考虑三角形图：$(A, B)=3, (A, C)=3, (B, C)=1$。
     - Prim 求出的 MST 边集为 $\{(B, C), (A, B)\}$，总权值为 4；
     - 以 $A$ 为源点求出的 SPT 边集必须为 $\{(A, B), (A, C)\}$，总权值为 6。两者拓扑结构完全不同。

## 3. 408 考场标准模型 vs 现代工程实现边界

| 维度 | 408 考场标准模型（学理解题口径） | 现代工程实现边界（工业级导航与网络） |
| :--- | :--- | :--- |
| **单源负权图求解** | 考查 Dijkstra 失效与负权环不可达概念 | 采用 **SPFA（队列优化版 Bellman-Ford）**，允许节点重复入队多次松弛，完全兼容负权图并可在 $O(|V||E|)$ 检出负环 |
| **全源求解选型** | 稠密与稀疏图均在 Floyd 与重复 Dijkstra 间权衡 | 稀疏负权图采用 **Johnson 算法**：利用势能技术（Reweighting）将所有边权修正为非负，再运行 $|V|$ 次堆优化 Dijkstra，时间压至 $O(|V||E| + |V|^2\log |V|)$ |
| **大规模地图导航** | 经典全图盲目 Dijkstra 搜索 | 真实地图应用（如高德/百度地图）采用 **A\* 启发式搜索算法**或 **CH（Contraction Hierarchies，分层收缩）**，数亿节点毫秒级导航 |

## 4. 跨章节与跨学科关联

### 1. 本学科内跨章节关联
- $\to$ 关联 [图的遍历 / 广度优先搜索 (BFS)](02-graph-traversal.md)：
  - **共同机制**：无权图上 Dijkstra 算法退化为层序推进的 BFS。
  - **关键差异**：BFS 依靠普通队列 $O(1)$ 出队；Dijkstra 在带权图上依赖小顶堆或扫描 $O(\log V)$ 挑最小。
  - **不可直接迁移的判据**：BFS 首次碰到的顶点即为最短路径（按边数计）；Dijkstra 首次被发现的顶点可能被后续更短的多跳边松弛。
- $\to$ 关联 [最小生成树（Prim 算法）](03-minimum-spanning-tree.md)：
  - **共同机制**：贪心切分集合，数组结构完全对称。
  - **关键差异**：Prim 松弛的是“到集合的单边距离”；Dijkstra 松弛的是“到源点的全路径累加距离”。
  - **不可直接迁移的判据**：最小生成树追求全局总边权最小；最短路径树追求从源点出发到各节点的单条距离最小。

### 2. 跨学科协同关联
- $\to$ 关联 [计算机网络 / 路由协议与 OSPF 算法](../../04-cn/04-network/02-routing-protocols.md)：
  - **共同机制**：OSPF（开放最短路径优先）协议路由器利用链路状态数据库（LSDB）构建全局拓扑后，运行 Dijkstra 算法计算路由表。
  - **关键差异**：算法题侧重静态顶点路径推演；网络 OSPF 路由器不仅计算到各主机的最短路，还要在路径等长时实现**等价多路径负载均衡（ECMP）**。
  - **不可直接迁移的判据**：网络层路由存在分层划分（OSPF Area 区域化），骨干区与非骨干区之间只通告汇总路由，不运行跨区域的全图完整 Dijkstra。

## 5. 核心考点自查清单与闭环判据

1. **Dijkstra 核心判据**：
   - 必须非负权边；若有负权边，贪心锁定失效；
   - 数组实现 $O(|V|^2)$，最小堆优化 $O(|E|\log |V|)$。
2. **Floyd 算法死律**：
   - 中继阶段 $k$ 严格在最外层；时间复杂度恒为 $O(|V|^3)$；
   - 负环检测：若运行后出现对角线 $A[i][i] < 0$，必含负权回路。
3. **路径倒推法则**：
   - 终点 $t \implies \text{path}[t] \implies \text{path}[\text{path}[t]] \dots \implies \text{源点 } s$。
