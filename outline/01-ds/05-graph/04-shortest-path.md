## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 最短路径的子结构最优性与松弛操作（Relaxation）
- **物理基石**：
  如果从源点 $s$ 到终点 $t$ 的最短路径途经中间节点 $u$，那么这条路径中从 $s$ 到 $u$ 的子路径，必定也是从 $s$ 到 $u$ 的全局最短路径（最优子结构性质）。
- **松弛方程（Relaxation）**：
  对于任意一条有向边 $(u, v)$，若发现借道 $u$ 前往 $v$ 的累计距离比已知的到 $v$ 的距离更短，则立即刷新并缩减估计值：
  $$\text{dist}[v] = \min(\text{dist}[v], \, \text{dist}[u] + \text{weight}(u, v))$$
  所有最短路径算法的本质，都是对图中各边进行特定时序和拓扑顺序的松弛操作。

---

### (2) Dijkstra 算法：贪心策略与单源求解
- **执行逻辑**：
  1. 维护集合 $S$，记录已确定全局最短路径的顶点。
  2. 每一轮在所有尚未确定最短路径的顶点（$V - S$）中，**挑选出当前 $\text{dist}$ 估计值最小的顶点 $u$**，将其永久并入集合 $S$。
  3. 以新确定的顶点 $u$ 为中继跳板，对从 $u$ 出发的所有出边 $(u, v)$ 进行松弛，更新未访问邻居的 $\text{dist}$ 值。
  4. 循环 $|V|$ 轮后，全图所有顶点的最短路径全部收敛。
- **时间复杂度**：
  - 数组线性扫描实现：**$O(|V|^2)$**。
  - 优先队列（小顶堆）优化实现：**$O(|E|\log |V|)$**。

#### 为什么 Dijkstra 绝对不能处理含负权边的图？（深刻物理剖析）
- **贪心单调性假设**：
  Dijkstra 算法能够将顶点 $u$ 放入集合 $S$ 并锁定其路径长度的物理前提是：**后续从 $s$ 经过其他尚未确定的顶点走弯路到达 $u$ 的路径，长度只会越来越长，绝不可能反而变短**。
- **物理崩溃**：
  若网络中存在一条负权边（例如某条边的权值为 $-50$），某条看似绕远路的迂回分支，可能因为吸收了这个巨大负权而使得总路径长度骤减，从而推翻之前早已被锁定进集合 $S$ 的顶点结论。Dijkstra 算法缺乏“悔棋修正”机制，因此在负权图上结论必错。

### (3) Floyd 算法：动态规划与全源全图求解
- **核心逻辑**：
  Floyd-Warshall 算法通过三维动态规划解决所有顶点对 $(i, j)$ 之间的最短路径。
  令 $A^{(k)}[i][j]$ 表示**仅允许使用前 $k$ 个顶点 $\{v_1, v_2, \dots, v_k\}$ 作为中继跳板**时，从 $i$ 到 $j$ 的最短路径长度。
- **状态转移方程**：
  $$A^{(k)}[i][j] = \min\Big( A^{(k-1)}[i][j], \quad A^{(k-1)}[i][k] + A^{(k-1)}[k][j] \Big)$$

#### 为什么中继节点 $k$ 必须置于最外层循环？
```c
// 严禁颠倒循环顺序！
for (int k = 0; k < n; k++) {          // k 必须在外层：中继阶段递推
    for (int i = 0; i < n; i++) {      // 起点
        for (int j = 0; j < n; j++) {  // 终点
            if (A[i][k] + A[k][j] < A[i][j])
                A[i][j] = A[i][k] + A[k][j];
        }
    }
}
```
- **物理必然性**：
  外层循环 $k$ 代表动态规划的“阶段（Stage）”。每完成一次外层 $k$ 循环，意味着系统状态成功递推到了“允许中继候选集扩大为包含前 $k$ 个节点”的新阶段。若将 $k$ 放在内层，意味着在计算某对 $(i, j)$ 时强行尝试所有中继，但此时其他节点对的最优子路径尚未形成，状态依赖彻底乱序，动态规划全面崩溃。

- **负权与回路特性**：
  Floyd 算法**能够正确处理含负权边**的图，但**绝对不能处理包含“负权回路（Negative Cycle）”**的图（因为沿负权环无限绕圈会导致路径趋于 $-\infty$）。

## 3. 本学科内跨章节系统性关联

```
                     ┌──────────────────────────────┐
                     │ 数据结构: 最短路径求解算法     │
                     └──────────────┬───────────────┘
                                    │ 网络拓扑路由计算
                                    ▼
┌──────────────────────────────┐         ┌──────────────────────────────┐
│ 数据结构: 广度优先搜索 (BFS)  │         │ 计网: 网络层路由协议 OSPF    │
│  - 无权图退化为单源最短路径  │ ◄────── │  - 链路状态数据库 (LSDB)     │
│  - 时间复杂度 O(|V| + |E|)   │         │  - 路由器以自身为源运行 SPF  │
└──────────────────────────────┘         └──────────────────────────────┘
```

1. **与广度优先遍历（BFS）的内在收敛**：
   - 当图的所有边权值严格相等（即无权图，或所有权值均为 1）时，Dijkstra 算法退化为纯粹的 **BFS 广度优先搜索**。
   - BFS 的队列天然保证了出队节点距离源点的步数单调递增，时间复杂度从 $O(|V|^2)$ 骤降至 **$O(|V| + |E|)$**。
2. **与计算机网络 OSPF 内部网关协议的现实映射**：
   - 计算机网络中的 OSPF 协议，路由器通过洪泛 LSA 建立完整的链路状态数据库（LSDB）后，正是**以自身为源点，在全网拓扑图上运行 Dijkstra 算法**，独立构建出到达全网各子网的最短路径树（SPT）。

## 4. 闭环决策模型与核心认知结论

### (1) 最短路径算法横向对比选型表

| 场景需求与图特征 | 最佳算法选型 | 时间复杂度 | 空间复杂度 | 负权边支持能力 |
| :--- | :--- | :---: | :---: | :--- |
| **无权图单源最短路径** | **BFS (广度优先)** | $O(\|V\| + \|E\|)$ | $O(\|V\|)$ | 无权（不可用） |
| **非负权单源最短路径** | **Dijkstra 算法** | $O(\|V\|^2)$ 或 $O(\|E\|\log \|V\|)$ | $O(\|V\|)$ | **不支持**（计算必错） |
| **全源最短路径 (稠密图)** | **Floyd 算法** | $O(\|V\|^3)$ | $O(\|V\|^2)$ | **支持**（但不能有负环） |
| **全源最短路径 (稀疏图)** | **重复 $\|V\|$ 次 Dijkstra** | $O(\|V\| \cdot \|E\|\log \|V\|)$ | $O(\|V\| + \|E\|)$ | **不支持**负权边 |

### (2) 考场定性闭环判据
1. **只要图中有负权边** $\to$ **严禁选择 Dijkstra 算法**！
2. **Floyd 算法执行完后，如何检测图中是否存在负权回路？**
   - 检查邻接矩阵对角线元素：**若存在某个 $i$ 使得 $A[i][i] < 0$**，说明从 $i$ 出发回到 $i$ 自身存在负权回路。
3. **连通图的单源最短路径构成的子图** $\to$ 必定是一棵**最短路径生成树（SPT）**，其包含 $|V|-1$ 条边且无环。
