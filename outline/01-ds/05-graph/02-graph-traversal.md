## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 图遍历的核心困境：环路与无限递归
* **物理矛盾**：树有天然的层级与父子方向（从根单向向下），绝无环路；而图是任意顶点之间皆可相连的网状拓扑。若直接像树一样递归遍历，算法会在环路中陷入无限死循环。
* **物理防线**：必须设立一个大小为 $|V|$ 的全局状态标记数组 `bool visited[]`。一旦某个顶点被访问，立刻置为 `true`。每次向邻接点推进前，必须先检查 `!visited[w]`。

### (2) DFS vs BFS：两种截然不同的搜索空间展开方式

| 算法维度 | 深度优先搜索（DFS） | 广度优先搜索（BFS） |
| :--- | :--- | :--- |
| **搜索策略** | 一条路走到黑，不撞南墙不回头（先深后广） | 以源点为中心，像水波纹一样层层向外扩散（先近后远） |
| **底层支撑结构** | **系统调用栈（递归栈）** | **先进先出队列（Queue）** |
| **树结构映射** | 等价于二叉树的**先序遍历** | 等价于二叉树的**层次遍历** |
| **时间复杂度** | 邻接表：$O(|V| + |E|)$；邻接矩阵：$O(|V|^2)$ | 邻接表：$O(|V| + |E|)$；邻接矩阵：$O(|V|^2)$ |
| **空间复杂度** | 最坏 $O(|V|)$（图退化为单链时递归栈深度） | 最坏 $O(|V|)$（极端星型图时队列容纳所有邻居） |
| **核心衍生能力** | 拓扑排序回溯、强连通分量、深度路径搜索 | **无权图的单源最短路径**（第一层到达必为最短步数） |

### (3) 图的连通性与“外层循环计数器”
* **非连通图的遍历机制**：
  ```c
  void TraverseGraph(Graph G) {
      for (int i = 0; i < G.vexnum; i++) visited[i] = false;
      int component_count = 0;
      for (int i = 0; i < G.vexnum; i++) {
          if (!visited[i]) {
              DFS(G, i); // 或 BFS(G, i)
              component_count++; // 每次触发一次完整遍历，说明发现了一个新的连通块
          }
      }
  }
  ```
* **物理结论**：**外层 `for` 循环内部调用 DFS/BFS 的总次数，严格等于该无向图的连通分量个数**！若调用次数为 1，说明该无向图是完全连通图。

### (4) 欧拉路径与欧拉回路判定（408 大题高频题眼）
* **欧拉回路（Eulerian Circuit）**：经过图中每一条边恰好一次且回到起点的闭合回路。
* **欧拉路径（Eulerian Path / EL 路径）**：经过图中每一条边恰好一次的开路径（起点和终点不同）。
* **无向连通图存在 EL 路径的充要条件（2021-41 大题核心）**：
  1. 图必须是**连通图**（除度数为 0 的孤立点外，非零度顶点同属一个连通分量）；
  2. 奇数度顶点的个数必须严格为 **0 或 2**：
     * **若奇数度顶点数为 0**：存在欧拉回路（任意顶点皆可作为起点和终点）；
     * **若奇数度顶点数为 2**：存在欧拉路径，且这两个奇数度顶点必定**分别作为路径的起点和终点**。

## 4. 闭环判定模型与核心认知结论

* **图的连通性判定**：从顶点 $v$ 出发调用一次 DFS，若全局访问计数 `count == |V|`，则该无向图必连通。
* **欧拉路径（EL 路径）两步判决法**：
  1. 先跑一次 DFS/BFS 验证连通性（`count == |V|`）；
  2. 统计各顶点的度数，计算度为奇数的顶点个数 $odd$：
     - 若 $odd == 0$ 或 $odd == 2 \implies$ 存在 EL 路径；
     - 其余情况 $\implies$ 不存在。
