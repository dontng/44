## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 二叉树的三大基本计算公式（408 必考物理守恒）

#### 定理一：叶子节点与度为 2 节点的守恒（$n_0 = n_2 + 1$）
* **物理推导**：
  * 设总节点数为 $n$。树中每个分支（边）都由父节点向下引出，因此总分支数 $B = n_1 \times 1 + n_2 \times 2$；
  * 另一方面，除根节点外，每个节点上方都连着一条唯一的入边，因此总分支数 $B = n - 1$；
  * 联立：$n - 1 = n_1 + 2n_2$。又因为总节点数 $n = n_0 + n_1 + n_2$；
  * 代入消去 $n_1$，立刻得出铁律：
    $$n_0 = n_2 + 1$$
* **核心价值**：**任何二叉树中，度为 0 的叶子节点数永远比度为 2 的分支节点数恰好大 1**！这个规律与树的高度、形状完全无关。

#### 定理二：第 $k$ 层的最大节点数
* 第 $k$ 层上至多有 $2^{k-1}$ 个节点（$k \ge 1$）。

#### 定理三：深度为 $h$ 的二叉树最大节点数
* 深度为 $h$ 的二叉树至多有 $2^h - 1$ 个节点（等比数列求和：$1 + 2 + 4 + \dots + 2^{h-1} = 2^h - 1$）。

### (2) 满二叉树 vs 完全二叉树的几何形态

| 类别 | 严格定义 | 节点编号与位置特征 |
| :--- | :--- | :--- |
| **满二叉树** | 每一层的节点数都达到最大极限（共 $2^h - 1$ 个） | 叶子节点全在最底下一层，非叶节点的度必须全为 2 |
| **完全二叉树** | 深度为 $h$ 的树中，前 $h-1$ 层是满的；第 $h$ 层的节点全集中在**最左边** | 节点的编号序列（$1 \sim n$）与同等深度的满二叉树完全一一对应 |

* **完全二叉树的极佳性质**：
  1. 度为 1 的节点 $n_1$ **最多只能有 1 个或 0 个**（若 $n$ 为偶数则 $n_1 = 1$，若 $n$ 为奇数则 $n_1 = 0$）；
  2. 具有 $n$ 个节点的完全二叉树的高度为 $\lceil \log_2(n+1) \rceil$ 或 $\lfloor \log_2 n \rfloor + 1$；
  3. **天然契合顺序存储（一维数组）**：节点按层序编号直接作为数组下标，既不浪费任何数组空间，又可以通过简单的乘除运算直接定位父子关系。

### (3) 链式存储结构（二叉链表与三叉链表）
* **二叉链表**：包含 `data`、`lchild`、`rchild`。
  * **空指针数守恒定律**：在含有 $n$ 个节点的二叉链表中，共有 $2n$ 个指针域；因为只有 $n-1$ 个节点被父节点的指针指向（除根外），所以**必有 $(2n - (n - 1)) = n + 1$ 个空链域**！这 $n+1$ 个闲置的空指针正是后续**线索二叉树**建立的物理基础。
* **三叉链表**：增加一个指向父节点的指针 `parent`，方便沿树向上回溯（如并查集向上查祖先）。

## 4. 闭环判定模型与核心认知结论

* **已知度为 1 的节点数判总数**：
  * 在完全二叉树中，只要知道节点总数 $n$：
    * 若 $n$ 为偶数 $\implies n_1 = 1$（最底下左边落单一个孩子）；
    * 若 $n$ 为奇数 $\implies n_1 = 0$。
* **空指针数秒判**：$n$ 个节点的二叉链表，永远有且仅有 $n+1$ 个 `NULL` 指针。
