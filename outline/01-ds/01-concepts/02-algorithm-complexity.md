## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 渐进分析的物理本质与硬件解耦
- **物理困境**：
  - 一段算法代码在真实硬件上的执行耗时取决于 CPU 主频、流水线深度、乱序执行能力、指令集架构、编译器优化等级以及各级 Cache 命中率。直接度量“绝对毫秒数”会导致性能结论与具体硬件强绑定，无法用于通用的算法理论评价。
- **解耦机制（渐进分析）**：
  - 渐进复杂度忽略具体的机器执行周期常数与低阶项，专注衡量**当输入规模 $n \to \infty$ 时，算法核心基本操作（如比较、赋值、加减运算）执行次数的渐进增长阶数**。
  - $O(g(n))$ 刻画渐进上界，$\Omega(g(n))$ 刻画渐进下界，$\Theta(g(n))$ 刻画同阶紧确界（408 考场在未严格指明时常以大 $O$ 表示紧确渐进复杂度）。

---

### (2) 循环嵌套的四维判定法则：打破“只看上界”的思维陷阱
考场常见的严重错误是“看到内层循环条件出现 `j <= i` 就直接判定为 $O(n^2)$”。双层循环的总执行次数取决于四个维度的共同约束：
1. **外层步进速度**：是单步线性递增（`i++`），还是指数翻倍（`i *= 2`），抑或是跳跃步进。
2. **内层步长模式**：是单步递增（`j++`），还是指数翻倍（`j *= 2`），还是随外层变量跨步（`j += i`）。
3. **内层变量生命周期**：内层控制变量是在外层每轮循环开始时**重置初始化**，还是在循环外部初始化并**单调跨轮持久递增**（双指针滑动窗口）。
4. **提前终止条件**：是否存在依赖输入数据特征的提前退出机制（如 `break`、`return` 导致的最坏与最好分化）。

#### 四种典型双层循环执行轨迹对照表（取固定输入规模 $n = 8$）

| 模式类型 | 典型 C 代码结构 | $n=8$ 各轮内层执行次数轨迹 | $n=8$ 总执行次数 | 通用时间复杂度 $\Theta$ |
| :--- | :--- | :--- | :--- | :--- |
| **① 依赖型线性步进** | `for (i=1; i<=n; i++)`<br>&nbsp;&nbsp;`for (j=1; j<=i; j++) work();` | $i=1: 1$<br>$i=2: 2$<br>$i=3: 3$<br>$\dots$<br>$i=8: 8$ | $1+2+3+\dots+8 = 36$ | **$\Theta(n^2)$**<br>等差数列求和：$\frac{n(n+1)}{2}$ |
| **② 翻倍外层 + 线性内层** | `for (i=1; i<=n; i*=2)`<br>&nbsp;&nbsp;`for (j=1; j<=i; j++) work();` | $i=1: 1$<br>$i=2: 2$<br>$i=4: 4$<br>$i=8: 8$ | $1+2+4+8 = 15$ | **$\Theta(n)$**<br>等比数列求和：$2n - 1 < 2n$ |
| **③ 调和级数（筛法跨步）** | `for (i=1; i<=n; i++)`<br>&nbsp;&nbsp;`for (j=i; j<=n; j+=i) work();` | $i=1: 8$<br>$i=2: 4$<br>$i=3: 2$<br>$i=4: 2$<br>$i=5\dots 8: 1 \times 4$ | $8+4+2+2+1+1+1+1 = 20$ | **$\Theta(n\log n)$**<br>调和级数：$n \sum_{i=1}^n \frac{1}{i} \approx n \ln n$ |
| **④ 持久单调变量（双指针）** | `int j = 0;`<br>`for (i=0; i<n; i++)`<br>&nbsp;&nbsp;`while (j<n && cond(i,j)) { work(); j++; }` | $i$ 遍历 $0 \to 7$ 的全过程中，`j` 从未回退，仅单调递增至多 8 次 | 内层 `work()` 累计至多 8 次 | **$\Theta(n)$**<br>均摊分析：外层走 $n$ 步，内层总计走 $n$ 步 |

> [!TIP]
> **机理深度解析：模式 ② 为什么不是 $O(n\log n)$ 而是严格 $\Theta(n)$？**
> - 外层循环变量 $i$ 经过 $\log_2 n$ 轮翻倍：$1, 2, 4, 8, \dots, 2^k$（其中 $2^k \le n$）。
> - 很多学习者误认为“外层走了 $\log_2 n$ 轮，内层最大走到 $n$，所以是 $O(n\log n)$”。
> - 实际上，内层执行总次数为公比为 2 的等比数列求和：
>   $$T(n) = 1 + 2 + 4 + 8 + \dots + 2^k = \frac{1 \cdot (1 - 2^{k+1})}{1 - 2} = 2^{k+1} - 1 < 2n$$
> - 等比数列的核心性质是**前各项之和严格受最后一项主导**。总工作量永远被 $2n$ 截断，因此渐进增长率严格为 $\Theta(n)$。

### (3) 递归算法的时间与空间复杂度度量模型

#### 1. 递归时间复杂度：递归树展开法
递归函数的运行时间由“递归树的所有节点总工作量之和”决定。

- **单分支线性递推**：$T(n) = T(n-1) + O(1)$
  - 递归树退化为一条单链，深度为 $n$，每个节点做 $O(1)$ 工作：
    $$T(n) = T(n-1) + c = T(n-2) + 2c = \dots = T(1) + (n-1)c = \Theta(n)$$
  - 典型场景：单链表递归遍历、阶乘递归计算。
- **平衡分治递推**：$T(n) = 2T(n/2) + O(n)$
  - 递归树为高度为 $\log_2 n$ 的完全二叉树：
    - 第 0 层（根节点）：1 个节点，规模为 $n$，划分/合并工作量为 $cn$。
    - 第 1 层：2 个节点，规模为 $n/2$，每节点工作量 $c(n/2)$，本层合计 $2 \times c(n/2) = cn$。
    - 第 $k$ 层：$2^k$ 个节点，规模为 $n/2^k$，本层合计 $2^k \times c(n/2^k) = cn$。
    - 树高共 $\log_2 n + 1$ 层，每层工作量恒为 $cn$。
    - 总时间复杂度：$T(n) = cn \times (\log_2 n + 1) = \Theta(n\log n)$。
  - 典型场景：归并排序、快速排序（基准划分平衡时）。
- **非分治多分支指数爆炸**：$T(n) = T(n-1) + T(n-2) + O(1)$（斐波那契数列朴素递归）
  - 递归树每层向下以接近 2 的分支因子裂变，树高为 $n$。
  - 递归树节点总数为几何级数增长，总时间复杂度为 $\Theta(\phi^n)$（其中黄金分割比 $\phi = \frac{1+\sqrt{5}}{2} \approx 1.618$），属于指数阶爆炸。

#### 2. 递归空间复杂度：调用栈瞬时最大深度
- **核心物理准则**：
  - 递归执行在底层依赖操作系统的**函数调用栈（Call Stack）**。
  - 递归算法的辅助空间复杂度，取决于**调用栈在任意时刻同时存在的活动栈帧（Stack Frame）数量的峰值**，即**递归调用树从根节点到任意叶子节点的最大瞬时路径深度**，**绝非**递归调用的总次数！
  - 公式：
    $$\text{递归空间复杂度} = \max(\text{调用栈瞬时深度}) \times \text{单栈帧局部变量空间} + \text{显式辅助堆空间}$$

- **典型结构对比**：
  1. **二叉树先序遍历递归**：
     - 虽然遍历了二叉树的全部 $n$ 个节点（时间为 $\Theta(n)$），但在任意瞬间，调用栈中仅保存从根节点到当前正在访问节点的单条祖先路径。
     - 最好情况（平衡完全二叉树）：树高 $h = \lceil \log_2(n+1) \rceil$，空间复杂度为 $O(\log n)$。
     - 最坏情况（单支倾斜退化为链表）：树高 $h = n$，空间复杂度为 $O(n)$。
  2. **归并排序（Merge Sort）**：
     - 递归分解调用栈最大深度为 $\lceil \log_2 n \rceil$，即栈空间为 $O(\log n)$。
     - 但归并操作需要在堆上显式开辟一个用于合并有序序列的辅助数组，其大小为 $n$。
     - 总空间复杂度取两者支配项：$\max(O(\log n), O(n)) = O(n)$。
  3. **快速排序（Quick Sort）**：
     - 原地划分，无需全局辅助数组。
     - 空间完全由递归栈深度决定：最好情况（基准每次平分）栈深 $O(\log n)$；最坏情况（已正序或逆序且每次取首尾为基准）退化为单支链，栈深 $O(n)$。

## 4. 闭环判定模型与核心认知结论

### (1) 常见复杂度阶数单调增长序列
$$O(1) < O(\log n) < O(\sqrt{n}) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$$

### (2) 闭环决策判定表

| 场景特征 | 核心观察点 | 闭环判定推论 |
| :--- | :--- | :--- |
| **单重循环** | 步长是加减常量（`i++`, `i+=k`） | **$O(n)$** |
| **单重循环** | 步长是乘除常量（`i*=2`, `i/=2`） | **$O(\log n)$** |
| **单重循环** | 循环条件为平方关系（`i*i <= n`） | **$O(\sqrt{n})$** |
| **双重嵌套** | 外层线性步进，内层从 $1$ 线性走到 $i$ | **$O(n^2)$**（等差求和 $\frac{n^2}{2}$） |
| **双重嵌套** | 外层翻倍步进，内层从 $1$ 线性走到 $i$ | **$O(n)$**（等比求和末项主导 $< 2n$） |
| **双重嵌套** | 内层步长由外层变量决定（`j+=i`，从 $i$ 到 $n$） | **$O(n\log n)$**（调和级数求和） |
| **双重嵌套** | 内层变量跨外层单调递增不重置（滑动窗口） | **$O(n)$**（均摊分析每个元素进出一次） |
| **分治递归** | 每次平分规模为 $2$ 半，合并耗费 $O(n)$ | **$O(n\log n)$**（递归树高 $\log n$，每层 $n$） |
| **递归空间** | 递归树最大深度为 $h$，无额外全局大数组 | **$O(h)$**（只与瞬时调用栈深度有关） |
