## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 栈的物理本质：嵌套与回溯的唯一天然宿主
* **物理矛盾**：在函数递归调用、语法括号匹配、迷宫路径探索中，问题的子任务是“后发生的必须先解决，先发生的问题必须等子任务收工后才能恢复现场”。
* **LIFO（后进先出）机制**：只允许在一端（栈顶 `top`）进行插入（`push`）与删除（`pop`）。栈底 `bottom` 永远固定。

### (2) 卡特兰数（Catalan Number）与出栈合法性判定（408 必考数学定律）
* **定理**：$n$ 个不同元素依次进栈，所有可能的不同出栈序列总数为卡特兰数 $C_n$：
  $$C_n = \frac{1}{n+1} \binom{2n}{n} = \frac{(2n)!}{(n+1)! n!}$$
  * $n=1 \implies C_1 = 1$
  * $n=2 \implies C_2 = 2$
  * $n=3 \implies C_3 = 5$
  * $n=4 \implies C_4 = 14$

#### 出栈合法性秒判铁律（408 核心排错判据）
* **物理规律**：设输入序列为 $1, 2, 3 \dots n$。对于任意一个输出序列，**在任何一个数后面，所有比它小的且尚未出栈的数字，出现的顺序必须严格保持“单调递减（从大到小）”！**
* **反例秒杀**：
  * 若某出栈序列前几位是 `... 4, 1, 2 ...`；
  * 数字 4 已经出栈，此时比 4 小的 1、2 必然还在栈中（因为 4 出栈前 1、2 必已入栈）；
  * 那么它们出栈的顺序必须是 `2` 先出、`1` 后出；序列中却出现了 `1` 在 `2` 前面，**物理上绝不可能，当场判非法**！

### (3) 中缀表达式转后缀表达式（逆波兰式 RPN）的栈机运算
* **人类中缀**：`A + B * (C - D)`
* **计算机后缀**：`A B C D - * +`（操作符永远在两个操作数后面，彻底摆脱括号与优先级嵌套）。
* **基于栈的转换物理流**：
  1. 遇到操作数：直接输出到后缀表达式队列；
  2. 遇到左括号 `(`：直接压入操作符栈；
  3. 遇到右括号 `)`：依次弹出栈顶操作符输出，直到碰到 `(` 为止，括号成对丢弃；
  4. 遇到普通运算符（`+ - * /`）：**若栈顶运算符优先级 $\ge$ 当前运算符，依次弹出输出**；然后将当前运算符压栈。

## 4. 闭环判定模型与核心认知结论

* **共享栈（双向栈）判满公式**：两个栈底设在数组两端（$0$ 与 $Maxsize-1$），向中间生长；**栈满的充要条件为：`top1 + 1 == top2`**。
* **非法序列秒判法**：扫描序列中的每一个数，把排在它后面、且比它小的数圈出来，检查它们是否严格降序。出现局部逆升序，立刻判定非法。
