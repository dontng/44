## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 多维数组的内存寻址模型（考纲基准计算）
- **物理约束**：物理内存（RAM）仅有一维物理线性地址。无论是二维、三维还是高维数组，在硬件层面上都必须被“展平”映射为一维连续地址空间。
- **通用二维数组形式化定义**：
  设二维数组 `A[l1..u1][l2..u2]`，行下标范围为 $[l_1, u_1]$，列下标范围为 $[l_2, u_2]$；
  - 行数：$R = u_1 - l_1 + 1$
  - 列数：$C = u_2 - l_2 + 1$
  - 每个元素占用 $L$ 字节，首元素起始地址为 $\text{LOC}(l_1, l_2)$。

#### 1. 行优先存储（Row-Major Order，C/C++ 标准）
- 先存第一行，再存第二行，依此类推。
- 欲求元素 $A[i][j]$ 的物理地址：前面已经存满了 $i - l_1$ 个完整的整行（每行含 $C$ 个元素），且在当前第 $i$ 行内前面有 $j - l_2$ 个元素：
  $$\text{LOC}(i, j) = \text{LOC}(l_1, l_2) + \left[ (i - l_1) \times C + (j - l_2) \right] \times L$$

#### 2. 列优先存储（Column-Major Order，Fortran/MATLAB 标准）
- 先存第一列，再存第二列，依此类推。
- 欲求元素 $A[i][j]$ 的物理地址：前面已经存满了 $j - l_2$ 个完整的整列（每列含 $R$ 个元素），且在当前第 $j$ 列内前面有 $i - l_1$ 个元素：
  $$\text{LOC}(i, j) = \text{LOC}(l_1, l_2) + \left[ (j - l_2) \times R + (i - l_1) \right] \times L$$

#### 3. 数值对比演算（0 基础 vs 1 基础）
设数组规模为 4 行 5 列（$R=4, C=5$），每个元素占 4 字节（$L=4$），基地址 $\text{LOC} = 1000$。
- **情况 A（1 基础下标 `A[1..4][1..5]`）**：求 $A[3][4]$ 的地址
  - 行优先：$\text{LOC}(3, 4) = 1000 + [(3 - 1) \times 5 + (4 - 1)] \times 4 = 1000 + [10 + 3] \times 4 = 1052$
  - 列优先：$\text{LOC}(3, 4) = 1000 + [(4 - 1) \times 4 + (3 - 1)] \times 4 = 1000 + [12 + 2] \times 4 = 1056$
- **情况 B（0 基础下标 `A[0..3][0..4]`）**：同一物理位置对应 `A[2][3]`
  - 行优先：$\text{LOC}(2, 3) = 1000 + [(2 - 0) \times 5 + (3 - 0)] \times 4 = 1000 + [10 + 3] \times 4 = 1052$
  - 无论下标体系从 0 还是从 1 开始，代入通用公式均精准一致。

### (2) 对称矩阵与三角矩阵压缩映射推导

为消除冗余内存占用，只为有效非重复元素分配一维数组空间。
通用推导心法：**“前面已占满的几何图形（三角形或梯形）累积元素总数 ＋ 当前行列内的相对偏移行列数”**。

设矩阵为 $n$ 阶方阵（行号 $i$、列号 $j$ 均从 1 开始，$1 \le i, j \le n$），压缩目标一维数组 $B[k]$ 下标从 0 开始。

```
       下三角矩阵 (i >= j)                    上三角矩阵 (i <= j)
      列 1  2  3  4                         列 1  2  3  4
行 1 [ a              ]               行 1 [ a  b  c  d ]
行 2 [ b  c           ]               行 2 [    e  f  g ]
行 3 [ d  e  f        ]               行 3 [       h  i ]
行 4 [ g  h  i  j     ]               行 4 [          j ]
```

#### 四种排列组合推导全解

| 矩阵类型 | 排列主序 | 前驱行/列形状与元素累加 | 当前行/列内偏移 | 一维数组下标 $k$ 映射公式 ($1 \le i, j \le n$, $k$ 从 0 开始) |
| :--- | :--- | :--- | :--- | :--- |
| **下三角矩阵** | **行优先** | 前 $i-1$ 行组成等差三角形：<br>$\sum_{r=1}^{i-1} r = \frac{(i-1)i}{2}$ | 第 $i$ 行内从第 1 列到第 $j$ 列：<br>$j - 1$ | $$k = \frac{i(i-1)}{2} + (j - 1)$$ |
| **下三角矩阵** | **列优先** | 前 $j-1$ 列组成直角梯形：<br>$\frac{(2n - j + 2)(j - 1)}{2}$ | 第 $j$ 列内从第 $j$ 行到第 $i$ 行：<br>$i - j$ | $$k = \frac{(2n - j + 2)(j - 1)}{2} + (i - j)$$ |
| **上三角矩阵** | **行优先** | 前 $i-1$ 行组成直角梯形：<br>$\frac{(2n - i + 2)(i - 1)}{2}$ | 第 $i$ 行内从第 $i$ 列到第 $j$ 列：<br>$j - i$ | $$k = \frac{(2n - i + 2)(i - 1)}{2} + (j - i)$$ |
| **上三角矩阵** | **列优先** | 前 $j-1$ 列组成等差三角形：<br>$\sum_{c=1}^{j-1} c = \frac{(j-1)j}{2}$ | 第 $j$ 列内从第 1 行到第 $i$ 行：<br>$i - 1$ | $$k = \frac{j(j-1)}{2} + (i - 1)$$ |

#### 对称矩阵与常数 $c$ 的存储容量边界
1. **对称矩阵（$A[i][j] = A[j][i]$）**：
   - 仅需存储下三角（或上三角）。若查询时给出的坐标落入另一半三角（例如只存下三角而要求访问 $A[1][3]$），只需**对称翻转坐标**（代入 $i'=3, j'=1$）即可复用公式。
   - 数组所需总容量：$\frac{n(n+1)}{2}$。
2. **三角矩阵（常数区全为常数 $C$）**：
   - 有效三角区占用 $\frac{n(n+1)}{2}$ 个槽位。
   - 紧随其后在数组末尾单设 1 个单元存储常数 $C$：
     - 若 $k$ 从 0 开始，常数 $C$ 存储在下标 $k = \frac{n(n+1)}{2}$ 处；
     - 数组所需总物理容量为 **$\frac{n(n+1)}{2} + 1$**。

### (3) 三对角矩阵（带状矩阵）的严谨数学双向映射

#### 1. 带状有效区间物理定义
- 在 $n$ 阶方阵中，所有非零元素集中在主对角线及其上下紧邻的次对角线中。
- **允许非零元素分布的带状存储区间边界**：$|i - j| \le 1$（带外 $|i - j| > 1$ 的区域规定恒为 $0$ 不分配空间；带内 $|i - j| \le 1$ 共分配 $3n - 2$ 个存储位置，带内位置允许非零，但个别带内元素的值本身仍可能恰好为 $0$）。
- **物理带宽与存储量**：
  - 第 1 行与第 $n$ 行各仅占 2 个位置（首尾无外侧对角线）；
  - 中间第 $2 \sim n-1$ 行每行占用 3 个位置；
  - 需分配存储单元总数：$2 + 3(n - 2) + 2 = \mathbf{3n - 2}$ 个。

#### 2. 前向映射：已知二维坐标 $(i, j)$，求一维下标 $k$（行优先，数组下标从 0 开始）
1. 前 $i-1$ 行占用的元素总数：
   - 第 1 行有 2 个元素，其余 $i-2$ 行每行有 3 个元素：
     $$\text{Preceding Count} = 2 + 3(i - 2) = 3i - 4$$
2. 在当前第 $i$ 行中：
   - 该行最左侧的非零元素列号为 $i - 1$；
   - 当前元素列号为 $j$，故在当前行内排在第 $j - (i - 1) + 1 = j - i + 2$ 位；
3. **合成一维下标公式**：
   $$k = (3i - 4) + (j - i + 2) - 1 = \mathbf{2i + j - 3}$$
   *(若一维数组下标从 1 开始，则为 $k = 2i + j - 2$)*。

#### 3. 逆向还原：已知一维下标 $k$（0 基础），反求行号 $i$ 与列号 $j$（1 基础）
考场常因整除向下/向上取整产生 $\pm 1$ 偏移。严谨的闭环还原推导如下：
- 由每行约 3 个元素，观察各行末尾元素对应的下标：
  - 第 1 行占 $k \in [0, 1]$
  - 第 2 行占 $k \in [2, 4]$
  - 第 3 行占 $k \in [5, 7]$
  - 第 $i$ 行占 $k \in [3i - 4, 3i - 2]$
- 将下标加 1 后除以 3 向下取整：
  $$i = \left\lfloor \frac{k + 1}{3} \right\rfloor + 1 = \left\lceil \frac{k + 2}{3} \right\rceil$$
- 求出 $i$ 后，直接反代前向公式解出列号 $j$：
  $$j = k - 2i + 3$$

#### 4. 边界校验验证表

| 一维下标 $k$ | 计算 $i = \lfloor \frac{k+1}{3} \rfloor + 1$ | 计算 $j = k - 2i + 3$ | 还原矩阵元素 | 物理状态检验 |
| :---: | :---: | :---: | :---: | :--- |
| **0** | $\lfloor 1/3 \rfloor + 1 = 1$ | $0 - 2 + 3 = 1$ | $A[1][1]$ | 第 1 行第 1 个元素（主对角线） |
| **1** | $\lfloor 2/3 \rfloor + 1 = 1$ | $1 - 2 + 3 = 2$ | $A[1][2]$ | 第 1 行第 2 个元素（上次对角线） |
| **2** | $\lfloor 3/3 \rfloor + 1 = 2$ | $2 - 4 + 3 = 1$ | $A[2][1]$ | 第 2 行第 1 个元素（下次对角线） |
| **3** | $\lfloor 4/3 \rfloor + 1 = 2$ | $3 - 4 + 3 = 2$ | $A[2][2]$ | 第 2 行第 2 个元素（主对角线） |
| **4** | $\lfloor 5/3 \rfloor + 1 = 2$ | $4 - 4 + 3 = 3$ | $A[2][3]$ | 第 2 行第 3 个元素（上次对角线） |
| **$3n-3$** (末项) | $\lfloor (3n-2)/3 \rfloor + 1 = n$ | $(3n-3) - 2n + 3 = n$ | $A[n][n]$ | 第 $n$ 行最后 1 个元素（主对角线） |

1. **与无向图邻接矩阵空间减半同构**：
   - [图的存储结构](../05-graph/01-graph-storage.md)：无向图的邻接矩阵满足 $A[i][j] = A[j][i]$，工程实现中常使用本节的对称矩阵下三角压缩算法，将 $|V|^2$ 个存储空间减少至 $\frac{|V|(|V|+1)}{2}$，空间节省接近 50%。
2. **极度稀疏矩阵向非连续存储的演化**：
   - 当非零元个数极少且分布无规则时，三对角或三角压缩公式失效，必须采用**三元组顺序表（行、列、值）**或**十字链表（Orthogonal List）**存储。

## 4. 闭环判定模型与核心认知结论

### (1) 考场公式推导“代入验算法”
面对复杂的选择题公式辨析，切忌死记易混淆的符号，采用**两点特征代入法**：
1. **代入首元素**：代入 $(1, 1)$，若 $k$ 数组从 0 开始则结果必为 0，若从 1 开始则结果必为 1；
2. **代入第二行首个有效元素**：
   - 下三角对称矩阵代入 $(2, 1)$：前面只存了第 1 行的 1 个元素，其 $k$ 必为 1（0 基础）；
   - 三对角矩阵代入 $(2, 1)$：前面存了第 1 行的 2 个元素，其 $k$ 必为 2（0 基础）。
3. 验证 2 个坐标点即可在 20 秒内彻底排除 3 个干扰项。
