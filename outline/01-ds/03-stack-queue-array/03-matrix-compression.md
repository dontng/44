## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 为什么需要矩阵压缩存储？
* **物理矛盾**：在图像处理、图的邻接矩阵和科学计算中，矩阵规模通常高达数千阶（$n \times n$）。若矩阵中存在大量值相同（如三角矩阵的常数区）或大量零元素（如对角带以外全为零），直接分配二维数组将浪费绝大部分物理内存。
* **压缩理念**：只为**有效非重复元素**分配一维数组空间，通过推导数学映射公式，将原二维坐标 $(i, j)$ 一对一转换到一维数组下标 $k$。

---

### (2) 对称矩阵与三角矩阵压缩映射推导（行优先为主）

设矩阵为 $n$ 阶（行号 $i$、列号 $j$ 从 1 开始，即 $1 \le i, j \le n$），一维压缩数组 $B[k]$ 下标从 0 开始。

#### 1. 对称矩阵（$A[i][j] = A[j][i]$，只存下三角及主对角线）
* **下三角元素特征**：$i \ge j$。
  * 前 $i-1$ 行包含的元素总数：$1 + 2 + 3 + \dots + (i-1) = \frac{(i-1)i}{2}$ 个；
  * 第 $i$ 行中，当前元素 $A[i][j]$ 是第 $j$ 个；
  * **一维数组下标公式**：
    $$k = \frac{i(i-1)}{2} + (j - 1) \quad (i \ge j)$$
  * 若访问上三角元素（$i < j$）：由于对称性，直接将公式中的 $i$ 与 $j$ 互换代入即可（计算 $k = \frac{j(j-1)}{2} + (i - 1)$）。

#### 2. 下三角矩阵（上三角区全为常数 $C$）
* 下三角区（$i \ge j$）：公式与对称矩阵完全一致：$k = \frac{i(i-1)}{2} + (j - 1)$；
* 上三角常数区（$i < j$）：统一映射到数组最后一个位置：$k = \frac{n(n+1)}{2}$。

---

### (3) 三对角矩阵（带状矩阵，408 核心大题与小题杀手）
* **特征**：除了主对角线及紧邻其上下两条次对角线（共 3 条线）之外，其余元素全为 0。
  * 存在非零元素的充要条件：$|i - j| \le 1$。
  * 第 1 行和第 $n$ 行各只有 2 个元素，中间第 $2 \sim n-1$ 行每行有 3 个元素。
  * 总非零元素个数：$2 + 3(n - 2) + 2 = 3n - 2$ 个。

#### 推导一：已知二维坐标 $(i, j)$，求一维下标 $k$（行优先，数组下标从 0 开始）
1. 前 $i-1$ 行的总元素数：第 1 行 2 个，后面 $i-2$ 行每行 3 个 $\implies 2 + 3(i-2) = 3i - 4$ 个；
2. 第 $i$ 行中，该行第一个非零元素列号为 $i-1$，当前元素列号为 $j$，故为该行的第 $j - (i - 1) + 1 = j - i + 2$ 个；
3. **公式合成**：
   $$k = (3i - 4) + (j - i + 2) - 1 = 2i + j - 3$$
   *(注：若一维数组下标从 1 开始，则 $k = 2i + j - 2$)*。

#### 推导二：已知一维下标 $k$（从 0 开始），反推所属行号 $i$ 和列号 $j$
* **行号计算**：因为每行约 3 个元素，观察前 $i$ 行共有 $3i - 1$ 个元素，可直接用向上取整公式：
  $$i = \left\lfloor \frac{k + 1}{3} \right\rfloor + 1$$
* **列号计算**：代入上一公式 $k = 2i + j - 3$，解得：
  $$j = k - 2i + 3$$

## 4. 闭环判定模型与核心认知结论

* **考场做推导题防错绝招（特殊值代入法）**：
  * 公式死记极易混淆“从 0 开始还是从 1 开始”；
  * **直接拿第一行第一列的元素检验**：
    * 比如三对角矩阵的 $A[1][1]$：按公式代入 $k = 2(1) + 1 - 3 = 0$，正好是数组第 0 个；
    * 拿第二行第一列的 $A[2][1]$ 检验：排在它前面的只有 $A[1][1]$ 和 $A[1][2]$ 两个元素，它必须是第 3 个（下标为 2）。代入公式 $k = 2(2) + 1 - 3 = 2$，完全吻合！
  * **30 秒内用前两三个坐标代入，选项错漏立显**。
