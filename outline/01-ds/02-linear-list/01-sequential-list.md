## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 顺序表的物理本质：物理连续与基址偏移
* **物理定义**：用一段地址连续的物理存储单元依次存储线性表的数据元素。
* **随机存取（Random Access）的数学物理根源**：
  * 设首元素 $a_1$ 的物理内存基地址为 $\text{LOC}(a_1)$，每个元素占用 $L$ 字节；
  * 则第 $i$ 个元素 $a_i$（逻辑位序从 1 开始）的内存地址可直接通过算术公式计算：
    $$\text{LOC}(a_i) = \text{LOC}(a_1) + (i - 1) \times L$$
  * **结论**：**获取任意第 $i$ 个元素的时间复杂度为 $O(1)$**！CPU 只需要一次乘加寻址运算，无需从头扫描。

### (2) 插入与删除的物理搬迁代价（408 经典计算）

#### 1. 插入操作（在第 $i$ 个位置插入元素，合法范围 $1 \le i \le n+1$）
* **动作**：必须将第 $i$ 个元素及其后面的所有元素（共 $n - i + 1$ 个）**从后往前依次向后挪动一位**。
* **平均移动次数推导**：
  * 假设在任何位置插入的概率均等（$p_i = \frac{1}{n+1}$）：
    $$E_{\text{insert}} = \sum_{i=1}^{n+1} p_i (n - i + 1) = \frac{1}{n+1} \times \frac{n(n+1)}{2} = \frac{n}{2}$$
  * 平均需要移动表中**一半（$\frac{n}{2}$）**的元素，时间复杂度为 **$O(n)$**。

#### 2. 删除操作（删除第 $i$ 个元素，合法范围 $1 \le i \le n$）
* **动作**：必须将第 $i+1$ 个元素及其后面的所有元素（共 $n - i$ 个）**从前往后依次向前挪动一位**。
* **平均移动次数推导**：
  * 假设删除任何位置的概率均等（$p_i = \frac{1}{n}$）：
    $$E_{\text{delete}} = \sum_{i=1}^n p_i (n - i) = \frac{1}{n} \times \frac{n(n-1)}{2} = \frac{n-1}{2}$$
  * 平均需要移动 **$\frac{n-1}{2}$** 个元素，时间复杂度为 **$O(n)$**。

## 3. 本学科内跨章节关联（网状贯通）

- $\to$ 关联 [链表](02-linked-list.md)：顺序表擅长“频繁按位查找，极少增删”，空间利用率高（无指针额外开销）；链表擅长“频繁增删，不要求随机存取”。
- $\to$ 关联 [查找 / 折半查找](../06-search/01-linear-and-binary-search.md)：折半查找（二分查找）**必须同时满足两个条件：元素有序，且必须是顺序存储（顺序表）**！链表因无法 $O(1)$ 获取中点，无法实现经典二分。
- $\to$ 关联 [二叉树性质与存储](../04-tree/01-binary-tree-properties.md)：完全二叉树的顺序存储正是借助顺序表的连续物理地址来计算父子下标。

## 4. 闭环判定模型与核心认知结论

* **位序 vs 下标**：
  * 题目说“第 $i$ 个元素”指的是**逻辑位序（从 1 开始）**；
  * C 语言数组存储指的是**物理下标（从 0 开始）**，第 $i$ 个元素的数组下标是 `data[i-1]`。
* **平均移动次数速记**：插入移动 $\frac{n}{2}$，删除移动 $\frac{n-1}{2}$，二者量级皆为 $O(n)$。
