## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 为什么必须有二叉搜索树？
* **物理矛盾**：
  * **普通顺序表**：支持折半查找（$O(\log n)$），但插入和删除必须批量移动元素（$O(n)$）；
  * **普通单链表**：插入删除极快（$O(1)$），但查找必须从头线性扫描（$O(n)$）。
* **设计融合**：二叉搜索树把**二分查找的逻辑结构（折半判定树）**硬编码到了**动态链式结构**中，期望同时获得 $O(\log n)$ 的查找与动态修改能力。

### (2) BST 的两大核心性质
1. **全局递归有序性**：
   * 若左子树非空，左子树上**所有节点**的值均小于根节点的值；
   * 若右子树非空，右子树上**所有节点**的值均大于根节点的值；
   * 左右子树本身也各是一棵二叉搜索树。
   * **常见思维陷阱**：仅满足“左孩子 < 根 < 右孩子”绝不等于 BST！必须是**整个左子树的所有后代**都小于根。
2. **中序遍历投影定理**：
   * **对一棵二叉树进行中序遍历（LDR），当且仅当遍历结果为“严格单调递增序列”时，该树必为二叉搜索树**！

---

### (3) 判定二叉树是否为 BST 的两大通用算法（408 大题母模）

#### 算法一：中序遍历单调性递增法
* **思想**：维护一个全局前驱变量 `pre = -INF`。在递归中序遍历（左 $\to$ 根 $\to$ 右）的过程中，访问当前节点时检查：
  * 若 `current->val <= pre`，说明逆序，立即返回 `false`；
  * 否则更新 `pre = current->val`，继续遍历右子树。
* **复杂度**：时间 $O(n)$，空间 $O(h)$（递归栈深度）。

#### 算法二：上下界区间收敛法（极适合顺序存储数组，2022-41 大题核心）
* **思想**：给每个子树传入它允许的数值范围 $[min\_val, max\_val]$。
  * 根节点的允许区间为 $(-\infty, +\infty)$；
  * 向左走时，所有后代必须小于当前根：左孩子的允许区间收缩为 $(min\_val, root->val)$；
  * 向右走时，所有后代必须大于当前根：右孩子的允许区间收缩为 $(root->val, max\_val)$；
  * 任何节点若跳出此范围，立即判定非 BST。

### (4) 顺序存储二叉树的下标计算规则（2022-41 考法）
当二叉树使用一维数组 `A[]` 顺序存储时（空节点记为 -1）：
* **若下标从 0 开始（`0 ~ n-1`）**：
  * 节点 $i$ 的左孩子下标为：$2i + 1$
  * 节点 $i$ 的右孩子下标为：$2i + 2$
  * 节点 $i$ 的双亲节点下标为：$\lfloor (i - 1) / 2 \rfloor$
* **若下标从 1 开始（`1 ~ n`）**：
  * 节点 $i$ 的左孩子下标为：$2i$
  * 节点 $i$ 的右孩子下标为：$2i + 1$
  * 节点 $i$ 的双亲节点下标为：$\lfloor i / 2 \rfloor$

## 4. 闭环判定模型与核心认知结论

* **判定一个序列是否可能是 BST 的查找过程**：
  * 模拟二分查找时，每遇到一个数，数值的合法取值区间就缩紧一次。
  * 若后续出现的数字跳出了之前收缩圈定的范围，说明该序列绝不可能存在。
