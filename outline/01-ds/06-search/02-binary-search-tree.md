## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 为什么必须引入二叉搜索树？
- **物理矛盾**：
  - **静态有序数组**：支持折半查找（$O(\log n)$），但插入和删除必须批量移动后续元素（$\Theta(n)$）；
  - **动态普通单链表**：已知指针时插入删除仅需修改指针（$O(1)$），但查找必须从头线性扫描（$\Theta(n)$）。
- **设计融合**：二叉搜索树将**折半查找的二叉判定拓扑结构**硬编码到了**动态链式指针结构**中，期望同时兼得 $O(\log n)$ 的查找性能与 $O(1)$ 的局部指针修改能力。

---

### (2) BST 的两大核心性质
1. **全局递归有序性**：
   - 若左子树非空，左子树上**所有节点**的值均小于其根节点的值；
   - 若右子树非空，右子树上**所有节点**的值均大于其根节点的值；
   - 左右子树本身也各是一棵二叉搜索树。
   - **常见误区警示**：局部满足“左孩子 < 根 < 右孩子”**绝不等于** BST！必须确保左子树的所有后代（包含其深层右孩子）都严格小于根。
2. **中序遍历投影定理**：
   - **对一棵二叉树进行中序遍历（LDR），当且仅当输出序列为严格单调递增时，该二叉树必为二叉搜索树**。

### (3) BST 删除算法三大分支及指针更新机制

在二叉搜索树中删除节点 $p$（设其双亲节点为 `parent`）：

#### 分支 1：被删节点 $p$ 为叶子节点（度为 0）
- 直接将 `parent` 指向 $p$ 的指针（`lchild` 或 `rchild`）置为 `NULL`，然后释放 $p$ 的物理内存。耗费 $O(1)$。

#### 分支 2：被删节点 $p$ 仅有左子树或仅有右子树（度为 1）
- 令 $p$ 的唯一非空子树直接替代 $p$ 成为 `parent` 的子树（独子继承）：
  ```c
  if (p->lchild != NULL) {
      if (parent->lchild == p) parent->lchild = p->lchild;
      else parent->rchild = p->lchild;
  } else {
      if (parent->lchild == p) parent->lchild = p->rchild;
      else parent->rchild = p->rchild;
  }
  free(p);
  ```

#### 分支 3：被删节点 $p$ 同时拥有左右子树（度为 2，核心难点）
- **物理策略**：不能直接拆卸树枝，必须寻找一个值最接近 $p$ 的替代节点，将“度为 2 的删除”转化为“度为 0 或 1 的删除”。
  - **替代方案 A（中序直接后继）**：在 $p$ 的**右子树中寻找最左下方的节点 $s$**（即右子树中的最小值，具有性质 `s->lchild == NULL`，度至多为 1）。
  - **替代方案 B（中序直接前驱）**：在 $p$ 的**左子树中寻找最右下方的节点 $s$**（即左子树中的最大值，具有性质 `s->rchild == NULL`，度至多为 1）。
- **两步执行流程**：
  1. 将 $s$ 的关键字值复制给 $p$：`p->data = s->data;`
  2. 在对应子树中删除节点 $s$（由于 $s$ 至多只有一个孩子，可直接套用分支 1 或分支 2 执行删除）。

### (4) 状态执行轨迹：6 节点树删除度为 2 节点与再插入拓扑非对称性

#### 1. 构造初始 6 节点二叉搜索树
```
           [ 50 ]
          /      \
      [ 30 ]    [ 70 ]
         \      /    \
        [40]  [60]  [80]
```
- 中序遍历序列：`30, 40, 50, 60, 70, 80`。

#### 2. 删除度为 2 的根节点 `50`（选用中序后继）
1. 在右子树（根为 70）中寻找最左节点，找到中序后继节点 `60`（`60` 为叶节点）。
2. 将值 `60` 拷贝至根节点：根节点数值由 `50` 变更为 `60`。
3. 从右子树中删除原来的节点 `60`（将其父节点 `70` 的 `lchild` 置为 `NULL` 并释放该节点）。
4. **删除后树形状态**：
   ```
              [ 60 ]
             /      \
         [ 30 ]    [ 70 ]
            \          \
           [40]       [80]
   ```
   中序遍历序列变为：`30, 40, 60, 70, 80`，BST 性质完全保持。

#### 3. 经典考点深度辨析：删除后再立即插入原关键字，树形是否恢复？
**问题**：若在二叉搜索树中删除关键字 $K$ 后，立刻调用 `Insert(T, K)` 重新插入 $K$，所得新树与原树是否必定同构？
- **结论**：**不一定！只有当 $K$ 原本就是叶子节点时才必定同构；若 $K$ 拥有孩子节点，重新插入后树形必然改变！**
- **机理必然性证明**：
  - 在 BST 插入算法中，新插入的节点**永远只会被挂接在树底的某个叶子节点位置**，绝不可能重新变成某个子树的非叶根节点。
  - 接上例：若此时重新插入 `50`：
    - `50 < 60` $\to$ 向左走至 `30`；
    - `50 > 30` $\to$ 向右走至 `40`；
    - `50 > 40` $\to$ 作为 `40` 的右孩子插入！
  - **再插入后的树形状态**：
    ```
               [ 60 ]
              /      \
          [ 30 ]    [ 70 ]
             \          \
            [40]       [80]
               \
               [50]  <-- 50 变成树底部的叶子节点，与最初作为根节点的树形完全不同！
    ```

### (5) 判定二叉树是否为 BST 的工程防御算法

#### 1. 中序遍历指针防御法（规避 `INT_MIN` 边界 Bug）
许多教材习惯使用 `pre = -INF`，但在 32 位 C 语言程序中，`-2147483648`（`INT_MIN`）完全可能是树中的有效节点键值！若树的第一个节点恰好为 `INT_MIN`，则条件 `cur->val <= pre` 将错误报警。
- **工业级健壮解法**：传入指针 `TreeNode **prev`（初始化为 `NULL`）：
```c
bool isValidBST(TreeNode *root, TreeNode **prev) {
    if (root == NULL) return true;
    if (!isValidBST(root->lchild, prev)) return false;

    // 第一次访问最左节点时，prev 为 NULL，直接记录而不作大小比对
    if (*prev != NULL && root->val <= (*prev)->val) {
        return false;
    }
    *prev = root; // 更新前驱指针

    return isValidBST(root->rchild, prev);
}
```

#### 2. 上下界区间收敛法（适合前序递归与并行检测）
```c
bool validate(TreeNode *root, long long min_val, long long max_val) {
    if (root == NULL) return true;
    if (root->val <= min_val || root->val >= max_val) return false;
    // 左子树必须落在 (min_val, root->val) 之间
    // 右子树必须落在 (root->val, max_val) 之间
    return validate(root->lchild, min_val, root->val) &&
           validate(root->rchild, root->val, max_val);
}
```

#### 3. 顺序存储二叉树的下标计算与无效槽位
当二叉树使用一维数组 `A[]` 存储时：
- **若下标从 0 开始**：节点 $i$ 的左孩子为 $2i + 1$，右孩子为 $2i + 2$，父节点为 $\lfloor (i - 1) / 2 \rfloor$。
- **若下标从 1 开始**：节点 $i$ 的左孩子为 $2i$，右孩子为 $2i + 1$，父节点为 $\lfloor i / 2 \rfloor$。
- **空节点哨兵约束**：考场常约定以 `-1` 代表空节点，这隐含了**节点有效键值必须均为非负数**的强前提；若键值允许为负数，系统必须维护一个独立的布尔位图 `bool valid[]` 或结构体有效标志位。

## 4. 闭环判定模型与核心认知结论

### (1) 查找路径可达性判定闭环法
面对“判定序列 $[a_1, a_2, \dots, a_k]$ 是否可能是某个关键字的查找比较路径”题型：
1. 初始合法取值开区间为 $(-\infty, +\infty)$；
2. 遇到 $a_1$ 后，若目标值大于 $a_1$，区间收紧为 $(a_1, +\infty)$；若小于 $a_1$，区间收紧为 $(-\infty, a_1)$；
3. 后续出现的每个数 $a_i$ **必须严格落在上一轮圈定的开区间内**；一旦出现任何数跳出当前开区间边界，直接断定该序列不可能存在。

### (2) BST 核心不变性法则
- **删除度为 2 节点的本质**：用中序前驱或后继的值覆盖，然后转化为删除度为 0 或 1 的节点。
- **树形可逆性**：删除叶子再插入，树形不变；删除内部节点再插入，原节点必降级为新叶子，树形必定重构。
