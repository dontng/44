## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) SRAM vs DRAM 的底层电路物理特性对比

CPU 对内存系统的终极期望是“速度无限快、容量无限大、成本无限低”。这一物理矛盾在半导体存储元层面被分化为两大阵营：

| 对比维度 | 静态随机存储器 (SRAM) | 动态随机存储器 (DRAM) | 机制分水岭 |
| :--- | :--- | :--- | :--- |
| **存储元结构** | **6 晶体管双稳态触发器 (6T)** | **1 晶体管 + 1 微小 MOS 电容 (1T1C)** | SRAM 依靠晶体管交叉耦合锁存；DRAM 依靠栅极电容电荷存储 |
| **集成度与芯片成本** | 集成度低，硅片面积大，造价昂贵 | 集成度极高，硅片面积微小，价格低廉 | DRAM 面积仅为 SRAM 的 $1/4 \sim 1/6$ |
| **功耗与发热** | 静态功耗极低，动态功耗中等 | 具有电荷泄漏，需定期刷新，持续发热 | DRAM 必须持续消耗电能执行刷新脉冲 |
| **读出破坏性** | **非破坏性读出**（读取不改变触发器状态） | **破坏性读出**（电容放电使原电平被破坏） | DRAM 读取时电荷与位线均分，电荷被释放 |
| **恢复机制** | 读出后无需重写，存取周期 $T \approx$ 存取时间 $t_A$ | **读出后必须立即由灵敏放大器重写（Restoration）** | DRAM 存取周期 $T$ 显著大于存取时间 $t_A$（通常为 $2 \times$） |
| **主要应用场景** | CPU 片内高速缓存（L1/L2/L3 Cache） | 计算机物理主内存（RAM）、显存（VRAM） | SRAM 追求纳秒级极速；DRAM 追求海量高密度 |

### (2) 破坏性读出重写（Restoration）与预充电（Precharge）的严谨物理界限

许多学习者常把 DRAM 的“破坏性读后恢复”与“预充电”混为一谈，两者在 DRAM 控制器时序中属于完全不同的物理阶段：

1. **破坏性读出与电荷恢复（Restoration）**：
   - 当行地址激活（`ACT` 命令）选通字线（Wordline）时，存储电容接通位线（Bitline），电容微弱电荷流入位线，导致原有电压被破坏。
   - 灵敏放大器（Sense Amplifier）检测到位线上几十毫伏的微小电压差，迅速放大并锁存为满幅的逻辑电平（0 或 $V_{DD}$）。
   - **重写机制**：在同一行激活周期内，灵敏放大器充当驱动源，**顺着位线将满幅电压自动反向写回原存储电容**，使电容重新充满电荷。该过程由硬件底层在行激活阶段自动闭环完成。
2. **预充电（Precharge）**：
   - 当 CPU 完成当前行的读写，准备关闭当前行并开启同一个 Bank 内的另一行之前，必须向 DRAM 发送预充电命令（`PRE` 命令）。
   - **物理动作**：断开当前字线，将所有位线的电平**强制拉回到基准中间电平（通常为 $V_{DD} / 2$）**。
   - **目的**：为下一次开启新行时的电荷分享比对重置基准点。若不预充电，位线上残留的满幅电平将导致下一次读取无法测出电容的微弱电荷。

### (3) DRAM 的刷新机制与考纲/工程双轨参数

- **电荷泄漏必然性**：由于半导体 PN 结存在微小的反向漏电流，DRAM 电容储存的电荷会随时间逐渐流失，导致“1”变成“0”。因此必须在电荷衰减至无法识别之前进行周期性补充充电（**刷新 Refresh**）。
- **刷新操作的物理特征**：**刷新是以“行（Row）”为单位进行的**。刷新一行等价于让该行经历一次假读出重写，只需给出内部行地址并驱动该行的所有灵敏放大器，整行所有存储元瞬间完成充电。

> [!NOTE]
> **双轨模型边界：刷新周期参数的考场模型 vs 现代工业标准**
> - **408 经典教材算例参数**：考题通常假设刷新周期（Refresh Period）为 **$2\text{ ms}$**，存储矩阵行数常见为 128 行或 256 行。
> - **现代工程器件标准（JEDEC DDR3/DDR4/DDR5）**：现代 DRAM 采用深沟槽与高介电常数电容，常温下刷新周期标准为 **$64\text{ ms}$**（高温环境 $>85^\circ\text{C}$ 时收紧为 $32\text{ ms}$），刷新行数通常为 8192 行（$8\text{K}$ Refresh）。
> - **计算通用性**：无论刷新窗口是 $2\text{ ms}$ 还是 $64\text{ ms}$，集中、分散、异步刷新的离散时序计算公式完全同构。

#### 三种刷新方式精算模型（以考场经典参数：128 行、刷新周期 $2\text{ ms} = 2000\mu\text{s}$、存取周期 $t_{\text{RC}} = 0.5\mu\text{s}$ 为例）

| 刷新方式 | 刷新时序分配 | 死区（Dead Zone）占比 | 优缺点与适用场景 |
| :--- | :--- | :---: | :--- |
| **集中刷新** | 在 $2\text{ ms}$ 周期的末尾，集中连续占用 128 个存取周期逐行刷新全部 128 行 | **死区长达 $128 \times 0.5\mu\text{s} = 64\mu\text{s}$**。<br>死区率 $= \frac{64}{2000} = 3.2\%$ | 优点：读写期内无刷新干扰，速度高。<br>缺点：死区连续时间过长，高速 DMA 或实时 I/O 会因等待而丢失数据。 |
| **分散刷新** | 将原本 $0.5\mu\text{s}$ 的存取周期人工延长至 $1.0\mu\text{s}$：前半段 $0.5\mu\text{s}$ 供 CPU 读写，后半段 $0.5\mu\text{s}$ 强制刷新某一行 | **死区时间为 0**（无连续卡顿） | 优点：不存在集中刷新那样的长连续死区，调度最简单。<br>缺点：全系统内存存取周期被虚增一倍，存取性能被严重浪费。 |
| **异步刷新**<br>(现代标准) | 将 128 行刷新均匀分散到 $2000\mu\text{s}$ 内：每隔 $\frac{2000\mu\text{s}}{128} \approx 15.625\mu\text{s}$ 发送一次刷新脉冲，占用单次存取周期 $0.5\mu\text{s}$ 刷新一行 | **单次死区仅 $0.5\mu\text{s}$**。<br>总死区累计仍为 $64\mu\text{s}$，死区率 $3.2\%$ | **工业界标准最优解**：将不可避免的死区细碎化，CPU 与 I/O 几乎感受不到停顿，避免了突发长等待。 |

### (4) 只读存储器（ROM）家族技术演进与 Flash Memory 特性

ROM 的核心本质是**非易失性（Non-Volatile）**，断电后数据仍能长期保持（非易失性），常用于存储计算机 BIOS / UEFI 固件与嵌入式引导程序。

| ROM 类型 | 写入与编程方式 | 擦除机制与颗粒度 | 擦写寿命 | 典型应用场景 |
| :--- | :--- | :--- | :---: | :--- |
| **MROM (掩膜 ROM)** | 芯片制造工厂光刻写入 | 物理不可擦除，内容终身固化 | 无法擦写 | 大批量标准化生产的出厂固件 |
| **PROM (一次可编程)** | 专用烧录器熔断内部熔丝 | 仅可写入一次，写入后不可更改 | 1 次 | 早期小批量定制固件 |
| **EPROM (紫外线擦除)** | 高压电荷注入浮栅 | 石英玻璃窗口用**紫外线全盘照射**擦除 | 约数百次 | 早期实验室调试（擦除需拆片照紫外线数十分钟） |
| **EEPROM (电可擦除)** | 隧道效应电学擦写 | **电学按字节擦除与写入**（无需光照） | 约十万次 | 存储主板 BIOS 设置、微控制器校准参数 |
| **Flash (NOR Flash)** | 电学热电子注入写入 | **按块（Block）擦除**，支持**随机按字节读取** | 约十万次 | **支持芯片内就地执行（XIP）**；用作路由器、主板 BIOS 固件芯片 |
| **Flash (NAND Flash)** | 量子隧道效应写入 | **按块（Block）擦除**，**按页（Page）读取/写入** | 约数千至数万次 | **不支持 XIP**；高密度、低成本，用作 SSD 固态硬盘、U 盘、手机闪存 |

> [!IMPORTANT]
> **Flash Memory 的核心物理约束：“先擦后写”与块/页粒度不对称**
> - Flash 存储元在擦除后所有位的值恢复为逻辑 `1`；写入数据实质上是将特定位的 `1` 变为 `0`。
> - **物理限制**：硬件无法直接将某个已经被写为 `0` 的位翻转回 `1`。若要改写已写入数据的页面，必须**先将整个包含该页面的擦除块（Block，通常包含数十至数百个 Page）全量擦除为全 1，然后再写入新数据**。
> - 这构成了现代 SSD 必须引入 FTL（闪存转换层）、垃圾回收（GC）以及磨损均衡（Wear Leveling）的底层物理根源。

### (5) 多模块存储器与流水线存取时序精算

为化解 CPU 纳秒级运算速度与主存数十纳秒级存取周期的矛盾，体系结构引入了多体交叉并行存储技术。

#### 1. 单体多字存储器
- 单个存储体具有统一的读写控制线与地址译码器，但数据总线宽度为 $m \times W$（每个存取周期并行读出 $m$ 个字）。
- **局限**：必须保证连续指令或数据在地址上严格连续。一旦遭遇分支跳转，取出的后几个字将全部作废，灵活性低。

#### 2. 高位交叉编址（顺序方式） vs 低位交叉编址（交叉流水方式）
设系统拥有 $m$ 个独立的物理存储体，每个体大小为 $M$ 个字。

```
高位交叉编址 (顺序方式):
┌───────────────────────────────┬──────────────────────────────┐
│       高位: 模块号 (体号)      │        低位: 体内地址        │
└───────────────────────────────┴──────────────────────────────┘
地址分布: 模块 0 存储 0 ~ M-1, 模块 1 存储 M ~ 2M-1 ...

低位交叉编址 (交叉流水方式):
┌───────────────────────────────┬──────────────────────────────┐
│        高位: 体内地址         │      低位: 模块号 (体号)      │
└───────────────────────────────┴──────────────────────────────┘
地址分布: 地址 A 的模块号 = A mod m, 连续地址依次轮流分布在各个存储体中！
```

- **高位交叉（顺序方式）**：同一个程序段集中存放在某一个存储体内。便于模块级独立扩容与多程序隔离；但当单个 CPU 连续读取连续地址数据时，访问请求全部打在同一个模块上，必须严格串行排队等待存取周期，对单线程连续地址访问无法提供跨模块流水加速。
- **低位交叉（流水方式）**：连续逻辑地址轮流映射到模块 $0, 1, 2, \dots, m-1$。CPU 能够以流水线方式连续向相邻模块发起存取请求。

#### 3. 流水线不冲突条件与时序推导
设每个存储体的存取周期为 $T$，数据在总线上的传输延迟为 $r$。
- **不间断流水启动条件**：当 CPU 启动模块 0 经过 $m$ 个周期再次轮回到模块 0 时，模块 0 必须已经完成了上一轮存取周期的恢复：
  $$m \times r \ge T \implies \mathbf{m \ge \frac{T}{r}}$$

#### 4. 连续存取精算实例（$m = 4$ 体交叉，$T = 40\text{ ns}, r = 10\text{ ns}$）

##### 读取 4 个连续字的时序推演：
- **高位交叉（顺序方式）耗时**：
  4 个字全在同一模块，必须串行执行 4 个完整的存取周期：
  $$t_{\text{seq}} = 4 \times T = 4 \times 40\text{ ns} = \mathbf{160\text{ ns}}$$
- **低位交叉（流水方式）耗时**：
  模块 0、1、2、3 错开 $r = 10\text{ ns}$ 依次启动。第 1 个字耗时 $T$，后续每个字仅需间隔 $r$ 即可在总线上交付：
  $$t_{\text{pipe}} = T + (4 - 1) \times r = 40 + 3 \times 10 = \mathbf{70\text{ ns}}$$

##### 连续读取 $n$ 个字的统一时序公式：
$$T_n = T + (n - 1) \times r$$
- 当 $n = 8$ 时：
  - 高位交叉方式：$8 \times 40 = 320\text{ ns}$
  - 低位交叉方式：$40 + (8 - 1) \times 10 = 110\text{ ns}$（加速比高达 $\frac{320}{110} \approx 2.91$ 倍）

##### 低位交叉 4 体流水时序甘特图（读取 4 个字）：
```
时标 (ns):   0   10   20   30   40   50   60   70
            │───│───│───│───│───│───│───│
模块 0 (字0): [==== 存取周期 T (40ns) ====]
            [启动]              [总线占10ns]
模块 1 (字1):     [==== 存取周期 T (40ns) ====]
                [启动]              [总线占10ns]
模块 2 (字2):         [==== 存取周期 T (40ns) ====]
                    [启动]              [总线占10ns]
模块 3 (字3):             [==== 存取周期 T (40ns) ====]
                        [启动]              [总线占10ns]
总线输出:                        [字0][字1][字2][字3]
```

## 4. 闭环决策模型与核心认知结论

### (1) DRAM 地址引脚复用计算法则
- DRAM 芯片内部将大存储阵列排列为正方形二维矩阵（行 $\times$ 列）。
- **引脚复用法则**：外部物理地址引脚数减半，分两次打入：
  $$\text{物理地址引脚数} = \max(\text{行地址位数}, \text{列地址位数}) \quad \left(\text{当行列地址位数相等时为 } \frac{\text{总地址位数}}{2}\right)$$
- 考题范例：容量为 $4\text{M} \times 8\text{位}$ 的 DRAM 芯片，若采用地址引脚复用，共需多少引脚？
  - $4\text{M} = 2^{22}$，总地址线 22 根。行地址与列地址各 11 根。
  - 地址引脚只需 11 根；数据引脚 8 根；控制引脚 3 根（$\overline{RAS}$ 行选通、$\overline{CAS}$ 列选通、$\overline{WE}$ 读写控制）；加上电源地线共计 24 根。

### (2) 存储器扩展核心设计准则
- **位扩展**：所有芯片片选与地址线全并联，数据线分开引至数据总线不同位。
- **字扩展**：低位地址线并联，高位地址线经译码器输出独立的片选信号 $\overline{CS}$。
- **低位交叉编址计算**：在无访存冲突且满足 $m \ge T/r$ 时，连续存取 $n$ 个字的总时间为 $T + (n - 1)r$；只要题目满足连续地址且模块数 $m \ge T/r$，直接套用该时序公式。
