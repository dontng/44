## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 为什么需要浮点数？
* **物理矛盾**：定点数（整数和小数）的小数点位置固定不变。若要表示像宇宙天体距离（$10^{30}$）或微观粒子尺寸（$10^{-30}$），需要成百上千位的超长定点寄存器，硬件极其浪费且绝大部分高低位都是无效的 0。
* **科学计数法思想**：将数值拆分成**大小（尾数）**与**范围规模（阶码）**，使有限的 32 位能够跨越巨大的动态表示范围。

### (2) IEEE 754 标准的存储布局（以 32 位单精度 float 为例）

```
  31      30          23 22                                 0
 ┌───┬──────────────────┬─────────────────────────────────────┐
 │ s │    e (8 位阶码)   │           f (23 位尾数)             │
 └───┴──────────────────┴─────────────────────────────────────┘
  符号位   移码（偏置值127）          尾数小数部分（隐藏最高位1）
```

* **符号位 $s$（1位）**：0 代表正数，1 代表负数。
* **阶码 $e$（8位，采用移码表示，偏置常数 Bias = 127）**：
  * 真实阶码指数 $E = e - 127$。
  * 正常取值范围为 $1 \sim 254$（指数 $E$ 为 $-126 \sim +127$）。
  * 全 0 和 全 1 留作特殊含义。
* **尾数 $f$（23位）**：
  * **隐藏位机制（规格化数）**：因为规格化数的最高位必为 1，IEEE 754 **不显式存储该最高位 1**，物理上只有 23 位，但**逻辑上具备 24 位有效精度**！
  * 真值公式：
    $$V = (-1)^s \times (1.f) \times 2^{e - 127}$$

---

### (3) IEEE 754 五大数值状态全景（408 计算高频陷阱）

| 阶码 $e$ (8位) | 尾数 $f$ (23位) | 数值类型 | 真值计算公式 | 物理含义 |
| :---: | :---: | :---: | :---: | :--- |
| **$1 \sim 254$** | 任意 | **规格化数（Normal）** | $(-1)^s \times (1.f) \times 2^{e - 127}$ | 常规绝大部分浮点数，隐藏位生效 |
| **$00000000$** | **全 0** | **零（$\pm 0$）** | $(-1)^s \times 0.0$ | 符号位决定正负零，全位均为 0 时为 $+0$ |
| **$00000000$** | **非零** | **非规格化数（Subnormal）** | $(-1)^s \times (0.f) \times 2^{-126}$ | **隐藏位变为 0**！平滑渐进下溢，填补 0 附近缝隙 |
| **$11111111$** | **全 0** | **无穷大（$\pm \infty$）** | 溢出溢界值 | 除以 0 或正负溢出（如 `+1.0 / 0.0`） |
| **$11111111$** | **非零** | **非数（NaN）** | 非法运算结果 | 如 `0.0 / 0.0`、负数开平方 |

### (4) 强制类型转换的精度与范围陷阱（必考选择题）
在 C 语言 32 位机器中（`int` 32位，`float` 32位，`double` 64位）：
1. **`int` 转 `float`**：
   * `int` 的有效位数是 31 位；而 `float` 逻辑有效尾数只有 24 位。
   * **数值范围不溢出，但可能发生精度损失（低位被舍入）**！
2. **`int` 转 `double`**：
   * `double` 的有效尾数长达 53 位（52位存储+1位隐藏位），$53 > 31$。
   * **既不溢出，也绝无精度损失，完全精准还原**！
3. **`float` 转 `int`**：
   * 浮点数可能截断小数部分，若浮点数绝对值超过 $2^{31}-1$，会直接**发生溢出异常**。

## 4. 闭环判定模型与核心认知结论

* **浮点数求真值速算三步法**：
  1. 看最高位定正负；
  2. 提取 8 位阶码，算出 $E = e - 127$；
  3. 尾数前补上隐藏的 `1.`，结合 $2^E$ 移动小数点还原真值二进制。
* **精度无损铁律**：从低精度整数向高精度浮点转换，必须检查**尾数位数是否大于整数的有效位数**（$32\text{位 int} \to \text{double(53位)} \implies \text{精准}$；$32\text{位 int} \to \text{float(24位)} \implies \text{可能丢精度}$）。
