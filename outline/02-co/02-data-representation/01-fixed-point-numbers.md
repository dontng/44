## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 为什么现代计算机全盘采用“补码”？
* **物理绝境**：在 CPU 的算术逻辑单元（ALU）中，硬件加法器非常廉价且速度极快。但如果计算机使用原码表示带符号数：
  * 做加法遇到异号，必须先比大小再做减法；
  * 原码存在 $+0$（`0000`）和 $-0$（`1000`）两个编码，不仅浪费状态，而且让判断“是否为零”的逻辑门电路变得异常复杂。
* **补码的数学哲学（模运算与同余）**：
  * 补码把减法转化为加法：$A - B = A + (-B)_{\text{补}}$。
  * **0 的唯一表示**：$[+0]_{\text{补}} = [-0]_{\text{补}} = 0000\dots 0$。
  * **额外多表示一个负数绝对值极值**：8 位补码能表示 $-128 \sim +127$（其中 `-128` 编码为 `1000 0000`，没有对应的原码）。

### (2) 四大编码体系的映射关系（以 8 位为例）

| 编码名称 | 正数规则 | 负数规则 | 8 位数值范围 | 特殊考点 |
| :--- | :--- | :--- | :---: | :--- |
| **无符号数** | 全部数位代表数值 | 无负数 | $0 \sim 255$ | 常用于地址、计数器 |
| **原码** | 最高位为 0，其余为绝对值 | 最高位为 1，其余为绝对值 | $-127 \sim +127$ | 有 $\pm 0$ 两个零，乘除法常用 |
| **反码** | 与原码相同 | 符号位为 1，数值位按位取反 | $-127 \sim +127$ | 补码的计算中间状态 |
| **补码** | 与原码相同 | 符号位为 1，数值位**按位取反再加 1** | $-128 \sim +127$ | 硬件主流，**快捷求相反数：全位取反加1** |
| **移码** | 补码符号位取反 | 补码符号位取反 | $-128 \sim +127$ | **全位保序性**：移码越大，真值越大；用于浮点阶码 |

### (3) 符号扩展规则（高频小题）
当短整数转换成长整数（如 8 位 `char` 转 16 位 `short` / 32 位 `int`）：
* **无符号数（零扩展）**：高位全部补 **0**。
* **带符号数补码（符号扩展）**：高位全部补**符号位**（正数高位全补 0，负数高位全补 1）。

### (4) 补码加减法与溢出判定的四大硬件标志位（408 核心大题判据）
ALU 执行加减运算后，硬件电路自动生成 4 个标志位：
1. **零标志 ZF（Zero Flag）**：结果全部为 0 时置 1，否则为 0。
2. **符号标志 SF（Sign Flag）**：结果的最高位（符号位）是几，SF 就是几。
3. **进位标志 CF（Carry Flag，针对无符号数）**：
   * **公式**：$\text{CF} = \text{最高位进位} \oplus \text{sub}$（加法有进位或减法有借位时置 1）。
4. **溢出标志 OF（Overflow Flag，针对带符号补码）**：
   * **双符号位法（变形补码）**：结果的高两位符号位为 `01`（正溢出）或 `10`（负溢出），即 $f_1 \oplus f_2 = 1$。
   * **最高位进位与次高位进位异或**：$\text{OF} = C_{\text{in}} \oplus C_{\text{out}}$。

## 4. 闭环判定模型与核心认知结论

* **溢出类型互斥铁律**：
  * **CF 标志仅对“无符号数运算”有意义**；
  * **OF 标志仅对“带符号补码运算”有意义**；
  * 两个正数相加得出负数，或两个负数相加得出正数，**OF 必然置 1**（符号异常反转必定溢出）。
