## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 加法器的进位链困境：串行进位 vs 超前进位
* **物理矛盾**：加法是计算机一切运算（减法、乘法、除法、地址偏移）的物理基石。
  * **一位全加器（FA）**：输入加数 $A_i$、$B_i$ 与低位进位 $C_{i-1}$，输出本位和 $S_i$ 与向高位进位 $C_i$。
  * **串行进位（行波进位 Ripple-Carry Adder）**：若将 32 个 FA 串联，最高位的进位信号必须等待前面 31 个全加器逐级传导电信号。门电路延迟线性累加，**计算 32 位加法需要几十个纳秒，严重拖慢 CPU 主频**！
* **超前进位加法器（CLA, Carry-Lookahead Adder）的设计飞跃**：
  * **数学解耦**：观察进位公式 $C_i = A_i B_i + (A_i \oplus B_i)C_{i-1}$；
  * 定义**进位产生项** $G_i = A_i B_i$（本位直接产生进位，与低位无关）；
  * 定义**进位传递项** $P_i = A_i \oplus B_i$（本位能否把低位的进位传上去）；
  * 则：
    $$C_1 = G_1 + P_1 C_0$$
    $$C_2 = G_2 + P_2 C_1 = G_2 + P_2 G_1 + P_2 P_1 C_0$$
    $$C_3 = G_3 + P_3 C_2 = G_3 + P_3 G_2 + P_3 P_2 G_1 + P_3 P_2 P_1 C_0$$
  * **硬件结果**：**所有高位进位信号直接由初始输入 $A, B$ 和 $C_0$ 通过两级门电路并行同时生成**！彻底打破了串行传导的延迟壁垒。

### (2) ALU 加减法统一实现与硬件标志位生成（408 必考大题通路）
* 计算机执行 `sub A, B` 时，并不单独造减法器电路，而是将 $B$ 各位通过异或门取反、低位进位输入 $C_0$ 置 1（相当于实现求补加 1）：
  $$A - B = A + \bar{B} + 1$$
* **四大条件标志位硬件生成公式**：
  1. **零标志 ZF**：所有输出结果位通过一个巨大的多输入**或非门（NOR）**，只有全为 0 时 $\text{ZF} = 1$；
  2. **符号标志 SF**：直接引出结果的最高位（符号位） $F_{n-1}$；
  3. **进位标志 CF（针对无符号数）**：$\text{CF} = C_{\text{out}} \oplus \text{sub}$；
  4. **溢出标志 OF（针对带符号补码）**：最高位进位与次高位进位异或 $\text{OF} = C_n \oplus C_{n-1}$。

### (3) 定点数乘法运算机理（Booth 乘法器）
* **软件原码乘法（移位加法）**：符号位单独异或，数值位做 $n$ 次移位和加法。
* **硬件补码 Booth 乘法（2020-43 大题核心）**：
  * 在乘数最低位后增加一个附加位 $y_{n+1}$（初始为 0）；
  * 每次观察末尾两位 $(y_n, y_{n+1})$：
    * `00` 或 `11` $\implies$ 仅部分积右移一位；
    * `01` $\implies$ 部分积加 $[X]_{\text{补}}$，随后右移一位；
    * `10` $\implies$ 部分积减 $[X]_{\text{补}}$（即加 $[-X]_{\text{补}}$），随后右移一位；
  * **物理价值**：直接对带符号补码进行乘法，无需区分正负，完全契合流水线硬件电路。

## 4. 闭环判定模型与核心认知结论

* **超前进位 CLA 的位宽极限**：由于门电路输入端数（扇入 Fan-in）受物理工艺限制，通常只做成 4 位一组的 CLA；多组之间再进行组间超前进位或组间串行进位。
* **溢出判定的异或本质**：只要最高位进位与次高位进位**不一致**（一个进了、一个没进），带符号运算**必定发生溢出（OF = 1）**。
