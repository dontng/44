## 优先处理的教学风险

1. **折半插入最好时间写错**：有序输入几乎无需搬移，标准逐次二分插入的总比较为Θ(n log n)，不是表中声称的最好n²。本轮n=8/16/32依次比较17/49/129次，移动均为0。复杂度表必须分别计算比较、搬移及总开销，不能只套平均/最坏上界。
2. **CLOCK被排除在Belady异常之外**：简单CLOCK不是栈算法，也可能增加框数后缺页更多。按本报告固定实现，引用串`5,2,4,1,5,2,0,5,2,3,1,0`，3框缺页9次、4框10次。这直接反驳“仅FIFO”。
3. **滑动窗口利用率可超过100%**：现有式子缺饱和上限。例W=8、发送一帧1秒、往返传播1秒，原式得到4。应为`min(1, W*Tf/(Tf+RTT))`，还需声明ACK/排队/首部等忽略条件。
4. **磁盘转速单位混用**：已定义r为RPM，却把`1/(2r)`和`60/(2r)`写成相等，传输时延也丢60因子。r按转/秒与按RPM必须使用不同公式。
5. **图示与正文冲突**：独立open应有独立打开文件描述/偏移；fork/dup才可能共享。现图把独立open画成同一表项，还说偏移独立，足以建立错误关系。
6. **缺页必磁盘、必阻塞的绝对化**：软缺页不需要I/O。教材可采用“目标页需从外存调入”的模型，但不得同时宣称描述所有现代缺页。[S2]
7. **硬链接计数0即回收**：忽略已打开文件等有效引用；删除名字不等于立刻释放内容。软链接独立盘块和一律从根解析也不是通用实现。[S3][S4]
8. **曼彻斯特标准约定反写**：标明IEEE802.3时，应1为低到高、0为高到低；有其他编码约定，做具体题以题目图例为准，不能把两套约定混称同一标准。[S5]
9. **TCP拥塞公式单位混乱**：若cwnd用字节，每ACK增量应为SMSS²/cwnd；若cwnd用MSS个数，则整体统一用段数。RFC减半门限用FlightSize且至少2SMSS，不能拿教学简化无条件替代。[S6]
10. **相关性被写成同一机制**：Clock≠C-SCAN、前缀编码≠Huffman最优编码、指令基址寻址≠分页CR3地址转换、一般多实例资源图≠普通DAG删入度0。跨章关联应同时写相同点、关键差异和不能迁移的判断。

## 独立反例核验记录

这些小检查用于推翻绝对说法，不能代替全面教学质量审核。

1. **结构体对齐**：当前64位执行环境，`struct { int data; void *next; }`大小16B，不是简单相加的12B；4B载荷密度为25%。教材忽略对齐的33.3%模型可使用，但不能声称是实际64位C节点布局。
2. **折半插入**：有序输入n=8/16/32，按标准二分定位插入，比较次数17/49/129，搬移次数全为0。否定“最好也必须平方搬移”。
3. **窗口饱和**：W=8、L=1000bit、C=1000bit/s、RTT=1s，未截断式给4；利用率必须截到1。
4. **CRC漏检**：生成多项式位串11001，以非零错误位串11001翻转接收码字，错误多项式正好为G，其模2余数仍为0。因此“余数0保证无差错”不成立。
5. **Dijkstra有负边但仍正确**：s→a=2、s→b=5、a→b=-1，先选a再更新b得1，结果正确。这不意味着可普遍用Dijkstra处理负边，只反驳“有负边就每次计算必错”。
6. **简单CLOCK的Belady反例**：初始所有框空、引用位0、指针0；命中置1；缺页时从当前指针扫描，遇1清0前移、遇0替换，新页位置1，指针前移。引用串如下，3框9缺页、4框10缺页。

```python
def clock_faults(sequence, capacity):
    pages = [None] * capacity
    used = [0] * capacity
    hand = faults = 0
    for page in sequence:
        if page in pages:
            used[pages.index(page)] = 1
            continue
        faults += 1
        while used[hand]:
            used[hand] = 0
            hand = (hand + 1) % capacity
        pages[hand] = page
        used[hand] = 1
        hand = (hand + 1) % capacity
    return faults

sequence = [5, 2, 4, 1, 5, 2, 0, 5, 2, 3, 1, 0]
assert clock_faults(sequence, 3) == 9
assert clock_faults(sequence, 4) == 10
```
