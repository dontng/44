## 四类问题及修复验收

### 一、错误结论、公式与判据

包括折半插入最好时间、CLOCK与Belady异常、窗口利用率饱和、磁盘转速单位、打开文件表图示等。逐项核证原句、前提及反例；优先修复会造成错误理解或错误计算的内容。报告附有小规模验证及原始资料，争议项应独立核验，不能把审查意见直接当新的绝对权威。

验收：同一推导、公式、图示、正文和末尾判据相容；至少能走通相应数值或算法反例；复杂度区分比较、移动、总时间及最好/平均/最坏，单位和起算约定明确。

### 二、考纲广度缺失或名义覆盖

包括KMP、基数排序、多维数组、大小端与对齐、线程实现、条件变量、IPv4分片、VLAN/无线介质访问等。也包括DHCP只有端口、IPv6只有校验和一句之类的“出现名称但没有解释”。

验收：逐条把仓库 `27outline.md` 条目映射到实质正文，明确已覆盖、部分覆盖、缺失；不靠标题或关键词命中认定完成。现代扩展不能冒称考纲明确要求，网页转录考纲也不能未经验证就升级为官方最新大纲。

### 三、机制深度与实际执行不足

包括BST没有完整删除、AVL只有旋转名称、PV经典问题没有完整展开，以及算法只写“选择、更新、重复”却没有状态轨迹等。知识页不放真题题面，不等于不能放最小自造例、过程图、伪代码和反例。

验收：读者能说明问题由来、对象与状态、每步更新、为什么正确、停止条件及条件变化的影响，并独立走完一个最小例。按主题需要补内容，不机械为81篇套同一长模板。

### 四、模型边界、跨章节关联与工程实现混用

区分教材简化模型、具体ISA、操作系统版本和一般性结论。包括缺页必磁盘/必阻塞、CR3/TLB切换、VMX模式与Ring特权级、Clock与C-SCAN、前缀码与Huffman、指令基址寻址与分页映射等。

验收：结论带明确成立条件；跨章节关联写清共同点、不同点、不能直接迁移的判据；现代实现引用可核对的原始资料，并标版本。允许合理的跨科深入，不用术语关系图替代机制解释。
