## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 为什么必须有层次化的分布式 DNS 架构？
* **物理矛盾**：人类擅长记忆语义化域名（如 `www.pku.edu.cn`），而网络路由器只认二进制数字 IP 地址（如 `162.105.131.8`）。如果全球建立一个集中的单台 DNS 服务器，全球数以亿计的并发解析请求会瞬间将其压垮，且单点故障会让全球互联网瘫痪。
* **树形分布式体系（自顶向下分权）**：
  1. **根域名服务器（Root DNS Server）**：全球只有 13 个逻辑大组（用字母 a 到 m 命名，通过泛播 Anycast 技术镜像到全球数千台物理服务器）。它们不知道具体的 IP，但知道所有顶级域名的地址。
  2. **顶级域名服务器（TLD Server）**：管理 `.com`、`.cn`、`.edu`、`.org` 等顶级域。
  3. **权威/权限域名服务器（Authoritative Server）**：真正拥有该机构或企业全部主机名到 IP 映射原始数据库的服务器（如北京大学的权威 DNS）。
  4. **本地域名服务器（Local DNS Server，LDNS）**：不属于树结构层次，由本地网络运营商（ISP）或企业校园网提供，充当**所有客户端的专属代购代理**。

### (2) 递归查询 vs 迭代查询的物理全流程（2021-47 大题核心）

主机向本地域名服务器查询，以及本地域名服务器向外网查询，通常采用以下经典折中组合：

```
 【用户主机】 ──────── (1) 递归查询 ────────► 【本地域名服务器 (LDNS)】
                                                    │
                 ┌──────────────────────────────────┼──────────────────────────────────┐
                 │ (2) 问根：谁管.cn？              │ (4) 问顶级：谁管.edu.cn？       │ (6) 问二级：谁管.pku.edu.cn？
                 ▼                                  ▼                                  ▼
      【根域名服务器】                    【顶级域名服务器 (.cn)】           【权限域名服务器 (pku.edu.cn)】
                 │                                  │                                  │
                 └────────► (3) 告知顶级IP ─────────┴────────► (5) 告知权限IP ─────────┴────────► (7) 给出目标真实IP
```

1. **主机 $\to$ 本地域名服务器：递归查询（Recursive Query，全权包办）**：
   * 主机问本地域名服务器：“帮我查一下目标 IP”。
   * 本地域名服务器作为受托人，承担全部跑腿任务，保证最终返回确切的 IP（或者返回查无此人），**主机只需要坐等答案**。
2. **本地域名服务器 $\to$ 外界服务器：迭代查询（Iterative Query，给指路牌）**：
   * 本地 DNS 问根域名服务器：根服务器不直接查出结果，而是回答：“我不知道它的 IP，但我知道管 `.cn` 的顶级域名服务器 IP 是多少，你去问它”；
   * 本地 DNS 拿指路牌去问顶级域名服务器：顶级回答：“去问权威服务器”；
   * 本地 DNS 问权威服务器：权威服务器直接给出目标的真实 IP 地址。
3. **DNS 缓存（TTL 生存时间）**：
   * 本地 DNS 拿到结果后在本地内存保存副本。在 TTL 时间内，若有其他用户访问相同域名，**直接从缓存秒级返回，不再向外走这 8 步网络查询**。

---

### (3) 传输层协议与端口
* **端口号**：标准熟知端口为 **53**。
* **主要协议**：
  * **日常客户端解析：使用 UDP 协议**（开销极小，不需要三次握手，一个请求一个响应直接完成）；
  * **区域传送（主从 DNS 数据库同步）或报文超过 512 字节：使用 TCP 协议**（保证数据传输可靠性）。

## 4. 闭环判定模型与核心认知结论

* **查询轮次计算大题判据**：
  * 若各级服务器**均无缓存**：本地域名服务器进行迭代查询，需要依次访问 **根服务器 $\to$ 顶级服务器 $\to$ 权限服务器**，经历 **3 次外网往返（RTT）**；
  * 若本地域名服务器**已缓存该域名**：经历 **0 次外网 RTT**，直接由本地 DNS 瞬间返回。
