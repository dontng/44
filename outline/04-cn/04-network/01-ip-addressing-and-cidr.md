## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) IP 地址历史演进的三次物理绝境
1. **第一代：分类 IP（A/B/C/D/E 类）的崩溃**：
   * A 类网络太巨型（主机数 $2^{24}-2 \approx 1600$ 万），普通企业根本用不完；B 类（6.5 万台）也被迅速瓜分；C 类（254 台）又太小。造成严重的 IPv4 地址浪费与全球路由表爆炸。
2. **第二代：子网划分（两级 $\to$ 三级结构）**：
   * 将原来的“网络号 + 主机号”变成“网络号 + 子网号 + 主机号”。对外依然表现为一个网络，对内通过**子网掩码（Subnet Mask）**按位与运算提取子网。
3. **第三代：无分类编址 CIDR（消除传统 ABC 类）**：
   * 采用斜线记法 `IP/前缀长度`（如 `192.168.1.0/24`）。
   * **路由聚合（形成超网 Supernetting）**：把前缀相同的多个较小网络合并为一个向外通告的路由项（例如把连续的 4 个 `/24` 聚合成一个 `/22`），极大压缩了全球核心路由器的转发表行数。

---

### (2) 最长前缀匹配原则（Longest Prefix Match，408 必考路由大题核心）
* **物理场景**：路由器收到一个目的 IP 地址，在路由表中查表时，发现与多条路由项的子网掩码进行“按位与”之后**都能匹配成功**。
* **决断铁律**：**选用子网掩码最长（即前缀长度数值最大、网络号最长）的那一条路由！**
* **必然性原理**：网络号越长，说明该子网划分得越精细、范围越小，定位越精确！

---

### (3) 网络地址转换（NAT）与私网地址划分（2020-47 大题核心）

#### 1. 专用私有 IP 地址范围（绝不能在公网上被路由器路由）
* A 类私网：`10.0.0.0 ~ 10.255.255.255`（`/8`）
* B 类私网：`172.16.0.0 ~ 172.31.255.255`（`/12`）
* C 类私网：`192.168.0.0 ~ 192.168.255.255`（`/16`）

#### 2. NAPT（网络地址与端口转换）的物理运作流
* **物理矛盾**：全球公有 IPv4 枯竭，成千上万台企业局域网主机必须共享同一个公网 IP 访问互联网。
* **运行机制**：NAT 路由器在出入端口维护一张 **NAT 转换表**：
  $$\text{内部源 IP : 内部源端口} \longleftrightarrow \text{公网 IP : 替换后的公网端口}$$
  * **出局时**：将 IP 头部里的私有源 IP 替换为路由器的公网 IP，将传输层的源端口号替换为一个唯一的外部端口；
  * **入局时**：公网服务器回包，目的地址是路由器的公网 IP 和外部端口；NAT 路由器查表，还原出局域网主机的真实私有 IP 和端口，转发回去。
* **物理关键点**：NAT 路由器打破了严格的分层协议，它**不仅要看第三层网络层（改 IP），还必须深入第四层传输层（改 TCP/UDP 端口号，并重新计算校验和）**！

- $\to$ 关联 [网络性能与时延](../01-architecture/02-performance-delays.md)：路由聚合减少了路由器路由表的大小，直接降低了数据包在路由器内部查找转发表的处理时延。

## 4. 闭环判定模型与核心认知结论

* **不可分配的主机地址两大保留（扣除 2 个）**：
  * 主机号全为 0 $\implies$ **网络本身的网络地址**；
  * 主机号全为 1 $\implies$ **该子网内的广播地址**。
  * 若主机号有 $k$ 位，该子网内**实际可分配的主机数必为 $2^k - 2$**。
* **默认路由（缺省路由）表示法**：`0.0.0.0/0`（匹配所有未命中的 IP，掩码长度为 0，优先级最低）。
