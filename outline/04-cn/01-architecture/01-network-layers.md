## 2. 核心机理与物理必然性（为什么这么设计？）

### (1) 为什么网络通信必须高度分层？
* **物理矛盾**：在嘈杂不可靠的铜线、光纤甚至无线电波上，要让两台相距几万公里的计算机进程稳定传输一份文件，涉及模拟信号调制、比特纠错、介质竞争、路由寻址、丢包重传、进程分用、数据呈现等上百个极其复杂的工程问题。
* **分层哲学（高内聚低耦合）**：每一层只专注解决一个特定尺度的通信难题，向上一层提供服务，向下一层请求服务；下层技术的革新（如光纤替代铜线）绝不波及上层应用软件。

### (2) 协议、接口与服务的黄金三角辨析（408 必考概念辨析）
1. **协议（Protocol，水平方向）**：
   * **定义**：对等实体（Peer Entity，如通信两端的运输层）之间为了协同工作而共同遵守的一套规则与报文格式。
   * **特性**：**水平的**，只有对等实体之间才有协议。
2. **服务（Service，垂直方向）**：
   * **定义**：下层为相邻上层提供的功能支持（如传输层向应用层提供可靠流服务或不可靠数据报服务）。
   * **特性**：**垂直的**，是由下层向上层提供的。下层协议对上层是**完全透明（不可见）**的。
3. **接口 / 服务访问点（SAP，层间交接处）**：
   * **定义**：相邻两层之间传递信息的边界大门。
   * **物理映射**：
     * 数据链路层的 SAP $\implies$ **MAC 地址**
     * 网络层的 SAP $\implies$ **IP 地址**
     * 传输层的 SAP $\implies$ **端口号（Port）**

### (3) OSI 七层 vs TCP/IP 四层 vs 五层教学模型

```
 OSI 七层参考模型           TCP/IP 四层模型         五层折中模型          各层协议数据单元 (PDU)
┌────────────────┐        ┌────────────────┐    ┌────────────────┐    ┌─────────────────────┐
│ 7. 应用层      │ ──┐    │                │    │ 5. 应用层      │    │ 报文 (Message)      │
├────────────────┤   │    │                │    ├────────────────┤    ├─────────────────────┤
│ 6. 表示层      │ ──┼──► │ 4. 应用层      │    │ 4. 传输层      │    │ 报文段 / 数据报     │
├────────────────┤   │    │                │    ├────────────────┤    ├─────────────────────┤

│ 4. 传输层      │ ─────► │ 3. 传输层      │    │ 2. 数据链路层  │    │ 帧 (Frame)          │

├────────────────┤        ├────────────────┤    └────────────────┘    └─────────────────────┘

└────────────────┘
```

* **OSI 独有的两层（TCP/IP 合并进应用层）**：
  * **表示层**：解决不同计算机的数据格式表示差异（加密解密、压缩解压缩、ASCII/Unicode 编码转换）；
  * **会话层**：建立、管理和终止不同机器进程之间的会话（插入检查点以支持断点续传）。

### (4) 报文封装与解封装的装箱物理过程
* **发送端逐层加头（封装）**：
  * 应用数据 $\to$ 加传输层头部（端口号） $\to$ 加网络层头部（源/目的 IP） $\to$ 加数据链路层头尾（源/目的 MAC + CRC校验） $\to$ 物理层转化为光电信号发射。
* **接收端逐层剥头（解封装）**：
  * 物理层接收比特流 $\to$ 链路层核验 MAC 并去掉帧头尾 $\to$ 网络层核验 IP 并去掉网络头 $\to$ 传输层根据端口号把纯净的有效载荷交付给对应应用进程。

## 4. 闭环判定模型与核心认知结论

* **协议与服务区分铁律**：
  * 凡是涉及“**两端对等实体**通过网络报文交互” $\implies$ **协议**；
  * 凡是涉及“**本机上下层之间**单向提供能力” $\implies$ **服务**。
* **各层传输单位 PDU 严谨对应**：
  * 传输层 $\to$ **段（Segment）**；网络层 $\to$ **分组/数据报（Packet）**；链路层 $\to$ **帧（Frame）**；物理层 $\to$ **比特（Bit）**。
