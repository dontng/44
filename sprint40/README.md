# 40天计划｜每天120分钟内以题带学

从对应的每日页开始，题图、必要知识和核对讲解已经放在执行路径内。当前已完成第1—8天；另外8个已经动笔的模块现已收尾，作为独立材料保留，不新增每日安排。原计划仍可作为后续讨论依据。先做题暴露缺口，再读折叠讲解补学，不另找视频或誊写答案。

每天预算：回忆10分钟＋选择题及补学50分钟＋两道大题及补学50分钟＋闭卷检查10分钟。总上限120分钟；不是默认要求210分钟后再让学习者自行删任务。105分作为最终考试目标，路径是否有效由独立重做与后续模考检验，不凭文件数量认定达标。

I=独立完成，H=引导后能重现，U=仍不会。U不能记为掌握。到120分钟如仍有未完成项，写下题号和断点，下一天先修复；如连续出现，须调题量或前置知识，不能用超时维持计划表面完成。
