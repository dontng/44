# 40 天冲刺每日作战库 (sprint40)

> **定位**：本目录为 40 天多学科并行冲刺的**每日真实执行档案库**，与 `src/` 同级。
> 
> **原则**：
> 1. **拒绝上下文遗忘**：做题思路、大题手写踩分点、易错陷阱、公式推导直接落盘，随时可以像翻错题本一样复习回顾。
> 2. **小步推进，不迈断腿**：每次只预备当前与次日内容，一步一个脚印，做完一天勾选一天。
> 3. **关联总纲**：任务标准严格对齐 [plan/40-day-sprint.md](../plan/40-day-sprint.md)。
