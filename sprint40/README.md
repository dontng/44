# Sprint40｜按src题组执行

**src确定题目和分类，day直接放当天题目及折叠解析。** 不再使用modules或lessons作为讲解入口；已退出的目录保存在Git历史。选择题先给答案和直接法，有价值的其他选项才补排除法或易混点，不另堆通用导学、离场检查和补救任务。

第一天是**数据结构＋操作系统**，第二天是**组成原理＋计算机网络**，每两天覆盖四科，循环40天。每次取两份完整src题单，组内保持原顺序。数据结构和计组各12份、操作系统和计网各8份；前24天覆盖所有题组，较早做完的科目穿插整组复做，后16天继续复习。

**选择题280道、大题49道，去重覆盖329／329。** 同题在不同src中重复归类时保留其组内位置，覆盖统计只算一次。每份src的选择题目前最多16道，先用大小题单搭配；今后若一份题单明显过大，再按原题顺序拆上下两次，不重新混排。src里混列的少量大题另在解答题部分安排。

用时按作答、看解析和核对一起估算，目标约两小时；重复题已会就快速通过，少数重日允许超出，不要求到120分钟强停。概念选择题初估3—5分钟、计算题5—8分钟，一道大题25—35分钟；表中为结合题组与复做情况的粗估，实际以作答记录为准。大题每天1—2道，双题优先安排在选择题较少的日子，共用题干同日处理。

**解析进度：120道不同选择题、46道大题已内嵌正文。** 其余题下短注待补；仓内2025参考键本身标为待官方核对，只有参考字母不算完整解析。题目排齐与解析齐全分开统计。
