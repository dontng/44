## 目录索引与主题导航

### 1. 操作系统（OS）
- [操作系统的特权模式与用户态物理边界](os/kernel_mode_vs_user_mode.md)
  - 核心痛点：Root 权限、Systemd、动态链接器、`malloc`、用户级线程、信号处理函数到底是用户态还是内核态？
  - 判定基准：CPU 硬件特权级（CPL / Ring 0 vs Ring 3）与软件安全身份（UID=0）的解耦。
  - 关联真题：`2026-23`、`2025-46`
- [中断、自陷与异常处理的底层硬件全链路](os/interrupt_and_trap_mechanisms.md)
  - 核心痛点：为什么 INT 3 必须是单字节 `0xCC`？中断发生时硬件自动完成什么、操作系统软件完成什么？
  - 硬件时序：硬件隐指令关中断、切内核栈、压栈 PC/PSW 与驱动程序读取控制器的分工。
  - 关联真题：`2026-24`、`2023-46`

### 2. 计算机组成原理（CO）
- [组相联 Cache 的跨步映射与无冲突遍历推导](co/cache_stride_and_conflict_mapping.md)
  - 核心痛点：二维数组按列遍历破坏了空间局部性，为什么特定条件下 Cache 命中率依然高达 87.5%？
  - 严密推演：行跨度 256B 导致组号以 8 为步长循环，24 行仅映射到 8 个组，每组 3 块少于 4 路容限，无组内置换。
  - 关联真题：`2023-43`
