# 今天怎么复习

[真题59条线：闭卷检查与变式](main.md) · [网络96题：按机制调用](network.md) · [原题主线](../src/README.md)

先处理少量已经学过的内容，再继续当前主线。日期只是题链编号；没有学过的旧日期不是欠账。现在的复盘记录为空，表示尚未在新流程中验证，并不抹去旧作答，也不替你宣称已经掌握。

## 一次20—25分钟的复盘

1. 选3—5道到期短题，或1道完整大题加1道短题。先看题面，合上解析，写出第一步和关键依据；大题必须带全部小问。
2. 核对以后定位一个真实断点：读漏条件、选错机制、运算失误、边界混淆或超时。只补这个断点，再合上重做。刚看完解析的复做记作“提示后完成”。
3. 做页面的条件变化检查。答对原题却不能解释变化，仍需加固；不靠记住选项字母通过。
4. 只记一句实际证据，例如“能列逐轮次数，但把几何和当轮数×最大项”。然后回主线，避免复盘耗尽新学习时间。

没有命令行也能直接点上面两张索引使用。可在对话中提交“题号、实际答案/过程、是否看提示、卡点、耗时”，由协作者核对后记录；不需要手工维护另一套长笔记。

## 怎样安排下次出现

首次独立完成后约1天再问；到期且再次独立完成才逐步延长为3、7、14、30、60天。提示、不确定或失败则回到约1天，先修复具体断点。同一天反复做对、提前复做都不会迅速升级；当天曾依赖提示，就保留短间隔。

这些天数是可调整的初始工作规则，不是测出了你的遗忘曲线。目标是延迟后能恢复方法，不能保证永久不忘。中断后只做今天预算内的重点项，未选项保留原到期日期，不算失败，也不要求补完所有欠账才能前进。

每周挑一次已学范围内的混合训练，先不显示机制分类：选择题向每题1—2分钟推进，大题按完整题预留时间。分别看独立正确、提示依赖、方法辨认、耗时；先把错因修好，再提高速度。日常恢复题默认预留4分钟，大题20分钟，预算只是选题估计，不是给每题统一成绩线。

## 让旧知识持续被使用

真题同一题跨能力线只保留一个题号、一个复习状态。后续新题独立用出了旧机制，可指明“加固哪一道旧题、具体哪一步”；它能作为那道旧题的迁移证据，避免机械重复。同主题、同标签、看过类似解析都不能自动抵扣，更不能一次判整条线掌握。

第一次卡在起手就回到该题解析；若多题都卡同一步，再回主线相应机制卡。原题恢复、换条件、延迟混合是三种不同证据；保留这种区别，比把所有题分进一个“已会”文件夹更有用。

<summary>可选：自动选出今天的到期项</summary>

在仓库根目录运行：

```bash
python tools/review.py today --limit 5 --minutes 25
python tools/review.py list 海明
python tools/review.py status
```

只有真实记录过的题进入到期队列；首次运行仅给两个可选入门入口，不把895道题全变成逾期任务。完整大题不会为凑时间被拆开。

实际做完后记录，下面只是命令示例，不是已经发生的成绩：

```bash
python tools/review.py record q:2011-01 prompted --note '提示后才想到逐轮求和'
python tools/review.py record net:2025-0912 independent --mode transfer --seconds 85 --note '闭卷解释在途量，并答出距离变化的影响'
```

状态只能选 `independent`（没看提示且说明依据）、`prompted`、`uncertain`、`failed`。`--date YYYY-MM-DD`仅用于补录实际发生日期，不允许未来成绩。复习类型 `original`、`transfer`、`mixed` 分别表示原题、条件变化、混合辨认。

后续独立迁移若确实加固了已记录过的旧题，可在 `record` 命令中加 `--reinforces 旧题号 --transfer-note '具体复用了哪一步'`；必须是不同日期且是独立迁移/混合作答。调度器只为指定旧题追加这次使用证据，不批量升级同组。

记录默认存入独立事件目录，永不覆盖首次记录。也可用全局参数 `--events-dir /自己的本地目录` 将新记录保存在仓库之外。程序不会自动推送，也不会从旧盒子数据导入状态。

<details>
<summary>设计依据与边界</summary>

[Roediger & Karpicke（2006）](https://doi.org/10.1111/j.1467-9280.2006.01693.x)比较了重新学习与提取练习对延迟保持的影响；因此这里把“先尝试恢复”放在看解析之前。[Cepeda等（2008）](https://doi.org/10.1111/j.1467-9280.2008.02209.x)考察间隔与保持时间的关系；因此这里安排跨日复现，并允许根据表现调节，而不宣称一套固定日期对所有人最优。

具体1/3/7/14/30/60天、题量预算、跨题加固与机制卡是本项目的实用设计，不是上述研究直接验证过的408提分处方。最终仍用实际延迟、迁移与混合限时表现检验。

</details>
