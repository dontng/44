## 定位：第一遍过书，理解优先

用户没有时间刷题、看书，但能聊天。所以聊天是唯一的生产过程，md 是产物。第一遍的目标不是细节，是地图：**哪厚哪薄、各章为什么存在、题从哪里出**。

## 目录

```text
data-structures/       数据结构（ch01–ch08）
computer-organization/ 计算机组成原理（ch01–ch07）
operating-systems/     操作系统（ch01–ch05）
computer-networks/     计算机网络（ch01–ch06）
```

每科按章节拆 md，标题沿用王道小结标题。聊完一章，把提纯写回对应 md——对话会蒸发，写回才沉淀。

## 维持与收敛的三个锚

1. **骨架当轨道**：聊得再远，最后落回 md 小结标题。
2. **跨章主线反复回收**：分层与局部性、幻觉工程、时间换空间、抽象屏蔽细节——新章节挂回老根。
3. **408 权重标尺**：C 位章节深挖、龙套扫过，持续标注"为什么考它"。

## 聊天的规矩

- 不背书、不说书：说理解、说看法，带 408 趋势的侧重。
- 命题人视角：知道什么有考点重量；不为严谨去读真题。
- 内容目标是**主菜级**（可直接当考点的判断句、公式算例、易错对照），不是只有认识的菜单级。
