# 1.5 计算机网络的性能指标-速率、带宽、吞吐量、时延

计算机网络的性能指标是衡量网络通信质量、传输效率与承载能力的定量标准。其中，**速率、带宽、吞吐量和时延**是最基础且最常用于链路评估与容量规划的核心指标。

---

## 一、速率（Data Rate / Bit Rate）

### 1. 基本概念
- **定义**：网络中数据传输的快慢，即单位时间内传输的比特（bit）数量。在计算机网络中也称为**比特率（Bit Rate）**或**数据率（Data Rate）**。
- **基本单位**：**b/s**（比特每秒，或写作 bps，bit/s）。
- **常用单位进位制（十进制 / 10 的幂次方）**：
  在电信通信与数据传输速率领域，数量级单位严格遵循国际度量衡进位规则（$10^3$ 进位制），**严禁与计算机内部存储容量单位混淆**：
  $$\begin{aligned}
  1\text{ kb/s} &= 10^3\text{ b/s} = 1{,}000\text{ b/s} \\
  1\text{ Mb/s} &= 10^6\text{ b/s} = 1{,}000\text{ kb/s} \\
  1\text{ Gb/s} &= 10^9\text{ b/s} = 1{,}000\text{ Mb/s} \\
  1\text{ Tb/s} &= 10^{12}\text{ b/s} = 1{,}000\text{ Gb/s}
  \end{aligned}$$

### 2. 关键辨析：传输速率与存储容量的度量单位差异
- **存储容量领域**：通常以**字节（Byte，1 Byte = 8 bits）**为基准单位，采用 $2^{10} = 1024$ 进位制：
  $$1\text{ KB} = 2^{10}\text{ B} = 1024\text{ B}, \quad 1\text{ MB} = 2^{20}\text{ B} = 1024\text{ KB}$$
- **数据传输速率领域**：以**比特（bit）**为基准单位，采用 $10^3 = 1000$ 进位制：
  $$1\text{ Mb/s} = 10^6\text{ b/s} = 1{,}000{,}000\text{ b/s}$$
- **换算示例**：
  将一个大小为 $100\text{ MB}$ 的文件通过 $100\text{ Mb/s}$ 的理想链路发送，该文件的实际总比特数为 $100 \times 2^{20} \times 8\text{ bit} \approx 8.3886 \times 10^8\text{ bit}$；链路每秒发送的数据量为 $100 \times 10^6\text{ bit} = 10^8\text{ bit}$。理论纯发送耗时为 $8.3886\text{ s}$，而非直觉上的 $1\text{ s}$ 或 $8\text{ s}$。

## 二、带宽（Bandwidth）

在不同的学术与工程语境下，“带宽”具有两种截然不同但紧密相连的物理定义：

```text
       【频域视角：模拟通信】                      【时域视角：数字通信】
  信号最高频率与最低频率之差 (Hz)              单位时间内信道通过的最高比特数 (b/s)
  例如：传统电话线路带宽为 3.1 kHz              例如：以太网接口带宽为 1 Gb/s
```

### 1. 信号处理 / 物理学定义（频域带宽）
- 指某个信号具有的频带宽度，或传输介质能够有效通过的**最高频率与最低频率之差**。
- **单位**：**赫兹（Hz）**、kHz、MHz、GHz。
- 例如：传统模拟电话语音信道的有效通频带为 $300\text{ Hz} \sim 3400\text{ Hz}$，其带宽为 $3.1\text{ kHz}$。

### 2. 计算机网络 / 数字通信定义（时域极限速率）
- 指一条通信信道或网络接口所能够承载的**最高数据传输速率（极限传输能力）**。
- **单位**：**b/s**、Mb/s、Gb/s。
- 习惯上常将“该网络链路的带宽为 $100\text{ Mb/s}$”表述为信道的最大理论数据率。

### 3. 两者的本质物理联系
根据**奈奎斯特定理（Nyquist Formula）**和**香农公式（Shannon Formula）**，信道在频域上的模拟带宽（$W$，单位 Hz）直接决定了该信道在数字通信中所能达到的最高信息传输速率（时域带宽，单位 b/s）：
$$C = W \log_2\left(1 + \frac{S}{N}\right) \quad (\text{b/s})$$
频带宽度越宽，单位时间内能够传输的数字信息极限上限越高。

## 三、吞吐量（Throughput）

### 1. 基本概念
- **定义**：单位时间内**实际通过某个网络（或信道、接口）的有效数据量**。
- **单位**：与速率相同，通常为 **b/s**、Mb/s，或以**分组数每秒（pps, packets per second）**度量。
- **与带宽的关系**：
  - **带宽（Bandwidth）**是链路在设计与物理极限上的**理论上限**；
  - **吞吐量（Throughput）**是网络在现实运行负载、协议开销、拥塞控制和碰撞冲突下的**实际传输效果**。
  - 吞吐量必然小于或等于链路带宽：$\text{Throughput} \le \text{Bandwidth}$。

### 2. 瓶颈链路（Bottleneck Link）
若端到端路径由多段具有不同带宽的串联链路组成，在不考虑其他并发流量干扰与排队丢包的理想情况下，端到端路径的最大理论吞吐量取决于**整条路径上带宽最小的那一段链路**（即瓶颈链路）：
$$\text{Throughput}_{\text{end-to-end}} \le \min\left(R_1, R_2, \dots, R_n\right)$$

```text
  [发送主机] ── 1 Gb/s ── [路由器 A] ── 10 Mb/s (瓶颈) ── [路由器 B] ── 100 Mb/s ── [接收主机]
                                       ▲
                         端到端最高吞吐量受限于 10 Mb/s
```

## 四、时延（Delay / Latency）

时延是指数据（一个报文、分组或单个比特）从网络的一端传送到另一端所耗费的全部时间。网络端到端总时延由四个不可分割的物理分量累加而成：

$$\text{总时延 } T_{\text{total}} = T_{\text{发送}} + T_{\text{传播}} + T_{\text{处理}} + T_{\text{排队}}$$

```text
  发送端节点                        传输信道 / 物理介质                       接收端节点
  ┌──────────────┐                                                   ┌──────────────┐
  │ 产生数据分组 │                                                   │ 完整接收分组 │
  └──────┬───────┘                                                   └──────▲───────┘
         │                                                                  │
         ▼                                                                  │
  [ 1. 发送时延 ] ───(电磁波推进)───> [ 2. 传播时延 ] ───> [ 3. 处理时延 ] ───> (放入输出队列)
  将所有比特推向信道                    在物理信道上传播时间      校验与寻径开销
         │                                                                  │
         └─────────────────────── [ 4. 排队时延 ] ──────────────────────────┘
                                 在路由器缓冲区等待调度转发
```

### 1. 发送时延（Transmission Delay / 传输时延）
- **物理过程**：主机或路由器将一个数据分组的**全部比特推送到物理传输信道上**所需要的时间，即从发送第一个比特算起，直到最后一个比特完全离开节点网卡进入物理信道为止的时间差。
- **数学计算公式**：
  $$T_{\text{发送}} = \frac{\text{分组长度（比特数 } L \text{）}}{\text{发送速率 / 链路带宽（} R \text{）}}$$
  - 分组越长（$L$ 越大），发送时延越长；
  - 节点接口发送速率越高（$R$ 越大），发送时延越短。
- **发生位置**：发生在**网络节点内部的网卡 / 适配器输出端**。

### 2. 传播时延（Propagation Delay）
- **物理过程**：电磁波信号在**物理传输介质（如光纤、双绞线、自由空间）中传播一定的物理距离**所消耗的时间。
- **数学计算公式**：
  $$T_{\text{传播}} = \frac{\text{物理信道长度（距离 } D \text{）}}{\text{电磁波在介质中的传播速率（} V \text{）}}$$
- **介质中的典型传播速度 $V$**：
  - 真空中的光速：$c = 3.0 \times 10^8\text{ m/s} = 300{,}000\text{ km/s}$；
  - 铜缆（双绞线/同轴电缆）中的电信号传播速度：约为 $2.0 \times 10^8\text{ m/s} = 200\text{ km/ms}$；
  - 光纤中的光脉冲信号传播速度：约为 $2.0 \times 10^8\text{ m/s} = 200{,}000\text{ km/s}$（因光纤玻璃纤芯折射率 $n \approx 1.5$，$V = c / n$）。
- **发生位置**：发生在**两节点之间的物理介质链路上**。

### 3. 处理时延（Processing Delay）
- **物理过程**：交换节点（路由器或交换机）在收到分组后，解析分组首部、提取目的地址、校验差错校验和、查询转发表以决定输出端口，以及必要时修改首部（如 TTL 减 1、重新计算首部校验和）等操作所耗费的 CPU 或硬件流水线处理时间。
- **数值量级**：在现代高性能硬件路由器中，处理时延通常在微秒（$\mu\text{s}$）级别。

### 4. 排队时延（Queuing Delay）
- **物理过程**：分组在进入路由器的输入队列等待处理，或在确定输出端口后进入输出队列等待链路可用并发射所消耗的时间。
- **特性**：**排队时延具有极大的动态不确定性**。
  - 若网络流量清闲，队列为空，排队时延趋近于零；
  - 若网络处于高峰拥塞状态，输出链路利用率极高，排队时延将急剧飙升；若队列缓存溢出，则会发生**丢包（Packet Loss）**。

## 五、发送时延与传播时延的核心本质辨析

工程实践中最容易被混淆的概念是发送时延与传播时延：

| 维度 | 发送时延（传输时延 $T_{\text{发送}}$） | 传播时延（$T_{\text{传播}}$） |
|---|---|---|
| **物理本质** | 节点把数据“挤上”信道的过程 | 信号在信道上“跑完全程”的过程 |
| **决定因素** | 分组大小 $L$、网卡发送速率 $R$ | 链路物理长度 $D$、介质内光电传播速度 $V$ |
| **与距离的关系** | **与传输距离毫无关系** | **与物理传输距离成严格正比** |
| **与速率的关系** | **与接口速率成严格反比** | **与接口发送速率毫无关系** |
| **典型改善途径** | 升级高速网卡、提升交换机端口带宽 | 缩短物理走线路径、优化地理路由 |

> **物理直观比喻（车队过收费站）**：
> - 一支拥有 10 辆车的车队通过收费站，收费员每 5 秒放行一辆车，全部 10 辆车完全通过收费站耗时 50 秒，这就是**发送时延**（取决于车辆数量与收费站服务速率）；
> - 车辆全部驶上高速公路后，以 100 km/h 的速度开往 100 公里外的另一座城市需要耗费 1 小时，这就是**传播时延**（取决于公路长度与车速）。提升收费站办理速度（提高带宽）丝毫无法改变车在高速公路上跑 100 公里所需的时间。
