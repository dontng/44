# 1.4 计算机网络的定义和分类

计算机网络在工程与学术上有着明确的定义。为了系统化地理解不同规模与形态的网络，通常从地理覆盖范围、传输介质、拓扑结构以及使用者性质等多个维度进行科学分类。

---

## 一、计算机网络的精准定义

计算机网络并没有单一的标准官方定义。目前国内外公认的最通用、最具概括性的定义为：

> **“计算机网络主要是由一些通用的、可编程的硬件（如个人电脑、服务器、智能终端等）互连而成的，而这些硬件并非专门用来实现某一特定目的（例如传送数据或视频）。计算机网络能够传送多种不同类型的数据，并能支持广泛且日益增长的应用。”**

- **定义的关键内涵**：
  1. **通用性与可编程性（General-Purpose & Programmable）**：区分了传统电话网（专用电路硬件不可软件编程）；
  2. **多业务数据承载能力**：文本、图像、语音、视频、物联网传感器信号均可统一数字化承载；
  3. **两大基本功能**：**数据通信**（首要功能，实现信息跨节点传输）与 **资源共享**（硬件、软件与海量数据的高效共享）。

---

## 二、计算机网络的常见分类方法

### 1. 按网络的地理覆盖范围划分（最核心分类）

根据网络覆盖的物理跨度与空间尺度，网络主要划分为四种经典层级：

```text
  [ 个人区域网 PAN ]  <  [ 局域网 LAN ]  <  [ 城域网 MAN ]  <  [ 广域网 WAN ]
     (1 ~ 10 米)          (10 米 ~ 1 公里)       (5 ~ 50 公里)        (几十 ~ 上万公里)
```

| 网络类别 | 英文缩写 | 典型地理覆盖范围 | 核心技术与归属特征 |
|---|:---:|---|---|
| **个人区域网** | **PAN** (Personal Area Network) | **$1 \sim 10$ 米**（个人工作空间范围） | 围绕个人智能设备构筑的短距离无线通信。典型代表：**蓝牙（Bluetooth）**、ZigBee、超宽带（UWB）。 |
| **局域网** | **LAN** (Local Area Network) | **数米至数公里**（一个房间、一栋大楼或一个校园/厂区） | 通常由单一企业、学校或单位**独立自主投资建设并专有拥有**。具有高带宽、低误码率与低时延特性。典型代表：**以太网（Ethernet）**、无线局域网（Wi-Fi）。 |
| **城域网** | **MAN** (Metropolitan Area Network) | **$5 \sim 50$ 公里**（一个城市或整个城区） | 通常由电信运营商或市政机构统筹建设，负责连接该城市内部的多个局域网。通常采用高速光纤作为骨干传输网络。 |
| **广域网** | **WAN** (Wide Area Network) | **几十公里到几千甚至上万公里**（跨省、跨国、跨大洲） | **因特网的核心主干骨干网即属于广域网**。通常由大型国家级电信运营商建设运营，负责远距离、超大容量的数据分组交换与跨洋光缆传输。 |

- **广域网与局域网的本质区别不仅仅是距离**：
  - **局域网**：通常属于单位私有资产，底层采用多路访问共享介质协议（如 CSMA/CD、以太网交换），网络层通常采用单一子网前缀；
  - **广域网**：属于公共商用电信基础设施，跨越多个独立自治系统，底层广泛采用点对点专线（如光纤传输网、SDH、DWDM）结合大规模分布式路由选择协议。

---

### 2. 按数据传输所采用的物理介质划分
- **有线网络（Wired Networks）**：
  - 依赖实体导引型传输介质，如**双绞线（Twisted Pair）**、**同轴电缆（Coaxial Cable）**、**光纤（Optical Fiber）**；
  - 特点：抗电磁干扰能力强、带宽极大、传输误码率极低、物理接入易于管控。
- **无线网络（Wireless Networks）**：
  - 依靠空间自由传播的非导引型电磁波传输，如无线电微波、红外线、卫星通信；
  - 特点：无需布线、终端具备极强的移动性；但信道容易受多径效应、天气与障碍物物理衰减干扰，误码率显著高于有线信道。

---

### 3. 按网络的物理与逻辑拓扑结构划分

```text
       【总线拓扑 (Bus)】              【星形拓扑 (Star)】              【网状拓扑 (Mesh)】
  ──┬─────┬─────┬─────┬──           [节点]    [节点]             [节点] ─── [节点]
    │     │     │     │                \       /                  │   \   /   │
  [A]   [B]   [C]   [D]                 [ 集线器/交换机 ]           │     X     │
  (单根总线广播，单点断开全网瘫痪)             /       \                  │   /   \   │
                                     [节点]    [节点]             [节点] ─── [节点]
                                     (中心故障全瘫，扩展极其方便)       (核心广域网标准，高可靠多冗余)
```

1. **总线拓扑（Bus Topology）**：所有节点共享挂接在同一根物理同轴电缆总线上。结构简单，但总线开路会导致全网反射瘫痪，目前已被全面淘汰；
2. **星形拓扑（Star Topology）**：每个节点都通过一条独立的双绞线连接到中心设备（集线器或交换机）。单条连线断开不影响其他节点，易于维护和故障隔离，是**现代局域网的标准物理拓扑**；
3. **环形拓扑（Ring Topology）**：各节点通过点对点物理链路串联成封闭回路（如早期令牌环网 Token Ring）；
4. **网状拓扑（Mesh Topology）**：每个节点与多个其他节点同时相连，存在多条可选传输路径。具有极高的抗毁冗余性与负载均衡能力，是**广域网和因特网骨干路由器的核心拓扑**。

---

### 4. 按网络的使用者性质划分
- **公用网（Public Network）**：由电信部门或 ISP 建设运营，面向社会全公众开放，任何用户只要按标准付费即可接入使用（如因特网、公共移动通信网）；
- **专用网（Private Network）**：由军队、政府、金融或铁路等特定行业部门自费独立建设，仅供本部门内部特定业务使用，不对外公开开放（如军用机密指挥网）。
