# 4.4.4 开放最短路径优先 OSPF

**开放最短路径优先（OSPF，Open Shortest Path First）** 协议是目前广泛使用的内部网关协议（IGP）。它基于**链路状态（Link-State）**路由选择算法，克服了 RIP 协议跳数受限和收敛缓慢的缺陷。

---

## 一、OSPF 的基本概念与核心特征

### 1. 协议核心属性
- **开放性（Open）**：OSPF 标准公开发表在 RFC 中，任何厂商设备均可遵循该标准实现互联；
- **底层报文封装**：OSPF 是直接运行在网络层之上的协议，其报文**直接封装在 IP 数据报中传送**（IP 首部的协议字段固定为 **89**）。OSPF 不使用传输层的 UDP 或 TCP，在协议自身内部实现了报文确认和重传机制；
- **度量标准（Cost / 费用）**：
  - OSPF 用链路的“代价（Cost）”作为度量标准，链路的代价通常与链路的**带宽成反比**；
  - 链路带宽越高，开销越小，选路越优；
- **组播发送**：
  - `224.0.0.5`：代表网络中所有的 OSPF 路由器；
  - `224.0.0.6`：代表所有的 DR（指定路由器）和 BDR（备用指定路由器）。

### 2. 链路状态协议的三大交换特征
1. **和谁交换**：使用**洪泛法（Flooding）**向本自治系统（或本区域）内的**全网所有路由器**发送信息；
2. **交换什么**：发送的信息是本路由器**直连的所有链路的状态信息**（包括连接的接口 IP、相邻路由器以及该链路的度量开销）；
3. **何时交换**：**只有当链路状态发生变化时**，路由器才使用洪泛法发送链路状态更新（另外配合极低频的周期性链路状态刷新）。

### 3. 全局链路状态数据库（LSDB）与无环生成树
- 全网每台路由器通过洪泛收集所有其他路由器发出的链路状态通告（LSA），在本地内存中构建起全网一致的**链路状态数据库（LSDB，Link State Database）**；
- LSDB 完整反映了全网所有路由器与链路的拓扑全貌；
- 每台路由器以自身为根节点，独立运行 **Dijkstra 最短路径优先（SPF）算法**，计算出一棵到达全网各个目的网络的最短路径生成树（SPF 树），从而生成路由表；
- **数学证明保证**：由于每台路由器都基于完整的全局拓扑图独立计算生成树，OSPF 在算法本质上从根本上杜绝了路由环路的产生。

## 二、OSPF 的五种分组类型与工作流程

```
       路由器 R1                                              路由器 R2
           │                                                      │
           ├─────────────── 1. Hello 报文 (组播 224.0.0.5) ──────>│ (发现并维持邻居)
           │<────────────── 1. Hello 报文 (确认包含 R1 标识) ─────┤
           │                                                      │
           ├─────────────── 2. DBD 报文 (数据库描述摘要) ─────────>│ (互相通告本端
           │<────────────── 2. DBD 报文 (数据库描述摘要) ─────────┤  拥有的 LSA 目录)
           │                                                      │
           ├─────────────── 3. LSR 报文 (链路状态请求) ───────────>│ (向对端索要缺失
           │                                                      │  或过期的详细条目)
           │<────────────── 4. LSU 报文 (链路状态更新) ───────────┤ (真正发送完整
           │                                                      │  的 LSA 详细实体)
           │                                                      │
           ├─────────────── 5. LSAck 报文 (链路状态确认) ─────────>│ (显式确认，
           │                                                      │  保证可靠传输)
           ▼                                                      ▼
     [LSDB 数据库达到完全同步一致，分别独立运行 SPF 算法生成路由表]
```

### 五种分组类型功能说明：
1. **Hello 报文**：用于发现、建立和周期性维护相邻路由器之间的邻居关系，并在广播网络中选举 DR 和 BDR；
2. **数据库描述报文（DBD，Database Description）**：向对端发送本地 LSDB 的目录摘要（只包含 LSA 的头部），供对端比对哪些数据已过期或缺失；
3. **链路状态请求报文（LSR，Link State Request）**：向对端请求发送某些特定的、详细的 LSA 条目；
4. **链路状态更新报文（LSU，Link State Update）**：用洪泛法向全网发送多条详细的 LSA 数据报文（全网同步的真正数据载荷）；
5. **链路状态确认报文（LSAck，Link State Acknowledgment）**：对收到的 LSU 报文进行逐一确认，确保更新报文在 IP 层之上的可靠交付。

## 三、指定路由器 DR 与备用指定路由器 BDR

在以太网等多路访问（Multi-Access）广播网络中，如果所有路由器两两之间都建立邻接关系，会导致相邻关系数量呈平方级爆炸（$N$ 台路由器产生 $\frac{N(N-1)}{2}$ 对关系），链路状态洪泛更新将引发严重的网络广播风暴。

### 1. DR 与 BDR 的工作机制
- **指定路由器（DR，Designated Router）**：广播网中的所有普通路由器（DRother）仅与 DR 建立完全的邻接关系，所有链路状态更新由 DR 统一接收并向全网转发；
- **备用指定路由器（BDR，Backup Designated Router）**：实时监听并同步网络状态。一旦 DR 发生故障，BDR 立即接替其工作，无需重新选举。

### 2. 选举准则
1. 比较接口的**路由器优先级（Priority）**，取值范围为 $0 \sim 255$（默认值为 1，优先级为 0 表示不参与选举），优先级最高者当选 DR；
2. 若优先级相同，则比较路由器的 **Router ID（通常为配置的 Loopback 接口中最大的 IP 地址）**，数值最大者当选；
3. **不可抢占原则**：DR 和 BDR 一旦选举产生并稳定运行，即使后续加入了一台优先级更高的路由器，也**绝不发生重新选举**，直到当前 DR 或 BDR 故障下线。

## 四、OSPF 的分层区域划分

为了能够支持上千台路由器的大型自治系统，OSPF 允许将一个自治系统划分为若干个更小的逻辑**区域（Area）**：

```
+---------------------------------------------------------------------------------+
|                        主干区域 Area 0 (Backbone Area)                          |
|             所有非主干区域之间的流量，必须且只能经过主干区域 Area 0 进行中转!     |
|             (包含主干路由器 BR 与区域边界路由器 ABR)                            |
+---------------------------------------------------------------------------------+
           ▲                                                         ▲
           │                                                         │
   +───────▼─────────────────────+                   +───────────────▼─────────────+
   |      非主干区域 Area 1      |                   |       非主干区域 Area 2     |
   | (区域内部的 LSA 洪泛更新    |                   | (区域内部的 LSA 洪泛更新    |
   |  被严格限制在 Area 1 内部)  |                   |  被严格限制在 Area 2 内部)  |
   +─────────────────────────────+                   +─────────────────────────────+
```

- **分层效果**：
  - 洪泛更新被限制在每个具体的区域内部，一个区域内的拓扑变化不会引发其他非主干区域重新计算 SPF 树；
  - 只有在主干区域与非主干区域之间才通告汇总路由，极大地减轻了路由器的内存与 CPU 负荷。

### 四类路由器角色定义：
1. **内部路由器（IR，Internal Router）**：所有的接口都属于同一个非主干区域的路由器；
2. **主干路由器（BR，Backbone Router）**：至少有一个接口连接在主干区域（Area 0）的路由器；
3. **区域边界路由器（ABR，Area Border Router）**：**同时连接主干区域 Area 0 和一个或多个非主干区域**的路由器，负责区域间路由的汇聚与转发；
4. **自治系统边界路由器（ASBR，AS Boundary Router）**：与其他自治系统或外部路由协议交换路由信息的路由器。
