# 4.4.4 开放最短路径优先OSPF

**开放最短路径优先（Open Shortest Path First，OSPF）** 是目前因特网自治系统内部使用最广泛的**分布式链路状态路由协议（Link-State Protocol）**。其核心算法是著名计算机科学家 Dijkstra 提出的**最短路径优先（SPF）算法**。

---

## 一、OSPF 的三大核心操作特征（与 RIP 的本质区别）

| 特征维度 | OSPF (链路状态协议) | RIP (距离向量协议) |
|---|---|---|
| **向谁发送？** | **向本自治系统中的所有路由器泛洪（Flooding）** | 仅与直连的相邻路由器交换 |
| **发送什么？** | **与本路由器相邻的所有路由器的链路状态（LSA）** | 自己当前的整个路由表 |
| **何时发送？** | **仅当链路状态发生变化时才触发通告（Triggered）** | 固定每隔 30 秒周期性广播 |
| **全网拓扑认知** | 全网每台路由器拥有**完全一致的链路状态数据库（LSDB）** | 传闻路由，各节点只知道距离和下一跳 |
| **协议栈归属** | **直接封装在 IP 数据报中传输（协议号 89）** | 封装在 UDP 用户数据报中传输（端口 520） |

> **关键考点**：OSPF **不使用** 传输层协议（UDP 或 TCP），而是**直接承载在 IP 数据报上（IP 协议字段 = 89）**。OSPF 自行实现可靠传输（通过确认与重传机制）。

---

## 二、OSPF 的工作过程（链路状态数据库 LSDB 的建立）

1. **发现并维护邻居关系（Hello 报文）**：
   - 每隔 10 秒向组播地址 `224.0.0.5` 发送 Hello 报文，确认邻居存活；40 秒未收到则判定邻居死亡。
2. **通告链路状态（LSA / LSU 报文）**：
   - 链路状态包括：直连网络的网络号与掩码、直连邻居、接口的**度量（Metric / 代价 Cost）**（OSPF 的 Cost 与链路带宽成反比，克服了 RIP 纯跳数的缺点）。
   - 通过**链路状态更新（LSU）**报文在全网泛洪。
3. **建立全网统一的 LSDB（全网拓扑图）**：
   - 泛洪收敛后，全网所有路由器的 **LSDB（Link State Database）** 达到完全一致。LSDB 本质上就是一张完整的有向加权连通图。
4. **运行 Dijkstra 算法计算路由**：
   - 每台路由器以**自己为根节点**，基于本地的 LSDB 独立运行 Dijkstra 算法，构建一棵**无环的最短路径树（SPF Tree）**；
   - 从树中提取出到达各目的网络的最优下一跳，写入本地 IP 路由表。
   - **核心优势**：从数学算法根源上**彻底杜绝了路由环路（No Routing Loops）**。

---

## 三、OSPF 的五种分组类型

| 分组类型 | 中文名称 | 核心功能 |
|:---:|---|---|
| **类型 1** | **问候分组 (Hello)** | 发现和维持相邻路由器的可达性，建立邻居关系 |
| **类型 2** | **数据库描述 (DBD)** | 向邻居发送本端 LSDB 的摘要目录，用于比对差异 |
| **类型 3** | **链路状态请求 (LSR)** | 收到 DBD 后，向对端索取自己所缺失的详细 LSA |
| **类型 4** | **链路状态更新 (LSU)** | 泛洪发送包含多条完整 LSA 的更新报文（真正的数据同步） |
| **类型 5** | **链路状态确认 (LSAck)**| 对收到的 LSU 报文进行显式单播/组播确认，保证可靠传输 |

---

## 四、OSPF 的层次化区域划分（应对超大规模网络）

当自治系统规模极其庞大时，全网泛洪 LSA 会消耗海量带宽，且频繁运行 SPF 算法会耗尽 CPU。OSPF 引入了**区域（Area）**概念，将一个 AS 划分为多个逻辑区域：

```text
+-------------------------------------------------------------+
|               主干区域 Area 0 (Backbone Area)               |
|            负责在各非主干区域之间中继转发路由信息            |
+-------------------------------------------------------------+
        ^                                             ^
        |                                             |
+-------v---------------------+             +---------v-------------------+
|     标准区域 Area 1         |             |       标准区域 Area 2       |
| 内部泛洪仅局限在 Area 1     |             | 内部泛洪仅局限在 Area 2     |
+-----------------------------+             +-----------------------------+
```

### 路由器类型分工（考点名词）
1. **内部路由器（IR）**：所有接口均属于同一个非主干区域；
2. **主干路由器（BR）**：至少有一个接口连接到主干区域 Area 0；
3. **区域边界路由器（ABR）**：连接一个或多个非主干区域与主干区域 Area 0，负责区域间的路由汇总与过滤；
4. **自治系统边界路由器（ASBR）**：连接外部网络或其他 AS，将外部路由引入 OSPF。
