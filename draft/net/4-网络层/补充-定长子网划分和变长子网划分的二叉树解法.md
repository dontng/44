# 补充 定长子网划分和变长子网划分的二叉树解法

在 408 综合大题中，面对复杂的变长子网划分（VLSM），手工编写十进制与二进制往往繁琐且极易算错。**二叉树划分法（Subnet Binary Tree）** 能够建立直观的几何空间模型，保证分配**绝对不重叠、无缝拼装**。

---

## 一、二叉树划分模型的核心几何原理

1. **根节点**：代表分配到的原始网络前缀（例如 `192.168.1.0/24`，空间大小为 256）；
2. **左分支代表 `0`，右分支代表 `1`**：每一次分裂，前缀长度增加 1 位（$/n 	o /n+1$），子网地址空间**严格对半减半**；
3. **分配黄金铁律（无重叠保证）**：
   - **如果一个节点已经被分配给某个子网（成为叶子节点），则其所有的子孙后代节点全部被锁死，绝不能再分配给其他子网！**

---

## 二、二叉树空间拆解全景图

以 `192.168.1.0/24` 为例：

```text
                                [ 192.168.1.0/24 ] (总容量 256)
                                       /         \
                                      /           \
                     [ .0/25 ] (容量 128)      [ .128/25 ] (容量 128)
                       /       \                  /       \
                      /         \                /         \
            [ .0/26 ] (64)   [ .64/26 ] (64) [ .128/26 ] (64) [ .192/26 ] (64)
                                                 /     \
                                                /       \
                                       [ .128/27 ](32) [ .160/27 ](32)
```

## 三、二叉树实战分配标准三步秒杀法

> **【实战题】**：基准网段为 `10.0.0.0/24`，需满足：
> - 子网 A：需要 90 台主机
> - 子网 B：需要 40 台主机
> - 子网 C：需要 10 台主机

### 第一步：自底向上，确定各子网所需最小叶子节点深度
- **子网 A (90台)**：$2^h - 2 \ge 90 \implies h=7$，前缀 $= 32 - 7 = \mathbf{/25}$（块大小 128）；
- **子网 B (40台)**：$2^h - 2 \ge 40 \implies h=6$，前缀 $= 32 - 6 = \mathbf{/26}$（块大小 64）；
- **子网 C (10台)**：$2^h - 2 \ge 10 \implies h=4$，前缀 $= 32 - 4 = \mathbf{/28}$（块大小 16）。

### 第二步：从大到小，在二叉树上截取叶子节点
1. **优先满足最大的 A（需容量 128）**：
   - 在深度 `/25` 上切出左节点：分配 **`10.0.0.0/25`**（范围 `.0` ~ `.127`）。
   - 左子树完全闭合。
2. **次优满足 B（需容量 64）**：
   - 走向右节点 `10.0.0.128/25`，继续对半向下分裂为两个 `/26`：
   - 摘取左侧 `/26`：分配 **`10.0.0.128/26`**（范围 `.128` ~ `.191`）。
3. **满足 C（需容量 16）**：
   - 剩余空间为右侧 `/26`（`10.0.0.192/26`，容量 64）；
   - 对半向下分裂为两个 `/27`（容量 32），再将左侧 `/27` 继续分裂为两个 `/28`（容量 16）；
   - 摘取第一个 `/28`：分配 **`10.0.0.192/28`**（范围 `.192` ~ `.207`）。
4. **剩余碎片统计**：
   - 树上剩余完好未割裂的地址块：一个 `/28`（`.208/28`）和一个 `/27`（`.224/27`），保留供未来无冲突扩容！
