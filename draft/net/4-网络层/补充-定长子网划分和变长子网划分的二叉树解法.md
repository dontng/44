## 一、变长子网划分（VLSM）的几何本质与二叉树模型

在进行变长子网划分（Variable Length Subnet Masking，VLSM）时，核心目标是在一个给定的总地址块内，根据不同子网的具体主机需求量，分配合适大小的子网块，同时**绝对避免任何两个子网发生地址重叠**，并尽量降低地址碎片的产生。

若纯依靠数值拼凑，在多个子网混合编址时容易出现跨越自然块边界或与相邻子网广播地址重叠的隐患。**二叉树空间模型（Subnet Binary Tree）** 将 32 位 IPv4 地址空间抽象为一棵严格的二叉树：
- **树的根节点**：代表分配到的初始总网络块（例如 `/24` 地址块，容量为 $2^{32-24} = 256$ 个地址）；
- **二叉向下分支**：树的每一次向下二叉分裂，对应网络前缀长度增加 1 位（$/n \to /n+1$）；
  - 左分支代表前缀扩展位为 `0`；
  - 右分支代表前缀扩展位为 `1`；
- **容量关系**：两个子节点严格平分父节点的地址容量（各占父节点的一半）。

```text
                                [ 根节点: 基准前缀 /n ] (容量 2^(32-n))
                                       /               \
                                      /                 \
                     [ 分支 0: 前缀 /(n+1) ]     [ 分支 1: 前缀 /(n+1) ] (容量各占一半)
                            /         \                  /         \
                           /           \                /           \
                     [ 00: /(n+2) ] [ 01: /(n+2) ] [ 10: /(n+2) ] [ 11: /(n+2) ]
```

## 二、二叉树子网划分的两大核心准则

在二叉树模型中进行子网选取与划分时，必须严格遵守以下两条数学准则：

### 1. 叶子节点锁死原则（防重叠充要条件）
- **规则定义**：**一旦某个节点被选定并分配给某个子网（该节点成为已分配的叶子节点），则以该节点为根的整棵子树（所有子孙节点）全部被彻底锁死，绝对不能再被任何其他子网选取；同时，该节点的所有祖先节点也已被部分使用，同样不能再整体分配。**
- **数学本质**：任何一个已分配节点的子孙节点，其地址范围均严格包含于该分配节点之内；祖先节点的地址范围则包含了该节点。只有在树上彼此互不为祖先与后代的独立叶子节点集合，其代表的 IP 地址区间才是**两两正交且互不重叠（Disjoint Sets）**的。

### 2. 容量降序分配原则（大块优先贪心准则）
- **规则定义**：**在树上截取子网时，必须严格按照“所需子网容量从大到小”的降序顺序依次分配。**
- **设计依据**：
  - 容量越大的子网，在树中的深度越浅（前缀长度越短）；
  - 若先分配容量小、深度深的小子网，会将原本连续的高层大块地址空间切碎；后续当需要分配大子网时，树中虽有足够的碎片容量，却无法找到整块连续的浅层节点；
  - 严格由大到小分配，可以保证地址空间始终保持最紧凑的自然对齐，最大化保留未切割的大分支供未来平滑扩容。

## 三、二叉树子网划分的标准执行时序

```text
【步骤 1: 计算需求并降序排列】
   依据公式: 块大小 B = 2^h >= 实际需求主机数 + 2 (保留网络地址与广播地址)
   确定主机位数 h 与前缀长度 Prefix = 32 - h
   将所有子网按照块大小 B (或主机位数 h) 从大到小降序排列
          │
          ▼
【步骤 2: 沿二叉树依次分裂下潜并锁定】
   从根节点出发，按降序顺序为每个子网寻找满足深度的节点:
   优先选取左侧空白分支向下分裂至目标深度，标记该节点为分配叶子，锁死其子树!
          │
          ▼
【步骤 3: 读取网络参数与空闲碎片】
   从每个分配叶子直接读出网络地址、广播地址与掩码;
   遍历统计树中所有未被使用的独立空闲子树，作为保留空闲地址块。
```

## 四、规划推演示例与参数对应关系

以给定网络块 `192.168.10.0/24`（总容量 256），需为 5 个不同规模的网络分配地址为例：
- 网络 A 需 100 台主机；
- 网络 B 需 50 台主机；
- 网络 C 需 25 台主机；
- 网络 D 需 12 台主机；
- 网络 E（路由器间点对点互联）需 2 台主机。

### 1. 容量与深度计算
根据 $2^h - 2 \ge \text{需求主机数}$：
1. **网络 A（100 台）**：$2^h - 2 \ge 100 \implies h = 7$，块大小 $2^7 = 128$，前缀长度 $32 - 7 = \mathbf{/25}$；
2. **网络 B（50 台）**：$2^h - 2 \ge 50 \implies h = 6$，块大小 $2^6 = 64$，前缀长度 $32 - 6 = \mathbf{/26}$；
3. **网络 C（25 台）**：$2^h - 2 \ge 25 \implies h = 5$，块大小 $2^5 = 32$，前缀长度 $32 - 5 = \mathbf{/27}$；
4. **网络 D（12 台）**：$2^h - 2 \ge 12 \implies h = 4$，块大小 $2^4 = 16$，前缀长度 $32 - 4 = \mathbf{/28}$；
5. **网络 E（2 台）**：$2^h - 2 \ge 2 \implies h = 2$，块大小 $2^2 = 4$，前缀长度 $32 - 2 = \mathbf{/30}$。

容量降序校验：$128 > 64 > 32 > 16 > 4$，总占用容量 $128 + 64 + 32 + 16 + 4 = 244 \le 256$。

### 2. 二叉树切割与节点选取推演

```text
                                      [ 192.168.10.0/24 ] (容量 256)
                                            /          \
                                           /            \
                【网络 A: 192.168.10.0/25】(128)      [ 192.168.10.128/25 ] (128)
                     [锁定子树, 分配完毕]                  /            \
                                                        /              \
                            【网络 B: 192.168.10.128/26】(64)       [ 192.168.10.192/26 ] (64)
                                 [锁定子树, 分配完毕]                  /            \
                                                                     /              \
                                         【网络 C: 192.168.10.192/27】(32)     [ 192.168.10.224/27 ] (32)
                                              [锁定子树, 分配完毕]                /            \
                                                                                 /              \
                                                    【网络 D: 192.168.10.224/28】(16)   [ .240/28 ] (16)
                                                         [锁定子树, 分配完毕]             /         \
                                                                                         /           \
                                                              【网络 E: .240/30】(4)   [ .244/30 ] (4)   [ .248/29 ] (8)
```

1. **截取网络 A**：根节点对半切为两个 `/25`。选取左节点 **`192.168.10.0/25`**（范围 `.0` ~ `.127`），锁死该左子树；
2. **截取网络 B**：右节点 `192.168.10.128/25` 对半切为两个 `/26`。选取左节点 **`192.168.10.128/26`**（范围 `.128` ~ `.191`），锁死该子树；
3. **截取网络 C**：右节点 `192.168.10.192/26` 对半切为两个 `/27`。选取左节点 **`192.168.10.192/27`**（范围 `.192` ~ `.223`），锁死该子树；
4. **截取网络 D**：右节点 `192.168.10.224/27` 对半切为两个 `/28`。选取左节点 **`192.168.10.224/28`**（范围 `.224` ~ `.239`），锁死该子树；
5. **截取网络 E**：右节点 `192.168.10.240/28` 分裂为两个 `/29`（容量 8）；左侧 `/29`（`.240/29`）再分裂为两个 `/30`（容量 4）。选取左侧节点 **`192.168.10.240/30`**（范围 `.240` ~ `.243`）。

### 3. 分配结果汇总对照

| 子网名称 | 网络地址 / 前缀 | 子网掩码 | 最小可用 IP | 最大可用 IP | 广播地址 |
|:---:|---|---|---|---|---|
| **网络 A** | `192.168.10.0/25` | `255.255.255.128` | `192.168.10.1` | `192.168.10.126` | `192.168.10.127` |
| **网络 B** | `192.168.10.128/26` | `255.255.255.192` | `192.168.10.129` | `192.168.10.190` | `192.168.10.191` |
| **网络 C** | `192.168.10.192/27` | `255.255.255.224` | `192.168.10.193` | `192.168.10.222` | `192.168.10.223` |
| **网络 D** | `192.168.10.224/28` | `255.255.255.240` | `192.168.10.225` | `192.168.10.238` | `192.168.10.239` |
| **网络 E** | `192.168.10.240/30` | `255.255.255.252` | `192.168.10.241` | `192.168.10.242` | `192.168.10.243` |

### 4. 剩余空闲地址块分析
树中未被锁死的独立分支即为剩余可用地址块：
- 在网络 E 旁剩余一个 `/30` 块：**`192.168.10.244/30`**（容量 4，可容纳 2 个可用主机 IP，适合下一条点对点链路）；
- 在 `.240/28` 内部剩余的右侧 `/29` 块：**`192.168.10.248/29`**（容量 8，可容纳 6 个可用主机 IP）。
- 容量校验：已分配容量 $244$ + 剩余容量 $(4 + 8) = 256$。整个地址空间无冲突且保持了最大程度的聚合完整性。
