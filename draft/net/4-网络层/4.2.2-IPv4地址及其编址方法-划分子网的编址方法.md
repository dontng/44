# 4.2.2 IPv4 地址及其编址方法-划分子网的编址方法

两级分类编址（网络号 + 主机号）存在明显的缺陷：一个单位若申请了 B 类网络，可容纳超过 6 万台主机，而普通单位往往只有几百到几千台主机，造成海量地址闲置；同时，所有主机同处一个物理网络会导致严重的广播风暴。为此，RFC 950 提出了**划分子网（Subnetting）**的方法。

---

## 一、划分子网的基本概念与演进

### 1. 从两级编址到三级编址
划分子网的核心思想是：**从原本的主机号高位中借用若干个比特作为“子网号（Subnet-ID）”**。

```
未划分子网 (两级结构):
[       网络号 (Net-ID)       ] [                 主机号 (Host-ID)                  ]
|<---------- 16 bit --------->|<-------------------- 16 bit ----------------------->|

划分子网后 (三级结构):
[       网络号 (Net-ID)       ] [  子网号 (Subnet-ID)  ] [      剩余主机号 (Host-ID)      ]
|<---------- 16 bit --------->|<-------- s bit -------->|<--------- (16 - s) bit --------->|
                                (向主机号高位借位)
```

- **对外透明性**：划分子网纯属机构内部的规划。对该机构外部的因特网骨干网而言，该机构依然表现为一个完整的单一网络（如原有的 B 类网络），因特网路由表中的条目数量不会增加；
- **对内独立性**：机构内部的路由器根据子网号将数据报路由到各个具体的子网中，各个子网各自构成独立的广播域。

---

## 二、子网掩码（Subnet Mask）与按位与运算

### 1. 为什么需要子网掩码？
在三级编址下，仅凭 IP 地址本身无法判断借用了多少位作为子网号。因此，必须引入一个 32 位的辅助参数——**子网掩码（Subnet Mask）**：
- **定义规则**：子网掩码由一串连续的 `1` 和后续的一串连续的 `0` 组成。其中，**对应网络号和子网号的所有位全部置为 `1`，对应剩余主机号的所有位全部置为 `0`**；
- 默认子网掩码：未划分子网时，A 类默认掩码为 `255.0.0.0`，B 类默认掩码为 `255.255.0.0`，C 类默认掩码为 `255.255.255.0`。

### 2. 路由器提取子网网络地址的计算过程
当路由器接收到一个目的 IP 地址时，将该目的 IP 地址与本网的子网掩码逐位进行**逻辑按位与（Bitwise AND）运算**，即可消除主机号部分，得到该 IP 所属的**子网网络地址**：

```
目的 IP 地址 : 172.16.10.33     ===>  10101100.00010000.00001010.00100001
子网掩码     : 255.255.255.192  ===>  11111111.11111111.11111111.11000000 (/26)
--------------------------------------------------------------------------------- (按位与 AND)
子网网络地址 : 172.16.10.0      <===  10101100.00010000.00001010.00000000
```

## 三、划分子网的核心数学计算模型

假设某个主类网络原本的主机号位数为 $H$，从中借用了 $s$ 位作为子网号，则剩余主机号位数为 $h = H - s$：

### 1. 核心参数计算公式

| 计算指标 | 计算公式 | 说明与规范 |
| :--- | :---: | :--- |
| **借用子网位数 $s$** | $2^s \ge \text{所需子网数}$ | 必须向上取整满足 2 的整数次幂。 |
| **剩余主机位数 $h$** | $h = H - s$ | 决定每个子网的地址容量空间。 |
| **理论可划分的子网数** | **$2^s$ 个** | **现行国际标准**：默认允许使用全 0 和全 1 子网，按 $2^s$ 计算。（仅当题目明确注明“不允许使用全 0 和全 1 子网”时，才扣除为 $2^s - 2$）。 |
| **每个子网最大可用主机数**| **$2^h - 2$ 个** | **必须严格减 2**。扣除该子网内主机号全 0 的网络地址，以及主机号全 1 的直接广播地址。 |
| **子网块大小（步长）** | $\Delta = 2^h$ | 子网网络地址在发生借位的字节上每次递增的步长数值。 |

### 2. 子网划分的边界与地址范围确定
通过步长 $\Delta = 2^h$（在 8 位边界内，$\Delta = 256 - \text{子网掩码非 255 的有效字节}$），可以清晰地划分每个子网的边界：
- **子网网络地址**：从基准网络开始，依次累加步长 $\Delta$（如 $0, \Delta, 2\Delta, \dots$）；
- **子网直接广播地址**：下一个子网的网络地址减 1；
- **有效主机 IP 地址范围**：网络地址加 1 到 直接广播地址减 1。

## 四、常见子网掩码与主机位速查表

在最后一字节（8 位主机号）借位时的常用对应关系：

| 借用位数 $s$ | 剩余主机位 $h$ | 子网掩码最后字节 | 步长 $\Delta$ | 可划分的子网数 | 每个子网可用主机数 |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 1 | 7 | `128` (`10000000`) | 128 | 2 | $2^7 - 2 = 126$ |
| 2 | 6 | `192` (`11000000`) | 64  | 4 | $2^6 - 2 = 62$ |
| 3 | 5 | `224` (`11100000`) | 32  | 8 | $2^5 - 2 = 30$ |
| 4 | 4 | `240` (`11110000`) | 16  | 16 | $2^4 - 2 = 14$ |
| 5 | 3 | `248` (`11111000`) | 8   | 32 | $2^3 - 2 = 6$ |
| 6 | 2 | `252` (`11111100`) | 4   | 64 | $2^2 - 2 = 2$ |
