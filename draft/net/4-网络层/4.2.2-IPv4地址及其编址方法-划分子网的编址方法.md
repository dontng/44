# 4.2.2 IPv4 地址及其编址方法-划分子网的编址方法

> **本节在 408 中的定位**：划分子网（Subnetting，RFC 950）是 408 统考综合应用大题中绝对的“出题常青树”。无论是考查路由器接口配置、子网网络地址与广播地址手算，还是定长子网划分，其核心命脉都在于：**“从主机号高位借 $s$ 位充当子网号”**、**“按位与（AND）硬件求网段运算”**、**“子网数算 $2^s$ 还是 $2^s - 2$ 的考场判决准则”**，以及**“每个子网可用主机数必须严格减 2 的边界推导”**。

---

## 一、第一性原理与设计动因：为什么两级编址必须进化为三级编址？

### 1. 两级分类编址的两大结构性死穴
在两级分类编址（网络号 + 主机号）体系下：
- **死穴 1：地址利用率低下到令人发指**
  一个拥有 300 台主机的中型企业，申请 C 类网络（最多 254 台主机）不够用，被迫申请一个 B 类网络。
  一个 B 类网络总共包含 **65,534 个主机地址**，该企业分配了 300 个，**剩下的 65,234 个宝贵公网 IP 全被该企业闲置占用**，全球其他单位无法使用！
- **死穴 2：路由表爆炸性膨胀**
  每一个新增的物理网络都必须在全球骨干网路由表中占有一行独立的路由条目。
- **死穴 3：企业内部缺乏拓扑灵活性**
  一个大学如果只有一个 B 类网络号，全校所有学院的数千台电脑必须挂在同一个扁平的广播域中，广播风暴无法抑制，物理隔离无法实现。

### 2. 划分子网的工程妥协：对外隐藏，对内切分
RFC 950 提出了极具智慧的解耦方案：
- **对外（对因特网骨干网）**：该机构依然表现为一个完整的单一主类网络（如 `172.16.0.0/16`），全球因特网路由表条目**一个都不增加**！
- **对内（在机构边界路由器内部）**：允许网络管理员**从原本 16 位的主机号高位，‘借用’若干个比特充当‘子网号（Subnet-ID）’**，在单位内部将大网络切碎成几十个互不干扰的独立子网广播域！

```
未划分子网 (两级结构):
[       网络号 (Net-ID)       ] [                 主机号 (Host-ID)                  ]
|<---------- 16 bit --------->|<-------------------- 16 bit ----------------------->|

划分子网后 (三级结构):
[       网络号 (Net-ID)       ] [  子网号 (Subnet-ID)  ] [      剩余主机号 (Host-ID)      ]
|<---------- 16 bit --------->|<-------- s bit -------->|<--------- (16 - s) bit --------->|
                                (向主机号高位借位)
```

## 二、微观机制：子网掩码与“按位与（AND）”硬件运算

### 1. 为什么必须引入子网掩码（Subnet Mask）？
在两级编址时代，只要看 IP 地址的第 1 个字节（如 172 在 128~191 之间），路由器无需任何额外信息，立刻就知道前 16 位是网络号。
但划分子网后：
- 给你一个 IP `172.16.10.5`，只看这串数字，**任何人或硬件都绝对不可能知道这个单位到底借了 1 位、2 位还是 8 位充当子网号**！
- **子网掩码的诞生**：必须给每个接口额外配备一个 32 位的掩码。
  - **掩码规则**：**对应网络号和子网号的所有二进制位严格置为 1；对应剩余主机号的所有二进制位严格置为 0！**

### 2. 路由器的核心硬件动作：逻辑按位与（Bitwise AND）
当路由器收到一个目的 IP 地址时，硬件通过逻辑门电路，**将目的 IP 与该子网的子网掩码逐位做按位与运算**，主机号部分瞬间被全 0 抹除，直接提取出该分组所属的**子网网络地址**：

```
目的 IP 地址 : 172.16.10.33     ===>  10101100.00010000.00001010.00100001
子网掩码     : 255.255.255.192  ===>  11111111.11111111.11111111.11000000 (/26)
--------------------------------------------------------------------------------- (按位与 AND)
子网网络地址 : 172.16.10.0      <===  10101100.00010000.00001010.00000000
```

## 三、408 划分子网核心数学计算模型与历史规范

设某单位获得一个主类网络，借用 $s$ 位主机号作为子网号，剩余主机号位数为 $h$：

### 1. 核心参数数学推导全景表

| 计算指标 | 数学计算公式 | 408 统考命题判决铁律 |
| :--- | :---: | :--- |
| **借用子网位数 $s$** | $2^s \ge \text{所需子网数}$ | 必须向上取整满足 2 的整数次幂。 |
| **剩余主机位数 $h$** | $h = \text{原主机位数} - s$ | 对 A 类为 $24-s$，对 B 类为 $16-s$，对 C 类为 $8-s$。 |
| **理论可划分的子网数** | **$2^s$ 个** | **考场标准**：现行考纲一律按 **$2^s$** 计算（完全允许全 0 和全 1 子网）。**唯有当题干白纸黑字写明“不允许使用全 0 和全 1 子网”时，才扣除为 $2^s - 2$**！ |
| **每个子网最大可用主机数**| **$2^h - 2$ 个** | **无论任何情况、任何题型，必须无条件严格减 2！** 扣除该子网内主机号全 0 的网络地址与主机号全 1 的直接广播地址！ |
| **子网块大小（步长 Block）**| $\Delta = 2^h$ | 子网网络地址在最后一个可变字节上每次递增的步长数值（极速口算钥匙）。 |

### 2. 考场极速秒杀：利用“块大小（Block Size）”推导子网边界
在 408 考场上，若遇到 `/26`、`/27`、`/28` 这种借位划分，**绝对不要逐位画 32 位二进制草稿**！
- **定义增量步长 $\Delta$**：
  $$\Delta = 256 - \text{子网掩码最后一个非零字节的数值}$$
  - 若掩码为 `.128`（借 1 位，余 7 位主机），$\Delta = 256 - 128 = 128$；
  - 若掩码为 `.192`（借 2 位，余 6 位主机），$\Delta = 256 - 192 = 64$；
  - 若掩码为 `.224`（借 3 位，余 5 位主机），$\Delta = 256 - 224 = 32$；
  - 若掩码为 `.240`（借 4 位，余 4 位主机），$\Delta = 256 - 240 = 16$；
  - 若掩码为 `.248`（借 5 位，余 3 位主机），$\Delta = 256 - 248 = 8$；
  - 若掩码为 `.252`（借 6 位，余 2 位主机），$\Delta = 256 - 252 = 4$。
- **子网网络地址序列**：直接从 `.0` 开始，每次累加 $\Delta$：
  $$0, \quad \Delta, \quad 2\Delta, \quad 3\Delta, \quad \dots$$
- **子网直接广播地址**：下一个子网网络地址减 1！
- **可用主机 IP 范围**：网络地址加 1 到 广播地址减 1！**1 秒钟写出全部子网全景！**

## 四、408 统考真题级场景逆向与子网参数推导演练

### 【题型模型：B 类网络划分子网全参数综合推导大题】

**【考题背景】**
某大型科研院所被分配到了一个公网 B 类网络地址块：`172.16.0.0/16`。
- 该院所拥有 14 个独立的研究室；
- 每个研究室当前拥有计算机终端约 500 台，未来规划可能扩容至 800 台；
- 院所网络中心决定采用**固定长度子网掩码（FLSM）**对该 B 类网络进行子网划分，使每个研究室分配到一个独立的子网中。

**【试推导并求解】**：
1. 为满足上述规模需求，至少需要从主机号借用多少位（$s$）作为子网号？此时剩余的主机号位数（$h$）是多少？
2. 写出该院所应采用的子网掩码的点分十进制表示形式以及 CIDR 斜线记法；
3. 计算采用该子网掩码后，理论上最多可以划分出多少个子网？每个子网实际最多可以分配给多少台主机网卡？
4. 写出分配给**第 1 个子网**（设允许使用全 0 子网）和**第 2 个子网**的：
   - 子网网络地址；
   - 最小可用主机 IP 地址；
   - 最大可用主机 IP 地址；
   - 子网直接广播地址。

---

### 【草稿纸执行第一步：列出需求不等式并确定借位数】
- 需求子网数 $\ge 14$；
- 每个子网需求主机数 $\ge 800$；
- 原 B 类网络主机总位数：$16$ 位。
- 借位分配方程：$s + h = 16$。

---

### 【严密推导过程】

#### 第 1 问：子网借位 $s$ 与剩余主机位 $h$ 计算
1. **从主机容量反推剩余主机位数 $h$**：
   - 每个子网需要容纳至少 800 台主机；
   - 可用主机数公式：$2^h - 2 \ge 800 \implies 2^h \ge 802$；
   - 检索 2 的幂次：
     - $2^9 = 512 < 802$（不足）
     - $2^{10} = 1024 \ge 802$（满足）
   - 因此，剩余主机位数**至少需要 $h = 10$ 位**！
2. **计算可用于子网借位的位数 $s$**：
   - $s = 16 - h = 16 - 10 = \mathbf{6\text{ 位}}$；
3. **检验子网数是否满足**：
   - 借用 $s = 6$ 位，可划分的子网数为：$2^6 = 64$ 个；
   - $64 \ge 14$，完全满足 14 个研究室的需求。
- **结论**：借用子网号位数 $s = 6$ 位，剩余主机号位数 $h = 10$ 位。

#### 第 2 问：子网掩码推导
- 网络前缀长度 = 原网络位 16 + 借用子网位 6 = **22 位**；
- CIDR 记法为：**`/22`**；
- 展开为 32 位二进制：
  `11111111.11111111.11111100.00000000`
- 转换为点分十进制：
  - 第 1、2 字节为 `255.255`；
  - 第 3 字节前 6 位为 1：$128 + 64 + 32 + 16 + 8 + 4 = 252$；
  - 第 4 字节为 `0`；
- **子网掩码为**：**`255.255.252.0`**。

#### 第 3 问：最大子网数与可用主机数计算
1. **最大子网数**：
   $$\text{子网数} = 2^s = 2^6 = \mathbf{64\text{ 个}}$$
2. **每个子网最大可用主机数**：
   $$\text{可用主机数} = 2^h - 2 = 2^{10} - 2 = 1024 - 2 = \mathbf{1022\text{ 台}}$$
   （$1022 \ge 800$，完全覆盖未来扩容需求）。

#### 第 4 问：前两个子网详细边界推导（利用步长法则）
- 观察子网掩码发生变化的第 3 字节：掩码数值为 `252`；
- 计算第 3 字节的增量步长：
  $$\Delta = 256 - 252 = 4$$
- 因此，各个子网在第 3 字节上每次递增 **4**！

1. **第 1 个子网（子网号全 0，基数从 0 开始）**：
   - **子网网络地址**：`172.16.0.0`
   - **最小可用主机 IP**：`172.16.0.1`（网络地址末尾加 1）
   - 下一个子网网络地址为 `172.16.4.0`，因此：
   - **子网直接广播地址**：`172.16.3.255`（下一个网络地址减 1）
   - **最大可用主机 IP**：`172.16.3.254`（广播地址末尾减 1）
2. **第 2 个子网（基数累加 4）**：
   - **子网网络地址**：`172.16.4.0`
   - **最小可用主机 IP**：`172.16.4.1`
   - 下一个子网网络地址为 `172.16.8.0`，因此：
   - **子网直接广播地址**：`172.16.7.255`
   - **最大可用主机 IP**：`172.16.7.254`

## 五、考场诱惑性暗礁与秒杀口诀

### 1. 致命诱惑与错误路线踩刹车

> [!CAUTION]
> **陷阱 1：可用主机数忘记减 2**
> - **408 考场丢分第一大案**：求可用主机数时算成 $2^{10} = 1024$。
> - **绝对警示**：**只要是问“主机数 / 可分配给网卡的 IP 数”，必须无条件减 2！** 少减 2 直接扣光步骤分！

> [!CAUTION]
> **陷阱 2：跨字节借位时广播地址算错**
> - 比如上面的第 1 个子网，网络地址是 `172.16.0.0`，广播地址是 `172.16.3.255`！
> - 很多考生想当然地写成 `172.16.0.255`。切记：**主机号跨越了第 3 字节和第 4 字节，主机号全 1 意味着第 4 字节全为 255，且第 3 字节剩余的 2 位主机位也必须全是 1（即 $0 + 3 = 3$）！** 用步长法“下一个子网网络地址减 1”可确保绝不出错！

### 2. 考场核心记忆桩
- **“借位成子网，掩码全置一，按位与出网”**：子网寻址三大核心动作。
- **“二五六减掩码算步长，下网减一是广播”**：子网边界秒杀极速口诀。
- **“子网数算二的 s 次，主机数必减二”**：参数计算保命符。
