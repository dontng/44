# 4.2.2 IPv4地址及其编址方法-划分子网的编址方法

为解决分类编址中“B类网络太大、C类网络太小”造成的巨大地址空间浪费，RFC 950 正式引入了**划分子网（Subnetting）**机制。

---

## 一、三级 IP 地址结构

划分子网的本质是：**从原本的主机号（Host-ID）高位借用若干位作为“子网号（Subnet-ID）”**：

```text
未划分时 (两级):  [   网络号 Net-ID   ] [           主机号 Host-ID           ]
划分子网 (三级):  [   网络号 Net-ID   ] [ 子网号 Subnet ] [  剩余主机号 Host-ID  ]
                                       |<--- 借用位 s --->|
```

- **对外透明性**：划分子网纯属机构内部的分配行为，从外部网络看，该机构仍然只是一个未划分子网的普通主类网络。外部路由器转发分组时，仍然只根据网络号寻址，只有当分组进入该机构的边界路由器后，边界路由器才根据子网号进一步转发给对应子网。

---

## 二、子网掩码（Subnet Mask）及其运算

由于从 IP 地址的数值本身无法看出借了多少位作为子网号，因此必须配合使用**子网掩码**：
- **子网掩码构造规则**：对应网络号和子网号的所有二进制位**全部置为 1**；对应主机号的所有二进制位**全部置为 0**。
- **默认子网掩码（未划分子网时）**：
  - A 类默认掩码：`255.0.0.0`（`/8`）
  - B 类默认掩码：`255.255.0.0`（`/16`）
  - C 类默认掩码：`255.255.255.0`（`/24`）

### 核心物理运算：按位与（AND）求网络地址
$$	ext{子网网络地址} = 	ext{目的 IP 地址} \quad \mathbf{AND} \quad 	ext{该子网的子网掩码}$$

---

## 三、子网划分的核心参数计算模型（408 严格规范）

假设机构获得一个主类网络，借用 $s$ 位主机号作为子网号，剩余主机位数为 $h$：

| 计算参数 | 数学计算公式 | 408 统考规范与历史细节 |
|---|---|---|
| **子网掩码** | 原主类掩码向右连续补充 $s$ 个 `1` | 借 1 位=`128`，借 2 位=`192`，借 3 位=`224`，借 4 位=`240`，借 5 位=`248` |
| **可划分的理论子网数** | **$2^s$ 个** | *早期 RFC 950 规定子网号全 0 和全 1 保留，实际可用为 $2^s - 2$；但现代标准（RFC 1812）完全支持全 0 与全 1 子网。**408 统考现行标准一律按 $2^s$ 计算（除非题目明确指明“不允许使用全0全1子网”）**。* |
| **每个子网的主机号位数** | $h = 	ext{原主机位数} - s$ | 对 B 类：$h = 16 - s$；对 C 类：$h = 8 - s$ |
| **每个子网最大可用主机数** | **$2^h - 2$ 个** | **无论任何情况必须严格减 2！** 扣除该子网内主机号全 0 的**子网网络地址**与主机号全 1 的**子网直接广播地址**。 |

## 四、经典划分子网推导演练

> **【408 典型例题】**：某公司分配到 B 类地址 `172.16.0.0/16`，现需划分出至少 500 个子网，且每个子网能容纳至少 50 台主机。求合理的子网掩码、每个子网实际最大主机数，并写出第 1 个可用子网的有效主机 IP 范围。

### 严密推导过程：
1. **求借用子网位数 $s$**：
   - 需求子网数 $\ge 500$。
   - $2^8 = 256 < 500 \le 2^9 = 512$，因此子网借位 $s = 9$ 位。
2. **校验剩余主机位数 $h$**：
   - B 类原主机位共 16 位，扣除借位后剩余 $h = 16 - 9 = 7$ 位。
   - 每个子网最大可用主机数 $= 2^7 - 2 = 128 - 2 = \mathbf{126	ext{ 台}}$。
   - $126 \ge 50$，完全满足各子网主机规模需求。
3. **确定子网掩码**：
   - 网络位 16 + 子网位 9 = 25 位。
   - 二进制：`11111111.11111111.11111111.10000000`
   - 点分十进制：**`255.255.255.128`**（即 `/25`）。
4. **求解第 1 个子网（子网号取 `00000000 0`）的地址边界**：
   - 子网网络地址：`172.16.0.0`
   - 第一个可用主机 IP：`172.16.0.1`
   - 最后一个可用主机 IP：`172.16.0.126`
   - 子网广播地址：`172.16.0.127`
