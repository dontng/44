# 4.2.3 IPv4 地址的应用规划

在计算机网络工程与规划中，如何为一个给定的网络块合理地划分子网以满足各业务部门及互联链路的需求，是网络层的核心实际应用技能。子网规划通常有两种模式：**定长子网掩码（FLSM）** 与 **可变长子网掩码（VLSM）**。

---

## 一、定长子网掩码（FLSM）与可变长子网掩码（VLSM）

### 1. 定长子网掩码（FLSM，Fixed-Length Subnet Mask）
- **特点**：网络内的所有子网使用完全相同的子网掩码长度；
- **局限性**：
  - 各个子网被分配了完全相同的地址容量；
  - 必须按照“规模最大的子网”来确定统一的主机号位数；
  - 对于规模较小的部门或仅需要 2 个 IP 地址的路由器点对点互联链路，会造成极大的 IP 地址浪费。

### 2. 可变长子网掩码（VLSM，Variable-Length Subnet Mask）
- **特点**：允许在同一个父网络块内部，针对不同规模的子网需求，使用不同长度的子网掩码；
- **优势**：
  - 大子网分配较短的前缀（容量大）；
  - 小子网分配较长的前缀（容量小）；
  - 极大提高了 IP 地址空间的利用率，避免了地址碎片化。

---

## 二、VLSM 地址规划的标准化设计原则

为了确保划分出来的各个子网之间**地址空间完全独立、互不重叠**，必须遵循以下工程设计原则：

```
                基准父网络块 (例如 192.168.1.0/24)
                           /        \
                          /          \
                子网 A (/25)        未分配空间 (/25)
             (满足最大规模需求)          /        \
                                      /          \
                            子网 B (/26)        未分配空间 (/26)
                         (满足次大规模需求)          /        \
                                                  ...        ...
```

### 1. “从大到小（降序）”分配原则
- **必须优先为需求主机数量最多的子网分配地址块**；
- 只有先满足大子网的块对齐要求，才能在剩余的高地址空间中灵活切分出小子网；
- 若从小子网开始分配，会导致原本连续的大块地址空间被切碎分割，后续无法凑出满足大子网所需的大连续地址块。

### 2. 主机号位数 $h$ 与前缀长度 $n$ 的确定
对于每个子网的有效主机需求数 $N$：
1. 求解满足下列不等式的最小非负整数 $h$（主机号位数）：
   $$2^h - 2 \ge N$$
2. 该子网的网络前缀长度为：
   $$n = 32 - h$$
3. 该子网对应的地址块总容量为 $2^h$ 个地址。

### 3. 基准边界对齐原则（地址块起始规则）
分配给子网的网络地址，其数值必须是该子网块大小（$2^h$）的整数倍（即末尾 $h$ 位二进制必须全为 0）。

---

## 三、点对点链路的地址规划

在网络拓扑中，路由器与路由器之间的广域网互联链路通常只连接两台路由器的网络接口：

```
[ 路由器 R1 ] ============================================= [ 路由器 R2 ]
(接口 1: IP_1)                                              (接口 2: IP_2)
```

- **有效 IP 需求数**：仅需要 **2 个可分配给接口的主机 IP 地址**；
- **主机位数推导**：
  $$2^h - 2 \ge 2 \implies 2^h \ge 4 \implies h = 2$$
- **网络前缀与掩码**：
  - 网络前缀长度为 $n = 32 - 2 = \mathbf{/30}$；
  - 子网掩码为 **`255.255.255.252`**；
  - 地址块总容量为 $2^2 = 4$ 个地址（1 个网络地址、2 个有效主机 IP、1 个直接广播地址）；
- 在 VLSM 规划中，所有点对点互联链路均推荐规划为标准的 `/30` 子网。

---

## 四、子网规划的核心参数汇总

为每一个子网完成地址分配后，应明确列出其四项关键网络参数：

1. **子网网络地址**：该子网块的首个 IP 地址（主机位全 0），配合斜线记法 `/n`；
2. **最小可用主机 IP**：网络地址数值加 1；
3. **最大可用主机 IP**：直接广播地址数值减 1；
4. **子网直接广播地址**：该子网块的最后一个 IP 地址（主机位全 1）。
