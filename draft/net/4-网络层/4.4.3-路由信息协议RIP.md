# 4.4.3 路由信息协议RIP

> **408 考纲地位**：**经典必考动态路由协议（综合大题常客，计算推演高频考点）**。核心考查点包括：**RIP 协议层次与 UDP 520 封装**、**跳数（Hop Count）度量与 16 极大值含义**、**Bellman-Ford 路由更新算法推演（整表更新六大准则）**、**“好消息传得快，坏消息传得慢”（计数到无穷）成因及四大缓解机制（水平分割、毒性逆转、触发更新、抑制计时）**。

---

## 一、为什么会有 RIP？（距离向量的最简设计与历史局限）

在早期的 ARPANET 和中小型局域网互连中，网络拓扑结构简单，路由器硬件处理性能极其有限（CPU 主频低、内存以 KB 计）。此时亟需一种算法：
1. **内存占用极小**：路由器不需要知道全网的完整拓扑图，只需记录“去各个网络要走多少步”；
2. **计算极其轻量**：不需要运行复杂的图论最短路径树算法，只需简单加法和大小比较；
3. **实现简单自愈**：依靠邻居之间的周期性心跳广播自动适应链路插拔。

这种最朴素的思想孕育了 **路由信息协议（Routing Information Protocol，RIP）**。但正是由于这种“缺乏全网全局视野”的盲目传闻机制，导致了其致命的收敛缺陷。

## 二、RIP 协议的核心规则与报文时序

### 1. 协议核心参数与硬性约束（考场秒杀表）

```text
+-----------------------+-------------------------------------------------------------+
| 核心属性              | 协议规范与考点定义                                          |
+-----------------------+-------------------------------------------------------------+
| 协议体系归属          | 应用层协议！报文使用 UDP 传输，熟知端口号为 520             |
+-----------------------+-------------------------------------------------------------+
| 选路度量标准 (Metric) | 纯粹以【跳数 (Hop Count)】作为代价度量。不考虑带宽、时延、负载|
|                       | - 路由器到【直接相连网络】的跳数定义为 1 (部分教材记为0，统考以1为准)|
|                       | - 每经过一个外部路由器，跳数加 1                            |
+-----------------------+-------------------------------------------------------------+
| 最大跳数限制          | 最大有效跳数为 15！跳数达到 16 即代表【距离无穷大 / 不可达】 |
|                       | (该硬性规定直接限制了 RIP 只能应用于网络直径小于 15 的小型网络) |
+-----------------------+-------------------------------------------------------------+
| 信息交换三要素        | 1. 和谁交换？── 仅与【直连相邻路由器】交换                  |
|                       | 2. 交换什么？── 交换本路由器【当前的整张路由表】            |
|                       | 3. 何时交换？── 【固定周期性交换】(默认每隔 30 秒广播一次)  |
+-----------------------+-------------------------------------------------------------+
| 路由老化超时机制      | 默认 180 秒未收到某相邻路由器的更新报文，判定该邻居失效，   |
|                       | 将经由该邻居的所有路由条目距离置为 16 (不可达)             |
+-----------------------+-------------------------------------------------------------+
```

### 2. 距离向量更新算法：Bellman-Ford 算法执行微观时序

当路由器 $X$ 收到相邻路由器 $Y$ 发送来的 RIP 路由报文时，严格执行以下两阶段四准则：

```text
[接收邻居 Y 发来的路由表]
           │
           ▼
【阶段 1: 预处理修正】
   将收到的所有条目:
   - 距离 d 统一加 1 (即 d = d + 1)
   - 下一跳地址统一强制修改为 Y
           │
           ▼
【阶段 2: 逐条与本地路由表比对更新】
   对修正后的每个条目 <Net, d, Y>，检索本地路由表中是否存在目的网络 Net:
           │
           ├─ 准则 1: 本地【无 Net 条目】
           │          └──> 直接作为新路由无条件添加进路由表！
           │
           ├─ 准则 2: 本地【已有 Net 条目，且本地记录的下一跳正是 Y】
           │          └──> 无条件用新收到的距离 d 覆盖本地原条目！
           │               (核心原理: 最新的路况正是来自负责该路径的同一个邻居 Y，
           │                无论路径变好还是变坏，都必须服从 Y 的最新裁决)
           │
           └─ 准则 3: 本地【已有 Net 条目，但本地记录的下一跳是其他路由器 Z】
                      │
                      ├─ 若修正后新距离 d < 本地原距离:
                      │   └──> 择优更新！将距离更新为更小的 d，下一跳修改为 Y！
                      │
                      └─ 若修正后新距离 d >= 本地原距离:
                          └──> 忽略不理，保留本地原条目！
```

### 3. 致命缺陷：“好消息传得快，坏消息传得慢”（计数到无穷剖析）

#### 经典环路产生过程（考场必考推演）
设网络拓扑为：`Net1 ── R1 ── R2`。正常稳态下：
- R1 到 Net1：距离 1，下一跳 Direct（直接交付）。
- R2 到 Net1：距离 2，下一跳 R1。

```text
时间 T0: Net1 突发物理故障中断！
         - R1 察觉链路断开，立刻将 Net1 距离标记为 16 (不可达)。
         - 但在 R1 向 R2 通告之前，R2 的 30 秒周期定时器恰好到期，R2 向 R1 发出广播：
           "我到 Net1 距离为 2，下一跳 R1"。

时间 T1: R1 收到 R2 的报文，根据 Bellman-Ford 算法预处理：
         - 修正为：到 Net1 距离 2 + 1 = 3，下一跳 R2。
         - R1 本地关于 Net1 原为 16，发现新距离 3 < 16，命中准则 3！
         - R1 误以为 R2 找到了一条绕道到达 Net1 的备用路径，于是更新本地：
           【Net1, 距离 3, 下一跳 R2】！

时间 T2: R1 周期广播，通告自身路由表。
         - R2 收到 R1 的通告：距离变为 3。
         - 预处理：距离 3 + 1 = 4，下一跳 R1。
         - R2 查本地：原本去 Net1 下一跳正是 R1，命中准则 2（无条件覆盖）！
         - R2 更新自身为：【Net1, 距离 4, 下一跳 R1】！

时间 T3~Tn: 互相递增欺骗...
         - R1 更新为 5... R2 更新为 6... 直到累加到 16，双方才最终确认不可达！
         - 在整个递增过程中，若有发往 Net1 的数据报，将在 R1 与 R2 之间无限来回弹跳！
```

#### 408 应对环路的四大防范机制（选择题核心词汇）
1. **定义最大度量（16 即无穷大）**：
   - 限制环路递增的上限，使得计数到无穷的过程在 16 跳以内终止，防止死锁持续数小时。
2. **水平分割（Split Horizon）**：
   - **铁律**：“从一个接口学到的路由信息，绝对不再从这个接口反向通告回去”。
   - 在上述例子中，R2 从 R1 处学到了关于 Net1 的路由，因此 R2 在从连接 R1 的接口发出的更新报文中，根本不包含 Net1 的条目！直接扼杀欺骗。
3. **毒性逆转（Poison Reverse）**：
   - 允许向学到该路由的接口反向通告，但**将该条目的距离强制标记为 16（不可达/毒化）**。明确告知对方“你不用指望通过我绕道回去”。
4. **触发更新（Triggered Update / 闪式更新）**：
   - 一旦路由器检测到直连链路故障或收到路由度量突变，**不等待 30 秒周期定时器**，立刻立即向前泛洪发送路由更新，尽可能抢在邻居发出陈旧通告之前刷新全网。

## 三、408 经典高频真题精析

### 【题型：Bellman-Ford 路由表更新精确推导大题】

**【题目描述】**
已知路由器 $R_1$ 当前维护的 RIP 路由表如下表所示：

| 目的网络 | 距离（跳数） | 下一跳路由器 |
|:---:|:---:|:---:|
| $N_1$ | 3 | $R_2$ |
| $N_2$ | 4 | $R_3$ |
| $N_3$ | 2 | $R_4$ |
| $N_4$ | 5 | $R_6$ |
| $N_6$ | 6 | $R_2$ |

此时，路由器 $R_1$ 收到相邻路由器 $R_2$ 发送来的 RIP 路由更新报文，该报文中包含到达各网络的距离向量如下：

| 目的网络 | 距离 |
|:---:|:---:|
| $N_1$ | 4 |
| $N_2$ | 2 |
| $N_3$ | 4 |
| $N_5$ | 3 |

请回答：
1. 请写出 $R_1$ 对 $R_2$ 发来的报文进行预处理（修正）后的路由条目列表。
2. 请详细推导 $R_1$ 处理该更新报文后，最终的完整 RIP 路由表内容（列出目的网络、距离、下一跳路由器），并对每一项的保留或更新理由给出具体说明。

---

### 【标准解题步骤（120+ 考场标准规范）】

#### 第一步：执行阶段 1——报文预处理（距离加 1，下一跳置为 $R_2$）
$R_1$ 收到 $R_2$ 的更新信息后，先将收到的所有条目的距离统一增加 1，并将下一跳统一标记为 $R_2$：
- 到 $N_1$：距离 $4 + 1 = 5$，下一跳 $R_2$。
- 到 $N_2$：距离 $2 + 1 = 3$，下一跳 $R_2$。
- 到 $N_3$：距离 $4 + 1 = 5$，下一跳 $R_2$。
- 到 $N_5$：距离 $3 + 1 = 4$，下一跳 $R_2$。

#### 第二步：执行阶段 2——逐项研判本地路由表
将预处理后的 4 个条目分别与 $R_1$ 原路由表进行规则比对：

1. **针对目的网络 $N_1$**：
   - 本地原条目为：`{Net: N1, 距离: 3, 下一跳: R2}`。
   - 研判依据：新修正条目的下一跳同样是 $R_2$（**命中准则 2：下一跳相同**）。
   - 决策动作：来自相同下一跳的最新路况通告具有唯一权威性，无论度量变大还是变小，**无条件覆盖更新**！
   - 结果：更新为 `{Net: N1, 距离: 5, 下一跳: R2}`。

2. **针对目的网络 $N_2$**：
   - 本地原条目为：`{Net: N2, 距离: 4, 下一跳: R3}`。
   - 研判依据：本地下一跳是 $R_3$，新通告来自 $R_2$（**下一跳不同**）。比对距离：新距离 $3 <$ 本地原距离 $4$（**命中准则 3：择优录取**）。
   - 决策动作：发现经过 $R_2$ 路径更短，更新路由！
   - 结果：更新为 `{Net: N2, 距离: 3, 下一跳: R2}`。

3. **针对目的网络 $N_3$**：
   - 本地原条目为：`{Net: N3, 距离: 2, 下一跳: R4}`。
   - 研判依据：本地下一跳是 $R_4$，新通告来自 $R_2$（**下一跳不同**）。比对距离：新距离 $5 >$ 本地原距离 $2$。
   - 决策动作：新路径开销更大，**不予更新，保留原条目**！
   - 结果：保留 `{Net: N3, 距离: 2, 下一跳: R4}`。

4. **针对目的网络 $N_5$**：
   - 本地原路由表中**不存在网络 $N_5$**（**命中准则 1：新网络**）。
   - 决策动作：直接将该路由作为新条目添加进路由表。
   - 结果：新增 `{Net: N5, 距离: 4, 下一跳: R2}`。

5. **针对网络 $N_4$ 与 $N_6$**：
   - 更新报文中未提及 $N_4$ 和 $N_6$，且未超时，直接**保持原条目不变**。

#### 第三步：整理输出最终路由表

| 目的网络 | 距离（跳数） | 下一跳路由器 | 理由说明 |
|:---:|:---:|:---:|---|
| **$N_1$** | **5** | **$R_2$** | 下一跳同为 $R_2$，无条件接受最新距离覆盖 |
| **$N_2$** | **3** | **$R_2$** | 新路径距离 3 < 原路径距离 4，择优更新 |
| **$N_3$** | **2** | **$R_4$** | 新路径距离 5 > 原路径距离 2，保留原优选路由 |
| **$N_4$** | **5** | **$R_6$** | 报文中无涉及，保持原状 |
| **$N_5$** | **4** | **$R_2$** | 原表中无此项，作为新路由直接添加 |
| **$N_6$** | **6** | **$R_2$** | 报文中无涉及，保持原状 |

## 四、考场肌肉记忆与避坑指南

### 1. 致命易错陷阱
- 陷阱 1：**看到下一跳相同但距离变大时，误以为“不更新”**
  - **严重失分点**！必须牢记：只要下一跳相同，说明前方的唯一向导就是该邻居。哪怕该邻居通知距离由 2 暴涨到 15，也**必须强制覆盖更新**！因为原先的好路已经塌方了。
- 陷阱 2：**预处理忘记给距离先加 1**
  - 考场上手忙脚乱容易直接拿收到的距离去比对，导致全盘皆输！第一步必须先把接收到的所有距离 $+1$。
- 陷阱 3：**距离 16 的真正含义**
  - RIP 中距离 16 **绝不代表还能跳 16 次**，而是代表**无穷大（不可达）**！实际网络直径不能超过 15。

### 2. 秒杀公式与反射条件
$$\text{预处理：} d_{\text{new}} = d_{\text{recv}} + 1, \quad \text{NextHop} = \text{Sender}$$
$$\text{判别式：} 
\begin{cases}
\text{无此条目} \implies \text{无条件新增} \\
\text{下一跳相同} \implies \text{无条件覆盖更新} \\
\text{下一跳不同} \implies \text{仅当 } d_{\text{new}} < d_{\text{old}} \text{ 时择优更新，否则丢弃}
\end{cases}$$
