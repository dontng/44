# 4.7.3 在局域网上进行硬件多播

> **408 考纲地位**：**跨层地址映射与二进制计算绝对核心考点（历年真题出现率极高）**。深入考查：**以太网组播 MAC 地址固定前缀 01-00-5E 与第 25 位固定为 0**、**从 32 位 IP 多播地址到 48 位以太网 MAC 地址的微观位映射推导**、**$2^5 = 32$ 对 1 的地址映射冲突数学推导**、**网卡硬件初筛与操作系统协议栈二次过滤协同机制**。

---

## 一、为什么需要硬件多播？（局域网网卡过滤的第一性原理）

IP 协议运行在第三层（网络层），而以太网交换机和主机网卡工作在第二层（数据链路层）。
- **痛点**：若在局域网中直接将 IP 多播数据报封装在全 1 的以太网广播帧（`FF-FF-FF-FF-FF-FF`）中发送，局域网内的所有主机网卡都会强制接收该帧，触发中断并送交 CPU 处理。这在本质上退化成了“广播轰炸”，未订阅该多播组的主机会遭受严重的 CPU 性能损耗。
- **解法**：必须让以太网数据链路层也具备“只接收特定组播”的硬件识别能力。为此，必须建立 **IP 多播地址 $\to$ 以太网组播 MAC 地址** 的确定性映射。网卡芯片通过硬件寄存器设置组播 MAC 过滤列表，只放行本机订阅的组播帧，其余帧在物理层直接被硬件芯片过滤丢弃，**零 CPU 占用**！

---

## 二、以太网多播 MAC 地址的构成标准与微观位映射

### 1. IANA 组播 MAC 编址标准规范

IEEE 规定，以太网组播 MAC 地址的第 1 个字节的最低有效位（I/G 位，即第 8 位）必须为 **1**（表示组播）。
IANA（因特网编号分配机构）购买了一段专属的以太网 MAC 地址块：
- 前 24 位（高 3 字节 OUI）：固定为 **`01-00-5E`**。
- 在接下来的 24 位中：IANA 规定将其**最高位（即 MAC 地址的第 25 位）固定为 `0`**。
- 剩余的 **后 23 位**：直接将 **D 类 IP 多播地址的低 23 位** 机械复制过来！

```text
 32 位 D 类 IP 多播地址:
   1 1 1 0   [ 丢弃 5 位 ]   [           提取低 23 位用于映射           ]
 +---------+---------------+-----------------------------------------+
 |  1110   |  x x x x x    |  b22 b21 b20 ...                    b1 b0|
 +---------+---------------+-----------------------------------------+
                                                │
                               (直接机械复制)   ▼
 48 位以太网多播 MAC 地址:
   [ 高 24 位固定为 01-00-5E ]  0  [           复制低 23 位           ]
 +-----------------------------+--+-----------------------------------+
 |   01  -  00  -  5E          | 0|  b22 b21 b20 ...             b1 b0|
 +-----------------------------+--+-----------------------------------+
   <--------- 24 位 ---------> 1位 <-------------- 23 位 ------------->
                               第25位
```

## 三、32 对 1 映射冲突的数学推导与两级过滤

### 1. 冲突成因的严密数学推导
1. D 类 IP 地址总长度为 32 位，其中最高 4 位固定为 `1110`，因此自由变化的组标识位有：
   $$32 - 4 = 28 \text{ 位}$$
2. 然而，以太网组播 MAC 地址只留出了 **23 位** 来容纳这 28 位的 IP 地址信息；
3. 中间有：
   $$28 - 23 = \mathbf{5 \text{ 位}}$$
   的信息在映射到 MAC 地址时被**直接丢弃**了！
4. **数学结论（408 必背考点）**：
   $$2^5 = \mathbf{32 \text{ 个不同的 IP 多播地址}} \longleftrightarrow \mathbf{映射到同一个以太网多播 MAC 地址！}$$

```text
 [IP 多播地址 1: 224.0.1.1]   ─────┐
 [IP 多播地址 2: 224.128.1.1] ─────┼───> 映射为相同的以太网 MAC: 01-00-5E-00-01-01
               ...                 │
 [IP 多播地址 32: 239.128.1.1] ────┘
```

### 2. 网卡硬件与系统内核的两级过滤体系

面对 32 对 1 的冲突，接收端主机如何避免误收不相干的组播数据？

```text
               [以太网物理链路接收到帧: 目的 MAC 为 01-00-5E-00-01-01]
                                          │
                                          ▼
   +─────────────────────────────────────────────────────────────────────────────+
   | 第一级: 网卡芯片 (NIC 硬件线速过滤)                                         |
   | - 网卡比对自身注册的组播 MAC 过滤寄存器表;                                 |
   | - 命中了 01-00-5E-00-01-01 ──> 接收该数据帧，剥去 MAC 头部，送交操作系统内核!|
   +─────────────────────────────────────────────────────────────────────────────+
                                          │
                                          ▼
   +─────────────────────────────────────────────────────────────────────────────+
   | 第二级: 操作系统网络层协议栈 (内核软件精确过滤)                             |
   | - 解析 IP 首部，提取真正的 32 位目的 IP 地址 (如 224.128.1.1);              |
   | - 检查本机是否有进程真正加入了 224.128.1.1:                                 |
   |   - 若加入了: 向上交付给应用程序 Socket 缓冲区;                             |
   |   - 若本机只订阅了 224.0.1.1 (仅仅是 MAC 撞车): 内核【静默丢弃】，不予向上交付!|
   +─────────────────────────────────────────────────────────────────────────────+
```

## 四、408 经典高频真题精析

### 【题型：IP 多播地址到 MAC 地址的手工二进制映射与冲突逆推】

**【题目描述】**
已知某多播组的 IP 地址为 `224.215.145.230`。
请回答：
1. 请写出该 IP 多播地址映射得到的以太网多播 MAC 地址（以十六进制两两一组表示，如 `01-00-5E-xx-xx-xx`）。请写出详细的二进制转换过程。
2. 请写出另外任意一个与该 IP 多播地址**映射为相同以太网多播 MAC 地址**的 D 类 IP 多播地址。
3. 共有多少个不同的 D 类 IP 多播地址会映射为该以太网多播 MAC 地址？为什么？

---

### 【标准解题步骤（120+ 考场标准规范）】

#### 第一问：组播 MAC 地址详细二进制映射推导
- **第一步：展开 IP 地址的后 3 个字节为二进制**：
  - IP 地址为：`224.215.145.230`
  - 第一字节 `224`：前 4 位为 `1110`，最后 4 位与映射无关，忽略。
  - 第二字节 `215`：二进制为 **`11010111`**。
  - 第三字节 `145`：二进制为 **`10010001`**。
  - 第四字节 `230`：二进制为 **`11100110`**。
- **第二步：截取低 23 位**：
  - 低 23 位覆盖：第二字节的后 7 位 + 第三字节全部 8 位 + 第四字节全部 8 位（$7 + 8 + 8 = 23$ 位）。
  - 第二字节 `215`（`11010111`）丢弃最高位（第 1 位 `1`），留下后 7 位：`1010111`。
  - 第三字节（8 位）：`10010001`。
  - 第四字节（8 位）：`11100110`。
- **第三步：装配以太网 MAC 地址的后 24 位**：
  - MAC 地址后 24 位 = 第 25 位的固定 `0` + 低 23 位。
  - 二进制拼装：
    - 字节 4（MAC 第 4 字节）：`0` 拼接 `1010111` $\to$ **`01010111`** $\to$ 十六进制为 **`0x57`**。
    - 字节 5（MAC 第 5 字节）：`10010001` $\to$ 十六进制为 **`0x91`**。
    - 字节 6（MAC 第 6 字节）：`11100110` $\to$ 十六进制为 **`0xE6`**。
- **第四步：组合完整 48 位以太网 MAC**：
  - 高 24 位固定为 `01-00-5E`。
  - **最终 MAC 地址**：**`01-00-5E-57-91-E6`**。

#### 第二问：逆推构造同 MAC 的其他 IP 多播地址
- **原理**：只要保持 IP 地址的低 23 位完全不变，仅改变丢失的 5 位（即第一字节的后 4 位，以及第二字节的最高位），就能构造出新的同映射 IP！
- 原 IP 第一字节后 4 位为 `0000`（`224` 的后 4 位），第二字节最高位为 `1`。
- 我们将第二字节最高位改为 `0`（其余位不变）：
  - 第二字节原为 `11010111`（215），最高位改为 `0` 变为 `01010111`（87）。
  - 第一字节仍为 `224`，第三字节仍为 `145`，第四字节仍为 `230`。
- **得到新同源 IP**：**`224.87.145.230`**（映射得到的 MAC 完全相同，同为 `01-00-5E-57-91-E6`）。
- *(或者改变第一字节后 4 位为 `0001`，得到 `225.215.145.230` 也完全正确)*。

#### 第三问：冲突总数与原因阐述
- **总数**：共有 **32 个** 不同的 D 类 IP 多播地址会映射为该 MAC 地址。
- **原因**：D 类 IP 地址中，除固定的前缀 `1110` 占 4 位和映射到 MAC 的低 23 位外，中间有 $32 - 4 - 23 = 5$ 位未被映射。这 5 位二进制位可以组合出 $2^5 = 32$ 种不同的状态，因此对应 32 个不同的 IP 多播地址。

## 五、考场肌肉记忆与避坑指南

### 1. 致命易错陷阱
- 陷阱 1：**MAC 第 4 字节直接照抄 IP 第 2 字节（严重失误点！）**
  - IP 第 2 字节必须**把最高位强制抹成 0**！例如本题中 IP 第二字节是 `215`（`0xD7`），直接抄会写成 `0xD7`，而正确答案必须是抹掉最高位后的 `0x57`！
- 陷阱 2：**混淆 23 位与 24 位**
  - IANA 拥有的块是 24 位，但**第 25 位固定填 0**，真正动态映射的只有 **23 位**！

### 2. 秒杀公式与反射条件
$$\text{MAC 前缀}：\text{01-00-5E} \quad (\text{固定 24 位})$$
$$\text{MAC 第 4 字节} = \text{IP 第 2 字节} \ \& \ \text{0x7F} \quad (\text{最高位强制置 0})$$
$$\text{MAC 第 5 字节} = \text{IP 第 3 字节}, \quad \text{MAC 第 6 字节} = \text{IP 第 4 字节}$$
$$\text{冲突地址总数} = 2^{32 - 4 - 23} = 2^5 = \mathbf{32}$$
