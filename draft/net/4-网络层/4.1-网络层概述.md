# 4.1 网络层概述

网络层（Network Layer）是计算机网络体系结构中最核心的一层，其核心任务是**实现主机到主机（Host-to-Host）的端到端数据传输**，向上只提供简单灵活的、无连接的、尽最大努力交付（Best-Effort）的数据报服务。

## 一、网络层向上提供的两种服务争论（历史与经典考点）

在计算机网络发展史上，关于网络层应该提供“面向连接”还是“无连接”服务曾有著名争论：

| 对比维度 | 虚电路服务 (Virtual Circuit, VC) | 数据报服务 (Datagram, 互联网采用) |
|---|---|---|
| **核心思路** | 电信网思维：可靠通信由**网络核心**来保障 | 计算机网络思维：可靠通信由**网络边缘端系统**保障 |
| **连接建立** | 必须先建立虚电路连接，分配通信资源 | **无需建立连接**，随时按需发送 |
| **终点地址** | 仅在建立连接时使用完整地址，传输时仅用虚电路号 | **每个分组携带完整的源 IP 和目的 IP 地址** |
| **分组路径** | 同一连接的所有分组沿着**同一条预定虚电路**顺序传送 | 每个分组独立选路，不同分组可能经过**不同路由路径** |
| **分组顺序** | 严格按序到达终点 | **可能乱序、重复或丢失**（由上层 TCP 保障按序） |
| **节点故障影响** | 沿途任一路由器故障，该虚电路立即中断瘫痪 | 单个路由器故障时，后续分组**自动动态绕路** |
| **典型代表** | X.25、帧中继、ATM | **因特网 IP 协议** |

> **考点归纳**：因特网的核心设计理念是**将复杂性和可靠性放在网络边缘（端系统）**，使**网络核心（路由器）尽可能简单高效**。

---

## 二、网络层的两个核心功能

1. **转发（Forwarding / 数据平面）**：当一个分组到达路由器的某条输入链路时，路由器如何将该分组移动到适当的输出链路（微观动作，硬件线速查转发表）。
2. **路由选择（Routing / 控制平面）**：网络范围内的协同过程，通过路由选择算法决定分组从源到目的所流经的端到端路径（宏观全局选路，构建路由表）。

## 三、网络层关键协议族关系

```
+-------------------------------------------------------+
|  网络层高层应用与辅助协议:                             |
|  - 路由协议: RIP (基于UDP), OSPF (基于IP), BGP (基于TCP)|
|  - 控制与管理协议: ICMP, IGMP                          |
|  - 地址解析协议: ARP (介于网络层与链路层之间)          |
+-------------------------------------------------------+
                          |
                          v
+-------------------------------------------------------+
|  核心协议: 网际协议 IP (IPv4 / IPv6)                  |
|  提供无连接、不可靠、尽最大努力交付的数据报传送服务   |
+-------------------------------------------------------+
```
