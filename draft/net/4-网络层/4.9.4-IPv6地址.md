# 4.9.4 IPv6地址

> **408 考纲地位**：**IPv6 语法与编址基础（选择题必考送分/陷阱点）**。深入考查：**128 位冒号十六进制记法标准**、**两大化简规则（前导零省略与双冒号 `::` 零压缩）及“双冒号只能出现一次”铁律**、**三大核心特殊地址（环回地址 `::1`、未指定地址 `::`、链路本地单播 `FE80::/10`、多播 `FF00::/8`）**、**无状态自动配置（SLAAC）与 EUI-64 硬件地址转换机制**。

---

## 一、为什么 IPv6 地址需要复杂的冒号十六进制记法？

IPv6 地址长达 **128 位（16 字节）**。
- 若沿用 IPv4 的点分十进制记法，一个地址将写为：`128.2.194.242.0.0.0.0.0.0.0.0.10.1.0.1`（包含 16 个十进制数字和 15 个点），极其冗长且难以阅读和排障；
- **规范标准**：采用 **冒号十六进制记法（Colon Hexadecimal Notation）**：
  - 将 128 位按每 16 位（2 字节）划分为一组，共分为 **8 组**；
  - 每一组用 4 位十六进制数表示，组与组之间用英文冒号 `:` 分隔：
    $$\text{完整格式示例：}\mathbf{2001:0\text{DB}8:0000:0000:0008:0800:200\text{C}:417\text{A}}$$

---

## 二、IPv6 地址的两大化简规则与核心语法（考场秒杀基石）

为了进一步简化书写，RFC 规定了必须严格执行的两大化简法则：

### 规则 1：前导零省略（Leading Zeros Omission）
在任何一个 16 位组内部，**开头的“0”（高位零）可以全部省略不写**，但**每组至少要保留一个字符**（全零组至少保留一个单独的 `0`）：
- `0DB8` 可以简写为 `DB8`；
- `0008` 可以简写为 `8`；
- `0000` 可以简写为 `0`（绝对不能写成空！）；
- 上述地址第一步化简后变为：
  $$\mathbf{2001:DB8:0:0:8:800:200C:417A}$$

### 规则 2：双冒号压缩（Zero Compression / `::`）
连续的一连串由全零（`0:0:...:0`）组成的组，可以用一个**双冒号 `::`** 压缩替代！
- 上述地址经过双冒号压缩后变为：
  $$\mathbf{2001:DB8::8:800:200C:417A}$$

```text
       【双冒号 :: 唯一性铁律 (408 核心经典考点)】
       在同一个 IPv6 地址的简写形式中，双冒号 "::" 绝对只能出现一次！
       
       错误反例: 2001::8::417A  <--- 严重语法错误! 无法确定左右各自压缩了多少组零!
       正确写法: 只能在最长的一段连续全零处使用一次 "::"，另一处必须写为 ":0:"
```

## 三、408 核心必背特殊 IPv6 地址

```text
+-----------------------+--------------------+---------------------------------------------------+
| IPv6 地址表示 (简写)  | 对应 IPv4 概念     | 核心功能与 408 考点                               |
+-----------------------+--------------------+---------------------------------------------------+
| **`::1`**             | `127.0.0.1`        | **环回地址 (Loopback Address)**，用于本机协议栈测试|
| (前 127 位为 0，最后为1)|                    | (完整: 0000:...:0001，绝不出现在公网物理线路上)   |
+-----------------------+--------------------+---------------------------------------------------+
| **`::`**              | `0.0.0.0`          | **未指定地址 (Unspecified Address)**              |
| (全 128 位皆为 0)     |                    | 主机尚未获取合法 IP 进行开机 DHCP/SLAAC 请求时使用 |
+-----------------------+--------------------+---------------------------------------------------+
| **`FE80::/10`**       | 类似 169.254.0.0   | **链路本地单播地址 (Link-Local)**                 |
| (前缀 1111 1110 10)   | (APIPA 自动私有)   | **极其重要！** 仅在同一个物理直连网段内有效，     |
|                       |                    | **路由器绝对禁止向外部转发该地址的数据报！**      |
+-----------------------+--------------------+---------------------------------------------------+
| **`FF00::/8`**        | D 类地址           | **多播地址 (Multicast)**，最高 8 位全为 1         |
| (前缀 1111 1111)      | (224.0.0.0/4)      | 取代了 IPv4 的全部广播功能                        |
|                       |                    | - `FF02::1`: 本地链路所有节点 (相当于广播)        |
|                       |                    | - `FF02::2`: 本地链路所有路由器                   |
+-----------------------+--------------------+---------------------------------------------------+
```

## 四、408 经典高频真题精析

### 【题型：IPv6 地址压缩展开与语法合法性判定】

**【题目描述】**
请回答下列关于 IPv6 地址表示与语法的问题：
1. 请将 IPv6 地址 `2001:0000:0000:004A:0000:0000:0000:0001` 化简为最简书写形式。
2. 某网络管理员给出的 IPv6 地址为 `FE80::20C::0001`，请判断该地址的书写是否合法？并详细阐述理由。
3. 将最简形式的 IPv6 地址 `FE80::1` 完全还原展开为标准的 8 组、每组 4 位的冒号十六进制完整未压缩格式。

---

### 【标准解题步骤（120+ 考场标准规范）】

#### 第一问：最简形式化简推导
- 原始地址：`2001:0000:0000:004A:0000:0000:0000:0001`
- **第一步（省略前导零）**：
  - 各组变为：`2001:0:0:4A:0:0:0:1`
- **第二步（挑选最长全零段使用双冒号）**：
  - 前段有 2 个全零组（`0:0`），后段有 3 个全零组（`0:0:0`）；
  - 应当优先将**最长的一段连续零（后段 3 个全零组）**使用双冒号 `::` 压缩；前段只能保留简写的 `:0:0:`；
  - **最简标准格式**：**`2001:0:0:4A::1`**。

#### 第二问：合法性判断与理由
- **判断结果**：**非法（书写错误）**！
- **理由阐述**：
  - 在给出的地址中，出现了两次双冒号：`::20C::`；
  - 根据 IPv6 语法标准，在同一个地址中**双冒号 `::` 绝对只能出现一次**！因为若出现两次，无法从数学上唯一确定两次双冒号各自究竟压缩了多少组连续的 0，破坏了解析的确定性。

#### 第三问：`FE80::1` 的完整展开还原推导
- **第一步：数出非零组数**：
  - `FE80` 占 1 组；
  - `1` 占 1 组；
  - 非零/明确给出的组共有 2 组。
- **第二步：计算被双冒号压缩的零组数量**：
  $$\text{压缩的零组数} = 8 - 2 = 6 \text{ 组}$$
- **第三步：补齐每组前导零（展开为 4 位十六进制）**：
  - 组 1：`FE80`
  - 组 2~7（共 6 组）：`0000`
  - 组 8：`0001`
- **完整未压缩形式**：
  $$\mathbf{FE80:0000:0000:0000:0000:0000:0000:0001}$$

## 五、考场肌肉记忆与避坑指南

### 1. 致命易错陷阱
- 陷阱 1：**双冒号出现两次**
  - 选择题如果看到一个选项里有两个 `::`，直接秒杀排除，判定非法！
- 陷阱 2：**前导零省略后变成空冒号**
  - 全零组省略前导零后必须剩下一个单独的数字 `0`，写成 `:::` 或 `::0::` 属于严重语法错误。
- 陷阱 3：**链路本地地址 FE80 能不能跨网段转发？**
  - **绝对不能！** 看到路由器转发源或目的为 `FE80::` 的数据报，直接判错丢弃。

### 2. 秒杀公式与反射条件
$$\text{总组数} = 8 \text{ 组 (每组 16 位，共 128 位)}$$
$$\text{压缩还原}：\text{压缩的 0 组数} = 8 - \text{显式书写的组数}$$
$$\text{双冒号限制}：\mathbf{::} \text{ 全局唯一出现，严禁使用两次！}$$
