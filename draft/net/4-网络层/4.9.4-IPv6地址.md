# 4.9.4 IPv6地址


## 一、IPv6 地址表示：冒号十六进制记法

IPv6 地址长达 **128 位（16 字节）**。若采用 IPv4 的点分十进制记法，将包含 16 个十进制数与 15 个英文句点，极其冗长且易于混淆。

为此，IPv6 统一采用 **冒号十六进制记法（Colon Hexadecimal Notation）**：
- 将 128 位二进制数按每 16 位（2 字节）划分为一组，共分为 **8 组**；
- 每一组用 4 个十六进制数字表示，组与组之间使用英文冒号 `:` 分隔。

**完整标准格式示例**：
$$2001:0\text{DB}8:0000:0000:0008:0800:200\text{C}:417\text{A}$$

---

## 二、IPv6 地址的两大化简规则

为了便于阅读与书写，RFC 规范定义了严格的两种化简规则：

### 1. 规则一：省略前导零（Leading Zeros Omission）
- 在任何一个 16 位组内部，**开头的“0”（高位零）可以省略不写**，但**每组至少要保留一个字符**（全零组至少保留单个 `0`）；
- 示例：
  - `0DB8` 可化简为 `DB8`；
  - `0008` 可化简为 `8`；
  - `0000` 必须简写为 `0`（不可留空）；
- 上述完整地址经过前导零省略后变为：
  $$2001:\text{DB}8:0:0:8:800:200\text{C}:417\text{A}$$

### 2. 规则二：双冒号零压缩（Zero Compression）
- 连续出现的一段或多段由全零组成的组（`0:0:...:0`），可以用一个**双冒号 `::`** 压缩替代；
- 上述地址经过双冒号压缩后变为：
  $$2001:\text{DB}8::8:800:200\text{C}:417\text{A}$$

```text
+-----------------------------------------------------------------------------------+
|                           【双冒号 :: 唯一性语法铁律】                               |
|                                                                                   |
| 在同一个 IPv6 地址的简写形式中，双冒号 "::" 绝对只能出现一次！                     |
|                                                                                   |
| 错误示例: 2001::8::417A  <--- 严重非法！                                          |
| 原因: 若出现两次双冒号，无法从数学上唯一确定两处各自压缩了多少组连续的 0。        |
| 规则: 若地址中存在两处不连续的连续全零组，只能在较长的一处使用 "::"，另一处保留 ":0:"|
+-----------------------------------------------------------------------------------+
```

### 3. 双冒号展开还原算法
若将一个简写形式的 IPv6 地址还原为 8 组完整格式：
1. **数出显式给出的组数** $m$；
2. **计算被压缩的全零组数**：$k = 8 - m$；
3. **在 `::` 所在位置展开插入 $k$ 个 `0000` 组**；
4. 将其余各组的高位前导零补齐至 4 位十六进制数。
- 示例：`FE80::1` 中显式给出的组为 `FE80` 和 `1`（$m = 2$），被压缩的组数为 $8 - 2 = 6$ 组。完整展开后为：
  $$\text{FE80}:0000:0000:0000:0000:0000:0000:0001$$

## 三、核心特殊 IPv6 地址

IPv6 将地址空间划分为不同的前缀范围，核心特殊地址定义如下：

| IPv6 地址表示 (简写) | 前缀范围与二进制特征 | 对应 IPv4 概念 | 核心功能与路由规则 |
|---|---|---|---|
| **`::1`** (或 `::1/128`) | 前 127 位为 0，最后 1 位为 1 | `127.0.0.1` | **环回地址 (Loopback Address)**。用于本机协议栈测试与进程间通信，绝对不出现在网络物理链路中。 |
| **`::`** (或 `::/128`) | 全 128 位皆为 0 | `0.0.0.0` | **未指定地址 (Unspecified Address)**。主机在尚未获得合法 IP 地址时（如初始化发送请求时）作为暂时的源地址。 |
| **`::/0`** | 前缀长度为 0 | `0.0.0.0/0` | **默认路由 (Default Route)**。路由表中匹配所有目的地址的兜底路由项。 |
| **`FE80::/10`** | 二进制前缀 `1111 1110 10` | 类似 `169.254.0.0/16` (APIPA) | **链路本地单播地址 (Link-Local Address)**。主机开机自动生成，仅在同一物理链路（本地网段）内有效，**路由器严禁向其他网段转发以该地址为源或目的的数据报**。 |
| **`FF00::/8`** | 二进制前缀 `1111 1111` (前 8 位全 1) | D 类地址 (`224.0.0.0/4`) | **多播地址 (Multicast Address)**。取代 IPv4 的全部广播功能。常用组播：<br>- `FF02::1`：本地链路所有节点<br>- `FF02::2`：本地链路所有路由器 |
| **`2000::/3`** | 二进制前缀 `001` | IPv4 公网单播地址 | **全球单播地址 (Global Unicast Address)**。在全球因特网上进行常规路由与端到端通信的标准公网地址。 |

## 四、IPv6 单播地址结构与自动配置

### 1. 全球单播地址的层次化结构
IPv6 全球单播地址通常划分为三级层次：
- **全球路由前缀（Global Routing Prefix）**：通常为 48 位，由 ISP 统一分配；
- **子网标识（Subnet ID）**：通常为 16 位，由企业或机构内部划分子网；
- **接口标识（Interface ID）**：固定为 64 位，用于唯一标识网络接口（通常采用 IEEE EUI-64 规范由网卡 48 位 MAC 地址变换生成，或随机生成以保护隐私）。

### 2. 无状态地址自动配置（SLAAC）
- **IPv4 局限**：IPv4 主机接入网络依赖 DHCP 服务器的有状态配置（Stateful Configuration），若网络中无 DHCP 服务器，主机只能依靠手动配置静态 IP。
- **IPv6 SLAAC 机制**：IPv6 支持**无状态地址自动配置（Stateless Address Autoconfiguration，SLAAC）**：
  - 主机启动后，自动为本地接口生成一个链路本地地址 `FE80::/10`；
  - 主机向本地链路所有路由器发送 ICMPv6 路由器请求（RS）；
  - 本地路由器回送 ICMPv6 路由器通告（RA），其中包含本地网络的 64 位网络前缀；
  - 主机将收到的 64 位网络前缀与本地接口的 64 位接口标识拼接，即可直接合成全球唯一的 IPv6 全球单播地址，实现“即插即用”，完全不需要依赖集中的 DHCPv6 服务器维护租约状态。
