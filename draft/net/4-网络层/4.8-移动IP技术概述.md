# 4.8 移动IP技术概述

**移动 IP（Mobile IP，RFC 5944）** 允许移动节点（如车载终端、手机）在跨越不同物理网络漫游时，**始终保持其原始的本地 IP 地址不变，且现存的 TCP 连接不中断**。

---

## 一、移动 IP 的三大实体与双重地址概念

```text
[归属网络 / 家乡网络 Home Network]                  [外地网络 Foreign Network]
+------------------------------------+             +------------------------------------+
|  归属代理 HA (家乡路由器)          |             |  外地代理 FA (外地路由器)          |
|  移动主机原本所在网络              |             |  移动主机当前漫游所在网络          |
+------------------------------------+             +------------------------------------+
```

1. **移动节点（MN）**：具备移动漫游能力的端系统。
2. **永久地址 / 主地址（Home Address）**：移动节点在归属网络分配的固定 IP，对外通信始终展示此身份。
3. **转交地址（Care-of Address，CoA）**：移动节点在漫游到外地网络时获取的临时有效 IP（反映其当前所在的物理位置）。

---

## 二、移动 IP 通信全流程（三角路由问题）

```text
[通信对端 CN] ------------------ 1. 普通单播发送到主地址 ------------------> [归属代理 HA]
      ^                                                                         |
      |                                                        2. IP-in-IP 隧道封装
      | 3. 直接使用主地址单播回复                                     发往转交地址 CoA
      |                                                                         v
[移动节点 MN] <------------------- 4. 外地代理拆包交付 ----------------- [外地代理 FA]
```

1. **漫游与注册**：MN 进入外地网络后获取转交地址 CoA，并向归属代理 HA 发送注册报文登记当前 CoA；
2. **对端发包（CN $	o$ MN）**：通信对端按照 MN 的主地址发包，数据报常规路由到 HA；
3. **隧道中继（HA $	o$ FA）**：HA 截获数据报，使用 **IP-in-IP 隧道技术**二次封装，将报文发往 FA；
4. **对端直接回包（MN $	o$ CN）**：MN 响应时，直接以自身主地址为源 IP、向 CN 发送单播，数据报直接沿最优路径返回给 CN（不经过 HA）。
- **三角路由问题（Triangle Routing）**：入站流量绕经 HA 导致时延增加；可通过对端绑定缓存进行路由优化。
