# 4.2.2 IPv4 地址及其编址方法-分类编址方法

> **本节在 408 中的定位**：分类编址方法（Classful Addressing，RFC 791）是整个因特网 IP 地址体系的母体与历史源头。408 统考对分类编址的考查主要集中在选择题中的**“A/B/C/D/E 五类地址首字节十进制范围秒杀判决”**、**“最大可用网络数与每个网络最大可用主机数（减 2 的数学推导）”**、**“三大私网地址段（Private IP）的范围死记硬背”**，以及**“主机号全 0/全 1、127 环回、0.0.0.0 的协议用途”**。

---

## 一、第一性原理与设计动因：为什么早期设计 A/B/C 分类？

### 1. 20 世纪 70 年代末的工程直觉
在 ARPANET 早期，网络规模很小。设计者根据“组织规模的大小”将网络划分为三种等级：
- **A 类（超巨型网络）**：只有极少数机构（如美国国防部、IBM、MIT），给它们分配巨大的主机容量（$2^{24} \approx 1677\text{ 万台}$）；
- **B 类（中型网络）**：大学和大型跨国企业，容量适中（$2^{16} = 65534\text{ 台}$）；
- **C 类（小型局域网）**：普通小公司或实验室，容量较小（$2^8 - 2 = 254\text{ 台}$）。

### 2. 硬件极速分类的“前导比特（Prefix Bits）”设计
为了让当时只有几兆赫兹（MHz）主频的早期路由器能够在**单个硬件指令周期内瞬间断定该 IP 属于哪一类**，设计者发明了前导二进制标记法：

```
A 类: 0...               (第 1 位是 0, 占全网 50% 地址空间)
B 类: 1 0...             (前 2 位是 10, 占全网 25% 地址空间)
C 类: 1 1 0...           (前 3 位是 110, 占全网 12.5% 地址空间)
D 类: 1 1 1 0...         (前 4 位是 1110, 占全网 6.25% 组播空间)
E 类: 1 1 1 1...         (前 4 位是 1111, 占全网 6.25% 保留空间)
```

## 三、数学微观推导：为什么可用网络数与主机数要“减 2”？

408 选择题极其喜欢在“减 2”的细节上挖坑，必须搞透每一个“减 2”的物理原因：

### 1. 为什么 A 类可用网络数是 $2^7 - 2 = 126$？
- A 类网络号共 8 位，首位固定为 0，剩余可变位为 7 位，理论上有 $2^7 = 128$ 种组合；
- **扣除第 1 个**：全 0 网络号（`00000000`，即 `0.x.x.x`）表示“本网络本身”，保留不分配；
- **扣除第 2 个**：`01111111`（即十进制 **127**，网络号 `127.x.x.x`），被保留用于**本地软件环回测试（Loopback）**（如 `127.0.0.1`）；
- 故 A 类可用的有效网络号严格为：**$1 \sim 126$**（共 126 个）！

> **408 致命考点对比**：
> - **B 类可用网络数为什么不减 2？**
>   B 类前导位为 `10`，可变网络位有 14 位。历史上 B 类网络号允许全 0（`128.0.x.x`）和全 1，因此 B 类最大网络数为严格的 **$2^{14} = 16384$**（不减 2）！
> - **C 类可用网络数**：严格为 **$2^{21} = 2,097,152$**（不减 2）！

### 2. 为什么任何网络中最大可用主机数必须“减 2”？
设某网络分配的主机号位数为 $h$ 位，则该网段总共有 $2^h$ 个二进制组合：
- **扣除组合一（主机号全 0）**：代表**该子网的网络地址（Network Address）**，标识的是整个网络本身（例如 `192.168.1.0`），不可分配给具体主机的网卡！
- **扣除组合二（主机号全 1）**：代表**该子网的直接广播地址（Directed Broadcast Address）**（例如 `192.168.1.255`），发往该地址的数据包会被目标局域网内所有主机接收，不可分配给具体主机！
- **结论**：**可分配给主机的有效 IP 数量严格满足：$2^h - 2$！**

## 四、私有/专用 IP 地址（RFC 1918）与特殊 IP 全表

因特网管理机构在 A、B、C 三类地址中，各划拨出一部分作为**专用网（私网）地址（Private IP Addresses）**：
- **核心法则**：**这些地址在因特网全球公共骨干网路由器中绝不分配路由！全世界所有家庭、学校、企业局域网都可以自由免费重复使用这些私有 IP！** 要访问外网必须在出口路由器上通过 **NAT（网络地址转换）** 换成公网 IP。

### 1. 三大私网地址段（408 必背考点）

```
+---------------------------------------------------------------------------------------------------+
|  A 类私网地址段 : 10.0.0.0   ~ 10.255.255.255   (即 10.0.0.0/8,   共 1 个巨大的 A 类网络)          |
|  B 类私网地址段 : 172.16.0.0 ~ 172.31.255.255  (即 172.16.0.0/12, 共 16 个连续的 B 类网络)       |
|  C 类私网地址段 : 192.168.0.0~ 192.168.255.255 (即 192.168.0.0/16,共 256 个连续的 C 类网络)      |
+---------------------------------------------------------------------------------------------------+
```

### 2. 特殊 IP 地址应用场景大汇总表

| 特殊地址形态 | 网络号部分 | 主机号部分 | 能否作为源 IP？ | 能否作为目的 IP？ | 协议功能与物理意义 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **本网络本主机** | 全 0 | 全 0 (`0.0.0.0`) | **可以** | **绝对不能** | 仅用于 DHCP 发现报文，主机未分配 IP 时做临时源 IP |
| **网络地址** | 特定值 | **全 0** | 否 | 否 | 代表整个网络本身，在路由表中指明目标网络 |
| **直接广播地址** | 特定值 | **全 1** | 否 | **可以** | 针对特定远程网络的广播（如 `192.168.1.255`） |
| **受限广播地址** | 全 1 | 全 1 (`255.255.255.255`)| 否 | **可以** | 在本地广播域内广播，**路由器绝对不向外转发** |
| **环回测试地址** | 127 | 任意非全0/全1 | **可以** | **可以** | 本地进程间通信自测（如 `127.0.0.1`），流量不出网卡 |

## 五、408 统考真题级场景逆向与分类判决演算

### 【题型模型：十六进制/十进制 IP 地址属性秒杀与可用主机判定】

**【考题背景】**
网络分析仪在路由器各接口捕获到 5 个 IPv4 地址如下：
1. `10.200.30.40`
2. `127.0.0.1`
3. `172.30.1.255`
4. `192.168.10.0`
5. `224.0.0.5`

**【试推导并回答】**：
1. 分析上述 5 个 IP 地址分别属于哪一类（A、B、C、D 还是 E 类）？
2. 判定上述地址中，哪些属于全球合法的公网 IP，哪些属于私网 IP，哪些具有特殊协议功能？
3. 针对地址 3（`172.30.1.255`）和地址 4（`192.168.10.0`）：
   - 在传统的分类编址（未划分子网）规则下，它们能否直接分配给某台普通 PC 的网络接口作为正常主机 IP 使用？为什么？
4. 某企业申请了一个标准的 B 类主类网络，问该企业最多可以在该网络中容纳多少台活跃主机网卡？若申请的是一个 C 类网络呢？

---

### 【草稿纸执行第一步：看第 1 个字节判定分类】
```
1. 10.x.x.x      ===> 10 属于 1~126   ===> A 类 (私网)
2. 127.0.0.1     ===> 127             ===> 环回测试
3. 172.30.x.x    ===> 172 属于 128~191 ===> B 类 (私网 172.16~172.31 之间)
4. 192.168.x.x   ===> 192 属于 192~223 ===> C 类 (私网)
5. 224.0.0.5     ===> 224 属于 224~239 ===> D 类 (组播 OSPF 报文)
```

---

### 【严密推导过程】

#### 第 1 问：五大地址类别归属判定
- 地址 1（`10.x`）：首字节在 $1 \sim 126$ 之间 $\implies$ **A 类**；
- 地址 2（`127.x`）：首字节为 127 $\implies$ **A 类中的环回测试保留地址**；
- 地址 3（`172.30.x`）：首字节在 $128 \sim 191$ 之间 $\implies$ **B 类**；
- 地址 4（`192.168.x`）：首字节在 $192 \sim 223$ 之间 $\implies$ **C 类**；
- 地址 5（`224.0.x`）：首字节在 $224 \sim 239$ 之间 $\implies$ **D 类（组播地址）**。

#### 第 2 问：公网/私网/特殊功能判定
- **地址 1（`10.200.30.40`）**：属于 A 类私网地址（`10.0.0.0/8`）；
- **地址 2（`127.0.0.1`）**：特殊本地环回测试地址；
- **地址 3（`172.30.1.255`）**：处于 `172.16.0.0 ~ 172.31.255.255` 之间，属于 **B 类私网地址**；
- **地址 4（`192.168.10.0`）**：处于 `192.168.0.0 ~ 192.168.255.255` 之间，属于 **C 类私网地址**；
- **地址 5（`224.0.0.5`）**：D 类组播地址（专用于 OSPF 路由器接收协议报文）。

#### 第 3 问：主机网卡合法性判定（408 核心考点陷阱！）
- **地址 3（`172.30.1.255`）**：
  - **可以合法分配给主机网卡！**
  - **核心原理解析**：在分类编址下，B 类地址的网络号为前 16 位（`172.30`），**主机号为后 16 位**（二进制共 16 个 bit）！
  - 只有当后 16 位全为 1（即 `172.30.255.255`）时，才是广播地址！
  - 该地址的主机号为十六进制 `0x01FF`（二进制 `0000 0001 1111 1111`），既非全 0 也非全 1，是一个**完全合法的有效主机 IP**！
- **地址 4（`192.168.10.0`）**：
  - **绝对不能分配给主机网卡！**
  - **核心原理解析**：在分类编址下，C 类地址的网络号为前 24 位（`192.168.10`），**主机号仅为最后 8 位**；
  - 此时最后 8 位为全 0（`.0`），代表该 C 类网络本身的网络地址，因此不可配置给网卡。

#### 第 4 问：主类网络最大主机容量计算
- **B 类主类网络**：
  - 主机号位数 $h = 16$ 位；
  - 最大可用主机数：$2^{16} - 2 = 65536 - 2 = \mathbf{65,534\text{ 台}}$；
- **C 类主类网络**：
  - 主机号位数 $h = 8$ 位；
  - 最大可用主机数：$2^8 - 2 = 256 - 2 = \mathbf{254\text{ 台}}$。

## 六、考场诱惑性暗礁与秒杀口诀

### 1. 致命诱惑与错误路线踩刹车

> [!CAUTION]
> **陷阱 1：一看到结尾是 .255 就判定为“广播地址”，一看到 .0 就判定为“网络地址”**
> - **408 考场特大诱惑陷阱**：像 `172.16.1.255`（B类）或 `10.1.1.0`（A类），末尾虽然是 255 或 0，但**它们的主机号根本没有全 1 或全 0！它们全都是完全合法的主机地址！**
> - 判别前**必须先看类别**：
>   - A 类看后 3 个字节；
>   - B 类看后 2 个字节；
>   - 只有 C 类才单看最后 1 个字节！

> [!CAUTION]
> **陷阱 2：私网 B 类范围记错（误记为 172.16 ~ 172.255）**
> - 记住：B 类私网只到 **`172.31.255.255`**（只有 16 个 B 类网络，掩码是 `/12`）！`172.32.x.x` 已经属于合法的公网 IP 了！

### 2. 考场核心记忆桩
- **“一二六、一九一、二二三、二三九”**：A/B/C/D 四类地址分割线极速心算。
- **“B 类主机十六位，末尾二五五也是真主机”**：破除 .255 盲目广播执念。
- **“十、一七二点十六、一九二点一六八”**：三大私网段秒杀桩。
