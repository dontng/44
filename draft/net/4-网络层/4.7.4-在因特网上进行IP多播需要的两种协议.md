# 4.7.4 在因特网上进行IP多播需要的两种协议

在因特网范围内实现完整的端到端 IP 多播通信，必须依赖两类分工明确的协议协同工作：

```text
[发送源主机] -----> [第一跳多播路由器] ===== (多播路由协议选路) =====> [最后一跳多播路由器] -----> [接收端成员主机]
                                                                        ^                     ^
                                                                        |                     |
                                                                        +--- IGMP 协议交互 ---+
                                                                             (确定本地子网有无组播成员)
```

1. **网际组管理协议（IGMP）**：
   - **作用范围**：运行在**本地局域网（主机与直连的第一跳多播路由器之间）**；
   - **核心任务**：让本地多播路由器知道本局域网内**是否存在某个多播组的成员主机**。
2. **多播路由选择协议（Multicast Routing Protocol）**：
   - **作用范围**：运行在**因特网的多播路由器与多播路由器之间**；
   - **核心任务**：跨越广域网构建一棵**多播分发树（Multicast Distribution Tree）**，确保多播数据报无环路、无重复地送达所有连接有组播成员的末梢路由器。
