# 2.4 编码与调制

本节是物理层中考查最细、最容易出画图/选择题的一节，核心是把"计算机里的数字比特"变成"能在信道上传输的信号"。

## 一、基本概念辨析（考点：常考名词混用陷阱）

- **数据（Data）**：运送消息的实体，是信息的数字化表示（比特序列）。
- **信号（Signal）**：数据在传输过程中的电磁波表示形式。
  - **模拟信号（连续信号）**：代表消息的参数的取值是连续的。
  - **数字信号（离散信号）**：代表消息的参数的取值是离散的（如用恒定电压的脉冲表示 0 和 1）。
- **码元（Symbol）**：在使用时间域（或频率域）的波形表示数字信号时，代表不同离散数值的基本波形，是数字通信中携带信息量的基本信号单位。
- **波特（Baud）**：码元传输的速率单位，即单位时间内传送的码元个数（码元速率，与比特速率不同，一个码元可以携带多个比特，这是计算题考点，常考"若一个码元携带 n 比特，波特率与比特率的换算关系" B = R/log2(M)，M 为码元的离散电平数目）。

## 二、基带信号与带通（频带）信号

- **基带信号**：来自信源的信号，常常是离散的电压脉冲信号（0、1 两种电平），没有经过调制，直接包含低频分量（包括直流分量）。
- **带通信号（频带信号）**：基带信号经过载波调制后，把信号频谱移动到较高的频率范围，以适应信道的频率特性（例如适应无线或长途传输信道，不能传输直流/低频分量的场景，如电话线）。

对应两类传输技术：
- **基带传输**：直接传送基带信号，近距离局域网常用（如以太网）。
- **频带传输（带通传输）**：先对基带信号调制再传输，电话网络接入互联网（如调制解调器 Modem）是典型场景。

## 三、常见的编码方式（画波形图是重灾区）

针对数字数据，常见的**基带编码**方式有：

1. **不归零编码（NRZ, Non-Return-to-Zero）**：用高电平表示 1、低电平表示 0，信号在一个码元周期内不会归零。缺点：无法从信号中提取时钟同步信息（长串连续的 1 或 0 时电平不变，接收方不知道码元边界）。
2. **归零编码（RZ, Return-to-Zero）**：每个码元传输之后都要归零，码元中间信号回归到零电平，能提供自同步信息，但**占用更多带宽**。
3. **曼彻斯特编码（Manchester Encoding）**：每个比特中间都有一次电平跳变，常用"**高到低跳变表示 1，低到高跳变表示 0**"（具体规定在不同教材可能相反，需以课程 PPT 规定为准），跳变既表示比特值又用作同步信号，**自带时钟同步能力**，典型应用：**传统以太网 10BASE-T 的物理层编码**（高频考点！）。
4. **差分曼彻斯特编码**：**每个比特周期中间都有一次跳变用于同步**，而比特值由**每个比特周期开始处是否发生跳变**决定：周期开始**有跳变**表示 0，**无跳变**表示 1（具体规定同样以课程为准）。抗干扰性能优于曼彻斯特编码，常用于**令牌环网**。

考点对比：曼彻斯特编码和差分曼彻斯特编码都利用"**中间跳变**"做同步，区别在于比特值的判定依据（中间跳变方向 vs 周期起始是否跳变）。画图题经常给出一串比特（如 1011001），要求画出两种编码对应的波形。

## 四、模拟信号调制：把数字信号转换为模拟信号

当信道只能传输模拟信号时（如传统电话线路），需要把数字基带信号转换为模拟信号，称为**调制**，用一个频率较高的载波承载数据，基本的三种调制方法：

1. **调幅（AM, Amplitude Modulation）**：载波的**振幅**随基带数字信号变化（0、1 对应不同振幅）。
2. **调频（FM, Frequency Modulation）**：载波的**频率**随基带数字信号变化。
3. **调相（PM, Phase Modulation）**：载波的**相位**随基带数字信号变化。

更高效率的调制技术会把幅度和相位结合起来，典型如 **QAM（正交幅度调制）**，可以用一个码元同时携带多个比特，提高频带利用率，是 ADSL、Wi-Fi 等高速调制技术的基础（了解即可，408 很少深入考 QAM 细节，但选择题会问"QAM 同时利用了调幅和调相"）。
