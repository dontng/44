# 2.2 传输媒体

传输媒体是信号经过的物理通路，位于物理层之下（见 2.1）。按信号是否沿固体线缆传播，分为**导向传输媒体**（有线）和**非导向传输媒体**（无线，信号在自由空间中传播）。

信号在媒体中传输必然受到两类物理损伤：
- **衰减**：信号能量随距离衰减，限制了单段线缆的最大物理距离；
- **干扰**：外界电磁噪声或相邻线缆的信号耦合，使接收端还原比特时可能误判。

每种传输媒体的物理设计，本质上都是在**抗干扰、传输距离、速率和布线成本**之间做取舍。

---

## 一、导向传输媒体

### 1. 双绞线

- **构造**：两根互相绝缘的铜导线按一定节距绞合在一起。
- **抗干扰机制**：
  - 信号在两根导线上采用**差分传输**（以两线电压之差代表数据），接收端读取两线差值。
  - 外界电磁干扰若同时影响两根导线，接收端求差即可抵消干扰。但如果两根导线平行放置，离干扰源距离不同，受干扰强度不同就无法完全抵消。
  - **绞合的意义**：使两根线在空间中交替靠近干扰源，受到的外界干扰趋于一致，从而让差分抵消生效；同时绞合也大幅削弱了线对向外的电磁辐射，降低了相邻线对间的相互串扰。
- **分类**：
  - **UTP（非屏蔽双绞线）**：外层无金属屏蔽层，成本低、柔软易弯折，是局域网中使用最普遍的线缆。
  - **STP（屏蔽双绞线）**：外层包裹金属屏蔽层，抗干扰能力强，但成本高、线体硬，要求屏蔽层必须妥善接地。
- **类别**：按抗串扰能力与支持频率划分为不同类别（如 Cat 5e、Cat 6 等）。类别越高，抗串扰能力越好，支持的传输速率上限越高。

### 2. 同轴电缆

- **构造**：中心为铜导体，外层依次是绝缘层、网状外导体屏蔽层和保护套，各层同心同轴。
- **特点与分类**：
  - 外导体屏蔽层有效阻挡了外界电磁干扰，因此抗干扰能力与传输频带优于普通双绞线。
  - **50 Ω 同轴电缆**：用于数字信号的基带传输（2.4 节），早期曾用于总线型以太网，现已被更便宜、易布线的双绞线取代。
  - **75 Ω 同轴电缆**：用于模拟信号的宽带传输（2.4 节），主要用于有线电视（CATV）与宽带接入网。

### 3. 光纤

光纤利用**光脉冲**承载信号，带来三大压倒性优势：
1. 光频极高，通信容量巨大；
2. 传输损耗极小，中继距离远超铜线；
3. **完全不受电磁干扰**，不向外辐射电磁波，抗雷击且保密性高。

#### 导光原理：全反射
光纤由中心高折射率的**纤芯**（$n_1$）和外层低折射率的**包层**（$n_2$）构成（满足 $n_1 > n_2$）。当光线在纤芯内射向包层界面的入射角大于临界角时，产生**全反射**，光线被完全束缚在纤芯内折射向前传播。

#### 单模光纤 vs 多模光纤（核心对比）

```text
多模光纤 (MMF):
   +-------------------------------------------------------+
   |  包层 (低折射率 n2)                                    |
   |   \      / \      / \      / \                         |
   |====\====/===\====/===\====/===\==== 光源: 发光二极管 (LED)
   |     \  /     \  /     \  /     \   纤芯较粗 (50/62.5 μm)
   |  包层 (低折射率 n2)                                    |
   +-------------------------------------------------------+
   * 存在【模式色散】：不同角度光线传播路径长短不同，导致同一脉冲到达时间不一
     产生脉冲展宽，限制了传输距离和速率 (多用于几百米~2 km 局域网/机房)

单模光纤 (SMF):
   +-------------------------------------------------------+
   |  包层 (低折射率 n2)                                    |
   |------------------------------------ 光源: 激光器 (LD)  |
   |                                    纤芯极细 (8~10 μm)  |
   |  包层 (低折射率 n2)                                    |
   +-------------------------------------------------------+
   * 无模式色散：光线只有沿轴线单一基模传播，脉冲不展宽
     传输距离长达数十至上百公里，成本较高 (用于骨干网/城域网/长途海缆)
```

| 对比维度 | 多模光纤 (MMF) | 单模光纤 (SMF) |
|---|---|---|
| **纤芯直径** | 较粗（约 $50\,\mu\text{m}$ 或 $62.5\,\mu\text{m}$） | 极细（约 $8 \sim 10\,\mu\text{m}$，仅光波长量级） |
| **光源类型** | 发光二极管（LED，低成本） | 半导体激光器（LD，高方向性、成本高） |
| **主要限制** | **模式色散**（脉冲展宽失真） | 衰减与材料色散（无模式色散） |
| **传输距离** | 较短（几百米至 2 公里以内） | 极长（数十至数百公里） |
| **应用场景** | 园区网、数据中心机房内部 | 城域网、广域骨干网、长途干线 |

## 二、非导向传输媒体

无线通信利用自由空间中传播的电磁波。电磁波在真空中以光速（$c \approx 3 \times 10^8\,\text{m/s}$）传播，频率 $f$ 与波长 $\lambda$ 满足 $c = \lambda f$。

```text
频率从低到高:
  无线电波 (Radio Wave)  --->  微波 (Microwave)  --->  红外线 (Infrared)
       (30 kHz ~ 1 GHz)           (1 GHz ~ 300 GHz)         (300 GHz ~ 400 THz)
波长从长到短:
  绕射(穿透)能力强              直线视距传播(强方向性)       短距离、不能穿墙、视距通信
```

- **无线电波（较低频）**：波长较长，具有较强的绕射（衍射）和穿墙能力，用于广播和远距离对讲通信。
- **微波（核心频段）**：频率高、波长短，**主要沿直线视距（Line-of-Sight）传播**，无法绕过较大障碍物。计算机网络中的地面通信、卫星通信和无线局域网（3.9 节）均工作在微波频段。
- **红外线**：严格直线视距传播，不能穿透不透明物体，抗干扰弱，用于室内超近距离互联（如遥控器）。

### 1. 地面微波接力通信
微波沿直线传播，受地球表面曲率阻隔，两地天线超出视距后无法直接互通。因此地面微波通信采用**接力（中继）方式**：
- 在地面上**每隔约 50 km 设立一个微波中继站**，将信号接收、放大后继续转发给下一站；
- 易受地形障碍和恶劣天气（雨衰）影响。

### 2. 卫星通信
卫星通信将中继站部署在太空中，最常见的是**地球同步轨道卫星**（静止卫星）：
- **轨道特性**：位于赤道上空约 **$36,000\,\text{km}$**，公转周期与地球自转完全同步，地面天线固定对准即可，无需跟踪转动。
- **全球覆盖**：**只需 3 颗同步卫星（互成 120 度夹角）**，即可覆盖除南北极极冠以外的全部地球表面。
- **传播时延特征（理论计算）**：
  - 地空单程距离至少为 $2 \times 36,000\,\text{km}$（地面站 $\to$ 卫星 $\to$ 地面站）：
    $$t = \frac{2 \times 36000 \times 10^3\,\text{m}}{3 \times 10^8\,\text{m/s}} = 0.24\,\text{s} = 240\,\text{ms}$$
  - 实际链路单向传播时延通常在 **$240 \sim 270\,\text{ms}$** 之间，一个往返往复周期（RTT）高达约 **$500\,\text{ms}$**。
  - 这种大时延特性对频繁来回确认的交互型协议（如低效的停止-等待协议）性能极具杀伤力，网络设计中需专门考虑“长肥管道”（高时延带宽积）问题。
