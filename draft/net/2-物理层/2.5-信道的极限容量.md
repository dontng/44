# 2.5 信道的极限容量

本节是整个物理层最重要的**计算题考点**，核心是两条公式：奈奎斯特定理（理想无噪声信道）和香农公式（带噪声信道）。几乎每年 408 真题的物理层/信道部分都围绕这两条公式出选择题或计算题。

## 一、任何信道都有传输能力的极限

信号在信道中传输会存在：
- **码间串扰**（信号失真，相邻码元的波形互相干扰，接收方难以分辨）；
- **噪声干扰**（信道中热噪声等带来的随机干扰）。

这两个因素决定了**任何信道的数据传输速率都是有限的**，不存在无限带宽、无噪声的理想信道。

## 二、奈奎斯特定理（Nyquist，针对理想低通信道，无噪声）

在**理想**低通信道（带宽为 W，不考虑噪声）下，为了避免码间串扰，极限码元速率为：

```
最大码元速率 B(max) = 2W  （单位：波特/秒，Baud）
```

如果每个码元可以表示 M 种离散电平（即携带 log2(M) 比特信息），则极限数据传输速率（信息速率/比特率）为：

```
C(max) = 2W · log2(M)   （单位：bit/s）
```

**要点与易错点**：
- 奈奎斯特定理只给出了码元速率的上限，并没有对信号电平的种数 M 做限制，M 越大，携带的信息量越大，但**实际上 M 不能无限增大**，因为噪声和信号检测精度会限制可分辨的电平数（这正是香农公式要补充解决的问题）。
- 奈奎斯特定理**只适用于理想信道**（不考虑噪声），是传输速率的"数学/几何"约束（由带宽决定码元速率上限），而不是物理噪声约束。

## 三、香农公式（Shannon，针对有噪声信道）

在**带宽受限且有随机热噪声**的信道中，信道的极限信息传输速率（信道容量）为：

```
C = W · log2(1 + S/N)   （单位：bit/s）
```

其中：
- `W`：信道带宽（Hz）；
- `S/N`：信噪比（信号功率与噪声功率的比值，常以 dB 为单位给出，考试中常给出 `S/N` 的分贝值，需要换算：`dB = 10·log10(S/N)`，这是计算题常见的"先换算再代公式"陷阱）；
- `C`：信道的极限传输速率，即**香农极限**，表示无论采用什么编码方法，信息的传输速率都不可能超过这个值。

**要点**：
- 香农公式表明：**只要信噪比或带宽足够大，就能获得任意高的信息传输速率**（理论上），但实际系统会受限于设备、编码效率等工程因素，实际速率总是低于香农极限。
- 噪声越大（S/N 越小），或带宽越窄，信道容量越低。
- 香农公式给出的是**上限**，实际可达到的码元速率/传输速率必须结合奈奎斯特定理一起考虑：奈奎斯特定理限制了码元速率（给定带宽下码元传输的物理极限），香农公式限制了总的信息传输速率上限（给定带宽和信噪比下）。

## 四、两个公式的综合对比与常见考法

| 对比项 | 奈奎斯特定理 | 香农公式 |
|---|---|---|
| 适用信道 | 理想、无噪声 | 有随机噪声 |
| 限制因素 | 信道带宽 W | 带宽 W 和信噪比 S/N |
| 结论 | 限制码元速率上限 | 限制信息传输速率（比特率）上限 |
| 公式 | `B(max)=2W` | `C=W·log2(1+S/N)` |

常见计算题套路：
1. 给定带宽 W 和码元的电平数 M，用奈奎斯特定理求最大数据传输速率。
2. 给定带宽 W 和信噪比（可能以 dB 给出），用香农公式求信道容量。
3. 综合题：先用奈奎斯特定理算出理论码元速率，再结合题目给出的编码方式（如每个码元携带的比特数）换算成比特率，与香农公式结果比较，判断方案是否可行。

**易错提醒**：
- `log2` 不要和 `log10` 搞混，分贝换算公式是用 `log10`，但代入香农公式计算信道容量时用的是 `log2`。
- 奈奎斯特定理里的"2W"前的系数 2 来源于**采样定理**（要无失真恢复信号，采样频率至少为信号最高频率的 2 倍），这也是通信原理中奈奎斯特采样定理的物理层应用。
