# 7.8 防火墙访问控制与入侵检测系统

防火墙与入侵检测系统（IDS）是构建企业内网边界防御纵深的两大核心硬件/软件安全网络设备。

---

## 一、防火墙（Firewall）的基本概念与分级

防火墙是部署在不同网络安全域之间（如企业可信内部网络与不可信外部公共互联网之间）的一道特殊访问控制屏障。

```text
       [ 内部可信局域网 ] <====> [ 防 火 墙 (Firewall) ] <====> [ 不可信公共互联网 (Internet) ]
       (如 192.168.1.0/24)        (依照安全策略规则阻断/放行)     (攻击者潜伏、公网流量)
```

根据检查数据报所处的网络层级深度，防火墙分为三大经典类型：

```text
+=================================================================================+
|                              防火墙三大经典技术分类                             |
+=================================================================================+
  │
  ├─ 1. 【无状态包过滤防火墙 (Stateless Packet Filter)】:
  │      - 工作在: 网络层与运输层
  │      - 检查: 仅独立检查单个数据包的【静态五元组】，不关心前序历史连接状态
  │
  ├─ 2. 【状态检测防火墙 (Stateful Inspection Firewall)】:
  │      - 工作在: 网络层与运输层
  │      - 检查: 维护动态【连接状态表 (State Table)】，追踪 TCP 握手与连接生命周期
  │
  └─ 3. 【应用级网关 / 代理防火墙 (Application-Level Gateway / Proxy)】:
         - 工作在: 应用层
         - 检查: 作为完全代理彻底终结 TCP 连接，逐字节深度解构并检查【应用层具体载荷】
```

---

## 二、包过滤 vs 状态检测 vs 代理防火墙机制全景对比

| 评估维度 | 无状态包过滤防火墙 | 状态检测防火墙 | 应用级网关 (代理服务器) |
|---|---|---|---|
| **最高处理层级** | **网络层 / 传输层** | **网络层 / 传输层** | **应用层 (第七层)** |
| **过滤决策依据** | 源/目的 IP、源/目的端口、协议号（静态单包五元组） | 单包五元组 + **动态连接状态表**（SYN/ACK、序列号、连接生命周期） | **完整应用层报文数据**（如 HTTP URL、FTP 指令、SQL 注入载荷） |
| **连接状态感知** | **完全无状态**（孤立处理每个包） | **有状态**（只放行属于已建立合法连接的回程报文） | **完全接管并终结两端 TCP 连接** |
| **处理转发性能** | **极高**（完全硬件线速查表匹配） | **较高**（内存状态表高速哈希查找） | **较低**（需完整解析协议语义并做双向代理中继） |
| **防护能力缺陷** | 极易被伪造 ACK 标志绕过，无法防范高层攻击 | 依然无法检查加密的或合法端口内的高层载荷攻击 | 对每个新协议均需单独开发专用代理，灵活性低 |

### 核心机制对比：状态检测如何解决“回程流量”漏洞？
- **无状态包过滤的困境**：内网主机主动访问外网 Web 80 端口，外网服务器必须返回响应包（源端口 80，目的端口为内网随机端口）。为了让回程响应进入，管理员只能在防火墙上放行“所有源端口为 80 的入站流量”。黑客只要伪造源端口为 80 的探测包，即可直接穿透防火墙入侵内网；
- **状态检测的破局**：
  - 当内网主机发起 SYN 请求时，状态检测引擎在内存中记录一条动态会话：`[192.168.1.5:54321 <-> 202.108.22.5:80, 状态: SYN_SENT]`；
  - 只有真正来自该目标 IP、端口且序列号严格匹配的回程响应包才会被临时放行；
  - 连接释放（收到 FIN/RST）或超时后，该会话条目立即从内存中抹除，对外网的主动入站探测再次恢复绝对封锁！

## 三、入侵检测系统（IDS）与入侵防御系统（IPS）

### 1. 为什么有了防火墙还需要 IDS？
- **防火墙的局限**：防火墙就像“大门警卫”，主要检查来访者的身份证和门禁卡（IP/端口/连接状态）。如果一个合法注册的用户（或者通过开放的 Web 80 端口发送的合法 HTTP 请求）内部携带了精心构造的 SQL 注入或缓冲区溢出木马，防火墙会直接放行；
- **入侵检测系统（IDS，Intrusion Detection System）**：就像“闭路电视监控”，旁路监听全网所有流量，通过深层内容匹配分析流量中是否存在已知的黑客攻击特征或异常行为，并即时发出报警。

### 2. IDS 核心检测技术分类
1. **基于签名的检测（Signature-Based / 特征检测）**：
   - 将捕获的报文载荷与已知的恶意代码特征库（攻击签名规则，如 Snort 规则）进行模式匹配；
   - **特点**：对已知攻击的检测准确率极高、误报率低；但**对未知的零日漏洞（0-Day）完全无能为力**。
2. **基于异常的检测（Anomaly-Based / 行为异常检测）**：
   - 预先建立正常网络基线（如平时的平均流量、常见请求类型）；当流量统计指标显著偏离基线模型时触发告警；
   - **特点**：能够发现未知的潜在攻击；但**误报率（False Positive）极高**，易将正常的突发业务峰值误判为攻击。

### 3. IDS vs IPS 的部署拓扑差异

```text
       【入侵检测系统 IDS (旁路镜像部署)】               【入侵防御系统 IPS (串行阻断部署)】
       
       [ 交换机核心 ] ──────────> [ 服务器 ]             [ 交换机核心 ] ───> [ IPS ] ───> [ 服务器 ]
             │ (端口镜像 SPAN)                                                 │
             ▼                                                          (能直接丢弃恶意包，
       [ 旁路 IDS ] (仅抓包分析，发出警报告警，                                  在线实时主动阻断!)
                     无法直接在线拦截该数据包!)
```
