# 7.7 网络体系结构各层采用的安全措施-物理层和数据链路层

物理层和数据链路层位于网络体系结构的最底层，负责处理直连物理介质上的比特流与帧传输。在此两层实施的安全措施能够从最基础的物理介质与局域网接入边界上，阻断非法设备的物理接入与窃听。

---

## 一、物理层安全措施

物理层安全主要针对物理传输介质（双绞线、光纤、无线电波）本身的物理特性进行防护：

```text
+---------------------------------------------------------------------------------+
|                              物理层主要安全机制                                 |
+---------------------------------------------------------------------------------+
| 1. 介质防电磁泄露与防窃听: 采用光纤传输 (无电磁辐射，弯曲窃听易引发光衰告警)   |
| 2. 屏蔽与物理隔离        : 屏蔽双绞线 (STP)、防电磁泄漏屏蔽机房、网线金属穿管   |
| 3. 扩频保密通信          : 跳频 (FHSS) 与 直接序列扩频 (DSSS)，隐藏信号频谱特征 |
+---------------------------------------------------------------------------------+
```

- **光纤作为安全介质的第一性原理**：
  - 双绞线和同轴电缆在传输高频电信号时，向周围空间辐射电磁波（电磁泄漏），攻击者利用高灵敏度射频接收机无需接触网线即可还原通信信号；
  - 光纤利用光在纤芯的全反射传输光脉冲，**对外几乎零电磁辐射泄漏**；且光纤若被物理破坏或弯曲以抽取微弱光信号，会引起光功率急剧衰减，光纤监控系统能即刻报警切断通信。

---

## 二、数据链路层安全措施

数据链路层的安全重点在于：**控制对局域网传输介质的访问权限（准入控制）**，以及**保护同一物理链路两端节点之间的数据帧机密性与防篡改**。

### 1. 局域网接入端口认证：IEEE 802.1X
在传统以太网中，任何外来人员只要将网线插入墙上的 RJ-45 网口，即可直接接入内网广播域并获取 IP 地址，带来巨大的渗透风险。**IEEE 802.1X 协议** 实现了基于物理端口的访问控制。

```text
  [ 申请者 (Supplicant) ]           [ 认证者 (Authenticator) ]               [ 认证服务器 (Authentication Server) ]
     (接入终端主机)                     (以太网交换机/无线 AP)                         (后方集中式 RADIUS 服务器)
            │                                     │                                              │
            ├─ 1. 发起 EAPoL 接入请求 ───────────>│                                              │
            │                                     │ (交换机处于【受控端口阻塞】状态,             │
            │                                     │  除 802.1X 认证报文外，其他所有数据流量禁止通行)
            │                                     │                                              │
            │<─ 2. 发送 EAP 身份请求 ─────────────┤                                              │
            │                                     │                                              │
            ├─ 3. 提供凭证 (密码/证书) ──────────>│                                              │
            │                                     ├─ 4. 将凭证封装为 RADIUS 报文转发 ───────────>│
            │                                     │                                              │
            │                                     │                                              ▼
            │                                     │                                        5. 集中核验密码/证书
            │                                     │                                              │
            │                                     │<─ 6. 回送 RADIUS-Access-Accept ──────────────┤
            │                                     │                                              │
            │                                     ▼ (交换机将该物理端口状态打开为【授权状态】!)  │
            │<─ 7. 通知客户端认证成功 ────────────┤                                              │
            │                                     │                                              │
            └────── 8. 客户端正常发送业务数据帧 ──┴────────── 允许向内网核心转发 ────────────────┘
```

- **物理端口隔离机制**：交换机端口默认处于“未授权”状态，仅放行 IEEE 802.1X 协议的 EAPoL 握手控制帧；只有后端 RADIUS 服务器返回认证成功通知后，交换机硬件才将该物理端口置为“授权”状态，放行常规以太网数据帧。

### 2. 无线局域网安全标准演进：WEP $\to$ WPA $\to$ WPA2 $\to$ WPA3
由于 802.11 无线局域网使用开放的空间电磁波作为传输介质，任何处于信号覆盖范围内的黑客网卡均可在混杂模式下接收所有帧，因此数据链路层必须包含强加密与鉴别机制：

| 安全标准 | 对应协议版本 | 加密算法与机制 | 历史安全评定 |
|---|---|---|---|
| **WEP** | 原始 802.11 | RC4 序列密码，仅 24 位初始向量（IV） | **存在严重数学漏洞**。IV 空间过短极易重复，攻击者收集数十万个广播帧即可在数分钟内反推出密钥，**早已被彻底废弃**。 |
| **WPA** | 802.11i 草案 | TKIP（临时密钥完整性协议），RC4 | 过渡方案。扩展了 IV 长度并引入动态逐包密钥混合，但依然基于 RC4。 |
| **WPA2** | **802.11i 正式版** | **CCMP 协议（基于 AES 分组密码的 CCM 模式）** | **长期工业级黄金标准**。采用 128 位 AES 高强度加密结合 CBC-MAC 提供数据机密性与防篡改。 |
| **WPA3** | 最新 802.11 标准 | SAE（等同对等认证协议），防离线字典猜测 | 废除了 WPA2 容易遭受的预共享密钥（PSK）离线暴力破解缺陷，提供前向保密性。 |

### 3. 数据链路层加密的局限性
- **逐跳解密开销大**：链路层加密（Link Encryption）仅在两台相邻物理节点之间的直接物理连路上有效；
- 数据帧到达中间路由器时，必须先在网卡硬件解密出明文以便路由器查看三层 IP 首部查表选路，在出端口重新加密发出；若中间某台路由器被黑客攻破入侵，数据依然会以明文形式泄露。
