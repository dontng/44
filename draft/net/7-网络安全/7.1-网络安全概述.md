# 7.1 网络安全概述

网络安全是计算机网络体系结构的重要保障，旨在防止网络系统中的硬件、软件和数据受到偶然或恶意的破坏、更改或泄露，确保系统能够连续可靠地正常运行。

---

## 一、计算机网络面临的主要安全威胁

网络面临的威胁通常分为两大类：**被动攻击** 与 **主动攻击**。

```text
       【被动攻击 (Passive Attacks)】                    【主动攻击 (Active Attacks)】
       (重点在于“偷听”，不破坏数据流)                  (重点在于“篡改”，直接破坏正常服务)
       
       [发送端] ───────────────> [接收端]               [发送端] ──────X        [接收端]
                   │                                                   │            ▲
                   ▼ (窃听)                                            ▼ (截获篡改) │
             [攻击者窃听]                                           [攻击者伪造注入]
```

### 1. 被动攻击（Passive Attacks）
- **核心特征**：攻击者在不干扰网络正常运行、不修改传输数据的前提下，仅仅截获并窃听通信内容；
- **主要形式**：
  - **截获（Eavesdropping / 窃听）**：通过网络嗅探工具捕获线路上明文传输的敏感数据（如密码、账号、文件内容）；
  - **流量分析（Traffic Analysis）**：即使通信内容已加密，攻击者通过观察数据包的发送频率、长度变化、源目的 IP 地址等元数据，推测通信双方的身份和业务规律；
- **防范机制**：被动攻击极其隐蔽，接收方往往难以察觉。**最有效的防范手段是端到端数据加密**。

### 2. 主动攻击（Active Attacks）
- **核心特征**：攻击者故意改变网络数据流的状态，或者伪造虚假数据注入网络，破坏信息的完整性或系统的可用性；
- **主要形式**：
  - **篡改（Modification）**：截获网络传输中的数据报文，修改其中的部分或全部内容后再转发；
  - **伪造（Fabrication / 欺骗）**：无中生有地制造假冒报文（如冒充合法用户发起请求、伪造源 IP 地址）；
  - **重放（Replay）**：录制之前截获的合法通信报文，随后原封不动地重新发送给接收方，以骗取系统执行重复操作（如重复转账）；
  - **拒绝服务（DoS / DDoS）**：向目标服务器或网络链路持续注入海量无用请求，耗尽其 CPU、内存或带宽资源，致使合法用户无法获得正常服务；
- **防范机制**：重点在于**检测与恢复**（利用数字签名、报文鉴别码、抗重放时间戳以及防火墙/入侵检测系统）。

## 二、安全通信的四大核心目标

为了抵御上述网络攻击，一个安全的端到端通信系统必须满足以下四个基本安全特性：

```text
+---------------------------------------------------------------------------------+
|                              安全通信四大核心属性                               |
+---------------------------------------------------------------------------------+
| 1. 机密性 (Confidentiality)   : 仅合法的发送方和接收方能理解报文内容 (防窃听)    |
| 2. 完整性 (Integrity)         : 确保报文在传输过程中未被未授权篡改或伪造 (防篡改)|
| 3. 端点鉴别 (Authentication)  : 确认通信对端的真实身份，防止冒充 (防伪造)        |
| 4. 抗抵赖性 (Non-Repudiation) : 发送方不能否认自己曾经发送过该报文 (防否认)      |
+---------------------------------------------------------------------------------+
```

1. **机密性（Confidentiality）**：
   - 防范被动攻击的核心。发送方通过加密算法将明文（Plaintext）转换为密文（Ciphertext），只有持有解密密钥的合法接收方才能还原为明文。
2. **完整性（Integrity）**：
   - 保证接收端收到的数据与发送端发出的完全一致，没有被插入、删除、替换或乱序。通常结合密码学散列函数（Hash）和报文鉴别码（MAC）实现。
3. **端点鉴别（Authentication）**：
   - 在建立会话或数据交互前，通信双方能够确凿验证对方的实体身份是否真实（证明“你是你”），防止攻击者伪造身份介入通信。
4. **抗抵赖性 / 不可否认性（Non-Repudiation）**：
   - 发送方一旦签署并发送了一条消息，后续无法否认该消息出自自己之手；接收方也无法伪造出带有发送方合法签署的虚假消息。通常依赖公钥体系下的数字签名技术。
