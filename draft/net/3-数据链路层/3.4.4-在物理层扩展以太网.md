# 3.4.4 在物理层扩展以太网

---

## 1. 物理层扩展的工程动因与物理极限

在局域网技术发展初期，单个物理网段的传输距离严格受限于电磁信号衰减与线缆物理特性：
- 细同轴电缆（10BASE2）：单段最大长度为 $185\text{ m}$；
- 粗同轴电缆（10BASE5）：单段最大长度为 $500\text{ m}$；
- 双绞线（10BASE-T）：单段最大长度为 $100\text{ m}$。

为了扩大网络的地理覆盖范围，最直接的手段是在物理层引入中继器（Repeater）、集线器（Hub）或光纤收发器，对微弱信号进行整形放大和跨介质传输。

### 1.1 物理层扩展的时延硬约束

物理层设备不能无限制串联级联，其根本制约来源于以太网介质访问控制的物理第一性原理：

$$\text{争用期 } 2\tau \le \frac{L_{\min}}{C}$$

在标准 $10\text{ Mbps}$ 以太网（最小帧长 $64\text{ B} = 512\text{ bit}$）中：
- 争用期时间上限被严格限定为 **$512\text{ bit时间} = 51.2\ \mu\text{s}$**；
- 电磁波在铜线中的传播时延约为 $5\ \text{ns/m}$，且中继器芯片的模拟放大、时钟重定时与门电路开关均会引入额外的固有处理延迟；
- 若串联中继器过多导致网络端到端往返时延 $2\tau > 51.2\ \mu\text{s}$，发送节点将在发送短帧完毕后才收到远端传回的冲突电平，**CSMA/CD 碰撞检测机制失效，引发隐蔽丢包与全网瘫痪**。

## 2. 5-4-3 规则与光纤收发器扩展

### 2.1 经典 10BASE5 “5-4-3 规则”

为了将全网最坏情况下的往返传播时延严格控制在 $51.2\ \mu\text{s}$ 内，IEEE 802.3 制定了 10BASE5 物理层扩展的工程上限：

```
[网段 1 (挂主机)] ==(中继器 1)== [网段 2 (点对点)] ==(中继器 2)== [网段 3 (挂主机)] 
                                                             ||
[网段 5 (挂主机)] <==(中继器 4)== [网段 4 (点对点)] <==(中继器 3)==+
```

1. **5 个网段（Segments）**：任意两台主机之间最多跨越 5 个线缆段，总电缆物理长度上限为 $5 \times 500\text{ m} = 2500\text{ m}$；
2. **4 个中继器（Repeaters）**：网段之间最多串联 4 个中继器，以严格约束中继电路累加的时钟抖动与处理延迟；
3. **3 个挂载主机网段（Populated Segments）**：5 个网段中最多只能有 3 个网段可以挂接计算机主机，其余 2 个网段必须作为无主机的点对点中继互联链路（避免过多网卡收发器并联导致总线阻抗失配）。

### 2.2 光纤收发器（Fiber Transceiver）的物理特性

在跨园区长距离互联中，常使用一对光纤收发器将双绞线电信号转换为光脉冲通过光纤传输：
- **物理层归属**：光纤收发器仅负责光电信号的线性转换与放大，不解析数据链路层帧结构；
- **域属性**：光纤收发器两端连接的所有设备在电气逻辑上依然处于**同一个冲突域与同一个广播域**；若光纤链路过长导致 $2\tau$ 超出争用期，在半双工模式下同样会导致 CSMA/CD 失效。

## 3. 物理层扩展的得失权衡与性能雪崩效应

| 评估维度 | 扩展前的独立网段（如独立 Hub） | 经物理层级联扩展后的合并网络 | 机制分析 |
| :--- | :--- | :--- | :--- |
| **地理覆盖范围** | 较小（单段百米级） | 显著扩大（可达公里级） | 物理信号经放大再生突破了介质损耗极限。 |
| **冲突域数量** | 多个相互独立的冲突域 | **合并为 1 个庞大的单一冲突域** | 物理层设备无脑透传所有电信号，任何局部碰撞均蔓延至全网。 |
| **全网总信道容量** | 各网段带宽独立累加（$M \times C$） | **萎缩为单一信道容量（$C$）** | 所有节点共同争用一条物理信道，并发总吞吐量大幅缩减。 |
| **通信冲突概率** | 较低（各网段站点少） | **呈指数级攀升** | 竞争节点数量激增，监听冲突与退避等待时间占满信道。 |
| **速率异构兼容** | 各网段可独立选择速率 | **全网必须速率与时钟严格一致** | 物理层无法完成跨速率时钟转换与数据缓冲。 |

**核心结论**：**在物理层扩展以太网是以“冲突域无限膨胀、可用总带宽被腰斩、有效吞吐率雪崩下跌”为代价换取物理距离延伸。这一严重缺陷直接促使网络技术转向数据链路层扩展（网桥与交换机）。**

## 4. 典型问题分析

### 题目：多级物理层集线器树状扩展性能分析

某大学三个学院分别建有独立的 10BASE-T 共享式以太网：
- 学院 A：使用 16 端口 $10\text{ Mbps}$ 集线器 Hub-1，连接 12 台主机；
- 学院 B：使用 16 端口 $10\text{ Mbps}$ 集线器 Hub-2，连接 10 台主机；
- 学院 C：使用 16 端口 $10\text{ Mbps}$ 集线器 Hub-3，连接 14 台主机；
在独立运行时，各学院内部平均每台主机的可用带宽为 $0.6\text{ Mbps}$。
现为实现三院互通，网络中心增设一台主干集线器 Hub-0（$10\text{ Mbps}$），将 Hub-1、Hub-2、Hub-3 级联连接至 Hub-0 构成二级树状拓扑。

```
                       +---------------+
                       |   主干 Hub-0  | (10 Mbps 物理层)
                       +---+---+---+---+
                          /    |    \
                         /     |     \  (级联双绞线)
            +-----------+  +---+-------+  +-----------+
            |   Hub-1   |  |   Hub-2   |  |   Hub-3   |
            +-----+-----+  +-----+-----+  +-----+-----+
                 / \            / \            / \
             [12台主机]     [10台主机]     [14台主机]
```

**问题**：
1. 级联互联前，三个学院网络合计共有几个冲突域？全网理论最大总吞吐量是多少？
2. 级联互联后，整个网络共有几个冲突域和几个广播域？
3. 级联互联后，若全网 36 台主机均有持续发送需求，每台主机理论上可分得的平均带宽上限是多少？
4. 分析级联互联后网络实际吞吐量发生严重下降的物理原因。

---

### 推导过程

#### 1. 级联前独立网络指标推导
- 互联前三台集线器彼此物理隔离，各自独立运行；
- **冲突域数量**：**3 个**独立的冲突域；
- **理论最大总吞吐量**：
  $$\text{总吞吐量} = 10\text{ Mbps} + 10\text{ Mbps} + 10\text{ Mbps} = \mathbf{30\text{ Mbps}}$$

#### 2. 级联后域属性推导
- Hub-0、Hub-1、Hub-2、Hub-3 均为物理层多端口中继设备，其级联将所有端口在电气层面直接并联；
- **冲突域数量**：由 3 个合并为 **1 个**；
- **广播域数量**：**1 个**。

#### 3. 级联后平均带宽上限推导
- 级联后全网共享单一 $10\text{ Mbps}$ 信道；
- 主机总数为 $12 + 10 + 14 = 36$ 台；
- 理论平均带宽上限为：
  $$\text{平均带宽} = \frac{10\text{ Mbps}}{36} \approx \mathbf{0.278\text{ Mbps}}$$
  （相较于级联前各学院内部实测的 $0.6\text{ Mbps}$，理论上限已低于原来的一半）。

#### 4. 吞吐量严重下降的机理分析
1. **竞争站点基数剧增**：参与 CSMA/CD 信道争用的站点从 10 余台激增至 36 台，多站点在单向时延 $\tau$ 盲区内并发发送的重叠概率呈指数上升；
2. **冲突退避开销剧增**：频繁的碰撞迫使节点进入截断二进制指数退避，大量信道时间被浪费在发送人为干扰信号（Jamming Signal）和退避空闲等待上；
3. **有效通信时间被挤占**：在高并发冲突下，信道实际有效利用率急剧恶化，导致全网实际吞吐率远低于名义上的 $10\text{ Mbps}$。
