# 3.4.4 在物理层扩展以太网

> **本节在 408 中的定位**：物理层扩展以太网（通过中继器 Repeater、集线器 Hub、光纤收发器）是网络工程发展史上的“双刃剑”。408 统考对本节的考查极其深刻，核心命题刀刃在于：**“扩大地理覆盖范围与冲突域恶性膨胀的不可调和矛盾”**、**“5-4-3 规则背后的电磁波时延硬约束”**，以及**“为什么物理层扩展会导致吞吐量不升反降（雪崩效应）”**。

---

## 一、第一性原理与设计动因：为什么需要扩展？为什么物理层扩展有极限？

### 1. 物理层扩展的工程驱动力
在局域网诞生初期，单一网段的物理覆盖范围受到介质物理特性的严格束缚：
- 细同轴电缆（10BASE2）最大单段长度仅 $185\text{ m}$；
- 粗同轴电缆（10BASE5）最大单段长度仅 $500\text{ m}$；
- 双绞线（10BASE-T）最大单段长度仅 $100\text{ m}$。
当一所大学或一个企业厂区的建筑跨度达到数公里时，单根线缆根本无法覆盖。最直观、最廉价的思路就是：**在物理层使用信号放大再生设备（中继器 Repeater 或光纤收发器），将多个分散的网段拼接起来**。

### 2. 物理层扩展的致命阿喀琉斯之踵（物理时延锁死）
为什么不能用中继器无限地将网段一直串联下去？
- **物理定律硬约束**：
  以太网能够稳定运行的铁律是：**争用期 $2\tau \le \frac{L_{\min}}{C}$**！
  在 $10\text{ Mbps}$ 速率与 $64\text{ B}$（$512\text{ bit}$）最小帧长下，争用期被焊死在 **$512\ \text{bit时间} = 51.2\ \mu\text{s}$**！
- **时延预算透支**：
  电磁波在铜线中传播需要时间（约 $5\ \text{ns/m}$），中继器内部的信号重定时、前导码再生、硬件门电路同样存在固有时延。如果串联的中继器过多、电缆过长，两端站点之间的单向往返时延 $2\tau$ 一旦突破 $51.2\ \mu\text{s}$，**CSMA/CD 的冲突检测机制将彻底失灵，导致短帧碰撞无法被发送端察觉，网络发生隐蔽丢包和瘫痪！**

## 二、微观机制：5-4-3 规则与物理层级联拓扑

### 1. 经典的“5-4-3 规则”（10BASE5 时代的神圣法则）
为确保全网往返传播时延严控在 $51.2\ \mu\text{s}$ 争用期之内，IEEE 802.3 委员会制定了著名的 **5-4-3 规则**：

```
[网段 1 (带主机)] ==(中继器 1)== [网段 2 (纯链路)] ==(中继器 2)== [网段 3 (带主机)] 
                                                            ||
[网段 5 (带主机)] <==(中继器 4)== [网段 4 (纯链路)] <==(中继器 3)==+
```

- **5 个网段（Segments）**：任意两个站点之间，信号最多经过 5 个物理线缆段（总长度上限为 $5 \times 500\text{ m} = 2500\text{ m}$）；
- **4 个中继器（Repeaters）**：5 个网段之间最多串联 4 个中继器（以严格限制中继芯片的累计累加时延）；
- **3 个挂载主机网段（Populated Segments）**：在 5 个网段中，**最多只能有 3 个网段可以挂接计算机主机**，其余 2 个网段必须作为纯粹连接远距离中继器的“点对点链路（Inter-repeater Link）”（无主机接入，以避免过多收发器并联导致总线阻抗失配和电平衰减）。

### 2. 光纤收发器（Fiber Modem）的物理层长途扩展
在现代工业或校园网中，常用一对光纤调制解调器（光收发器）连接两个远距离集线器：
- **微观动作**：光收发器将双绞线的电信号转换为激光/光脉冲，经数公里单模光纤传输后在对端还原为电信号；
- **本质归属**：依然是**物理层设备**！虽然光纤极大延伸了距离，但两端的所有主机在电气逻辑上依然处于**同一个冲突域**！如果距离过远导致 $2\tau > 51.2\ \mu\text{s}$，该链路在半双工模式下同样会引发 CSMA/CD 冲突检测失效。

## 三、物理层扩展的得失全维横评（408 核心命题暗礁）

很多考生以为“把网络接在一起就是好事”，但在 408 体系中，物理层扩展带来的负面效应远大于正面收益：

| 评估维度 | 扩展前的两个独立网段 (Hub 1 / Hub 2) | 经物理层级联扩展后的单一网络 | 408 考场深层考点 |
| :--- | :--- | :--- | :--- |
| **地理覆盖范围** | 各自 $100\text{ m}$ | 扩大至数百米甚至公里级 | 扩大了物理服务半径 |
| **主机容纳数量** | 各自 $N_1$、$N_2$ 台 | 容纳 $N_1 + N_2$ 台主机 | 实现了所有主机全互联 |
| **冲突域 (Collision Domain)**| **2 个独立的冲突域** | **合并为 1 个庞大的单一冲突域** | **恶性恶化！** 任何一台主机碰撞，全网所有主机全部躺平！ |
| **广播域 (Broadcast Domain)**| 2 个独立的广播域（若各自独立） | 1 个庞大的单一广播域 | 广播风暴风险倍增 |
| **信道总容量 / 带宽** | 各自拥有 $10\text{ Mbps}$（全网总容量 $20\text{ Mbps}$） | **全网总容量萎缩为 $10\text{ Mbps}$** | **带宽雪崩！** 扩展后全网总吞吐量反而下降了一半！ |
| **异构网络支持** | 各网段可独立选型 | **所有网段必须速率完全一致** | 无法混合 10M 与 100M，时钟必须同步 |

> **关键命题结论**：
> **在物理层扩展以太网，是以“牺牲全网有效吞吐率、成倍放大冲突概率、恶化网络抗灾能力”为沉重代价，换取微不足道的“物理距离拉长”！**
> 正因如此，物理层扩展技术在 20 世纪 90 年代末被**数据链路层扩展技术（网桥、以太网交换机）彻底终结和取代**！

## 四、408 统考真题级情景逆向与性能退化计算演练

### 【题型模型：多集线器多层级联的冲突域合并与吞吐量雪崩推导】

**【考题背景】**
某大学三个系分别建有自己的独立共享式以太网：
- 计算机系：使用一台 16 端口 $10\text{ Mbps}$ 集线器 Hub 1，连接 12 台主机；
- 数学系：使用一台 16 端口 $10\text{ Mbps}$ 集线器 Hub 2，连接 10 台主机；
- 物理系：使用一台 16 端口 $10\text{ Mbps}$ 集线器 Hub 3，连接 14 台主机；
三个系在独立运行期间，各系内部平均每台主机的实际有效网络数据率为 $0.6\text{ Mbps}$。
现校网络中心为了实现三系互联，采购了一台主干集线器 Hub 0，将 Hub 1、Hub 2、Hub 3 的上联端口分别用双绞线插入 Hub 0 的端口中，构建成二级树状星形网络。

```
                       +---------------+
                       |  主干 Hub 0   | (10 Mbps 物理层设备)
                       +---+---+---+---+
                          /    |    \
                         /     |     \  (级联双绞线)
            +-----------+  +---+-------+  +-----------+
            |   Hub 1   |  |   Hub 2   |  |   Hub 3   |
            +-----+-----+  +-----+-----+  +-----+-----+
                 / \            / \            / \
             [12台主机]     [10台主机]     [14台主机]
```

**【试推导并回答】**：
1. 级联互联前，三个系合计共有几个冲突域？全网理论最大并发吞吐量总和是多少？
2. 级联互联后，整个校园网中共有几个冲突域？几个广播域？
3. 级联互联后，若全网 36 台主机同时活跃通信，每台主机理论上能够分到的平均独占带宽上限变为多少？
4. 分析级联互联后网络实际吞吐率为什么会出现“雪崩式下跌”？

---

### 【草稿纸执行第一步：画出物理层设备的合并逻辑】
```
Hub 是 L1 设备，既不隔离冲突域，也不隔离广播域。
4 台 Hub (Hub 0, 1, 2, 3) 互联 = 电气上将 36 台主机并联在同一根物理共享线上！
```

### 【严密推导过程】

#### 第 1 问：级联前独立网络指标推导
- 互联前，三台 Hub 各自独立工作，互不干扰；
- **冲突域数量**：3 个独立的冲突域；
- **理论最大并发吞吐量总和**：
  $$\text{总容量} = 10\text{ Mbps} + 10\text{ Mbps} + 10\text{ Mbps} = \mathbf{30\text{ Mbps}}$$

#### 第 2 问：级联后网络域划分推导
- Hub 0、Hub 1、Hub 2、Hub 3 均为纯物理层设备，信号在它们之间无阻碍广播穿透；
- 整个网络在电气上变成了一个连通的共享介质；
- **冲突域数量**：由原来的 3 个锐减合并为 **1 个**；
- **广播域数量**：**1 个**。

#### 第 3 问：级联后平均带宽上限推导
- 级联后，全网总带宽上限被唯一锁死在 Hub 0 背板共享的 **$10\text{ Mbps}$**；
- 全网主机总数为：$12 + 10 + 14 = 36\text{ 台}$；
- 36 台主机共同瓜分这 $10\text{ Mbps}$ 带宽：
  $$\text{平均理论带宽} = \frac{10\text{ Mbps}}{36} \approx \mathbf{0.278\text{ Mbps}}$$
  （对比级联前各系平均 $0.6\text{ Mbps}$ 的实际速率，理论上限直接被腰斩了一半以上！）。

#### 第 4 问：吞吐率雪崩下跌机理深度剖析
1. **竞争站点数倍增引发冲突概率几何级上升**：
   单网段 10 台主机时，CSMA/CD 碰撞尚可控；当 36 台主机挂在同一个冲突域中时，多个站点同时监听空闲并发送的重叠概率呈指数级攀升；
2. **截断二进制退避开销吞噬信道**：
   频繁的碰撞导致所有主机频繁进入退避等待状态，线路上充斥着 32~48 位的 Jamming 干扰信号与残帧碎片；
3. **有效通信时间趋近于零**：
   当冲突域规模过大时，实际网络利用率往往由原本的 $30\%\sim40\%$ 暴跌至不足 $5\%$，整个网络陷入近乎瘫痪的“拥塞风暴”。

## 五、考场诱惑性暗礁与秒杀口诀

### 1. 致命诱惑与错误路线踩刹车

> [!CAUTION]
> **陷阱 1：以为“主干集线器 Hub 0”具有汇聚加速能力**
> - **考场直觉陷阱**：很多考生望文生义，以为 Hub 0 是“主干设备”，能把 3 个 10M 网段聚合成 30M。
> - **物理击碎**：**Hub 没有交换矩阵，没有端口缓冲区！** 它只是把所有电线拧在了一起，总容量永远只有 10M，绝对不可能加速，反而是最大的瓶颈！

> [!CAUTION]
> **陷阱 2：误以为光纤收发器能把两个冲突域隔开**
> - 光收发器只是物理层电/光转换器，**不具备任何数据链路层帧解析与存储转发能力**。用光纤收发器连接两个远程网段，两端依然属于**同一个冲突域**！

### 2. 考场核心记忆桩
- **“五网四中继三挂机，时延拉满不能逾”**：5-4-3 规则的极限记忆。
- **“物理扩展大合并，合出一个大冲突，总线带宽被腰斩”**：物理层扩展必合并冲突域、稀释总带宽。
