# 3.4.1 网络适配器和MAC地址

## 一、网络适配器（网卡，NIC）

**网络适配器（Network Interface Card，NIC）**，俗称网卡，是计算机与局域网之间的接口硬件，工作在**物理层和数据链路层的交界**处：

- **物理层功能**：将数字信号编码为可在传输介质上传输的电/光/无线信号，并反向解码。
- **数据链路层功能**：封装/解封装以太网帧，进行 MAC 地址过滤（只接收发给自己或广播地址的帧），以及 CRC 校验。

网卡工作时，接收到帧后先检查目的 MAC 地址，若不匹配则丢弃（不上交 CPU），若匹配则去掉帧头帧尾后将数据交给网络层——这叫做**混杂模式（Promiscuous Mode）**的关闭状态；开启混杂模式后网卡接收所有经过的帧（用于网络抓包分析，如 Wireshark）。

## 二、MAC 地址

**MAC 地址（Media Access Control Address）**，也称物理地址或硬件地址，是网卡出厂时**固化在 ROM 中**的全球唯一标识符（BIA，Burned-In Address）。

### 格式

MAC 地址长 **48 位（6 字节）**，通常写成十六进制：

```
XX : XX : XX : XX : XX : XX
  前 3 字节（OUI）    后 3 字节
  ← 厂商标识 →       ← 设备序列号 →
```

- **OUI（Organizationally Unique Identifier）**：前 3 字节，由 IEEE 分配给各网卡制造商，标识厂商身份；
- 后 3 字节：由厂商自行分配，保证其产品间不重复。
- 理论上全球每块网卡的 MAC 地址唯一（实际可软件修改，但出厂时唯一）。

### 特殊 MAC 地址

| 地址 | 含义 |
|---|---|
| `FF:FF:FF:FF:FF:FF` | **广播地址**，局域网内所有站点都接收 |
| 第 1 字节最低位 = 1 | **组播（Multicast）地址**，如 `01:00:5E:xx:xx:xx` 用于 IP 组播 |
| 第 1 字节最低位 = 0 | **单播（Unicast）地址**（普通 MAC 地址） |

> 考点：广播地址是全 F（48 个 1），组播地址第一字节最低位为 1——选择题常考"下面哪个是广播地址/组播地址"。

## 三、MAC 地址 vs IP 地址

| 对比 | MAC 地址 | IP 地址 |
|---|---|---|
| 所在层 | 数据链路层 | 网络层 |
| 长度 | 48 位（6 字节） | 32 位（IPv4）/ 128 位（IPv6） |
| 结构 | 扁平（无层次结构） | 层次结构（网络号+主机号） |
| 分配 | 出厂固定，全球唯一 | 由网络管理员/DHCP 动态分配 |
| 作用范围 | **仅本段链路**（每跳更换） | **端到端**（源到目的不变） |
| 用途 | 标识链路上某个接口 | 标识网络中某个主机 |

**关键区别**：IP 数据报在从源到目的的整个路径中，源 IP 和目的 IP 不变；但每经过一个路由器，帧的源 MAC 和目的 MAC 都要**重新封装**——源 MAC 变为当前路由器接口的 MAC，目的 MAC 变为下一跳的 MAC。

IP 地址和 MAC 地址的绑定由 **ARP 协议**（地址解析协议）负责解析（见 4.2.5）。
