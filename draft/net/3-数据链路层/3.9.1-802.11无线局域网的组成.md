# 3.9.1 802.11 无线局域网的组成

> **本节在 408 中的定位**：IEEE 802.11 无线局域网（WLAN / Wi-Fi）是现代移动互联网的接入主力。408 统考对 802.11 组成的考查极其精准，核心考核点包括：**“基本服务集（BSS）的两类工作模式（有基础设施 vs 自组织 Ad-hoc / IBSS）”**、**“服务集标识符 SSID（Wi-Fi 名）与 BSSID（AP 的 MAC 地址）的本质区别”**、**“扩展服务集（ESS）、分配系统（DS）与二层无缝漫游（Roaming）”**，以及**“移动终端接入 AP 的扫描-认证-关联三大状态转移”**。

---

## 一、第一性原理与设计动因：为什么需要 BSS 与 ESS？

### 1. 自由空间无线电磁波的天然局限
有线网络中，双绞线将电信号束缚在金属铜线中；但在无线通信中，高频电磁波在自由空间中呈球面辐射，面临两大工程硬约束：
- **空间覆盖半径有限**：单个无线发射机的合法功率（约 $100\text{ mW}$）受国家法规严格限制，室内有效覆盖半径通常仅为 $20\sim50\text{ 米}$；
- **终端算力与功耗受限**：手机、笔记本等电池供电设备无法承受与远距离基站全时高功率通信。

### 2. 蜂窝化分布式覆盖与集中调度哲学
为了覆盖一整所大学或大型商场，802.11 借鉴了蜂窝移动通信思想：
- **化整为零（BSS）**：部署数十个小功率无线接入点（AP），每个 AP 负责局部微型蜂窝小区；
- **聚零为整（ESS 与 DS）**：机房通过高速有线以太网骨干（分配系统 DS）将所有分散的 AP 串联成一个统一的逻辑大网络；
- 移动终端用户在园区内行走时，网络在底层自动完成**基站无缝切换（漫游）**，TCP 连接不中断，用户毫无感知。

## 二、微观体系结构：BSS、ESS、DS 与 Portal 的层级模型

```
+---------------------------------------------------------------------------------------------------+
|                        扩展服务集 ESS (对外呈现为一个统一的逻辑大局域网)                              |
|                                                                                                   |
|                       +========================================+                                  |
|                       |   分配系统 DS (通常是有线以太网交换机)    | <==== 门桥 (Portal / 路由器) ====> 外网
|                       +===+================================+===+                                  |
|                           |                                |                                      |
|                 (有线以太网链路)                   (有线以太网链路)                               |
|                           v                                v                                      |
|                  +-----------------+              +-----------------+                             |
|                  |   接入点 AP 1   |              |   接入点 AP 2   |                             |
|                  +--------+--------+              +--------+--------+                             |
|                          / \                              / \                                     |
|               (无线电波)/   \(无线电波)        (无线电波)/   \(无线电波)                           |
|                        v     v                          v     v                                   |
|                     [STA 1] [STA 2]                  [STA 3] [STA 4]                              |
|                                                                                                   |
|              |<------ 基本服务集 BSS 1 ------>|  |<------ 基本服务集 BSS 2 ------>|                 |
+---------------------------------------------------------------------------------------------------+
```

### 1. 基本服务集（BSS，Basic Service Set）
- **有基础设施模式（Infrastructure Mode，最常用商业模式）**：
  - 核心设备是**无线接入点（AP，Access Point）**；
  - **集中式枢纽特征**：BSS 内部的所有移动终端站（STA）之间，**严禁直接点对点相互发射信号**！哪怕两台笔记本电脑挨在一起只有 10 厘米，STA 1 发给 STA 2 的数据也**必须先发给天花板上的 AP，再由 AP 转发给 STA 2**！
- **无基础设施模式（Ad-hoc / 独立 BSS，IBSS）**：
  - 没有固定 AP；终端主机临时自组织建立对等网络（Peer-to-Peer）；
  - 适用于战场紧急通信、灾难救援临时组网。

### 2. SSID 与 BSSID 的微观辨析（408 高频概念选择题）

| 标识符 | 全称与中文 | 物理/协议本质 | 典型格式与用户可见性 |
| :--- | :--- | :--- | :--- |
| **SSID** | Service Set Identifier<br>（服务集标识符） | **整个无线网络的逻辑名称**，一个 ESS 内所有 AP 共享同一个 SSID | 用户手机 Wi-Fi 列表里看到的字符串（如 `Tsinghua-Secure`），最长 32 字节。 |
| **BSSID** | Basic Service Set Identifier<br>（基本服务集标识符）| **某个特定物理 AP 的唯一硬件 MAC 地址**，用于在微观上区分具体连接的是哪个天线 | 48 位十六进制 MAC 地址（如 `00-1A-2B-3C-4D-01`），用户界面通常隐藏。 |

### 3. 分配系统（DS）与门桥（Portal）
- **分配系统（DS，Distribution System）**：互联多个 AP 的内部主干物理通路（$99\%$ 的情况下就是普通的有线以太网交换机与光纤）；
- **门桥（Portal）**：将 802.11 扩展服务集接入非 802.11 网络（如因特网或传统有线局域网）的边界桥接/路由设备。Portal 核心职责是**在 802.11 复杂三/四地址无线 MAC 帧与 802.3 标准以太网二地址 MAC 帧之间进行格式转换**。

## 三、移动终端（STA）接入网络的三大微观状态转移

一台手机从开机搜索信号，到最终能上网传输数据，必须在数据链路层严格经历三个连续状态：

```
[ 状态 1: 未认证，未关联 ]
       |
       +---> 步骤 1: 【网络扫描 (Scanning)】
       |     • 被动扫描: 手机静默监听 AP 周期性广播的【信标帧 (Beacon Frame, 约 100ms 一发)】
       |     • 主动扫描: 手机主动向空中发射【探针请求 (Probe Request)】，AP 回复探针响应
       |
[ 状态 2: 已认证，未关联 ]
       |
       +---> 步骤 2: 【身份认证 (Authentication)】
       |     • 交换 Authentication 报文 (开放系统认证或 WPA2/WPA3 4-Way Handshake)
       |
[ 状态 3: 已认证，已关联 ]
       |
       +---> 步骤 3: 【服务关联 (Association)】
             • 手机发送【关联请求 (Association Request)】
             • AP 检查资源并回复【关联响应 (Association Response)】，为手机分配 AID (关联 ID)
             • 正式加入 BSS，开启数据帧传输通道与 DHCP 申请 IP 流程！
```

## 四、408 统考真题级场景推导：无缝漫游（Roaming）微观时空追踪

### 【题型模型：多 AP 扩展服务集内部移动与二层漫游追踪】

**【考题背景】**
某大学图书馆大楼部署了 IEEE 802.11 WLAN 系统：
- 1 楼部署无线接入点 AP 1（MAC: `MAC_AP1`，信道 1）；
- 2 楼部署无线接入点 AP 2（MAC: `MAC_AP2`，信道 6）；
- 两个 AP 的无线射频信号在楼梯间重叠，且均配置了相同的 SSID：`"Library-WLAN"`；
- 两个 AP 的有线接口通过双绞线连接到同一台二层以太网交换机 SW 的 1 号和 2 号端口上（构成分配系统 DS）；
- 学生拿着笔记本电脑（MAC: `MAC_STA`，初始 IP: `10.1.1.50`）在 1 楼与 AP 1 关联并正在进行 TCP 视频播放；
- 该学生沿着楼梯走上 2 楼，笔记本信号平滑切换连接到了 AP 2。

```
                  [ 以太网交换机 SW (分配系统 DS) ]
                           / (Port 1)     \ (Port 2)
                          /                \
                   [ AP 1 (1 楼) ]   [ AP 2 (2 楼) ]
                      (信道 1)          (信道 6)
                         \                  /
                          \                /
                           \              / (走上 2 楼)
                         [ 学生笔记本 STA ]
```

**【试推导并回答】**：
1. 1 楼的无线网络属于 BSS 还是 ESS？1 楼与 2 楼合并起来的网络属于什么？
2. 笔记本从 1 楼移动到 2 楼的过程中，其连接的 **SSID** 是否发生改变？其连接的 **BSSID** 是否发生改变？
3. 在漫游切换瞬间，笔记本电脑与 AP 2 重新建立关联（Reassociation）后：
   - 笔记本电脑原有的 IP 地址 `10.1.1.50` 是否需要重新向 DHCP 申请更换？为什么？
   - 底层的以太网交换机 SW 的 MAC 地址转发表是如何感知到笔记本电脑已经从 1 号端口“漂移”到 2 号端口的？

---

### 【严密推导过程】

#### 第 1 问：服务集层级定义判定
- 1 楼由 AP 1 及其覆盖范围内的终端组成的网络是：**基本服务集（BSS）**；
- 1 楼与 2 楼通过交换机 SW（分配系统 DS）互联、使用相同 SSID 的整体网络是：**扩展服务集（ESS）**。

#### 第 2 问：SSID 与 BSSID 动态变化判定
- **SSID 保持不变**：整个 ESS 统一广播名称 `"Library-WLAN"`，终端在同一个逻辑网络内漫游；
- **BSSID 发生改变**：在 1 楼时，笔记本关联的 BSSID 为 AP 1 的物理硬件地址 `MAC_AP1`；移动到 2 楼后，笔记本关联的 BSSID 变更为 AP 2 的物理硬件地址 `MAC_AP2`。

#### 第 3 问：二层无缝漫游微观机制分析
- **IP 地址无需更换**：
  因为 AP 1 和 AP 2 挂接在同一台二层交换机 SW 上，属于**同一个二层广播域（同一子网）**。漫游属于“二层漫游（Layer 2 Roaming）”，笔记本电脑的 IP 地址 `10.1.1.50` 保持不变，传输层 TCP 连接不会断开，视频流丝滑持续播放。
- **交换机 MAC 表更新（自学习修正）**：
  1. 笔记本与 AP 2 成功关联后，AP 2 立即代表该笔记本（或由笔记本主动）向有线交换机 SW 发送一个帧（如免费 ARP 或数据帧），其**源 MAC 地址为 `MAC_STA`**；
  2. 交换机 SW 从其 **2 号端口** 接收到该帧；
  3. 交换机执行**自学习算法**：立即将转发表中 `MAC_STA` 原本映射的 `Port 1` **强行更新覆盖为 `Port 2`**；
  4. 后续因特网下发给该笔记本的数据包，交换机瞬间精准定向转发到 2 号端口送达 AP 2，完成无缝平滑漫游。

## 五、考场诱惑性暗礁与秒杀口诀

### 1. 致命诱惑与错误路线踩刹车

> [!CAUTION]
> **陷阱 1：以为无线局域网中同一 AP 下的主机是“直连通信”**
> - **408 经典常识陷阱**：在有基础设施的 BSS 中，主机之间**严禁直通！** 所有通信必须走 AP 中转。AP 既充当无线中继器，又充当二层协调调度网桥。

> [!CAUTION]
> **陷阱 2：混淆 BSSID 与 SSID**
> - 见到字符串（如 `eduroam`）必是 **SSID**；
> - 见到 48 位十六进制 MAC 地址必是 **BSSID**！

### 2. 考场核心记忆桩
- **“一个 AP 一个 BSS，有线串起大 ESS”**：无线局域网层次架构秒杀桩。
- **“SSID 是网名，BSSID 是 AP 身份证”**：两类标识符的极速记忆。
- **“扫描认证再关联，二层漫游不换 IP”**：接入与漫游核心三部曲。
