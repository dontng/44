# 3.9.1 802.11 无线局域网的组成

IEEE 802.11 是无线局域网（WLAN）的通用国际标准族。由于无线信道具有开放性、自由空间路径损耗大以及发射功率受限等物理特性，无线局域网在体系结构上采用了与传统有线以太网截然不同的服务集层级模型。

---

## 一、基本服务集（BSS）

**基本服务集（BSS，Basic Service Set）** 是 802.11 无线局域网的最基本构建构件。根据是否具备固定中心控制设备，基本服务集分为两种工作模式：

```
1. 有基础设施模式 (Infrastructure Mode):
             +-----------------+
             |   接入点 AP     |
             +--------+--------+
                     / \
                    /   \
                   v     v
                [STA 1] [STA 2]
   (所有通信必须由 AP 进行中转)

2. 无基础设施模式 (自组织模式 / IBSS):
                [STA 1] <======> [STA 2]
                   ^               ^
                    \             /
                     v           v
                        [STA 3]
   (终端站点之间直接对等点对点通信)
```

### 1. 有基础设施模式（Infrastructure Mode）
- **核心组成**：包含一个基站（在 802.11 中称为**接入点 AP，Access Point**）以及若干个移动终端站点（STA，Station）。
- **工作机制**：
  - AP 通常通过有线电缆连接到骨干网络（如交换机）；
  - **集中中转机制**：BSS 内的所有站点之间**不能直接相互通信**，所有的上行流量和下行流量都必须先发送给 AP，由 AP 统一进行调度与转发。
- **应用场景**：企业、校园、家庭 Wi-Fi 等绝大多数商用网络场景。

### 2. 无基础设施模式（自组织网络 / IBSS）
- **核心组成**：也称为独立基本服务集（IBSS，Independent BSS）或自组网（Ad-hoc 模式）。
- **工作机制**：
  - 网络中没有预先部署的中心 AP；
  - 彼此处于无线信号覆盖范围内的移动站点临时自动组织形成对等网络，站点之间直接进行点对点数据传输。
- **应用场景**：野外搜救、临时会议、灾难应急救援等无固定网络基础设施的环境。

---

## 二、扩展服务集（ESS）与分配系统（DS）

单个 AP 的发射功率受无线法规限制，其覆盖半径通常在数十米范围内。为了覆盖大范围区域（如教学楼、整个校园或大型商场），802.11 引入了扩展服务集架构：

```
+---------------------------------------------------------------------------------------------------+
|                        扩展服务集 ESS (对外呈现为一个统一的逻辑大局域网)                              |
|                                                                                                   |
|                       +========================================+                                  |
|                       |   分配系统 DS (通常是有线以太网交换机)    | <==== 门桥 (Portal / 路由器) ====> 外网
|                       +===+================================+===+                                  |
|                           |                                |                                      |
|                     (有线以太网)                     (有线以太网)                                  |
|                           v                                v                                      |
|                  +-----------------+              +-----------------+                             |
|                  |   接入点 AP 1   |              |   接入点 AP 2   |                             |
|                  +--------+--------+              +--------+--------+                             |
|                          / \                              / \                                     |
|                         v   v                            v   v                                    |
|                      [STA 1][STA 2]                   [STA 3][STA 4]                              |
|                                                                                                   |
|              |<------ 基本服务集 BSS 1 ------>|  |<------ 基本服务集 BSS 2 ------>|                 |
+---------------------------------------------------------------------------------------------------+
```

### 1. 扩展服务集（ESS，Extended Service Set）
- 多个 AP 通过有线骨干网络相互连接，即可将多个相邻的基本服务集（BSS）组合为一个更大范围的**扩展服务集（ESS）**；
- 对上层协议栈或外部网络而言，整个 ESS 表现为一个统一的单一逻辑二层局域网；
- 移动站点可以在同一个 ESS 覆盖的各个 AP 之间移动，实现**二层无缝漫游（Roaming）**。

### 2. 分配系统（DS，Distribution System）
- 连接各个 AP 的主干网络通路称为分配系统（DS）；
- 在绝大多数实际工程中，分配系统由普通的**有线以太网交换机**及光纤/双绞线网络构成。

### 3. 门桥（Portal）
- 门桥是将 802.11 扩展服务集与非 802.11 外部网络（如传统的有线以太网、因特网）互联的边界设备（通常为路由器或三层网关）；
- 门桥的核心职责是在 802.11 无线 MAC 帧格式与 802.3 有线以太网 MAC 帧格式之间进行格式转换与桥接转发。

## 三、网络标识符：SSID 与 BSSID

在 802.11 无线局域网中，存在两种关键的网络标识符，两者的功能与应用层次不同：

| 标识符 | 全称 | 作用与物理本质 | 表现形式与应用场景 |
| :--- | :--- | :--- | :--- |
| **SSID** | Service Set Identifier<br>（服务集标识符） | **整个无线网络的逻辑名称**。<br>同一个 ESS 内的所有 AP 通常配置相同的 SSID。 | 终端用户在手机或电脑 Wi-Fi 列表里看到的字符串名称（如 `Campus-WiFi`），最长 32 字节。用于用户识别和选择网络。 |
| **BSSID** | Basic Service Set Identifier<br>（基本服务集标识符） | **某个特定 AP 的物理硬件标识**。<br>用于在底层数据链路层唯一标识一个具体的 BSS。 | 通常直接采用该 **AP 对应无线接口的 48 位 MAC 地址**（如 `00-2A-3B-4C-5D-6E`）。在底层 MAC 帧头中用于寻址。 |

## 四、移动终端接入 AP 的状态转移流程

一台移动设备（STA）要在有基础设施的 BSS 中传输数据，必须在数据链路层完成以下三个连续阶段：

```
[ 状态 1: 未认证，未关联 ]
       |
       +---> 阶段 1: 【网络扫描 (Scanning)】
       |     • 被动扫描: 终端静默监听 AP 周期性广播的【信标帧 (Beacon 帧)】;
       |     • 主动扫描: 终端主动发送【探针请求帧 (Probe Request)】，AP 收到后回复探针响应。
       |
[ 状态 2: 已认证，未关联 ]
       |
       +---> 阶段 2: 【身份认证 (Authentication)】
       |     • 终端与 AP 之间交换认证帧，验证接入权限（如开放系统认证或 WPA/WPA2 密码握手）。
       |
[ 状态 3: 已认证，已关联 ]
       |
       +---> 阶段 3: 【服务关联 (Association)】
             • 终端向 AP 发送【关联请求帧 (Association Request)】;
             • AP 确认后返回【关联响应帧 (Association Response)】，建立正式的逻辑连接;
             • 只有处于已关联状态，终端才能正常收发上层数据帧，并启动 DHCP 获取 IP 地址。
```

### 二层漫游（Layer 2 Roaming）机制
当移动设备在同一个 ESS 内部从 AP 1 的覆盖区域移动到 AP 2 的覆盖区域时：
1. 终端与 AP 2 执行**重关联（Reassociation）**流程，接入新的 BSS；
2. 由于两个 AP 属于同一个 ESS（挂接在同一个二层分配系统交换机上），终端的**IP 地址保持不变**，传输层 TCP 连接不会中断；
3. AP 2 通过向交换机发送数据帧，触发交换机的**自学习算法**，将交换机转发表中该终端 MAC 地址对应的端口更新为连接 AP 2 的新端口，从而实现流量的无缝切换。
