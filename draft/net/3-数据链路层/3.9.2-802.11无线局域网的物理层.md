# 3.9.2 802.11 无线局域网的物理层

> **本节在 408 中的定位**：802.11 无线物理层是电磁波空间调制、频谱信道划分与多载波传输的汇聚点。408 统考对无线物理层的考查侧重于**“2.4 GHz 频段三大互不重叠非交叠信道（1、6、11）的数学频宽推导”**、**“2.4 GHz 与 5 GHz 频段物理特性的根本权衡”**，以及**“扩频（DSSS/FHSS）与正交频分复用（OFDM）对抗无线多径衰落的核心原理”**。

---

## 一、第一性原理与设计动因：无线物理层的三大恶劣生存环境

无线电波在空气中传播，面临着有线光纤和铜线完全没有的致命物理挑战：
1. **多径时延扩展（Multipath Delay Spread）与选择性衰落**：
   发射机发出的电磁波打在墙壁、天花板、地面上发生反射与折射，多条不同路径的电磁波到达接收天线时存在微秒级的相位差，相互叠加发生相消干涉（衰落），导致传统单载波调制发生严重的**码间串扰（ISI）**；
2. **严重的同频电磁干扰**：
   Wi-Fi 工作在免许可授权的 **ISM（工业、科学、医学）频段**，蓝牙耳机、微波炉、无线电话甚至遥控玩具全在这个频段上大声轰鸣；
3. **空间路径损耗剧烈**：
   根据自由空间电磁辐射定律，信号衰减与距离平方和载波频率平方成正比（Friis 传输方程）。

## 二、微观结构：2.4 GHz 频段信道重叠与非重叠信道推导

### 1. 2.4 GHz 频段的离散信道划分模型
国际 IEEE 802.11 标准在 $2.4\text{ GHz}$ 频段（$2.400 \sim 2.4835\text{ GHz}$）共划分了 13 个（部分国家 14 个）信道：
- **信道中心频率间隔**：相邻信道中心频率仅相隔 **$5\text{ MHz}$**；
- **单信道占用频宽**：根据 802.11 物理层频谱掩模规范，每个信道实际占用的信号频宽为 **$20\text{ MHz} \sim 22\text{ MHz}$**！

```
频谱重叠微观全景图 (中心频率相隔 5MHz, 实际信号跨度 22MHz):
 信道 1: [2401 ~ 2423 MHz] (中心 2412)  ======> 涵盖信道 1, 2, 3
 信道 6: [2426 ~ 2448 MHz] (中心 2437)  ======> 涵盖信道 4, 5, 6, 7, 8
 信道 11: [2451 ~ 2473 MHz] (中心 2462) ======> 涵盖信道 9, 10, 11, 12, 13

 频率轴 (MHz):
 2412(CH1)        2437(CH6)        2462(CH11)
    |                |                |
 /-----\          /-----\          /-----\
|  CH1  |        |  CH6  |        | CH11  |  <=== 彼此频谱完全分离，边缘留有 3MHz 安全保护间隔!
 \-----/          \-----/          \-----/
```

### 2. 著名的三大互不干扰非交叠信道（1、6、11）推导
- 信道 1 的上限频率：$2412\text{ MHz} + 11\text{ MHz} = 2423\text{ MHz}$；
- 信道 6 的下限频率：$2437\text{ MHz} - 11\text{ MHz} = 2426\text{ MHz}$；
- $2426\text{ MHz} > 2423\text{ MHz}$，两者之间存在 **$3\text{ MHz}$ 的安全保护频带**，互不干扰！
- 同理，信道 6 与信道 11 之间也完全独立分离！
- **408 核心结论**：**在 2.4 GHz 频段内，最多只能同时部署 3 个完全互不干扰的无线信道！经典组合为 1、6、11（或 2、7、12；3、8、13）！**

## 三、2.4 GHz 频段 vs 5 GHz 频段全维物理横评

| 物理特性 | 2.4 GHz 频段 | 5 GHz 频段 | 底层电磁波物理原理 |
| :--- | :--- | :--- | :--- |
| **电磁波波长 $\lambda$** | $\approx 12.5\text{ cm}$（较长） | $\approx 6.0\text{ cm}$（较短） | $\lambda = c / f$，频率越高，波长越短 |
| **绕射与穿墙能力** | **强**（可绕过常见室内家具） | **弱**（易被钢筋混凝土墙体吸收衰减） | 波长越长，衍射/绕射效应越显著 |
| **空间衰减速度** | 慢，物理覆盖半径大（$30\sim50\text{ m}$） | 快，物理覆盖半径小（$10\sim20\text{ m}$） | 自由空间损耗 $L \propto f^2$，高频信号损耗极快 |
| **可用频谱带宽** | 极窄（仅约 $83.5\text{ MHz}$） | **极宽**（数十个信道，数百 MHz 频宽） | 5GHz 频段频谱资源极其丰富 |
| **互不重叠信道数** | **仅 3 个**（1、6、11） | **多达 24 个以上**（可随意信道绑定） | 彻底消除同频邻频干扰 |
| **环境杂波干扰** | **极度严重**（蓝牙、微波炉全在抢） | **极少**（主要为专业雷达避让 DFS） | 纯净的工业通信环境 |
| **峰值传输速率** | 较低（通常数十至百 Mbps） | **极高**（轻松突破 Gbps 级别） | 香农定理：信道容量 $C$ 与带宽 $W$ 成正比 |

## 四、核心调制与多址技术演进

### 1. 扩频通信：DSSS 与 FHSS
- **直接序列扩频（DSSS）**：用伪随机码（Barker 码）将 1 比特信号扩展为 11 位的码片（Chip）发送，提高信号信噪比容限与抗窄带干扰能力（802.11b 采用）；
- **跳频扩频（FHSS）**：载波频率在极短时间内按伪随机规律在多个频点上快速跳变。

### 2. 正交频分复用（OFDM）与多天线 MIMO
- **OFDM（Orthogonal Frequency Division Multiplexing）**：
  将原本几十兆的宽带高速串行数据流，**切分成数十个相互正交的窄带低速子载波并行传输**！每个子载波的码元周期被大幅拉长，使得多径反射时延远小于单个码元周期，**在物理上彻底消除了多径码间串扰（ISI）**！
- **MIMO（Multi-Input Multi-Output）**：
  利用发射端和接收端的多根物理天线，在同一频段内同时开辟多个**空间物理流（Spatial Streams）**，实现速率成倍倍增（如 802.11n 4x4 MIMO 速率翻 4 倍）。

## 五、408 统考真题级场景分析与蜂窝信道规划演练

### 【题型模型：多 AP 连续覆盖下的 2.4 GHz 蜂窝无干扰信道规划】

**【考题背景】**
某大型软件园区需要在单层开放式研发大厅（长 $120\text{ 米}$，宽 $60\text{ 米}$）部署企业级无线网络：
- 经过现场无线射频工勘，单个 AP 的 2.4 GHz 有效高质量覆盖半径约为 $20\text{ 米}$；
- 为实现无缝漫游与全区域盲区覆盖，网络规划工程师决定部署 6 台 AP（标记为 AP 1 至 AP 6），采用经典的蜂窝状六边形网格交错排列；
- 大厅内所有 AP 均工作在 2.4 GHz 频段，且要求**相邻或覆盖范围重叠的 AP 之间绝对不能发生同频干扰**。

```
研发大厅蜂窝 AP 排列拓扑:
      ( AP 1 )       ( AP 2 )       ( AP 3 )
         \             / \             /
          \           /   \           /
        ( AP 4 )       ( AP 5 )       ( AP 6 )
```

**【试推导并回答】**：
1. 2.4 GHz 频段通常推荐选用哪三个信道构建无同频干扰的蜂窝网络？请写出其信道编号与中心频率；
2. 为大厅中的 AP 1 至 AP 6 分配具体的信道编号，使整个大厅所有相邻 AP 的信道完全互不干扰；
3. 若某非专业管理员随意将 AP 1 配置为信道 1，将相邻的 AP 2 配置为信道 3：
   - 分析 AP 1 与 AP 2 之间是否会发生信号干扰？为什么？
   - 这种干扰在通信原理中称为什么干扰？

---

### 【严密推导过程】

#### 第 1 问：非重叠信道参数推导
- 推荐选用的三大非交叠互不干扰信道为：**信道 1、信道 6、信道 11**；
- 对应中心频率分别为：
  - 信道 1：$2412\text{ MHz}$；
  - 信道 6：$2437\text{ MHz}$；
  - 信道 11：$2462\text{ MHz}$。

#### 第 2 问：蜂窝无干扰信道分配方案
利用经典的“三色定理”，将 1、6、11 交错涂色，确保任意相邻节点的信道编号均不相同：
- **上排分配**：
  - **AP 1**：分配 **信道 1**；
  - **AP 2**：分配 **信道 6**；
  - **AP 3**：分配 **信道 11**；
- **下排交错分配**：
  - **AP 4**：分配 **信道 6**（与上方的 AP 1 和右侧的 AP 5 均不冲突）；
  - **AP 5**：分配 **信道 11**（与 AP 2、AP 4、AP 6 均不冲突）；
  - **AP 6**：分配 **信道 1**（与 AP 3、AP 5 均不冲突）。
- **结果检验**：全网任意两个几何相邻、电磁波信号重叠的 AP 之间，信道跨度均至少相隔 5 个编号，彻底杜绝同频干扰！

#### 第 3 问：错误配置（信道 1 与信道 3）干扰深度剖析
- **是否会发生干扰**：**会发生严重干扰！**
- **底层物理原因推导**：
  - 信道 1 的中心频率为 $2412\text{ MHz}$，占用频宽为 $2401 \sim 2423\text{ MHz}$；
  - 信道 3 的中心频率为 $2422\text{ MHz}$，占用频宽为 $2411 \sim 2433\text{ MHz}$；
  - 两者的频谱在 **$2411 \sim 2423\text{ MHz}$（整整 12 MHz 的频宽内）发生了严重的物理重叠**！
- **通信专业命名**：
  这种由于相邻信道频谱重叠交错而引起的通信质量恶化与乱码，称为**邻频干扰（Adjacent-Channel Interference，ACI）**。

## 六、考场诱惑性暗礁与秒杀口诀

### 1. 致命诱惑与错误路线踩刹车

> [!CAUTION]
> **陷阱 1：以为信道 1 和信道 2 是独立的两个信道**
> - **408 核心误区**：很多考生以为“每个信道各占 5MHz，信道 1 是 $1\sim5$，信道 2 是 $6\sim10$”。
> - **铁律警示**：**信道编号相隔 5MHz 只是中心频率！实际信号宽度是 20~22MHz！** 信道 1、2、3、4 之间全部严重互相交叠踩踏！只有相隔 5 个编号（如 1、6、11）才能完全独立！

> [!CAUTION]
> **陷阱 2：误以为 5 GHz 穿墙性能优于 2.4 GHz**
> - 考场生活经验常识反差：5 GHz 速率虽快，但其波长极短，穿过一堵承重墙后信号强度断崖式暴跌（衰减可达 20~30 dB）；2.4 GHz 波长长，绕射和穿墙能力远强于 5 GHz！

### 2. 考场核心记忆桩
- **“一六十一三非叠，相差五档才安全”**：2.4G 非交叠信道秒杀桩。
- **“二点四穿墙稳，五点零速度狂”**：两频段核心物理取舍。
