# 3.7.1 虚拟局域网 VLAN 概述

虚拟局域网（VLAN，Virtual Local Area Network）是一种将局域网内的设备从逻辑上划分成一个个网段，从而实现虚拟工作组的新兴技术。在传统局域网中，物理拓扑决定了逻辑拓扑；而 VLAN 的引入打破了这一限制，使得逻辑工作组的划分可以独立于物理位置。

---

## 一、为什么需要虚拟局域网（VLAN）？

### 1. 传统交换式以太网面临的广播风暴与安全隔离问题
在由以太网交换机构建的局域网中：
- 交换机能够隔离冲突域（每个端口都是一个独立的冲突域）；
- 但交换机**无法隔离广播域**：整台交换机以及所有互联的交换机默认属于同一个广播域。

当网络规模扩大、接入主机增多时，扁平的广播域会带来严重的工程缺陷：
1. **广播风暴与系统资源浪费**：
   - 常见的网络协议（如 ARP 地址解析、DHCP 动态主机配置）频繁使用广播帧（目的 MAC 为全 1：`FF-FF-FF-FF-FF-FF`）。
   - 交换机接收到广播帧后，会无条件向除接收端口外的所有端口泛洪转发。
   - 当网络中存在成百上千台主机时，频繁的广播报文会导致主机网卡不断触发硬件中断，消耗大量的主机 CPU 算力和信道带宽。
2. **缺乏网络安全边界**：
   - 处于同一广播域的主机之间缺乏链路层隔离。恶意节点可以轻松发起 ARP 欺骗攻击或监听广播信息。企业中的不同部门（如财务部、研发部、访客网络）若处于同一广播域，存在极大的信息泄露隐患。
3. **工作组规划受制于物理布线**：
   - 实际企业中，同一工作组的员工可能分布在不同楼层或不同房间。如果不采用逻辑划分手段，为了让同一部门的主机处于独立局域网，就必须跨楼层铺设专属物理线缆，组网灵活性极差。

### 2. VLAN 的核心思想：逻辑划分与物理拓扑解耦
IEEE 802.1Q 标准定义了虚拟局域网技术。其核心思想是：**在物理局域网的基础之上，通过网络管理软件和交换机配置，将网络从逻辑上划分为多个互不相通的子网（虚拟局域网）**。

- 处于同一个 VLAN 的主机，不论其连接在同一台交换机的不同端口，还是分散在不同楼层的多台交换机上，都具有与处于传统物理局域网相同的通信能力；
- 处于不同 VLAN 的主机，即便它们插在同一台物理交换机紧邻的两个端口上，在数据链路层也彼此隔绝。

```
物理拓扑 (主机连接到不同楼层的交换机):
        [ 楼层 1 交换机 SW1 ] <==== 级联链路 ====> [ 楼层 2 交换机 SW2 ]
           /             \                           /             \
        [主机 A]       [主机 B]                   [主机 C]       [主机 D]
       (财务部门)     (研发部门)                 (财务部门)     (研发部门)

逻辑拓扑 (按业务划分为两个独立的虚拟局域网):
       【VLAN 10: 财务虚拟局域网】                 【VLAN 20: 研发虚拟局域网】
         [ 主机 A ] <===========> [ 主机 C ]         [ 主机 B ] <===========> [ 主机 D ]
             |                                           |
             +---------------- 数据链路层完全隔离 ---------+
```

## 二、虚拟局域网的核心性质

理解 VLAN 必须牢牢把握以下三条核心性质：

### 1. VLAN 划分的是广播域，而非冲突域
- **冲突域**是由交换机的物理端口和传输介质工作模式决定的（全双工模式下，交换机的每个端口就是一个独立的冲突域）。VLAN 的划分不会改变物理端口的冲突域属性。
- **广播域**是广播报文所能扩散的范围。**每一个 VLAN 就是一个独立的逻辑广播域**。当某台主机发出广播帧时，交换机只会将该帧转发给同属于该 VLAN 的其他端口，绝不会跨越到其他 VLAN 的端口上。

### 2. 不同 VLAN 在数据链路层（二层）完全隔离
- 如果两台主机被分配在不同的 VLAN 中，即使它们插在同一台交换机上、甚至人为将它们的主机 IP 地址配置在同一个 IP 网段内，它们之间也**无法在数据链路层直接通信**。
- **原因**：主机在通信前需要通过 ARP 解析目的 IP 对应的 MAC 地址。由于 ARP 请求是广播帧，该广播帧被交换机限制在源主机所属的 VLAN 内部，处于另一个 VLAN 的目的主机根本收不到该 ARP 请求，因而无法回复 ARP 应答。源主机无法获取目的 MAC 地址，数据帧无法成功封装发送。

### 3. 跨 VLAN 通信必须依赖网络层（三层）路由
既然不同 VLAN 在数据链路层完全隔离，那么当不同部门之间需要受控互通时，必须借助**网络层设备（路由器或三层交换机）**进行分组转发。

常见的跨 VLAN 路由实现方式有两种：
1. **单臂路由（Router-on-a-Stick）**：
   - 交换机与外部路由器之间仅连接一根物理链路（配置为干道 Trunk 链路）；
   - 路由器在该物理接口上配置多个逻辑子接口（Sub-interface），每个子接口对应一个 VLAN，作为该 VLAN 的默认网关；
   - 跨 VLAN 数据先由交换机送至路由器子接口解封装路由，再由路由器封装发回交换机转发至目的 VLAN。
2. **三层交换机（Layer 3 Switch）**：
   - 现代局域网的主流组网架构。三层交换机内部集成了路由引擎；
   - 为每个 VLAN 创建一个虚拟接口（在标准中称为 VLAN 路由接口，工程中常称为 SVI，Switch Virtual Interface），并为每个虚接口配置对应的 IP 地址作为该 VLAN 的默认网关；
   - 跨 VLAN 通信直接在交换机内部完成路由查表与硬件转发生效，避免了外部单臂链路的带宽瓶颈。

## 三、虚拟局域网（VLAN）的划分方法

IEEE 802.1Q 标准及网络工程中，通常有以下四种划分 VLAN 的方法：

| 划分方法 | 划分依据与机制 | 优点 | 缺点 / 适用场景 |
| :--- | :--- | :--- | :--- |
| **基于端口的划分 (Port-based)** | 最常用的划分方式。管理员将交换机的每个物理端口直接指定给某个 VLAN ID。连接到该端口的主机即属于该 VLAN。 | **配置简单直观**，交换机查表转发效率最高。 | 若主机物理移动并更换了插口的端口，管理员必须重新配置新端口的所属 VLAN。 |
| **基于 MAC 地址的划分 (MAC-based)** | 交换机根据接入主机的源 MAC 地址来决定其所属的 VLAN。 | 主机无论更换插入哪个物理端口，甚至移动到其他交换机，其所属 VLAN 保持不变。 | 初始配置工作量大；每台主机的网卡更换时需重新修改交换机配置。 |
| **基于网络层 IP 地址的划分 (IP-based)** | 交换机根据数据帧内承载的 IP 数据报的源 IP 地址或子网掩码来划分 VLAN。 | 主机更换物理接口无需重配，且逻辑工作组划分与网络层子网规划高度吻合。 | 交换机在二层转发时需要解析三层 IP 报头，增加了解析开销。 |
| **基于协议类型的划分 (Protocol-based)** | 交换机根据数据帧的“类型”字段（如 IP 报文、IPX 报文等）将不同协议的数据流划分至不同的 VLAN。 | 适合在单一局域网内运行多种网络层协议的历史兼容场景。 | 现代网络绝大多数统一运行 IP 协议，该方法在实际生产中已极少采用。 |
