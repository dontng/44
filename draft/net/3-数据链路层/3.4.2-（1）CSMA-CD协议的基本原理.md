# 3.4.2 （1）CSMA/CD协议的基本原理

**CSMA/CD（Carrier Sense Multiple Access with Collision Detection，带冲突检测的载波监听多路访问）** 是共享式以太网的介质访问控制协议，解决多个站点竞争共享信道时的冲突问题。

## 一、三个关键概念

- **多路访问（MA，Multiple Access）**：多个站点共享同一条信道。
- **载波监听（CS，Carrier Sense）**：发送前先**监听信道**，若信道空闲（无载波信号）则发送，若信道忙则等待。
- **冲突检测（CD，Collision Detection）**：发送过程中持续**监听信道**，若检测到信号叠加异常（电压超出阈值）则说明发生了冲突。

## 二、CSMA/CD 工作算法（四步口诀）

1. **先听后发**：发送前监听信道，若空闲则发送，若忙则继续监听等待空闲。
2. **边发边听**：发送过程中同时监听信道，检测是否发生冲突。
3. **冲突停发**：一旦检测到冲突，立即停止发送数据，并向信道发送一段**强化冲突信号（Jamming Signal，干扰信号）**，通知所有站点发生了冲突。
4. **随机延迟后重发**：发完 Jamming 信号后，等待一段**随机退避时间**，再重新执行步骤 1。

```
开始发送
    ↓
监听信道是否空闲 → 忙 → 等待，继续监听
    ↓ 空闲
开始发送帧，同时监听
    ↓
检测到冲突？ → 是 → 发 Jamming 信号 → 随机退避 → 重新开始
    ↓ 否
发送完毕，成功
```

## 三、为什么无线局域网不能用 CD？

CSMA/CD 的冲突检测在**有线**介质中可行，因为发送方可以同时检测到自己发出的信号和信道上的叠加信号，二者电平差异明显。但在无线信道中：

1. **隐藏终端问题**：A 和 C 都能与 B 通信，但 A 和 C 互相听不到对方——A 误以为信道空闲而发送，与 C 的发送在 B 处冲突，但 A 根本检测不到；
2. **信号衰减**：无线信号传播损耗大，发送站自身的信号远强于接收到的信号，无法有效检测出冲突。

因此 Wi-Fi（802.11）使用 CSMA/**CA**（冲突**避免**）而非 CD（冲突**检测**），见 3.9.3。

## 四、CSMA/CD 的关键性质

- CSMA/CD 是**竞争式（随机访问）**协议，不预先分配信道，效率随负载变化。
- 发送站必须在发完帧之前检测到冲突，否则认为帧已成功发出——这决定了最小帧长（见 3.4.2(2)）。
- 冲突检测需要**全双工的硬件能力**（同时收发），这在同轴电缆/集线器时代可行，在交换机全双工链路上不再需要 CSMA/CD。

> 考点：CSMA/CD 四步口诀（先听后发、边发边听、冲突停发、随机延迟后重发），以及为什么无线不能用 CD——这两点是最常出现的选择题/简答题考点。
