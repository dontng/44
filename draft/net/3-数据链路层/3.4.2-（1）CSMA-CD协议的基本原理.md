# 3.4.2-（1）CSMA/CD 协议的基本原理

---

## 1. 介质访问控制演进与载波监听盲区

在共享信道中，如何协调多个节点有序使用传输介质是介质访问控制（MAC）的核心问题。

### 1.1 从无序发射到载波监听的演进

1. **纯 ALOHA 协议**：节点有数据便立即发送，完全不感知信道状态。冲突概率极高，最大理论吞吐率仅为 $\frac{1}{2e} \approx 18.4\%$；
2. **时隙 ALOHA（Slotted ALOHA）**：将信道时间划分为离散的时隙，节点仅在时隙起始边界发送，将碰撞重叠时间缩减为单个时隙，理论吞吐率提升至 $\frac{1}{e} \approx 36.8\%$；
3. **载波监听多路访问（CSMA）**：引入“发送前监听”机制。
   - **1-坚持 CSMA**：监听信道，若信道忙则持续监听；一旦空闲，**立即以概率 1 发送**（以太网采用此基础策略）；
   - **非坚持 CSMA**：若信道忙，随机延迟一段时间后再来监听；
   - **p-坚持 CSMA**：若信道空闲，以概率 $p$ 发送，以概率 $1-p$ 推迟到下一个时隙再评估。

### 1.2 物理盲区：为什么“先听后发”依然无法避免碰撞？

电磁波在铜线或光纤中的传播速度并非无限大，而是受物理常数制约（在铜导线中约为 $V \approx 2 \times 10^8\text{ m/s}$，即每传输 $1\text{ km}$ 耗时 $5\ \mu\text{s}$）。

```
【电磁波在总线上传播的时空碰撞盲区】
时刻 t = 0:    主机 A 监听总线，总线当前无电平信号。A 开始发送数据帧。
               A 的电磁波沿总线向右以 200 m/μs 速度推进...
时刻 t = τ - ε: 在 A 的信号抵达最右端主机 B 前的极短瞬间 (ε)，主机 B 也产生发送需求。
               B 监听总线：A 的电磁波尚未传到 B 的网卡处！B 检测到的总线仍是“空闲”！
时刻 t = τ - ε: B 判定信道空闲，也启动发送电路向总线注入信号！
时刻 t = τ:     A 与 B 的信号在总线上相遇，发生电压叠加与波形严重畸变（发生碰撞）！
```

**物理本质**：**“载波监听”只能获知“此时此刻到达本地网卡收发器的信号是否为空闲”，无法获知“整根导线上是否有远端节点刚刚发出的信号正在途中”。在信号传播的单向时延 $\tau$ 范围内，存在无法规避的检测盲区。**

## 2. CSMA/CD 的四大核心步骤与工作流程

为了在发生碰撞时能够及时止损，避免长数据帧在已损坏的信道上继续盲目传输浪费带宽，以太网在 CSMA 基础上引入了 **CD（Collision Detection，冲突检测）**：

```
+---------------------------------------------------------------------------------------------------+
|  1. 先听后发 (CS)    --->  2. 边发边听 (CD)    --->  3. 冲突停发 (Jamming)  --->  4. 随机重发 (BEB)      |
+---------------------------------------------------------------------------------------------------+
| 发送前监听信道96bit   | 发送过程中硬件电压采样  | 检测到电压异常立即停发数据  | 执行截断二进制指数退避算法  |
| 确保信道当前无载波    | 比对是否发生叠加畸变    | 发送 32~48bit 人为干扰信号  | 随机延迟 r 个争用期后重试   |
+---------------------------------------------------------------------------------------------------+
```

### 2.1 冲突检测的物理实现

在基带同轴电缆或双绞线中，发送端在驱动输出电压的同时，通过片内模拟比较器采样信道上的实际电平：
- 单一节点发送时，总线电平处于规范的单信号幅值范围（如曼彻斯特编码的差分电平）；
- 多个节点并发时，多路电流叠加，总线电压幅值瞬间超出设定的冲突门限（阈值）；
- 硬件比较器翻转，在纳秒级直接触发冲突检测信号。

### 2.2 人为干扰信号（Jamming Signal）的机制作用

当节点 A 率先检测到冲突并停止发送时，若对方节点 B 距离较远，其信号相遇点可能尚未传回 B。
- 为了确保全网所有节点（尤其是正在冲突的另一方以及正在准备发送的第三方）都能明确得知碰撞已发生，检测到冲突的节点必须继续向信道发送一段持续 **32~48 比特的人为干扰信号**；
- 干扰信号强化了信道上的畸变波形，使所有节点的收发器均能检测到非法信号，从而丢弃残破帧碎片。

## 3. 有线网络与无线局域网的物理差异：为什么 Wi-Fi 不能用 CSMA/CD？

以太网可以使用 CSMA/CD，但 IEEE 802.11 无线局域网（Wi-Fi）必须改用 **CSMA/CA（碰撞避免）**。这一技术路径分流是由两种介质的物理特性差异决定的：

```
有线以太网 (同轴电缆/双绞线)                          无线局域网 (802.11 Wi-Fi)
+-----------------------------------+             +-----------------------------------+
| 信号在金属介质中传播，衰减小       |             | 信号在自由空间全向扩散，衰减遵循距离平方反比 |
| 发送信号与接收信号幅值处于同一数量级 |             | 发送信号功率通常比接收信号功率高 50~60 dB  |
| 碰撞叠加电压差异显著，模拟比较器易检测 |          | 自身发射的大功率信号完全淹没微弱的接收信号  |
+-----------------------------------+             +-----------------------------------+
```

### 3.1 动态范围悬殊与硬件“自聋”现象

在无线传输中，天线发射功率通常为几十毫瓦（$\approx 100\text{ mW}$），而远端传来的微弱信号经过空间衰减到达接收天线时通常仅剩纳瓦甚至皮瓦级（$10^{-12}\text{ W}$）。
- 这种高达到 $10^5 \sim 10^6$ 倍（50~60 dB）的功率落差，使得本地发射机在发射信号时，接收电路完全处于高功率饱和状态；
- 网卡根本无法在自己发出的大功率电磁波中，识别出远处节点传来的微弱叠加信号。

### 3.2 空间拓扑中的“隐藏终端（Hidden Terminal）”问题

在自由空间无线拓扑中，节点受物理障碍物遮挡或距离限制，彼此超出直接通信范围：

```
[ 节点 A ] --------> [ 节点 B (AP) ] <-------- [ 节点 C ]
 (A 的覆盖半径)          (共同接收者)            (C 的覆盖半径)
   |<---------------- A 与 C 互相不可见（隐藏终端） --------------->|
```

- 节点 A 监听信道：由于距离遥远，检测不到节点 C 的电磁信号，判定信道空闲并向 AP 发送；
- 节点 C 监听信道：同样检测不到节点 A，判定信道空闲并向 AP 发送；
- 两路信号在中心接收节点 B 处发生剧烈碰撞，但 A 与 C 在本地根本检测不到该碰撞。
- **结论**：**无线介质在物理上无法实现“载波全局监听”与“边发边听冲突检测”，必须放弃 CSMA/CD，转而采用以确认重传、帧间间隔（IFS）及可选 RTS/CTS 为核心的 CSMA/CA 机制。**

## 4. 典型问题分析

### 题目：CSMA/CD 最恶劣碰撞时间与争用期推导

设有一段长度为 $D = 1000\text{ m}$ 的共享式同轴电缆以太网，信号在介质中的传播速率为 $V = 2 \times 10^8\text{ m/s}$。
- 总线两端分别连接主机 A 与主机 B；
- $t = 0$ 时刻，主机 A 监听信道空闲并开始发送数据帧；
- 主机 B 在某一时刻 $t_B$ 产生发送需求，发送前执行信道监听。

**问题**：
1. 计算总线端到端的单向物理传播时延 $\tau$；
2. 分析主机 B 在什么时间区间内启动监听会导致碰撞发生；
3. 设主机 B 恰在 $t_B = \tau - \varepsilon$（$\varepsilon \to 0$）时刻启动发送，主机 A 最早将在什么时刻检测到此次碰撞？
4. 主机 A 从开始发送算起，最多需要经过多长时间才能断定本次数据帧的发送绝对安全（不会再发生任何碰撞）？

---

### 推导过程

#### 1. 单向传播时延计算
$$\tau = \frac{D}{V} = \frac{1000\text{ m}}{2 \times 10^8\text{ m/s}} = 5 \times 10^{-6}\text{ s} = 5\ \mu\text{s}$$

#### 2. 主机 B 发生误判的时间区间推导
- 主机 A 在 $t = 0$ 发出的电信号前沿以速率 $V$ 向右传播，将在 $t = \tau = 5\ \mu\text{s}$ 时刻到达主机 B 的网卡；
- 在 $0 \le t < \tau$（即 $0 \le t < 5\ \mu\text{s}$）期间，A 的信号尚未传至 B；
- 若主机 B 在此区间内监听信道，其网卡测得总线电平为 0（空闲），主机 B 将立即启动发送，从而在总线上引发碰撞；
- 故主机 B 误判的时间区间为：**$[0, \tau)$**（即 $[0, 5\ \mu\text{s})$）。

#### 3. 最恶劣碰撞发生时刻与检测时延推导
- 当 $t_B = \tau - \varepsilon$ 时，主机 B 刚开始发送信号，A 的信号前沿与 B 的输出信号在紧邻 B 的总线处迎头相撞；
- 发生碰撞的畸变波形必须反向沿着总线重新传回主机 A；
- 反向传播距离仍为 $D = 1000\text{ m}$，耗时仍为 $\tau$；
- 主机 A 检测到冲突的时刻为：
  $$t_{\text{detect}} = t_B + \tau = (\tau - \varepsilon) + \tau = 2\tau - \varepsilon$$
  取极限 $\varepsilon \to 0$，得 $t_{\text{detect}} = 2\tau = 10\ \mu\text{s}$。

#### 4. 安全发送时间上限推导
- 最迟可能发生的碰撞是在信号前沿到达网络最远端节点的瞬间（耗时 $\tau$）；
- 碰撞信号返回原发送端再次耗时 $\tau$；
- 发送端从启动发送到确信不会再发生碰撞，最多需要经历 **$2\tau$** 时间；
- 只要一个数据帧在持续发送 $2\tau$ 时间之后仍未检测到冲突，则表明该信号已传遍全网所有节点，全网节点均已检测到总线处于繁忙状态，该帧后续绝不会再遭遇碰撞；
- 这个时间上限 $2\tau$ 被称为**争用期（Contention Period）**或**碰撞窗口（Collision Window）**。本例中争用期为 $10\ \mu\text{s}$。
