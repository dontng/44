# 3.4.2-（1）CSMA/CD 协议的基本原理

> **本节在 408 中的定位**：带冲突检测的载波监听多路访问（CSMA/CD，Carrier Sense Multiple Access with Collision Detection）是整个计算机网络介质访问控制技术的心脏。408 统考历年对 CSMA/CD 的考查覆盖了选择题与综合大题，命题刀刃不仅要求背诵“先听后发、边发边听、冲突停发、随机重发”的十六字口诀，更要求透彻掌握**“电磁波传播时延导致载波监听存在盲区”**的微观时空图演进，以及**“为什么有线能 CD 而无线 Wi-Fi 绝不能做 CD”**的深层物理原因。

---

## 一、第一性原理与设计动因：为什么需要 CSMA/CD？

### 1. 从 ALOHA 纯盲目发射到“礼貌交谈”的演化
- **纯 ALOHA 协议**：任何站点想发就发，完全不看信道。冲突概率极高，理论极限信道利用率仅为 $18.4\%$；
- **分隙 ALOHA（Slotted ALOHA）**：划分时间槽，所有站点只能在时隙开始时发。极限信道利用率提升到 $36.8\%$，但依然存在盲目碰撞；
- **载波监听多路访问（CSMA）**：引入“听（Sense）”的机制——**“说话前先听别人有没有在说”**。
  - **1-坚持 CSMA**：听到信道忙，持续监听；一旦空闲，**立即以概率 1 发送**（以太网采用此策略）；
  - **非坚持 CSMA**：听到忙，随机延迟一段时间后再来听；
  - **p-坚持 CSMA**：听到空闲，以概率 $p$ 发送，以概率 $1-p$ 推迟到下一个时隙。

### 2. 致命盲区：为什么“先听后发”依然无法彻底避免碰撞？
很多考生常有疑问：“既然大家在发送前都认真听了信道，为什么还会发生碰撞？”
**物理根源：电磁波在铜线中的传播速度是有限的（约为 $2 \times 10^8\text{ m/s}$，即 $5\text{ ns/m}$）！**

```
【电磁波在总线上传播的时空碰撞盲区】
时刻 t=0:  A 监听总线，总线完全空闲。A 开始发送数据帧。
           A 的电磁波以 200m/μs 的速度向右扩散...
时刻 t=τ-ε: 在电磁波即将抵达最右端 B 之前的极短瞬间(ε)，B 也想发数据。
           B 监听总线：此时 A 的信号还没飞到 B 的网卡处！B 测得总线依然是“空闲”！
时刻 t=τ-ε: B 判定信道空闲，也开始向总线发送数据帧！
时刻 t=τ:   A 和 B 的信号在总线上正面迎头相撞！波形严重畸变叠加！
```

- **结论**：**“载波监听”只能知道“此时此刻到达我网卡这里的信号是不是空闲”，绝不能知道“整根长导线上是否有其他人刚刚发出了信号”！在信号飞过来的这段时间差内，存在绝对的盲区！**

## 二、微观机制：CSMA/CD 的四大核心基石与硬件判决

为彻底解决盲区碰撞带来的带宽浪费，以太网在 CSMA 基础上叠加了 **CD（Collision Detection，冲突检测）**：

```
+---------------------------------------------------------------------------------------------------+
|  1. 先听后发 (CS)    --->  2. 边发边听 (CD)    --->  3. 冲突停发 (Jamming)  --->  4. 随机重发 (BEB)      |
+---------------------------------------------------------------------------------------------------+
| 发送前监听信道96bit   | 发送过程中硬件电压采样  | 检测到电压异常立即停发数据  | 执行截断二进制指数退避算法  |
| 确保信道当前无载波    | 比对是否发生叠加畸变    | 发送 32~48bit 人为干扰信号  | 随机延迟 r 个争用期后重试   |
+---------------------------------------------------------------------------------------------------+
```

### 1. 硬件如何检测冲突？（物理层电平检测）
在以太网同轴电缆或双绞线上，信号是基带传输。
- 发送端网卡在驱动输出电压的同时，片内集成了一个**模拟比较器电路**实时采样线缆上的实际电压：
  - 若线缆上只有自己发送的信号，电压幅值稳定在正常范围（如 $-1\text{V} \sim 0\text{V}$）；
  - 若有其他站点同时发送，两路电压叠加，总线电平幅值瞬间倍增（超过阈值门限）；
  - 比较器翻转，硬件瞬间产生**碰撞中断（Collision Signal）**。

### 2. 为什么检测到冲突必须发送“人为干扰信号（Jamming Signal）”？
- 当主机 A 率先检测到冲突并停止发送时，对方主机 B 可能由于距离较远，其信号相撞点尚未传到 B 的收发器；
- 为了确保**全网所有参与争用的站点都能在最短时间内明确知道“碰撞已经发生”**，检测到冲突的站点必须向信道追加发送一段持续的 **32 到 48 比特的人为干扰信号（Jamming Signal）**，强化冲突电平，使全网接收设备立刻丢弃残破帧碎片。

## 三、为什么有线网络能用 CSMA/CD，而无线局域网（Wi-Fi）绝不能用？（408 核心问答）

408 统考极高频的经典大题/简答考点：

```
有线以太网 (同轴电缆/双绞线)                          无线局域网 (802.11 Wi-Fi)
+-----------------------------------+             +-----------------------------------+
| 信号在密闭金属导线中传播，衰减极小  |             | 信号在自由空间电磁辐射，衰减遵循平方反比定律 |
| 发送信号强度与接收信号强度处于同数量级 |             | 发送信号强度通常比接收信号强度强 10万~100万倍! |
| 碰撞叠加电压差异极其明显，硬件极易检测 |             | 自己的发射功率完全把接收天线“震聋”，无法检测! |
+-----------------------------------+             +-----------------------------------+
```

### 1. 根本原因一：信号动态范围的巨大落差（“大声喧哗时听不到蚊子叫”）
- 在无线通信中，发射天线的输出功率可达数百毫瓦（$\approx 100\text{ mW}$），而从远处其他节点传来的微弱电磁波由于自由空间衰减，到达天线时仅有皮瓦级（$10^{-12}\text{ W}$）；
- **动态差距高达 $10^5 \sim 10^6$ 倍（50~60 dB）**！网卡在发射强功率电磁波时，自己的接收机完全处于饱和过载状态，**根本无法在自己巨大的发射信号中检测出远方传来的微弱冲突信号**！

### 2. 根本原因二：无线“隐藏终端（Hidden Terminal）”问题
在空间无线拓扑中，节点之间受物理障碍物遮挡或传输距离限制，彼此无法感知：

```
[ 节点 A ] --------> [ 节点 B (AP) ] <-------- [ 节点 C ]
 (A 覆盖范围)          (共同接收者)            (C 覆盖范围)
   |<---------------- 距离过远，A 和 C 互相听不到对方! ---------------->|
```

- A 监听信道：听不到 C 的信号，判定信道空闲，开始向 B 发送；
- C 监听信道：听不到 A 的信号，也判定信道空闲，也开始向 B 发送；
- **两路信号在中心节点 B 处剧烈碰撞！但 A 和 C 自身永远无法在自己的天线处检测到这个碰撞！**
- **结论**：**无线局域网在物理上既做不到载波全监听，也做不到边发边听碰撞检测，因此 Wi-Fi 彻底放弃 CSMA/CD，改为采用 CSMA/CA（碰撞避免）协议！**

## 四、408 统考真题级情景逆向与时空推导演练

### 【题型模型：CSMA/CD 碰撞时间窗口与信号时空轨迹图】

**【考题背景】**
设有一条长度为 $1\text{ km}$ 的共享同轴电缆总线以太网，电磁波在电缆中的传播速率为 $V = 2 \times 10^8\text{ m/s}$。
- 总线两端分别连接主机 A 和主机 B；
- 设 $t = 0$ 时刻，主机 A 监听信道为空闲，开始向主机 B 发送数据帧；
- 设主机 B 在时刻 $t = t_B$ 也试图发送数据帧，且在发送前监听信道。

**【试推导并求解】**：
1. 信号从主机 A 传播到主机 B 所需的单向传播时延 $\tau$ 是多少微秒（$\mu\text{s}$）？
2. 主机 B 在什么时间范围内（$t_B$ 的取值区间）启动监听，会误认为信道空闲从而开始发送数据并引发碰撞？
3. 若主机 B 恰在 $t_B = \tau - \varepsilon$（$\varepsilon \to 0$，即信号到达前的微小瞬间）开始发送数据，主机 A 最早将在什么时刻检测到这次碰撞？
4. 主机 A 从开始发送到确认本次发送必定不会再发生碰撞，最多需要经历多长时间？

---

### 【草稿纸执行第一步：画出单向传播时延与时间轴】
```
单向传播时延 τ = D / V = 1000m / (2 * 10^8 m/s) = 5 μs
A 在 t=0 发送信号，信号波前位置: x(t) = V * t
信号到达 B 的时刻: t = τ = 5 μs
```

### 【严密推导过程】

#### 第 1 问：单向传播时延计算
$$\tau = \frac{D}{V} = \frac{1000\text{ m}}{2 \times 10^8\text{ m/s}} = 5 \times 10^{-6}\text{ s} = 5\text{ }\mu\text{s}$$

#### 第 2 问：主机 B 误判时间区间推导
- 主机 A 发出的信号在 $t = 0$ 出发，以恒定速率向 B 推进；
- 在 $0 \le t < \tau$（即 $0 \le t < 5\text{ }\mu\text{s}$）期间，A 的信号尚未抵达 B；
- 因此只要主机 B 在区间 **$[0, \tau)$** 内监听信道，B 的网卡都只能测得总线空闲，因而会立即启动发送并导致碰撞！

#### 第 3 问：最迟碰撞时刻主机 A 检测到冲突的时间
- 当 $t_B = \tau - \varepsilon$ 时，B 刚开始发射，A 的信号与 B 的信号在紧靠 B 的总线处迎头相撞；
- 碰撞产生的畸变电压波形必须从 B 的位置反向传播回主机 A；
- 反向传播距离仍为 $D = 1\text{ km}$，耗时仍为 $\tau$；
- 因此，碰撞信号飞回 A 的时刻为：
  $$t_{\text{detect}} = t_B + \tau = (\tau - \varepsilon) + \tau = 2\tau - \varepsilon \to 2\tau = 10\text{ }\mu\text{s}$$
- 主机 A 最早在 $t = 10\text{ }\mu\text{s}$ 时刻检测到该碰撞。

#### 第 4 问：确认发送成功的安全时间上限推导
- 由第 3 问可知，从 A 开始发送数据算起，最恶劣的碰撞发生在最远端的节点即将收到信号的前一瞬间；
- 碰撞信号返回 A 最多耗费时间：
  $$T_{\text{safe}} = 2\tau$$
- **核心结论**：**只要主机 A 发送数据持续了 $2\tau$ 时间之后，依然没有检测到碰撞，就能够 $100\%$ 确定全网所有节点都已感知到 A 的载波，本次发送绝对安全，后续绝不可能再发生冲突！**
- 这个时间上限 $2\tau$ 在以太网中被称为**争用期（Contention Period）**或**碰撞窗口（Collision Window）**。本例中为 $10\text{ }\mu\text{s}$。

## 五、考场诱惑性暗礁与秒杀口诀

### 1. 致命诱惑与错误路线踩刹车

> [!CAUTION]
> **陷阱 1：以为只要“先听后发”就不会碰撞**
> - **408 经典概念题**：“在 CSMA/CD 中，只要发送前监听信道为空闲，发送时就绝不会发生碰撞（判断正误）”——**错误！**
> - 电磁波传播需要时间（存在单向时延 $\tau$ 的盲区），在信号飞向对端的途中，对端同样可能监听信道为空闲并启动发送，引发碰撞。

> [!CAUTION]
> **陷阱 2：混淆 1-坚持 CSMA 与非坚持 CSMA 的监听策略**
> - 以太网采用的是 **1-坚持 CSMA**：只要信道忙，就死死盯住信道持续监听；一旦信道由忙变闲，立即（概率为 1）发送数据帧！而不是“随机退避后再来监听”。只有在**检测到冲突后**，才执行随机退避算法！

### 2. 考场核心记忆桩
- **“先听后发防大撞，边发边听抓现行”**：CSMA 与 CD 的分工。
- **“最迟发现两倍套，两倍套内判生死”**：检测碰撞最迟时间严格为 $2\tau$（争用期）。
- **“有线靠电压比对，无线被自己震聋”**：有线可用 CD、无线必用 CA 的物理根源。
