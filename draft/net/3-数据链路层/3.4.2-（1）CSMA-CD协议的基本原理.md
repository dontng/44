# 3.4.2-（1）CSMA/CD 协议的基本原理

---

## 1. 介质访问控制协议演进与载波监听盲区

在共享介质网络中，如何协调多个主机有序使用信道是介质访问控制（MAC）的核心问题。

### 1.1 从 ALOHA 到 CSMA 的演进

1. **纯 ALOHA 协议**：任何站点想发就发，完全不理会信道状态。冲突概率极高，理论最大信道利用率仅为 $18.4\%$；
2. **时隙 ALOHA（Slotted ALOHA）**：将信道时间划分为离散的时隙，站点只能在时隙起点发送。将碰撞区间减半，最大信道利用率提升至 $36.8\%$；
3. **载波监听多路访问（CSMA）**：引入“发送前监听”机制，即**“先听后发”**：
   - **1-坚持 CSMA**：监听信道，若信道忙则继续监听；一旦信道空闲，**立即以概率 1 发送**（以太网采用此策略）；
   - **非坚持 CSMA**：若信道忙，随机放弃一段时间后再来监听；
   - **p-坚持 CSMA**：用于时隙信道，若信道空闲，以概率 $p$ 发送，以概率 $1-p$ 推迟到下一个时隙。

### 1.2 为什么“先听后发”依然无法避免碰撞？

电磁波在金属线缆中的传播速度是有限的（在铜线中约为 $V \approx 2 \times 10^8\text{ m/s}$，即每传播 $1\text{ km}$ 约耗时 $5\ \mu\text{s}$）。

```text
电磁波传播时延导致的碰撞盲区:
时刻 t = 0:    主机 A 监听总线为空闲，开始发送数据帧。信号以 200 m/μs 沿导线向右推进。
时刻 t = τ - ε: 信号到达最右端主机 B 之前的瞬间 (ε)，主机 B 也想发送数据。
               B 监听总线：A 发出的电磁波还没有传到 B 的网卡处！B 检测到总线依然是“空闲”！
时刻 t = τ - ε: B 判定信道空闲，也开始向总线发送数据帧。
时刻 t = τ:     A 和 B 的信号在总线上相遇，发生电压叠加与严重波形畸变（发生碰撞）！
```

**物理本质**：**“载波监听”只能知道“当前到达本地网卡处的信号是否为空闲”，无法预知“远端节点刚刚发出的信号是否正在赶来的途中”。在信号传播的单向时延 $\tau$ 内，存在绝对的监听盲区。**

## 2. CSMA/CD 协议的核心工作流程

为了在发生碰撞时能够及时止损，避免长数据帧在受损信道上继续发送浪费带宽，以太网在 CSMA 基础上叠加了 **CD（Collision Detection，碰撞检测）**。

CSMA/CD 的核心工作流程可概括为十六字要诀：**先听后发、边发边听、冲突停发、随机重发**。

```text
+---------------------------------------------------------------------------------------------------+
|  1. 先听后发 (CS)    ───>  2. 边发边听 (CD)    ───>  3. 冲突停发 (Jamming)  ───>  4. 随机重发 (BEB)      |
+---------------------------------------------------------------------------------------------------+
| 发送前监听信道，若空  | 发送过程中网卡比较器采  | 一旦检测到碰撞立即停止发帧，| 执行截断二进制指数退避算法，|
| 闲满 96 比特时间则发  | 样电压，判断是否发生畸变| 并追加发送人为干扰信号通知全网| 随机延迟 r 个争用期后重试   |
+---------------------------------------------------------------------------------------------------+
```

### 2.1 碰撞检测的硬件实现

在以太网同轴电缆或双绞线上，信号是基带传输。
- 发送端网卡在驱动输出电压的同时，片内集成模拟比较器实时采样线缆上的实际电压；
- 单一节点发送时，总线电压处于正常幅值范围；
- 多个节点同时发送时，两路电压叠加，总线电平幅值超出正常阈值，比较器翻转，硬件在纳秒级直接检测到**碰撞（Collision）**。

### 2.2 人为干扰信号（Jamming Signal）的作用

当主机 A 检测到碰撞并停止发送时，为了确保远端的主机 B 以及全网其他所有站点都能明确得知碰撞已经发生，检测到碰撞的站点必须立即继续向信道发送一段持续 **32 到 48 比特的人为干扰信号**。这样可以强化冲突波形，使所有设备及时丢弃受损的残帧。

## 3. 为什么有线网络能用 CSMA/CD，而无线 Wi-Fi 不能用？

关于介质特性的核心问题：

| 介质特性对比 | 有线以太网 (同轴电缆 / 双绞线) | 无线局域网 (802.11 Wi-Fi) |
| :--- | :--- | :--- |
| **信号空间衰减** | 信号在封闭导线中传播，衰减极小 | 信号在自由空间全向辐射，衰减遵循距离平方反比定律 |
| **接收与发送信号差** | 发送信号与接收信号幅值处于同一数量级 | 发送天线功率比接收天线处收到的微弱信号高数万到数百万倍 |
| **碰撞检测可行性** | 叠加电压倍增明显，硬件容易检测 | **自身发射的强功率完全把接收天线“震聋”，无法检测远端微弱碰撞** |
| **空间可见性** | 全网共享一根导线，各节点互相可见 | **存在“隐藏终端”问题**（A 和 C 彼此距离过远听不到对方，但同时发向中间的 AP 发生碰撞） |
| **协议选型结论** | **采用 CSMA/CD（碰撞检测）** | **放弃 CD，改用 CSMA/CA（碰撞避免）配合 ACK 确认** |
