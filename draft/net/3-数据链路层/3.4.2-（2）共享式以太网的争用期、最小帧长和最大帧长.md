# 3.4.2 （2）共享式以太网的争用期、最小帧长和最大帧长

## 一、争用期（Contention Period / Slot Time）

**争用期**（又称**冲突窗口**或**时隙时间**）是共享式以太网中一个关键参数，等于信号在总线上**端到端往返传播时延**：

$$\text{争用期} = 2\tau$$

其中 $\tau$ 为信号在总线上从一端传到另一端的单向传播时延。

**物理含义**：发送方最迟在发出帧后 $2\tau$ 时间内能检测到冲突——因为最坏情况是信号传到对端（$\tau$）时刚好另一端也开始发送，冲突信号再经过 $\tau$ 才传回来。

### 以太网（10 Mbps）的争用期

以太网规定最大网段长度 2500 m，信号传播速度约 $2 \times 10^8$ m/s，单向传播时延 $\tau \approx 25.6\ \mu\text{s}$，因此：

$$2\tau \approx 51.2\ \mu\text{s}$$

## 二、最小帧长（考点）

发送方必须保证：在**帧发完之前就能检测到冲突**，否则一旦帧已发完，发送方就不会重传，接收方收到的是错误数据。

因此，帧的发送时间必须 $\geq 2\tau$：

$$\text{最小帧长} = \text{数据率} \times 2\tau = 10\ \text{Mbps} \times 51.2\ \mu\text{s} = 512\ \text{bit} = \mathbf{64\ \text{字节}}$$

**以太网规定最小帧长为 64 字节**（含帧头 14 字节 + 数据 + FCS 4 字节，数据字段最少 46 字节）。

若帧的数据部分不足 46 字节，需**填充（Padding）**零字节至最小帧长。

接收方收到长度 < 64 字节的帧，认为是**残帧（Runt Frame）**，直接丢弃（这是冲突的产物）。

> 易错点：64 字节最小帧长不是"数据"最少 64 字节，而是**整帧**（含帧头帧尾）最少 64 字节，数据最少只有 46 字节。

## 三、最大帧长（MTU）

以太网规定最大帧长为 **1518 字节**（数据字段最大 **1500 字节**）。

设置最大帧长的原因：
- 防止某个站点长时间独占信道，影响其他站点的公平性；
- 限制接收方缓冲区的最大占用；
- 以太网 MTU = 1500 字节，这也是 IP 分片的基准（见网络层 4.2.7）。

## 四、考点速记

| 参数 | 以太网（10 Mbps）值 | 意义 |
|---|---|---|
| 争用期 $2\tau$ | 51.2 μs | 冲突检测的最大等待时间 |
| 最小帧长 | **64 字节**（512 bit） | 保证能在帧发完前检测到冲突 |
| 最大帧长 | **1518 字节** | MTU = 1500 字节（数据部分） |
| 数据字段范围 | **46 ~ 1500 字节** | 不足 46 字节需填充 |

**最小帧长 64 字节是 408 中最高频考点之一**，要会推导：$10\ \text{Mbps} \times 51.2\ \mu\text{s} = 64\ \text{字节}$，并理解为什么——确保发送方能在帧发完前收到冲突信号。
