# 3.5 交换式以太网

---

## 1. 架构演进与设计动因

### 1.1 共享介质的性能瓶颈

在共享式以太网（总线拓扑或集线器星形拓扑）中，系统性能受到介质共享机制的根本制约：
1. **碰撞概率随节点规模激增**：所有挂接节点处于同一个冲突域，多节点并发通信导致碰撞频繁发生，信道大部分时间被截断二进制指数退避与人为干扰信号（Jamming Signal）占据，实际吞吐量极低；
2. **半双工模式限制**：为了通过物理采样检测总线上的电平叠加碰撞，节点网卡必须工作在半双工模式（边发边听），发送与接收无法同时进行；
3. **物理距离与速率互锁**：受争用期约束（$L_{\min} \ge 2\tau \cdot C$），在最小帧长固定的前提下，传输速率越高，允许的最大网络覆盖跨度越短。

### 1.2 交换式以太网的核心架构

交换式以太网以**以太网交换机（Ethernet Switch）**为核心设备，构建全双工点对点星形拓扑：

```
【共享式以太网 (集线器 Hub)】                      【交换式以太网 (以太网交换机 Switch)】
         [ Hub 内部电气短接 ]                              [ Switch 硬件交换结构 ]
   - 所有主机在同一条电路上争用                     - 每个端口具备独立收发回路与 FIFO 队列
   - 只能工作于半双工，依赖 CSMA/CD                 - 点对点全双工通信，无碰撞机制
   - 10 Mbps 带宽由全网节点共享瓜分                  - 每个端口独享 100M/1000M 标称带宽
   - 同一时刻全网仅允许一对节点通信                 - 内部支持多对端口无阻塞并发传输
```

## 2. 全双工通信与 CSMA/CD 的退出

### 2.1 物理全双工通道的实现

在双绞线或光纤点对点连接中，主机网卡与交换机端口之间使用物理隔离的传输通路：
- **双绞线环境**：采用独立线对，一组用于发送（Tx，Transmit），另一组用于接收（Rx，Receive）；
- **光纤环境**：采用双芯光纤分别负责发送光信号与接收光信号。

数据在物理上沿各自的单向通道传输，发送信号与接收信号在介质层面完全隔离，不存在电压叠加或电磁冲突的物理条件。

### 2.2 CSMA/CD 协议的弃用

由于全双工物理链路消除了介质层面的信号碰撞：
1. **无需载波监听与碰撞检测**：发送节点在有数据待发时可立即驱动发送电路，无需在发送前监听信道（CS），也无需在发送过程中监测碰撞（CD）；
2. **解除帧长与物理距离的互锁**：由于不存在争用期 $2\tau$ 约束，理论上不再强制要求发送时延大于往返传播时延，帧长约束仅用于协议格式统一和接口芯片缓冲区管理。

## 3. 交换机硬件结构与无阻塞并发机制

以太网交换机的核心是高速硬件交换结构（Switch Fabric），通常基于专用集成电路（ASIC）实现：

```
                    输入端口 (Ingress Ports)
                   Port 1    Port 2    Port 3    Port 4
                     |         |         |         |
输   Port 1 --------[x]-------[ ]-------[ ]-------[ ]
出   Port 2 --------[ ]-------[x]-------[ ]-------[ ]
端   Port 3 --------[ ]-------[ ]-------[x]-------[ ]
口   Port 4 --------[ ]-------[ ]-------[ ]-------[x]
(Egress)             |         |         |         |
```

### 3.1 交叉矩阵（Crossbar）并发转发

- 当端口 1 需向端口 4 转发数据，同时端口 2 需向端口 3 转发数据时，ASIC 硬件在微秒级时间内闭合交叉点开关矩阵的对应通路；
- 只要不同输入端口的目标输出端口不发生冲突（即未发往同一出口端口），多对端口之间的帧转发在内部矩阵中完全并行展开，互不干扰，从而实现**多端口并行无阻塞并发交换**。

### 3.2 共享式与交换式核心属性对比

| 属性维度 | 共享式以太网 (Hub / Bus) | 交换式以太网 (Switch) | 机制机理 |
| :--- | :--- | :--- | :--- |
| **介质访问控制** | **强制采用 CSMA/CD** | **全双工下弃用 CSMA/CD** | 全双工物理通道收发分离，不存在信号碰撞 |
| **工作双工模式** | **半双工（Half-Duplex）** | **全双工（Full-Duplex）** | 收发物理回路独立，支持同时满速收发 |
| **冲突域划分** | **全网同处于 1 个冲突域** | **每个端口独立为 1 个冲突域** | 交换机端口具备帧缓存与地址过滤能力，隔离碰撞 |
| **广播域划分** | **全网 1 个广播域** | **默认全网 1 个广播域** | 广播 MAC 帧依然在全端口泛洪（依赖 VLAN 划分隔离） |
| **带宽分配特征** | **共享总物理带宽（$C/N$）** | **各端口独占标称带宽（$C$）** | 每台主机与交换机端口之间形成专线级物理通道 |

## 4. 带宽与吞吐量计算关系

### 4.1 单端口带宽 vs 背板交换容量

1. **单端口可用带宽**：
   对于标称速率为 $C$ 的端口，在全双工工作模式下，该接口具备同时以速率 $C$ 发送和以速率 $C$ 接收的能力；
2. **线速无阻塞背板带宽（Backplane Bandwidth）**：
   为保证所有端口在全双工全速收发时不发生内部矩阵阻塞排队，交换机内部交换结构的吞吐能力需满足：
   $$\text{背板带宽} \ge N \times C \times 2$$
   - $N$：交换机端口总数；
   - $C$：单端口标称速率；
   - 系数 $2$：表示全双工模式下同时支持发送和接收两个方向。

### 4.2 半双工设备接入时的自协商降级

当交换机某一端口连接老式集线器（Hub）或仅支持半双工的网卡时：
- 该端口通过以太网物理层自协商机制（Auto-Negotiation）自动降级为半双工工作模式，并重新启用 CSMA/CD 逻辑；
- 该端口与其下挂的集线器及所有主机共同构成一个局部的共享冲突域；
- 交换机的其他全双工端口不受影响，依然保持冲突域隔离与全双工运行。
