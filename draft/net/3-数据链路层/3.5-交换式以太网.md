# 3.5 交换式以太网

> **本节在 408 中的定位**：交换式以太网（Switched Ethernet）是现代计算机局域网的绝对统治形态。408 统考对“共享式到交换式”的历史跃迁考查极为深刻，核心考核点在于：**“全双工点对点物理链路如何彻底宣判 CSMA/CD 的死刑”**、**“交换结构（Switch Fabric）背板无阻塞并发微观机制”**，以及**“独占端口带宽与整机背板吞吐容量的代数关系”**。

---

## 一、第一性原理与设计动因：为什么交换式彻底埋葬了共享式？

### 1. 共享介质的物理天花板
在共享式以太网中，无论网络技术如何升级（从 10M 到 100M 再到 1000M），只要介质是共享的，就永远逃不出两大紧箍咒：
1. **碰撞争用诅咒**：主机数量越多，碰撞概率呈指数级爆发，信道利用率逼近于零；
2. **半双工束缚**：为了监听碰撞，必须半双工，网卡无法同时全速收发数据。

### 2. 交换式以太网的核心破局哲学
交换式以太网将网络彻底重构为**以以太网交换机（Switch）为中心的专用点对点星形连接**：

```
【共享式以太网 (集线器/总线)】                  【交换式以太网 (现代以太网交换机)】
         [ Hub / Bus ]                                    [ Switch ]
      (所有主机在同根线上争抢)                          (每个端口拥有专属高速缓冲区)
  - 只能半双工，必须 CSMA/CD 边发边听              - 全双工点对点，彻底废除 CSMA/CD!
  - 10M 带宽由 N 台主机瓜分                      - 每个端口独占 100M/1000M 带宽!
  - 任一瞬间仅允许 1 台主机发数据                 - 多对端口硬件级并发高速转发!
```

- **全双工点对点消除碰撞**：
  主机网卡与交换机端口之间，使用双绞线中**两对完全独立的铜线（一对专门发 Tx，一对专门收 Rx）**。
  - 主机发数据走 Tx 线，交换机发数据走 Rx 线；
  - 信号在各自独立的线路上单向奔驰，物理上**绝对不可能迎头相撞**！
  - **历史性结论**：**在全双工交换式以太网中，碰撞（Collision）在物理上彻底不复存在，CSMA/CD 协议被彻底弃用！最小帧长 64 字节与物理距离的互锁限制在全双工模式下彻底失效！**

## 二、微观机制：交换机内部交换架构与并发矩阵

### 1. 为什么交换机能够实现“多端口并行无阻塞转发”？
集线器内部是单根广播总线，而以太网交换机内部集成了高密度的**专用集成电路（ASIC）硬件交换矩阵（Crossbar Switch Fabric）**：

```
                    输入端口 (Ingress Ports)
                   Port 1    Port 2    Port 3    Port 4
                     |         |         |         |
输   Port 1 --------[x]-------[ ]-------[ ]-------[ ]
出   Port 2 --------[ ]-------[x]-------[ ]-------[ ]
端   Port 3 --------[ ]-------[ ]-------[x]-------[ ]
口   Port 4 --------[ ]-------[ ]-------[ ]-------[x]
(Egress)             |         |         |         |
```

- 当 Port 1 想发给 Port 4，且 Port 2 想发给 Port 3 时：
  ASIC 硬件通过交叉点开关矩阵，**在微秒级同时闭合 $(1, 4)$ 和 $(2, 3)$ 两个内部物理通路**！
  两对端口的数据在芯片内部**完全并行全速穿透，互不产生任何等待与阻塞**！

### 2. 交换式以太网的四大颠覆性特征（408 核心考点）

| 特征维度 | 共享式以太网 (Hub / Bus) | 交换式以太网 (Switch) | 408 命题深层机制 |
| :--- | :--- | :--- | :--- |
| **介质争用机制** | 强依赖 **CSMA/CD** | **彻底废除 CSMA/CD** | 全双工点对点物理消除碰撞 |
| **双工通信能力** | 仅支持**半双工（Half）** | 标配**全双工（Full）** | 收发独立线对，吞吐量翻倍 |
| **冲突域划分** | 全网所有端口为 **1 个冲突域** | **每个端口是独立冲突域** | 冲突域被彻底切碎隔离在单个物理端口内部 |
| **广播域划分** | 全网 1 个广播域 | 默认全网 **1 个广播域** | 广播帧依然全端口泛洪（需 VLAN 隔离） |
| **主机独占带宽** | 共享带宽（$C / N$） | **独占标称带宽（$C$）** | 每台主机与交换机之间独享物理链路带宽 |

## 三、408 统考真题级计算演练与容量推导

### 【题型模型：交换机背板带宽、并发吞吐量与连接模式判定】

**【考题背景】**
某高校实验室部署了一台拥有 24 个 $100\text{BASE-TX}$ 端口的以太网交换机：
- 每个端口标称传输速率为 $100\text{ Mbps}$；
- 交换机所有端口均工作在全双工模式下；
- 现将 20 台高性能工作站连接到该交换机的 1 至 20 号端口上。

**【试推导并求解】**：
1. 该交换机若要实现真正的“全端口线速无阻塞交换（Wire-Speed Non-blocking Switching）”，其内部交换结构的最小背板带宽（Backplane Bandwidth）应达到多少 $\text{Gbps}$？
2. 假设在某一高峰时刻，连接的 20 台工作站两两配对（构成 10 对独立会话），同时进行全速双向文件传输。此时该以太网系统能够达到的**瞬时并发总数据吞吐量**是多少？
3. 若此时第 21 号端口接入了一台早期的老式 $100\text{ Mbps}$ 半双工集线器 Hub，并在该 Hub 上挂接了 4 台主机。分析该局部接入对全网冲突域与通信模式的影响。

---

### 【草稿纸执行第一步：列出全双工线速背板带宽公式】
$$\text{背板带宽} \ge \text{端口总数} \times \text{单端口速率} \times 2\text{ (全双工双向)}$$

---

### 【严密推导过程】

#### 第 1 问：线速无阻塞背板带宽推导
- 交换机共有 $N = 24$ 个端口，每个端口速率 $C = 100\text{ Mbps} = 0.1\text{ Gbps}$；
- 全双工模式下，每个端口既能以 $100\text{ Mbps}$ 发送，又能同时以 $100\text{ Mbps}$ 接收，单端口双向吞吐量为 $2 \times 100\text{ Mbps} = 200\text{ Mbps}$；
- 为保证所有 24 个端口同时满载收发时内部交换矩阵不发生排队丢包：
  $$\text{最小背板带宽} = 24 \times 100\text{ Mbps} \times 2 = 4800\text{ Mbps} = \mathbf{4.8\text{ Gbps}}$$

#### 第 2 问：并发总数据吞吐量计算
- 20 台工作站构成 10 对全双工会话（每对包含两台主机）；
- 涉及的活动端口数为 20 个；
- 每一台工作站均独占 $100\text{ Mbps}$ 发送带宽与 $100\text{ Mbps}$ 接收带宽；
- 20 个端口同时处于全双工全速通信状态，系统瞬时并发总吞吐量为：
  $$\text{总吞吐量} = 20 \times 100\text{ Mbps} \times 2 = 4000\text{ Mbps} = \mathbf{4\text{ Gbps}}$$
  （如果是单向统计，则为 $20 \times 100\text{ Mbps} = 2\text{ Gbps}$；408 大题若特别强调全双工双向总吞吐量，需乘以 2）。

#### 第 3 问：混接半双工集线器的微观影响剖析
- 交换机的第 21 号端口与 Hub 相连；
- **自协商降级**：
  交换机第 21 号端口通过以太网自协商机制（Auto-Negotiation），自动由“全双工模式”降级为“半双工模式”，并启动 CSMA/CD 碰撞检测功能；
- **局部冲突域扩张**：
  Hub 下挂的 4 台主机与交换机 21 号端口**共同形成 1 个局部的共享冲突域**，这 4 台主机共享 $100\text{ Mbps}$ 带宽并存在碰撞；
- **对交换机其他端口的零干扰**：
  交换机 1 至 20 号端口**依然维持独立冲突域和全双工全速通信**，Hub 内部的碰撞电平被交换机 21 号端口彻底阻断，绝不会泄漏蔓延到其他工作站。

## 四、考场诱惑性暗礁与秒杀口诀

### 1. 致命诱惑与错误路线踩刹车

> [!CAUTION]
> **陷阱 1：以为现代交换机还需要 CSMA/CD**
> - **408 经典概念题**：“全双工以太网交换机中的端口在发送帧前仍需执行载波监听（判断正误）”——**大错特错！**
> - 全双工点对点物理链路无任何碰撞可能，**CSMA/CD 完全被关闭！** 只要网卡想发，立即驱动发送电路，无需任何退避和监听！

> [!CAUTION]
> **陷阱 2：算全双工吞吐量漏乘因子 2**
> - 题目若明确注明“全双工通信”，单个端口同时具备发 $C$ 和收 $C$ 的能力，计算双向极限通信容量时必须 **$\times 2$**！

### 2. 考场核心记忆桩
- **“交换全双无碰撞，CSMA 进故宫”**：现代交换式以太网彻底废除 CSMA/CD。
- **“每个端口独享速，背板线速乘双工”**：交换机独占带宽与背板带宽计算秘诀。
