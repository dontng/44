# 3.5 交换式以太网

交换式以太网（Switched Ethernet）以**以太网交换机（Ethernet Switch）**为核心构建，彻底取代了早期以集线器和总线为代表的共享式以太网，是现代局域网的主导形态。

## 一、从共享到交换的演进

- **共享式以太网**：所有主机共享一条传输介质，半双工通信，受制于 CSMA/CD 碰撞争用，总带宽固定。
- **交换式以太网**：主机通过双绞线独占连接到交换机的专用端口，内部采用高速交换架构，支持**全双工（Full-Duplex）**无碰撞通信。

## 二、交换式以太网的核心优势

1. **消除碰撞（No Collisions）**：在全双工点对点链路上，两端同时收发数据互不干扰，**不再需要 CSMA/CD 碰撞检测算法**。
2. **独享带宽**：若每个端口速率为 100Mbps，则每个连接端口的主机独享 100Mbps 双向带宽，交换机总容量（背板带宽）远超单端口速率。
3. **多端口并发通信**：交换机内部能够建立多对端口之间的并发无阻塞连接。
4. **即插即用（Plug and Play）**：交换机通电即用，通过硬件自学习算法自动维护 MAC 表，无需人工配置即可工作。
