# 3.4.3 使用集线器的共享式以太网

---

## 1. 集线器取代同轴电缆总线的工程动因

在以太网发展早期，使用粗缆或细缆的同轴电缆总线在工程维护上面临严重的单点故障问题：
1. **开路反射导致全网瘫痪**：
   电信号在导线中传播时，必须在总线两端连接阻抗匹配的终端电阻吸收电磁波。若电缆任意一处接头松动或发生断裂，断口处的阻抗失配将引发全反射波，导致**整条总线上的所有计算机全部无法通信**；
2. **故障定位极难**：
   网络管理员必须逐段排查整栋楼的物理线缆，维护成本极高。

1990 年 IEEE 制定了 10BASE-T 标准，采用双绞线和中心**集线器（Hub）**：
- **物理星形布线**：每台主机拉一根双绞线单独接入集线器端口；
- **物理容错隔离**：任意一根双绞线损坏或接头松动，集线器自动将该故障端口旁路隔离，**完全不影响其他端口之间的正常通信**。

## 2. 集线器（Hub）的微观工作原理与物理层属性

### 2.1 本质：多端口中继器（Multiport Repeater）

集线器在 OSI 体系结构中严格属于 **物理层（第 1 层，L1）** 设备：
1. **信号放大与波形整形**：
   集线器从某个端口接收到衰减失真的输入电信号后，内部模拟电路对其进行放大和波形整形，消除抖动；
2. **盲目电气广播**：
   集线器不具备数据链路层帧识别能力，无法读取帧首部的 MAC 地址。它将整形后的信号**无差别同步复制并分发到除输入端口外的所有其他端口**。

### 2.2 集线器的四大物理限制

| 限制维度 | 物理本质 | 核心考点结论 |
| :--- | :--- | :--- |
| **碰撞域（冲突域）** | 内部电路总线短接，两端口同时输入必引发碰撞 | **所有端口同处于 1 个碰撞域**（集线器绝不隔离碰撞域） |
| **广播域** | 物理层设备无法识别广播 MAC 地址 | **所有端口同处于 1 个广播域**（集线器绝不隔离广播域） |
| **通信双工方式** | 必须边发边听检测总线碰撞 | **只能工作在半双工方式**（必须执行 CSMA/CD） |
| **信道带宽分配** | 所有端口共享内部背板总线 | **所有端口平分总物理带宽**（$N$ 个端口共享 $10\text{ Mbps}$ 带宽） |
| **端口速率匹配** | 内部无帧缓冲区，无法进行跨时钟速率转换 | **所有端口速率必须严格一致**（不能混接 10M 与 100M 端口） |

## 3. 集线器（Hub）与以太网交换机（Switch）的核心对比

| 对比维度 | 集线器 (Hub) | 以太网交换机 (Switch) |
| :--- | :--- | :--- |
| **OSI 工作层次** | **物理层（第 1 层）** | **数据链路层（第 2 层）** |
| **主要工作机制** | 信号整形放大、无差别全端口广播 | 存储转发、基于 MAC 地址表定向单播转发 |
| **内部帧缓冲区** | **无缓冲区**（纯比特位流直通放大） | **有独立缓冲区**（每个端口具备收发队列） |
| **碰撞域隔离能力** | **不隔离**（全网 1 个碰撞域） | **隔离**（**每个端口都是一个独立的碰撞域**） |
| **广播域隔离能力** | **不隔离**（全网 1 个广播域） | **不隔离**（默认全网 1 个广播域，依赖 VLAN 隔离） |
| **支持的双工方式** | 仅支持半双工（强依赖 CSMA/CD） | **支持全双工**（全双工下弃用 CSMA/CD） |
| **带宽分配方式** | **共享带宽**（所有主机瓜分总带宽 $C$） | **独占带宽**（每个端口独享链路标称带宽 $C$） |
| **不同速率混接** | 不支持（全网速率必须完全一致） | 支持（端口缓冲区可自适应连接 10M/100M/1000M） |
