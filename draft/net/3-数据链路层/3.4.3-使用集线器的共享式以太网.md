# 3.4.3 使用集线器的共享式以太网

> **本节在 408 中的定位**：集线器（Hub）是局域网物理拓扑由“同轴电缆总线”迈向“双绞线星形”的里程碑设备，也是 408 统考考查网络设备层次归属与域隔离能力的经典靶子。必须彻底穿透**“物理星形、逻辑总线”**的表里矛盾，搞透集线器在电气内部的**“广播式无脑放大”**机制，以及集线器与交换机在带宽分配、双工模式、冲突域/广播域上的根本分水岭。

---

## 一、第一性原理与设计动因：为什么集线器取代了同轴电缆？

### 1. 物理总线的工程噩梦（单点故障脆弱性）
在 10BASE5（粗缆）和 10BASE2（细缆）时代，整栋楼的所有计算机串联在同一根同轴电缆上。
- **灾难 1：开路反射全网瘫痪**
  高频交流电信号在传输介质中传播时，必须在总线两端接入 $50\ \Omega$ 终端匹配电阻来吸收电磁能量。如果某间办公室的 BNC T 型接头松动，或者电缆某处被老鼠咬断，总线出现开路，电磁波在断裂处发生全反射，反射波与正常波叠加形成剧烈驻波干扰，**整条总线上的所有主机全部无法通信，全网瞬间瘫痪！**
- **灾难 2：排查极难**
  网络管理员必须拿着万用表或时域反射仪（TDR），一间办公室一间办公室地拧开接头测量阻抗，排查耗时长达数小时甚至数天。

### 2. 双绞线星形集线器的妥协与救赎
为了解决可维护性难题，1990 年 IEEE 颁布了 10BASE-T 标准：采用双绞线（UTP）和中心集线器（Hub）。
- **物理布线革命（星形）**：每台主机拉一根双绞线（RJ-45 水晶头）单独插到机房的 Hub 上；
- **容错隔离**：任何一根双绞线损坏、拔掉或短路，集线器内部的隔离电路会自动将该端口旁路（Partition），**完全不影响其他端口的正常通信**；
- **工程妥协（逻辑总线）**：由于当时交换芯片（ASIC）极其昂贵，集线器内部并没有数据处理芯片，仅仅是在背板电气上把所有端口的发送脚和接收脚焊死连在一起！**通信本质上依然是一根共享总线！**

## 二、微观机制：集线器（Hub）的内部电路与物理层属性

### 1. 集线器的本质：多端口中继器（Multiport Repeater）
- **协议层次归属**：严格属于 **OSI 物理层（第 1 层，L1）** 设备；
- **微观工作流程**：
  1. 端口 1 收到来自主机 A 的模拟电信号；
  2. 集线器内部放大整形电路对衰减失真的方波进行**整形（Reshaping）与放大（Amplification）**，消除高频抖动；
  3. **无脑广播分发**：集线器完全看不懂以太网帧首部的 MAC 地址，甚至不知道帧是什么东西，它像一个电气广播扬声器一样，**将该信号原封不动地同步复制并灌入端口 2、端口 3、端口 4... 等所有其他端口！**

```
                     +---------------------------------------+
                     |         集线器 Hub (物理层 L1)         |
                     |                                       |
                     |   [物理放大与信号整形]                 |
                     |            |                          |
                     |            v (内部总线短接广播)        |
                     |    +-------+-------+-------+          |
                     +----+-------+-------+-------+----------+
                          |       |       |       |
                       Port 1  Port 2  Port 3  Port 4
                          |       |       |       |
                       [Host A][Host B][Host C][Host D]
```

### 2. 集线器的四大死穴特征（408 核心考点）

| 特征维度 | 集线器 (Hub) 的物理表现 | 为什么必然如此？（底层物理机理） |
| :--- | :--- | :--- |
| **冲突域 (Collision Domain)** | **所有端口同属于 1 个冲突域** | 内部电路总线短接，若 Port 1 与 Port 2 同时有输入信号，两路电压直接在背板上叠加相撞，引发全网碰撞。 |
| **广播域 (Broadcast Domain)** | **所有端口同属于 1 个广播域** | 物理层设备无法识别 MAC 广播地址，更无法阻断，对所有信号一律全端口广播。 |
| **双工模式 (Duplex)** | **只能是半双工（Half-Duplex）** | 所有主机必须使用 CSMA/CD 边发边听；如果搞全双工，发送线与接收线同时有信号，集线器无法仲裁。 |
| **信道带宽 (Bandwidth)** | **所有端口共享总带宽** | 若 Hub 标称带宽为 $10\text{ Mbps}$，连接 $N$ 台主机，全网瞬时吞吐量上限就是 $10\text{ Mbps}$，平均每台分得 $\frac{10}{N}\text{ Mbps}$。 |
| **时钟与速率限制** | **所有端口速率必须严格一致** | Hub 内部没有帧缓冲区（SRAM），无法做速率匹配和时钟跨频转换，不能把 10M 端口与 100M 端口混接！ |

## 三、408 经典对比：集线器（Hub）vs 以太网交换机（Switch）

这是 408 统考选择题年年必考的高频对比：

```
       [ 主机 A ] <---(10 Mbps 共享)---> [ 主机 B ]
                    \                 /
                     +--- [ Hub ] ---+             ===> 全网总吞吐上限: 10 Mbps
                    /                 \                 (任一时刻仅允许一对通信)
       [ 主机 C ] <---------------------> [ 主机 D ]

       [ 主机 A ] ====(10 Mbps 独占)====> [ 主机 B ]
                    \                 /
                     +-- [ Switch ] -+             ===> 全网并发总吞吐上限: 20 Mbps (甚至双工 40 Mbps!)
                    /                 \                 (两对主机同时全速通信，互不干扰!)
       [ 主机 C ] ====(10 Mbps 独占)====> [ 主机 D ]
```

| 对比维度 | 集线器 (Hub) | 交换机 (Switch) |
| :--- | :--- | :--- |
| **OSI 工作层次** | **物理层（L1）** | **数据链路层（L2）**（部分三层交换机含 L3） |
| **核心功能** | 信号放大与再生、盲目广播 | 存储转发、根据 MAC 地址自学习精准定向转发 |
| **内部缓冲区** | **无**（纯比特位流直通转发） | **有**（端口具备独立 FIFO 缓冲区） |
| **隔离冲突域？** | **否**（全网 1 个冲突域） | **是**（**每个端口都是独立的冲突域**） |
| **隔离广播域？** | **否**（全网 1 个广播域） | **否**（默认全网 1 个广播域，需 VLAN 隔离） |
| **工作模式** | 半双工（Half Duplex，需 CSMA/CD） | **全双工（Full Duplex，彻底淘汰 CSMA/CD）** |
| **端口带宽** | 共享带宽（$C / N$） | **独占带宽**（每个端口独享标称速率 $C$） |
| **异构速率互联** | 不支持（不能跨速率） | 支持（可通过端口缓冲区互联 10M/100M/1000M） |

## 四、408 统考真题级情景逆向与带宽计算演练

### 【题型模型：多集线器级联网络吞吐量与冲突判定综合推导】

**【考题背景】**
某机构采用集线器组建局域网，拓扑结构如下：
- 集线器 Hub A 拥有 8 个端口，连接了 6 台主机（H1 到 H6）；
- 集线器 Hub B 拥有 8 个端口，连接了 4 台主机（H7 到 H10）；
- Hub A 的第 8 号端口与 Hub B 的第 8 号端口通过一条超五类双绞线直连级联；
- 两个集线器的标称端口速率均为 $10\text{ Mbps}$。

**【试推导并求解】**：
1. 整个网络中包含几个冲突域？包含几个广播域？
2. 假设在某一瞬间，主机 H1 正在向主机 H2 发送一个以太网单播数据帧：
   - 主机 H7 的网卡收发器上是否能接收到该帧的物理电信号？
   - 此时主机 H7 能否同时向主机 H8 发送数据帧？为什么？
3. 在理想调度下，全网所有 10 台主机同时满负荷通信时，整个网络能够达到的最大理论总吞吐量是多少？每台主机理论上平均分得的带宽是多少？
4. 若将 Hub A 和 Hub B 替换为两台 $10\text{ Mbps}$ 的以太网交换机，重新回答上述第 1 问和第 3 问。

---

### 【草稿纸执行第一步：画出 Hub 级联拓扑的电气等价图】
```
Hub A (8端口) <====== 级联 ======> Hub B (8端口)
电气本质: 16 个端口全部短接在一起的一根长电缆！
所有连接的主机 (共 10 台) 共同接入这根唯一的共享总线。
```

---

### 【严密推导过程】

#### 第 1 问：冲突域与广播域数量判定
- Hub 是物理层设备，完全不具备任何隔离能力；
- 两个 Hub 级联，将两边的冲突域融为一体；
- **冲突域数量**：**1 个**；
- **广播域数量**：**1 个**。

#### 第 2 问：微观通信行为判定
- **H7 是否能收到信号**：
  - **能收到**！因为 Hub A 不懂 MAC 地址，收到 H1 的单播帧后向全端口广播，信号通过级联线灌入 Hub B；Hub B 再次向其所有端口广播，因此 H7 的网卡收发器**必定会接收到该帧的完整电信号**（H7 的网卡在 MAC 过滤阶段发现目的 MAC 不是自己，才在硬件层丢弃）。
- **H7 此时能否向 H8 发送数据**：
  - **绝对不能**！因为全网同处一个冲突域，当 H1 正在发送时，信道上充斥着载波信号；H7 在发送前执行 CSMA/CD“先听后发”，必定检测到信道忙而被迫推迟等待。若 H7 强行发送，两路信号必定相撞，导致两起通信**全部破坏**！

#### 第 3 问：集线器网络总吞吐量与平均带宽推导
- 整个网络共享一条 $10\text{ Mbps}$ 物理信道，任一时刻全网只允许一台主机发送数据；
- **全网最大理论总吞吐量**：严格受限于信道总容量，为 **$10\text{ Mbps}$**；
- 10 台主机平分总带宽，每台主机平均分得：
  $$\text{平均带宽} = \frac{10\text{ Mbps}}{10} = \mathbf{1\text{ Mbps}}$$

#### 第 4 问：替换为交换机后的剧烈对比
若替换为两台 $10\text{ Mbps}$ 以太网交换机（每台交换机每个端口是独立冲突域，支持全双工）：
- **冲突域数量**：
  - 交换机每个端口是一个独立冲突域；
  - 6 台主机连 Switch A（6 个冲突域） + 4 台主机连 Switch B（4 个冲突域） + 级联链路端口（1 个冲突域） = **共 11 个冲突域**！
- **广播域数量**：交换机默认不隔离广播域，依然是 **1 个广播域**。
- **全网最大总吞吐量**：
  - 交换机支持多对端口并行无阻塞通信；
  - 10 台主机可两两配对（例如 H1 $\to$ H2, H3 $\to$ H4, H5 $\to$ H6, H7 $\to$ H8, H9 $\to$ H10），共 5 对通信链路同时全速传输；
  - 在半双工模式下，总吞吐量可达 $5 \times 10\text{ Mbps} = \mathbf{50\text{ Mbps}}$；
  - 在全双工模式下，总吞吐量最高可冲上 **$100\text{ Mbps}$**！

## 五、考场诱惑性暗礁与秒杀口诀

### 1. 致命诱惑与错误路线踩刹车

> [!CAUTION]
> **陷阱 1：看到“集线器每个端口 10 Mbps”，误以为总带宽是 $10 \times N$**
> - **考场特大惨剧**：“某 8 端口 10 Mbps 集线器的总吞吐量是多少？”——有考生写 $80\text{ Mbps}$，直接零分！
> - **铁律**：**集线器是“独乐乐不如众乐乐”，总带宽永远只有 10 Mbps，端口越多分得越少！** 只有交换机才是“每个端口独享 10 Mbps”！

> [!CAUTION]
> **陷阱 2：以为单播帧在集线器中只会发给目的主机**
> - 集线器是“傻瓜盲盒”，它没有大脑（没有 MAC 地址表），**无论单播、组播还是广播，集线器全是一视同仁地向所有端口狂轰滥炸！**

### 2. 考场核心记忆桩
- **“集线器内一根线，端口再多共十兆”**：物理层 Hub 共享带宽、单一冲突域。
- **“星形外观总线心，单播广播全轰滥”**：物理星形、逻辑总线，盲目泛洪复制。
