# 3.5.2 共享式以太网和交换式以太网的对比

共享式以太网与交换式以太网的对比是计算机网络考试中区分物理层与数据链路层概念的**最经典考点**。

## 一、综合对比速查表

| 对比维度 | 共享式以太网 (集线器/总线) | 交换式以太网 (以太网交换机) |
|---|---|---|
| **核心设备** | 集线器 (Hub) 或 粗/细同轴电缆 | 以太网交换机 (Switch) |
| **工作层次** | 物理层 (L1) | 数据链路层 (L2) |
| **冲突域 (碰撞域)** | **所有端口共属一个冲突域** | **每个端口是独立的冲突域** |
| **广播域** | 所有端口共属一个广播域 | **所有端口默认共属一个广播域** (除非划分VLAN) |
| **工作模式** | 半双工 (Half-Duplex) | 全双工 (Full-Duplex) (也可自适应半双工) |
| **MAC 协议** | 必须严格依赖 CSMA/CD 碰撞检测 | 全双工下**不需要** CSMA/CD |
| **带宽分配** | 所有站点共享总带宽 (N台分10M) | 每个端口独享名义带宽 (N台各享10M) |
| **数据安全性** | 极低（任意站点均可窃听广播信号） | 较高（单播帧定向转发至目的端口） |
| **可扩展性** | 差（站点增加导致碰撞率剧增） | 好（端口并发处理，背板容量大） |

## 二、两大核心概念判别（必考）

### 1. 冲突域（Collision Domain）
- 物理层设备（中继器、集线器）：**不能隔离冲突域**。
- 数据链路层设备（网桥、交换机）：**能隔离冲突域**。
- 网络层设备（路由器）：**能隔离冲突域**。

### 2. 广播域（Broadcast Domain）
- 物理层设备（集线器）：**不能隔离广播域**。
- 数据链路层设备（交换机、网桥）：**默认不能隔离广播域**（VLAN 技术可逻辑隔离）。
- 网络层设备（路由器）：**能隔离广播域**（路由器默认阻断广播帧）。

> **经典考题结论**：一个拥有 8 个端口的集线器连接 8 台 PC，有 **1 个冲突域，1 个广播域**；一个拥有 8 个端口的以太网交换机连接 8 台 PC，有 **8 个冲突域，1 个广播域**。
