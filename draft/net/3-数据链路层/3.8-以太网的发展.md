# 3.8 以太网的发展

> **本节在 408 中的定位**：以太网演进史（10M $\to$ 100M $\to$ 1Gbps $\to$ 10Gbps 及以上）是 408 统考考查物理介质命名规范、技术代际妥协与体系结构向前兼容性的综合考点。核心考核点包括：**“以太网物理层命名规则（如 100BASE-T、1000BASE-SX/LX）的逐段解码”**、**“吉比特以太网半双工模式下的‘载波延伸（Carrier Extension）’与‘分组突发（Packet Bursting）’物理成因与计算”**，以及**“万兆以太网（10GbE）彻底废除半双工与 CSMA/CD 的划时代意义”**。

---

## 一、第一性原理与设计动因：为什么以太网能统治局域网半个世纪？

在 20 世纪 80~90 年代，以太网曾面临令牌环网（Token Ring，IBM 主导）、FDDI 光纤分布式数据接口、ATM 异步传输模式等技术强敌的围剿。
以太网最终一统天下的根本原因：
1. **向下兼容（Backward Compatibility）神圣不可侵犯**：
   从 $10\text{ Mbps}$ 升级到 $100\text{ Gbps}$，上层网络层看到的**以太网 MAC 帧结构（目的 MAC 6B、源 MAC 6B、类型 2B、FCS 4B）始终保持严格不变**！所有上层软件、驱动程序、协议栈无需修改一行代码即可平滑升级；
2. **极简硬件与极致低成本**：
   通过大规模专用集成电路（ASIC）量产，硬件成本降至对手的十分之一；
3. **因时制宜的技术迭代妥协**：
   速率不够加光纤，碰撞受限改全双工交换，彻底完成了蜕变。

---

## 二、微观结构：以太网物理层代际命名法与参数拆解

408 统考常考给出物理层标准名称，要求说出其介质类型、传输距离与速率：

```
       1000       BASE   -     T
         |          |          |
      传输速率    传输方式    传输介质类型与波长
     (1000 Mbps)  (基带传输)   (Twisted-pair 双绞线)
```

### 1. 字段拆解黄金规则
1. **第一部分（速率）**：
   - `10`：$10\text{ Mbps}$；`100`：$100\text{ Mbps}$；`1000`：$1\text{ Gbps}$；`10G`：$10\text{ Gbps}$。
2. **第二部分（信号调制）**：
   - **`BASE`**：**基带传输（Baseband）**，未经调制的数字脉冲信号（以太网 $99.9\%$ 为基带）；
   - `BROAD`：宽带传输（Broadband，已淘汰频分复用模拟调制）。
3. **第三部分（介质代码）**：
   - **`T` / `TX`**：**双绞线（Twisted Pair）**，通常最大传输距离被物理限制为 **$100\text{ 米}$**；
   - **`F` / `FX`**：光纤（Fiber optic）；
   - **`S` / `SX`**：短波长光纤（Short wavelength，通常使用 $850\text{ nm}$ 激光/LED，**多模光纤**，距离约 $550\text{ 米}$）；
   - **`L` / `LX`**：长波长光纤（Long wavelength，通常使用 $1310\text{ nm}$ 激光，**单模光纤**，距离 $5\sim10\text{ 千米}$）；
   - **`C` / `CX`**：屏蔽双绞线铜缆（Copper，极短距离数米）。

## 三、吉比特以太网（1 Gbps）的工程绝唱与技术妥协

当以太网速率从 $100\text{ Mbps}$ 暴涨到 $1\text{ Gbps}$（翻了 10 倍）时，若继续保留 CSMA/CD 半双工机制，遇到了致命的**“最小帧长与物理距离互锁”矛盾**：

### 1. 物理矛盾推导（10 米网段荒谬剧）
- 保持 $64\text{ 字节}$（$512\text{ bit}$）最小帧长不变：
  $$L_{\min} = 2 \cdot \frac{D_{\max}}{V} \cdot C \implies D_{\max} = \frac{L_{\min} \cdot V}{2C}$$
  $$D_{\max} = \frac{512\text{ bit} \times (2 \times 10^8\text{ m/s})}{2 \times 10^9\text{ bps}} = \mathbf{51.2\text{ 米}}$$
- 扣除中继芯片和接口收发器的内部时钟抖动时延后，**最大允许网段物理长度仅剩可怜的 10 米左右**！
- 连一间普通办公室都拉不过去，以太网将彻底失去实用价值！

### 2. IEEE 802.3z 引入的两大补丁技术（408 核心考点）

```
【补丁 1：载波延伸 (Carrier Extension)】
  将争用期时隙时间由 512 bit 扩大整整 8 倍至 4096 bit 时间 (512 字节):
  
  [ 标准以太网 MAC 帧 (如 64 字节) ] [ 物理层填充非数据符号 (448 字节) ]
  |<-------------------------- 满 512 字节 ------------------------->|
  - 效果: 网络最大物理跨度重新拉回到 100 米以上!
  - 代价: 传输短帧时信道有效利用率跌破 12.5%, 大量带宽被垃圾填充符号浪费!

【补丁 2：分组突发 (Packet Bursting)】
  为弥补载波延伸的短帧带宽浪费:
  [ 帧 1 (带载波延伸) ] === [ 帧 2 ] === [ 帧 3 ] === [ 帧 4 ] ...
  |<--- 经历首帧争用期 --->|<-------- 连续发送短帧突发串 (最大 1500 字节) -------->|
  - 效果: 仅在首帧经历 512 字节争用期，一旦抢占信道成功，允许站点连续发送一串短帧，
          各帧之间仅填充微小的帧间隙，吞吐率大幅回升!
```

> **历史的结局**：
> 载波延伸和分组突发虽然精妙，但过于复杂。随着以太网交换芯片成本雪崩，吉比特以太网在商用落地时，**全行业直接普及了全双工交换机模式**！半双工 CSMA/CD 在千兆时代沦为了技术标本。

## 四、万兆以太网（10 Gbps）及更高速率的划时代变革

IEEE 802.3ae（10G 以太网标准）确立了现代以太网的终极架构形态：

```
+-------------------------------------------------------------------------------+
|                        万兆以太网 (10 GbE) 的三大划时代特征                    |
+-------------------------------------------------------------------------------+
|  1. 彻底斩断历史包袱：完全不再支持半双工通信，彻底废除 CSMA/CD 碰撞检测算法!  |
|  2. 彻底解除帧长诅咒：最小帧长 64 字节与物理传输距离彻底解耦，单模光纤跨度可达数十公里! |
|  3. 彻底走向光电融合：既能局域网互联 (LAN PHY)，又能无缝接入电信骨干网 (WAN PHY OC-192)!|
+-------------------------------------------------------------------------------+
```

### 1. 为什么万兆以太网敢彻底废除 CSMA/CD？
在 $10\text{ Gbps}$ 超高速率下，哪怕是 $1\text{ 米}$ 长的铜线，电磁波时延都会显著大于纳秒级的比特发送时间，物理碰撞检测在电气上已经变得毫无意义。所有连接全部由光纤或高质量双绞线（Cat6a）构建为**端到端全双工点对点物理通路**，没有碰撞的物理土壤，自然不再需要 CSMA/CD。

### 2. 帧格式的永恒继承
万兆及后续的 $40\text{G} / 100\text{G} / 400\text{G}$ 以太网：
- **依然严格保留 14 字节帧头 + 4 字节 FCS 帧尾**；
- **依然保留最小帧长 64 字节与最大帧长 1518 字节限制**；
- 使得数十年积累的企业级网络监控、防火墙、DPI 深度报文分析软件体系零成本兼容。

## 五、408 统考真题级情景逆向与标准判定演练

### 【题型模型：以太网代际标准选型与载波延伸开销推导】

**【考题背景】**
某大型工业自动化园区需要对原有局域网进行全面升级改造，涉及如下三组物理链路：
- 链路 1：中控室与主楼服务器机房之间，距离为 $80\text{ 米}$，要求带宽为 $1000\text{ Mbps}$，采用铜缆降低成本；
- 链路 2：主厂区与相距 $8\text{ 公里}$ 的远端分厂监控室之间，要求带宽为 $10\text{ Gbps}$；
- 链路 3：研发楼内相邻两间相距 $300\text{ 米}$ 的办公室之间，要求带宽为 $1000\text{ Mbps}$。

**【试推导并回答】**：
1. 为上述三条链路分别推荐最符合 IEEE 802.3 标准的物理层规范名称（写出形如 `XXXXBASE-XX` 的标准代号）；
2. 假设在吉比特以太网的半双工模式下，某站点连续发送一个数据载荷仅为 $46\text{ 字节}$ 的以太网 MAC 短帧（整帧长 64 字节）：
   - 该帧在物理层触发载波延伸后，在物理信道上线速发射的有效符号总长度是多少字节？
   - 计算该短帧发送过程中，有用数据（以太网 MAC 帧）占用的信道利用率是多少？
3. 阐述万兆以太网在体系结构上与标准 10M 以太网相比，发生的**最根本的两大体制改变**。

---

### 【严密推导过程】

#### 第 1 问：物理层标准代号选型推导
- **链路 1**：$80\text{ 米} \le 100\text{ 米}$，速率 $1000\text{ Mbps}$，铜缆双绞线 $\implies$ 选用 **`1000BASE-T`**（使用 Cat5e/Cat6 双绞线）。
- **链路 2**：$8\text{ 公里}$，速率 $10\text{ Gbps}$，长途长波长单模光纤 $\implies$ 选用 **`10GBASE-LR`**（Long Range，支持达 $10\text{ km}$）。
- **链路 3**：$300\text{ 米}$（超过双绞线 100 米极限，但在多模光纤 $550\text{ 米}$ 范围内），速率 $1000\text{ Mbps}$ $\implies$ 选用 **`1000BASE-SX`**（短波长多模光纤）。

#### 第 2 问：载波延伸信道开销计算
1. 吉比特以太网在半双工模式下，时隙时间被强制延伸到 **512 字节（4096 bit）**；
2. 待发送的以太网 MAC 帧长为 $64\text{ 字节}$；
3. **物理层发射符号总长度**：硬件在帧后填充 $512 - 64 = 448\text{ 字节}$ 的载波延伸扩展符号，使线路上发射的载波总长度严格达到 **$512\text{ 字节}$**；
4. **信道有效利用率**：
   $$U = \frac{L_{\text{MAC}}}{L_{\text{total}}} = \frac{64\text{ 字节}}{512\text{ 字节}} = \frac{1}{8} = \mathbf{12.5\%}$$
   *分析*：高达 $87.5\%$ 的信道时间全被无意义的载波延伸符号浪费，直观证明了千兆半双工技术的严重弊端。

#### 第 3 问：万兆以太网的两大根本体制改变
1. **介质访问控制层（MAC 子层）体制改变**：
   **彻底抛弃了沿用数十年的半双工与 CSMA/CD 碰撞争用协议**，成为纯粹的全双工点对点网络，信道利用率与稳定性达到极致；
2. **物理层服务覆盖范围体制改变**：
   不再仅仅局限于局域网（LAN），而是同时定义了 LAN PHY 与 WAN PHY（支持 SONET/SDH OC-192 封装），使得以太网技术**首次直接横跨城域网（MAN）与广域网（WAN）骨干传输网**。

## 六、考场诱惑性暗礁与秒杀口诀

### 1. 致命诱惑与错误路线踩刹车

> [!CAUTION]
> **陷阱 1：以为万兆以太网修改了以太网 MAC 帧首部格式**
> - **408 经典概念题**：“万兆以太网为了提高效率，去除了以太网帧头的源和目的 MAC 地址（判断正误）”——**大错特错！**
> - 万兆以太网的 MAC 帧结构、48 位寻址、类型代码与最初的 10M 以太网**一模一样**，这也是它能打败一切对手的核心根基！

> [!CAUTION]
> **陷阱 2：混淆 SX（短波长多模）与 LX（长波长单模）**
> - S = Short（短波长，便宜，配多模光纤，几百米）；
> - L = Long（长波长，贵，配单模光纤，几公里到几十公里）。408 见到几公里的长途光纤，必选 L（LX/LR）！

### 2. 考场核心记忆桩
- **“T 是双绞线百米限，S 是短波多模几百米，L 是长波单模数公里”**：以太网介质代码秒杀桩。
- **“千兆载波延五一二，万兆全双废 CSMA”**：两代核心变革考点一口清。
