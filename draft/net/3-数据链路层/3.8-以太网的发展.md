# 3.8 以太网的发展

以太网自 1970 年代诞生以来，从最初的 $10\text{ Mbps}$ 共享式总线网络，逐步演进到 $100\text{ Mbps}$（快速以太网）、$1\text{ Gbps}$（吉比特以太网）、$10\text{ Gbps}$（万兆以太网）乃至更高带宽的高速网络。以太网之所以能够战胜令牌环网（Token Ring）、光纤分布式数据接口（FDDI）和异步传输模式（ATM）并长期统治局域网，其核心优势在于**保持 MAC 帧格式的严格向后兼容**、**低成本的专用芯片实现**以及**平滑的技术代际演进**。

---

## 一、以太网物理层命名规范

IEEE 802.3 标准定义了一套规范的物理层介质命名方法，其命名格式通常由三部分组成：

```
       1000       BASE   -     T
         |          |          |
      传输速率    传输方式    传输介质类型与波长
     (1000 Mbps)  (基带传输)   (Twisted-pair 双绞线)
```

1. **第一部分（速率）**：
   - `10`：$10\text{ Mbps}$；
   - `100`：$100\text{ Mbps}$（快速以太网）；
   - `1000`：$1000\text{ Mbps}$ 或 $1\text{ Gbps}$（吉比特以太网）；
   - `10G`：$10\text{ Gbps}$（万兆以太网）。
2. **第二部分（信号传输方式）**：
   - **`BASE`**：**基带传输（Baseband）**，即传输未经调制的数字基带信号。绝大多数现代以太网均采用基带传输；
   - `BROAD`：宽带传输（Broadband），采用频分复用模拟调制技术（早期同轴电缆偶尔使用，现已淘汰）。
3. **第三部分（传输介质代码）**：
   - **`T` 或 `TX`**：**双绞线（Twisted Pair）**，其最大段长通常受电气衰减限制为 **$100\text{ 米}$**；
   - **`F` 或 `FX`**：光纤（Fiber optic）；
   - **`S` 或 `SX`**：短波长光纤（Short wavelength，通常使用 $850\text{ nm}$ 激光器或发光二极管配合**多模光纤**，传输距离一般在 $550\text{ 米}$ 左右）；
   - **`L` 或 `LX`**：长波长光纤（Long wavelength，通常使用 $1310\text{ nm}$ 激光器配合**单模光纤**，传输距离可达数千米至十千米以上）；
   - **`C` 或 `CX`**：铜缆（Copper cable，通常指短距离屏蔽双绞线或专用铜缆）。

## 二、快速以太网（Fast Ethernet，100BASE-T）

快速以太网的标准为 IEEE 802.3u，其数据传输速率提升至 $100\text{ Mbps}$。

### 1. 技术特点
- **帧格式不变**：继续保持标准以太网的 MAC 帧格式（最小帧长 $64\text{ 字节}$，最大帧长 $1518\text{ 字节}$）；
- **争用期与最小帧长**：由于传输速率提高至原来的 10 倍，为了继续保持最小帧长 $64\text{ 字节}$ 不变，若工作在半双工 CSMA/CD 模式下，其网络的最大物理跨度必须缩短为原来的十分之一（由 10BASE-T 的约 $1000\text{ 米}$ 缩减至约 $100\text{ 米}$）；
- **工作模式**：既可工作在全双工模式（通过交换机连接），也可工作在半双工模式（通过集线器连接，使用 CSMA/CD）。全双工模式下不受争用期物理距离约束。

### 2. 自协商机制（Auto-Negotiation）
IEEE 802.3u 引入了**自协商机制**，允许两个互联的以太网端口自动检测并协商最佳的工作参数（如工作速率是 $10\text{ Mbps}$ 还是 $100\text{ Mbps}$，工作模式是半双工还是全双工），极大提升了网络的易用性与向后兼容性。

## 三、吉比特以太网（Gigabit Ethernet，1 Gbps）

吉比特以太网（千兆以太网）的标准为 IEEE 802.3z（光纤）和 IEEE 802.3ab（双绞线），其数据传输速率达到 $1\text{ Gbps}$（$1000\text{ Mbps}$）。

### 1. 最小帧长与物理距离的矛盾
若速率提升至 $1\text{ Gbps}$，如果依旧保持半双工模式下的最小帧长为 $64\text{ 字节}$（$512\text{ bit}$），由公式 $L_{\min} = 2\tau \cdot C$ 可算出：
$$2\tau = \frac{512\text{ bit}}{10^9\text{ bps}} = 512\text{ ns}$$
在传播速度为 $2 \times 10^8\text{ m/s}$ 的介质中，双向往返距离仅为 $102.4\text{ 米}$，单程最大网段距离仅为约 $51.2\text{ 米}$；扣除接口和转发芯片时延后，实际网络跨度仅剩约 10 米，将严重失去实用价值。

### 2. 半双工模式下的技术妥协：载波延伸与分组突发
为了在半双工模式下既能维持最小帧长 $64\text{ 字节}$，又能将网段物理跨度扩展至实用的 $100\text{ 米}$ 以上，IEEE 802.3z 提出了两项特殊机制：

```
1. 载波延伸 (Carrier Extension):
   将半双工争用期时隙从 512 bit 扩大为 4096 bit 时间 (512 字节):
   [ MAC 帧 (如 64 字节) ] [ 物理层填充非数据符号 (448 字节) ]
   |<---------------------- 512 字节争用期 --------------------->|

2. 分组突发 (Packet Bursting):
   为避免载波延伸造成的信道利用率急剧下降:
   [ 首帧 (带载波延伸) ] === [ 帧 2 ] === [ 帧 3 ] === [ 帧 4 ] ...
   |<--- 首帧争用成功 --->|<------ 连续发送短帧突发串 (最高达 1500 字节) ------>|
```

1. **载波延伸（Carrier Extension）**：
   - 规定半双工争用期的时隙时间从 $512\text{ bit}$ 时间拉长 8 倍至 **$4096\text{ bit}$ 时间（对应 $512\text{ 字节}$）**；
   - 当发送站点发送的 MAC 帧长度小于 $512\text{ 字节}$ 时，物理层会在帧后自动填充特殊的载波延伸符号，使其在线路上传输的总时间达到 $512\text{ 字节}$ 时间，从而将网段物理跨度重新拉回至 $100\text{ 米}$ 以上；
   - 接收端在收到帧后，自动剥离填充的载波延伸符号，上交 MAC 子层；
   - **代价**：当频繁传输短帧时，信道有效利用率严重下降。
2. **分组突发（Packet Bursting）**：
   - 为了弥补载波延伸在传输短帧时的巨大开销，允许站点在成功抢占信道并发送完第一个带有载波延伸的帧后，如果该站点还有后续短帧待发，可以不必再次退避竞争，而是连续发送一串短帧（短帧之间仅保留微小的帧间隙）；
   - 突发传输的数据总长度有一个上限限制（通常为 1500 字节），以保证信道占用的公平性。

> **工程实际**：由于交换机技术的成熟与普及，吉比特以太网在实际部署中**几乎全部工作在全双工点对点模式下**。在全双工模式下，两端收发完全隔离，不存在碰撞，因此不需要载波延伸和分组突发，争用期概念不复存在。

## 四、万兆以太网（10 Gigabit Ethernet，10 Gbps）

万兆以太网（10GbE）的标准为 IEEE 802.3ae，传输速率达到 $10\text{ Gbps}$。

### 1. 万兆以太网的划时代变革
1. **完全废除半双工与 CSMA/CD 协议**：
   - 万兆以太网**只支持全双工通信**，彻底不再支持半双工工作模式；
   - 介质访问控制层中彻底移除了沿用数十年的 CSMA/CD 碰撞检测算法；
   - 传输距离与最小帧长彻底解耦，传输距离仅取决于光纤物理衰减和光模块发射功率（使用单模光纤可达数十千米）。
2. **严格保持 MAC 帧格式不变**：
   - 万兆以太网依然保留了标准以太网的帧格式（目的 MAC 6 字节、源 MAC 6 字节、类型 2 字节、数据载荷 $46 \sim 1500$ 字节、FCS 4 字节，最小帧长依然维持 $64\text{ 字节}$）；
   - 保证了与现有以太网网络设备和上层软件协议栈的完全无缝兼容。
3. **同时支持局域网物理层与广域网物理层**：
   - **LAN PHY**：用于连接局域网和城域网；
   - **WAN PHY**：支持将以太网数据无缝封装进电信运营商的同步光纤网（SONET/SDH OC-192）传输网络中，使得以太网技术正式跨越了局域网与广域网的界限。
