# 3.4.2-（3）共享式以太网的退避算法和信道利用率

---

## 1. 截断二进制指数退避算法（BEB）设计动因

当多个节点在 CSMA/CD 网络中发生碰撞后，必须推迟一段时间再重新尝试发送。退避算法的设计直接决定了网络的稳定性和吞吐量：

### 1.1 固定退避与线性退避的缺陷

1. **固定退避时间**：若相撞节点均等待相同的固定时间，它们将在下一轮同一时刻再次启动监听并同时发送，导致**确定性死循环再次碰撞**；
2. **固定随机区间**：
   - 若随机区间过小（例如仅在 $\{0, 1\}$ 中选择），在多节点并发的高负载场景下，碰撞概率极高，无法有效缓解信道拥塞；
   - 若随机区间过大（例如直接在 $\{0, \dots, 1023\}$ 中选择），在只有 2 台主机偶尔碰撞的轻负载场景下，节点会产生大量无谓的空闲等待，降低信道利用率。

### 1.2 指数退避的自适应动态博弈

**截断二进制指数退避算法（Truncated Binary Exponential Backoff，BEB）**通过冲突次数动态感知网络拥塞程度：
- 冲突次数少（网络轻载）$\to$ 采用较小的退避区间，快速重传；
- 冲突次数多（网络重载）$\to$ 退避区间呈指数级（$2^k$）快速放大，将竞争节点在时间轴上大幅稀释分散，抑制冲突蔓延；
- **截断点（$k = 10$）**：若无限制指数增长，退避时延将过大导致上层协议超时，因此在第 10 次碰撞后退避区间上限固定锁定在 1023 个时隙；
- **上限阈值（16 次）**：连续 16 次碰撞表明物理信道可能已发生严重故障或信道过载已不可逆，算法终止重试并直接报错，防止系统彻底锁死。

## 2. BEB 算法的离散数学模型与状态机

设发送节点遭遇的连续碰撞次数为 $k$（$k = 1, 2, \dots, 16$）：

```
步骤 1: 确定有效退避阶数 k_eff
        k_eff = min(k, 10)

步骤 2: 构建均匀分布离散随机整数集合 R
        R = { 0, 1, 2, ..., 2^(k_eff) - 1 }
        (从集合 R 中等概率随机抽取一个整数 r)

步骤 3: 计算实际退避等待时间 T_backoff
        T_backoff = r × 争用期 (2τ)
        (基准争用期 2τ: 10 Mbps 以太网为 51.2 μs)

步骤 4: 终止条件判决
        若 k > 16: 终止重试，宣告发送失败并向上层网络协议上报异常。
```

### 2.1 冲突序号与随机数区间对照表

| 冲突序号 $k$ | 有效阶数 $k_{\text{eff}}$ | 随机数集合范围 $R$ | 元素个数 $2^{k_{\text{eff}}}$ | 最大可能等待时间（以 $2\tau$ 计） |
| :---: | :---: | :--- | :---: | :---: |
| **第 1 次** | $1$ | $\{0, 1\}$ | $2^1 = 2$ | $1 \times 2\tau$ |
| **第 2 次** | $2$ | $\{0, 1, 2, 3\}$ | $2^2 = 4$ | $3 \times 2\tau$ |
| **第 3 次** | $3$ | $\{0, 1, 2, \dots, 7\}$ | $2^3 = 8$ | $7 \times 2\tau$ |
| **第 4 次** | $4$ | $\{0, 1, 2, \dots, 15\}$ | $2^4 = 16$ | $15 \times 2\tau$ |
| $\dots$ | $\dots$ | $\dots$ | $\dots$ | $\dots$ |
| **第 10 次** | $10$ | $\{0, 1, 2, \dots, 1023\}$ | $2^{10} = 1024$ | $1023 \times 2\tau$ |
| **第 11～15 次** | **10（截断）** | **$\{0, 1, 2, \dots, 1023\}$** | **1024（恒定）** | **$1023 \times 2\tau$** |
| **第 16 次** | — | **达到最大尝试次数** | — | **终止尝试，丢弃并上报错误** |

## 3. 信道利用率与参数 $a = \tau / T_0$ 的数学分析

### 3.1 理想极限与实际争用模型

设：
- $T_0$：单个数据帧的发送时延（$T_0 = \frac{L}{C}$）；
- $\tau$：信道端到端的单向物理传播时延；
- $a = \frac{\tau}{T_0}$：单向传播时延与发送时延的比值。

```
时间轴宏观构成:
+---------------+---------------+ ... +---------------+---------------------------------------+
|  争用时隙 1   |  争用时隙 2   | ... |  争用时隙 k   |            有效帧发送时间 T_0         |
+---------------+---------------+ ... +---------------+---------------------------------------+
|<---------- 碰撞及空闲浪费的争用期 --------->|<----------- 信道有效承载时间 ------------->|
```

1. **理想上界模型（无争用碰撞）**：
   发送完一个帧之后，信号需经过 $\tau$ 时间完全清空信道，随后的节点才能开始下一轮传输：
   $$S_{\max} = \frac{T_0}{T_0 + \tau} = \frac{1}{1 + \frac{\tau}{T_0}} = \mathbf{\frac{1}{1 + a}}$$
2. **实际争用模型（包含碰撞与退避）**：
   在实际共享网络中，平均成功发送一个数据帧需要经历若干个长度为 $2\tau$ 的争用时隙（统计平均约为 $e - 1 \approx 1.72$ 个争用期）：
   $$S_{\text{practical}} = \frac{T_0}{T_0 + 4.44\tau} = \mathbf{\frac{1}{1 + 4.44a}}$$

### 3.2 参数 $a$ 对信道性能的决定性意义

- **当 $a \to 0$ 时**：$T_0 \gg \tau$（帧长很大、链路距离极短、速率适中）。发送时延占绝对主导，信道利用率逼近 **$100\%$**；
- **当 $a \ge 1$ 时**：$\tau \ge T_0$（传输距离过远或帧长极短）。信号尚未传遍信道帧发送已结束，信道长期陷入碰撞与争用，有效吞吐率趋近于 **$0$**。
- **系统结论**：**共享式以太网为了保持高利用率，必须约束网络地理跨度并设定最小帧长，确保参数 $a \ll 1$。**

## 4. 典型问题分析

### 题目：双节点连续碰撞退避概率与截断时延计算

在一条 $C = 10\text{ Mbps}$ 的共享式以太网中，争用期基准时间为 $2\tau = 51.2\ \mu\text{s}$。
现有两个站点 A 和 B 同时启动发送引发碰撞，两站点均执行标准截断二进制指数退避算法。

**问题**：
1. 经历第 1 次碰撞后，两站点在下一次尝试中**再次发生碰撞**的概率是多少？
2. 经历第 1 次碰撞后，其中某一个站点比另一个站点更早发送成功的概率是多少？此时获胜站点需要等待的最短退避时延是多少？
3. 若两站点在第 2 次尝试中再次相撞（发生第 2 次碰撞），求它们在第 3 次尝试时**再次发生碰撞**的概率；
4. 设某一站点在发送过程中极端恶化，连续遭遇了 12 次碰撞，求该站点在第 12 次碰撞后可选的最大随机等待时隙数，并计算其对应的最大可能退避物理时间。

---

### 推导过程

#### 1. 第 1 次碰撞后再次相撞概率推导
- 发生第 1 次碰撞时，$k = 1$，退避区间为 $R_1 = \{0, 1\}$；
- 站点 A 独立等概率选择 $r_A \in \{0, 1\}$，站点 B 独立等概率选择 $r_B \in \{0, 1\}$；
- 联合状态样本空间总数为 $2 \times 2 = 4$ 对组合：
  $$\{(0,0), (0,1), (1,0), (1,1)\}$$
- 再次发生碰撞的充要条件为两站点选取的时隙数相同（$r_A = r_B$），即事件 $\{(0,0), (1,1)\}$；
- 再次碰撞概率为：
  $$P(\text{第1次后再次碰撞}) = \frac{2}{4} = \mathbf{0.5\ (50\%)}$$

#### 2. 单方抢先成功概率与最短退避时间推导
- 单方成功发送对应 $r_A \neq r_B$ 的事件，即 $\{(0,1), (1,0)\}$；
- 成功概率为：
  $$P(\text{单方抢先}) = 1 - P(r_A = r_B) = 1 - 0.5 = \mathbf{0.5\ (50\%)}$$
  （其中 A 先发概率为 $25\%$，B 先发概率为 $25\%$）。
- 若获胜方抽中 $r = 0$，其退避时隙数为 0，只需在信道空闲后等待帧间最小间隔（96 比特时间）即可立即发送，对应**最短退避等待时延为 $0\ \mu\text{s}$**。

#### 3. 第 2 次碰撞后再次相撞概率推导
- 经历第 2 次碰撞后，$k = 2$，退避集合扩展为 $R_2 = \{0, 1, 2, 3\}$（元素总数 $N = 4$）；
- 样本空间总对数为 $4 \times 4 = 16$；
- 再次相撞即 $r_A = r_B$，包含 4 种等可能组合：$(0,0), (1,1), (2,2), (3,3)$；
- 再次碰撞概率为：
  $$P(\text{第2次后再次碰撞}) = \frac{4}{16} = \frac{1}{4} = \mathbf{0.25\ (25\%)}$$
  *(规律：两节点竞争时，第 $k$ 次碰撞后再次碰撞的概率严格为 $\frac{2^k}{(2^k)^2} = \frac{1}{2^k}$)*。

#### 4. 第 12 次碰撞截断时延推导
- 当碰撞次数 $k = 12$ 时，由于 $k > 10$，触发算法**截断机制**；
- 有效退避阶数锁定为 $k_{\text{eff}} = 10$；
- 随机数集合范围为 $\{0, 1, 2, \dots, 2^{10} - 1\} = \{0, 1, 2, \dots, \mathbf{1023}\}$；
- 最大随机时隙数为 **1023**；
- 最大可能等待的物理时间：
  $$T_{\max} = 1023 \times 2\tau = 1023 \times 51.2\ \mu\text{s} = 52377.6\ \mu\text{s} \approx \mathbf{52.38\ \text{ms}}$$
