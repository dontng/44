# 3.1 数据链路层概述

数据链路层是 OSI/TCP-IP 体系结构中负责**相邻两个节点之间**可靠、高效地传送数据帧的一层，其传输的 PDU 称为**帧（Frame）**。

## 一、链路与数据链路的区分（易混考点）

- **链路（物理链路）**：从一个节点到相邻节点的物理线路（光纤、双绞线、无线信道），是一条"通道"，没有任何协议软件。
- **数据链路**：在物理链路之上，加上实现通信协议所需要的硬件和软件，才构成数据链路。即：数据链路 = 物理链路 + 数据链路层协议。

> 考试常以"链路和数据链路有什么区别"作为简答题，核心是：物理链路只管传信号，数据链路层协议才管帧的格式、差错控制、介质访问控制等。

## 二、数据链路层的三大使用场景

| 场景 | 说明 | 典型技术 |
|---|---|---|
| 点对点链路（Point-to-Point） | 两端各一个节点，直接相连 | PPP、HDLC |
| 广播链路（共享介质） | 多节点共享同一信道，存在介质争用 | 共享式以太网（总线/集线器） |
| 交换式局域网 | 通过交换机连接，各链路独立 | 交换式以太网、WLAN |

## 三、数据链路层解决的核心问题

数据链路层的核心任务可归纳为以下三个问题（3.2 节详细展开）：

1. **封装成帧（Framing）**：将网络层交下来的 IP 数据报封装成帧，加上帧头和帧尾，使接收方能识别一帧的起止边界。
2. **差错检测（Error Detection）**：在帧中加入冗余校验位（如 CRC），使接收方能检测出帧在传输过程中是否发生了比特差错。
3. **可靠传输（Reliable Transmission）**：通过 ARQ 协议（确认、重传、序号）保证帧能正确到达对端。注意：并非所有数据链路层协议都实现可靠传输（如以太网不做，Wi-Fi 做）。

## 四、数据链路层与网络层、物理层的关系

```
网络层（IP 数据报）
        ↓ 封装
数据链路层（帧：帧头 + IP 数据报 + 帧尾）
        ↓ 编码成信号
物理层（比特流 → 电/光/电磁波信号）
```

- 数据链路层使用 **MAC 地址**（物理地址）标识本地网络中的节点，区别于网络层使用 IP 地址。
- 帧在每一跳（相邻节点间）都要重新封装/解封装，而 IP 数据报在源到目的之间始终保持不变。
