# 3.4 共享式以太网

> **本节在 408 中的定位**：共享式以太网（Shared Ethernet）是局域网（LAN）技术发展的原点，也是 408 统考考查冲突域、广播域、拓扑演进与介质访问控制（MAC）的战略基石。本节作为 3.4 全系列的纲领，必须彻底搞透**“介质共享引发的物理信号叠加冲突”**、**“广播信道与广播域/冲突域的本质划分”**，以及**“从总线拓扑到双绞线星形 Hub 的历史妥协与必然瓶颈”**。

---

## 一、第一性原理与设计动因：为什么会有共享式以太网？

### 1. 计算机网络的“修路”困境
在 20 世纪 70 年代初（Bob Metcalfe 在施乐 PARC 发明以太网），计算机硬件与线缆造价极其高昂。如果让办公室内的 $N$ 台计算机两两拉专用光纤或铜线（网状拓扑），线路数量为 $\frac{N(N-1)}{2}$，成本呈平方级爆炸，工程上完全不可行。

### 2. 共享介质的工程妥协与物理冲突
以太网最天才的原始构想：**全楼只铺设一根粗同轴电缆总线（黄缆），所有计算机通过“刺血针（Vampire Tap）”直接扎破电缆外皮挂在同一根铜线上**。

```
              ================= 粗同轴电缆总线 (10BASE5) =================
                     |                         |                         |
                 [ 主机 A ]                [ 主机 B ]                [ 主机 C ]
```

- **广播特性的天然赋予**：
  任何一台主机在总线上驱动高低电平，电磁波均沿着铜线向左右两端扩散。全网所有网卡都能接收到该信号。
- **物理冲突（Collision）的不可避免性**：
  当主机 A 和主机 C **同时（或在极短的传播时延差内）**向总线注入电流时，电磁波在线缆中相遇，由于基带传输是电压叠加，总线上的电压瞬时超过阈值，波形发生严重畸变破坏！
  - **结果**：接收端采样到的全是无意义的乱码垃圾电压，双方通信**双双毁灭**！
- **介质访问控制（MAC，Medium Access Control）子层的诞生**：
  为了在一条共享的无序线路上，建立起有秩序的“交通管制规则”，数据链路层被正式划分为两层：
  1. **LLC 子层（逻辑链路控制）**：负责向上层提供统一的接口（现代已弱化）；
  2. **MAC 子层（介质访问控制）**：负责具体的信道争用、MAC 帧寻址、冲突仲裁（即著名的 **CSMA/CD 协议**）。

## 二、微观拓扑演进：从总线同轴到星形集线器（Hub）

### 1. 两代共享以太网硬件形态演进

```
【第一代：物理总线同轴电缆 (10BASE5 / 10BASE2)】
   终端匹配电阻                                                      终端匹配电阻
     [ 50Ω ] ======= Host A ======= Host B ======= Host C ======= [ 50Ω ]
   - 致命缺陷：单点故障脆弱性！总线任何一处被老鼠咬断或插头松动，整条总线阻抗失配反射，全网彻底瘫痪！找故障点必须拿着仪器全楼排查！

【第二代：物理星形、逻辑总线的双绞线集线器 (10BASE-T Hub)】
                           +--------------+
                           |  集线器 Hub  | (内部电路上依然是共享总线!)
                           +---+---+---+--+
                              /    |    \
                             /     |     \  (双绞线点对点连接)
                        [Host A] [Host B] [Host C]
   - 重大突破：某根双绞线断开，仅该主机下线，全网依然正常运行，故障排查极易。
   - 本质未变：集线器只是个多端口中继器（物理层设备），在电气上依然把所有端口短接在一起，依然是“共享信道”！
```

### 2. 共享式以太网的核心物理属性矩阵（408 必背）

| 核心属性 | 物理/工程本质 | 408 考场判决标准 |
| :--- | :--- | :--- |
| **信道工作模式** | **半双工（Half-Duplex）** | 必须边发边听（监听碰撞）。绝对不能全双工！若全双工收发同时进行，就无法区分自己发出的信号与对方的碰撞信号。 |
| **冲突域 (Collision Domain)** | **全网所有节点同处于 1 个冲突域** | 任意两台主机同时发信号，必定发生物理碰撞。集线器（Hub）绝不隔离冲突域！ |
| **广播域 (Broadcast Domain)** | **全网所有节点同处于 1 个广播域** | 任何一台主机发出目的 MAC 为 `FF-FF-FF-FF-FF-FF` 的广播帧，所有主机网卡都会收到。 |
| **有效带宽共享** | $N$ 个节点瓜分总带宽 $C$ | 若总线带宽为 $10\text{ Mbps}$，挂接 10 台主机，每台主机的平均理论带宽**不足 $1\text{ Mbps}$**（由于碰撞退避开销，实际更低）。 |

## 三、408 统考情景推导与考法切入点剖析

### 【题型模型：冲突域、广播域与多设备级联判定大题】

**【考题背景】**
某高校实验室组建小型局域网，拓扑结构如下：
- 主机 H1、H2、H3 连接到集线器 Hub 1；
- 主机 H4、H5 连接到集线器 Hub 2；
- Hub 1 的一个上联端口通过一条双绞线直连到 Hub 2 的上联端口；
- 所有链路均为 $10\text{BASE-T}$（带宽 $10\text{ Mbps}$，半双工）。

```
  [ H1 ]    [ H2 ]    [ H3 ]             [ H4 ]    [ H5 ]
     \        |        /                    \        /
      +---+---+---+---+                      +---+---+---+
      |     Hub 1     |======================|   Hub 2   |
      +---------------+   双绞线级联链路      +-----------+
```

**【试推导并回答】**：
1. 整个网络中包含几个冲突域？包含几个广播域？
2. 若主机 H1 与主机 H5 **同时向网络发送数据帧**，网络中会发生什么物理现象？两台主机的网络适配器将执行何种动作？
3. 若全网 5 台主机同时满负荷通信，每台主机理论上能够分到的平均独占带宽上限是多少？

---

### 【草稿纸执行第一步：画出设备的层次属性】
```
Hub (集线器) ===> 属于物理层设备 (Layer 1)
                 功能: 纯物理信号放大并向所有其他端口广播转发 (多端口中继器)
                 隔离能力: 既不隔离冲突域，也不隔离广播域！
```

### 【严密推导过程】

#### 第 1 问：冲突域与广播域数量判定
- 集线器 Hub 是物理层（第 1 层）设备，不具备任何存储转发或 MAC 地址识别能力，它仅仅是将收到的电信号放大后向所有其他端口广播；
- Hub 1 与 Hub 2 级联后，在电气特性上等价于将所有主机连接在同一根同轴电缆总线上；
- **冲突域数量**：**1 个**（全网所有 5 台主机处于同一个冲突域）；
- **广播域数量**：**1 个**（物理层设备无法隔离广播帧）。

#### 第 2 问：并发通信碰撞行为微观分析
- 当 H1 与 H5 同时发送数据时：
  - H1 的信号通过 Hub 1 广播，沿级联线缆涌入 Hub 2；
  - H5 的信号通过 Hub 2 广播，沿级联线缆涌入 Hub 1；
  - 两路电信号在 Hub 或双绞线缆中相遇叠加，**瞬时电压超过碰撞检测阈值，发生冲突（Collision）**；
- 两台主机的网卡通过 CSMA/CD 电压比较电路检测到冲突：
  1. 立即停止发送当前数据帧；
  2. 连续向总线发送 32 或 48 比特的**人为干扰信号（Jamming Signal）**，通知全网“碰撞已发生，所有接收设备丢弃当前帧”；
  3. 执行**截断二进制指数退避算法（BEB）**，各自随机后退一段时间后，再尝试重新监听信道发帧。

#### 第 3 问：平均独占带宽上限推导
- 整个网络共享 $10\text{ Mbps}$ 的总信道容量；
- 5 台主机平分信道总带宽：
  $$\text{平均理论带宽} = \frac{10\text{ Mbps}}{5} = 2\text{ Mbps}$$
  （注：在实际工程中，由于 5 台主机高负荷竞争会导致碰撞概率急剧上升，信道利用率往往跌破 $30\%$，实际平均吞吐率远低于 $2\text{ Mbps}$）。

## 四、考场诱惑性暗礁与秒杀口诀

### 1. 致命诱惑与错误路线踩刹车

> [!CAUTION]
> **陷阱 1：看到“星形拓扑”就误以为是“交换式以太网”**
> - **408 头号混淆概念**：现代交换机是星形拓扑，集线器 Hub 也是星形拓扑！
> - **鉴别钥匙**：**看中心节点是谁！**
>   - 中心是 **Hub（集线器）**：**“物理星形、逻辑总线”**，依然是共享式以太网，全网 1 个冲突域，半双工；
>   - 中心是 **Switch（交换机）**：每个端口是独立冲突域，支持全双工，独占带宽！

> [!CAUTION]
> **陷阱 2：误以为集线器可以连接不同速率的以太网（如 10M 和 100M）**
> - 集线器不能缓冲帧，只是个纯比特位流转发器，两端时钟频率必须严格一致。因此，**集线器不能互联两个不同速率的网段**（交换机可以）。

### 2. 考场核心记忆桩
- **“集线器是傻瓜放大器，连成一片大冲突”**：物理层 Hub 不隔离冲突域，也不隔离广播域。
- **“共享信道必半双工，边发边听防碰撞”**：共享以太网必须依赖半双工与 CSMA/CD。
