# 3.4 共享式以太网

---

## 1. 共享介质与设计动因

### 1.1 局域网互联的拓扑权衡

在计算机网络早期，将办公区域内的 $N$ 台计算机互相连接面临着严峻的布线与硬件成本挑战：
- **网状网（Mesh Topology）**：两两铺设专用点对点物理线路需要 $\frac{N(N-1)}{2}$ 条链路，线路数量呈 $O(N^2)$ 级爆炸，硬件接口与工程成本极高；
- **共享总线（Bus Topology）**：以太网（Ethernet）最初的设计思想是铺设一根公共的物理通信信道（如粗同轴电缆总线），所有主机通过接口挂接在同一根物理介质上，物理链路数量降为 1 条。

### 1.2 介质共享引入的物理冲突

共享信道在大幅降低布线成本的同时，带来了信道争用与信号叠加问题：
1. **广播特性**：任何挂接节点在公共总线上发送基带电信号时，电磁波均沿着导线向两侧传播，沿线的所有网卡都能物理感应到该信号；
2. **信号冲突（Collision）**：当节点 A 与节点 B 同时（或在电磁波单向传播时延差内）向总线注入电流时，两路电信号在物理导线上发生代数叠加，导致总线电压幅值剧烈畸变并超出正常判决电平；
3. **后果**：接收节点采样的波形完全破碎，无法解调出有效的比特流，双方通信同时宣告失败。

为了在无序的共享物理线路上建立协调秩序，数据链路层被正式划分为两个子层：
- **LLC（Logical Link Control，逻辑链路控制）子层**：负责向上层网络协议屏蔽不同局域网介质的技术差异，提供统一的数据链路服务接口；
- **MAC（Medium Access Control，介质访问控制）子层**：负责具体的信道争用控制、物理寻址以及帧校验，核心为 **CSMA/CD 协议**。

## 2. 拓扑形态的物理演进

共享式以太网在其演进过程中，经历了从物理总线到物理星形的硬件形态迁移：

```
【第一代：物理总线结构 (10BASE5 / 10BASE2)】
   终端匹配电阻                                                      终端匹配电阻
     [ 50Ω ] ======= Host A ======= Host B ======= Host C ======= [ 50Ω ]
   - 特点：单根同轴电缆串联所有节点，两端接终端电阻防止信号反射回折。
   - 缺陷：可靠性脆弱。总线任何一处物理损坏或接头松脱，均导致阻抗失配产生强反射波，引发全网瘫痪；且故障点难以迅速定位。

【第二代：物理星形、逻辑总线结构 (10BASE-T Hub)】
                          +--------------+
                          |  集线器 Hub  |  (内部电气总线短接)
                          +---+---+---+--+
                             /    |    \
                            /     |     \  (双绞线点对点辐射)
                       [Host A] [Host B] [Host C]
   - 特点：物理布线为双绞线星形辐射拓扑，中心节点为集线器（Hub）。若某一分支线缆损坏，仅该节点掉线，其余节点正常运作。
   - 本质：集线器内部在电气上依然是将所有接口短接在同一条共享总线上，属于物理层多端口中继器，其逻辑拓扑和介质访问机制依然是纯粹的共享总线。
```

## 3. 共享式以太网的核心物理属性

| 核心属性 | 机制解析 | 关键结论与系统表现 |
| :--- | :--- | :--- |
| **工作模式** | **半双工（Half-Duplex）** | 节点在发送信号的同时必须通过模拟电路监听信道电压（边发边听）。如果采用全双工（同时收发），收发回路完全物理独立，发送端无法通过总线电压叠加感知到信道碰撞。 |
| **冲突域（Collision Domain）** | **全网所有节点处于同一个冲突域** | 任何两个节点同时发送信号都会发生碰撞。物理层设备（集线器 Hub、中继器 Repeater）不解析帧结构，纯粹放大电气波形，**绝不隔离冲突域**。 |
| **广播域（Broadcast Domain）** | **全网所有节点处于同一个广播域** | 任何节点发出的广播帧（目的 MAC 为 `FF-FF-FF-FF-FF-FF`），集线器都会无差别向全网所有端口转发扩散。 |
| **带宽共享机制** | **竞争式瓜分总物理带宽** | 若共享总线名义带宽为 $C = 10\text{ Mbps}$，挂接 $N$ 台主机，且多台主机同时需要通信时，不仅每台主机的可用带宽平均不足 $C/N$，而且碰撞与退避机制还会进一步消耗信道有效时间。 |

## 4. 典型问题分析

### 题目：多级物理层集线器级联网络的冲突域与性能推导

某局域网采用 10BASE-T 双绞线以太网技术构建，其拓扑结构如下：
- 集线器 Hub-1 下接主机 A、B、C；
- 集线器 Hub-2 下接主机 D、E；
- Hub-1 与 Hub-2 之间通过一条双绞线端口级联直连；
- 总线额定传输速率为 $10\text{ Mbps}$，工作在半双工模式。

```
  [ Host A ]  [ Host B ]  [ Host C ]         [ Host D ]  [ Host E ]
      \           |           /                  \           /
       +----------+----------+                    +----------+
       |        Hub-1        |====================|  Hub-2   |
       +---------------------+   双绞线级联链路    +----------+
```

**问题**：
1. 分析该拓扑中包含多少个冲突域和多少个广播域；
2. 若主机 A 与主机 E 几乎在同一时刻开始向网络发送数据帧，两台主机的网络适配器及信道将发生何种物理现象？
3. 若 5 台主机全部尝试满负荷持续传输数据，该网络在理论上的吞吐量表现如何？

---

### 推导过程

#### 1. 冲突域与广播域数量判定
- 集线器（Hub）属于物理层（OSI 第 1 层）互连设备，功能仅为电信号的整形、放大与全端口广播，不具备数据链路层帧缓冲区或 MAC 地址识别解析能力；
- 级联线缆在电气上将 Hub-1 与 Hub-2 的内部总线合二为一，等价于所有 5 台主机挂接在同一根长总线上；
- **冲突域数量**：**1 个**（任意两台主机并发通信均会发生信号叠加碰撞）；
- **广播域数量**：**1 个**（物理层设备无法隔离广播帧）。

#### 2. 并发通信过程与硬件动作推导
1. 主机 A 的信号通过 Hub-1 扩散并沿级联线缆涌入 Hub-2；同时主机 E 的信号通过 Hub-2 扩散并涌入 Hub-1；
2. 两束高频电信号在线路或集线器内部叠加，总线电压幅值瞬间超出正常判决阈值，发生**物理冲突（Collision）**；
3. 主机 A 与 E 的网卡硬件内置模拟比较器检测到电压异常：
   - 立即终止当前有效数据帧的发送；
   - 连续向信道发送一段 32~48 位的**人为干扰信号（Jamming Signal）**，确保全网所有节点明确感知到碰撞发生；
   - 启动截断二进制指数退避算法（BEB），各自随机推迟一段争用期时间后重新竞争信道。

#### 3. 满负荷下的网络吞吐量表现
- 整个网络共享 $10\text{ Mbps}$ 的总线带宽；
- 在多主机均有持续发送需求的高负荷场景下，信道争用冲突概率急剧增加，大量信道时间被消耗在碰撞、人为干扰信号以及随机退避等待中；
- 网络的实际有效吞吐率（Goodput）会显著低于 $10\text{ Mbps}$（通常在冲突严重时信道利用率会降至 $30\%$ 以下），单台主机的平均可用速率远低于名义上的 $2\text{ Mbps}$。
