# 3.9.4 802.11 无线局域网的 MAC 帧

> **本节在 408 中的定位**：802.11 MAC 帧结构是数据链路层最复杂、也是 408 统考综合大题最钟爱的压轴考点。有线以太网只有 2 个 MAC 地址（源与目的），而 802.11 帧头拥有多达 **4 个地址字段**！必须彻底掌握**“To DS 与 From DS 两位标志位的二进制状态机”**、**“地址 1 永远是直接接收端（RA）、地址 2 永远是直接发送端（TA）的底层物理定位”**、**“上行链路（STA $\to$ AP）与下行链路（AP $\to$ STA）地址 1/2/3 的秒级映射”**，以及**“4 字节 FCS 与以太网帧的转换细节”**。

---

## 一、第一性原理与设计动因：为什么 802.11 需要多达 4 个地址？

### 1. 有线以太网的“扁平简单性”
在有线以太网中，主机网卡与交换机通过电缆直连。
- 帧在线路上飞时，发送它的就是源主机（SA），接收它的就是目的主机（DA）；
- 中间的交换机工作在二层透明转发，不需要在帧头里体现交换机自己的 MAC 地址。

### 2. 无线信道的“空间中继复杂性”
在无线 BSS 中：
1. **无线信号是空间广播的**：天空中飞舞着数十个 AP 和数百台手机发出的电磁波；
2. **所有通信必须经由 AP 中转（两跳传输）**：
   - 当手机 A 发数据给因特网服务器或同局域网的电脑 B 时，**当前这一瞬间无线电波的物理直接接收者是天花板上的 AP**，但**最终的数据消费者是远端的 B**；
   - 同样，AP 把数据推给手机 A 时，**物理发射电磁波的是 AP**，但**数据的最初制造者是远端的服务器**；
3. **AP 与 AP 之间的无线桥接（WDS 模式）**：
   - 两个 AP 之间通过无线空中搭桥，此时需要同时记录：最终源、最终目的、发送端 AP、接收端 AP！
- **结论**：**802.11 必须将“当前单跳的无线收发天线（RA/TA）”与“端到端的最初源/最终目的（SA/DA）”彻底解耦，因此必须设计多地址字段！**

## 二、微观结构：802.11 MAC 帧标准位图拆解

```
 字节偏移:
  0         2         4         10        16        22        24        30        32 ...          N-4       N
 +---------+---------+---------+---------+---------+---------+---------+---------+--------------+---------+
 | 帧控制  | 持续时间| 地址 1  | 地址 2  | 地址 3  | 序号控制| 地址 4  | QoS控制 |   数据载荷   |   FCS   |
 | FrameCtrl|Duration | Address1| Address2| Address3| SeqCtrl | Address4| (可选)  | Frame Body   | (4 字节)|
 | (2 字节)| (2 字节)| (6 字节)| (6 字节)| (6 字节)| (2 字节)| (6 字节)| (2 字节)| (0~2312 字节)|         |
 +---------+---------+---------+---------+---------+---------+---------+---------+--------------+---------+
 |<----------------------------------- MAC 帧头 (最长 30 字节) ---------------------------------->|
```

### 1. 帧控制字段（Frame Control，16 bit）的关键标志位
帧控制字段包含 11 个子字段，其中 408 统考最核心的是：
- **Type（2 bit）与 Subtype（4 bit）**：
  - `Type = 00`：**管理帧（Management）**（如 Beacon 信标帧、Probe 探针、Association 关联帧）；
  - `Type = 01`：**控制帧（Control）**（如 RTS、CTS、ACK）；
  - `Type = 10`：**数据帧（Data）**（承载上层 IP 报文）。
- **To DS 与 From DS（各 1 bit，考场命题核心钥匙）**：
  - **`To DS = 1`**：说明该帧是发往有线分配系统（DS）的（即**手机发给 AP**）；
  - **`From DS = 1`**：说明该帧是从有线分配系统（DS）出来的（即**AP 发给手机**）。

## 三、四大地址字段的微观状态映射表（408 核心重中之重）

在 802.11 物理层空间传输中，遵循两条铁律：
- **铁律 1（第一跳原则）**：**地址 1 永远是当前无线链路上的【直接接收端 RA（Receiver Address）】**！即谁的天线负责在空中把这个电波收下来，地址 1 就是谁！
- **铁律 2（发射者原则）**：**地址 2 永远是当前无线链路上的【直接发送端 TA（Transmitter Address）】**！即谁的天线在空中把这个电波发射出去，地址 2 就是谁！

### 1. 四大地址场景映射全矩阵（408 必背大表）

| To DS | From DS | 地址 1 (RA) | 地址 2 (TA) | 地址 3 | 地址 4 | 物理场景与方向 | 考场极速理解 |
| :---: | :---: | :--- | :--- | :--- | :---: | :--- | :--- |
| **0** | **0** | **目的地址 (DA)** | **源地址 (SA)** | **BSSID (AP MAC)** | *不用* | **自组网 Ad-hoc / IBSS** | 终端之间直传，无需跨 DS |
| **1** | **0** | **AP MAC (BSSID)** | **源主机 MAC (SA)** | **目的地址 (DA)** | *不用* | **上行链路：STA $\to$ AP** | 手机发给 AP，去往 DS |
| **0** | **1** | **目的主机 MAC (DA)**| **AP MAC (BSSID)** | **源主机 MAC (SA)** | *不用* | **下行链路：AP $\to$ STA** | AP 发给手机，来自 DS |
| **1** | **1** | **接收端 AP (RA)** | **发送端 AP (TA)** | **目的地址 (DA)** | **源地址 (SA)** | **AP 间无线桥接 (WDS)** | 两个 AP 空中中继，4 个地址全满 |

## 四、408 统考真题级情景逆向与双向传输推导演练

### 【题型模型：主机通过 AP 访问有线网络服务器全流程地址跟踪】

**【考题背景】**
如下图所示网络拓扑中，无线移动终端 H1 通过无线接入点 AP 连接到有线局域网：
- 移动终端 H1 的 MAC 地址为：`MAC_H1`，IP 地址为：`192.168.1.100`；
- 无线接入点 AP 的无线接口 MAC（BSSID）为：`MAC_AP`；
- AP 通过有线以太网双绞线直连到二层交换机 SW；
- 有线网络中的 Web 服务器 Server 的 MAC 地址为：`MAC_SVR`，IP 地址为：`192.168.1.200`；
- 设 H1 与 Server 处于同一个 IP 子网，ARP 缓存已预热。

```
[ 无线终端 H1 ] ~~~~~~(802.11 无线链路)~~~~~~> [ AP ] ======(802.3 有线以太网)======> [ 交换机 SW ] ===> [ 服务器 Server ]
(MAC_H1 / .100)                              (MAC_AP)                                                 (MAC_SVR / .200)
```

**【试推导并回答以下两个通信阶段中的帧格式与地址字段】**：
1. **阶段一（上行发送）**：
   - 当 H1 向 Server 发送 HTTP 请求时，在 H1 到 AP 的无线空中链路上传输的 802.11 数据帧中：
     - `To DS` 与 `From DS` 标志位分别是多少？
     - 地址 1、地址 2、地址 3 分别填入什么 MAC 地址？
   - 当该数据帧到达 AP 并被转换为 802.3 有线以太网帧送往交换机 SW 时，以太网帧的目的 MAC 和源 MAC 分别是什么？
2. **阶段二（下行回复）**：
   - 当 Server 向 H1 回复 HTTP 响应数据时，服务器发出的 802.3 以太网帧的目的 MAC 和源 MAC 分别是什么？
   - 当该数据到达 AP 并被转换为 802.11 无线帧在空中发射给 H1 时：
     - `To DS` 与 `From DS` 标志位分别是多少？
     - 地址 1、地址 2、地址 3 分别填入什么 MAC 地址？

---

### 【草稿纸执行第一步：画出单跳直接天线 RA/TA 与端到端 SA/DA】
```
阶段一 (H1 -> AP):
  发射者 TA = MAC_H1, 接收者 RA = MAC_AP
  最初源 SA = MAC_H1, 最终目的 DA = MAC_SVR
  这是发给有线分配系统 DS: To DS = 1, From DS = 0

阶段二 (AP -> H1):
  发射者 TA = MAC_AP, 接收者 RA = MAC_H1
  最初源 SA = MAC_SVR, 最终目的 DA = MAC_H1
  这是来自有线分配系统 DS: To DS = 0, From DS = 1
```

---

### 【严密推导过程】

#### 阶段一（上行发送：H1 $\to$ Server）推导
1. **无线链路（802.11 帧）**：
   - 该帧从终端发出，目标是通过有线骨干网（DS）投递给外部服务器，因此：
     - **`To DS = 1`**，**`From DS = 0`**；
   - 根据 802.11 规则：
     - **地址 1（RA，直接接收端）**：空中直接收信的是 AP 的无线网卡 $\implies$ **`MAC_AP`**；
     - **地址 2（TA，直接发射端）**：空中直接发射电磁波的是 H1 $\implies$ **`MAC_H1`**；
     - **地址 3（DA，最终目的地址）**：最终接收数据的目的地 $\implies$ **`MAC_SVR`**；
     - 地址 4：不使用。
2. **有线链路（AP $\to$ SW $\to$ Server）格式转换**：
   - AP 是数据链路层的门桥（Portal），它剥除 802.11 首部，将其重新封装为标准 Ethernet V2 以太网帧：
     - **目的 MAC 地址**：取自 802.11 帧的地址 3 $\implies$ **`MAC_SVR`**；
     - **源 MAC 地址**：取自 802.11 帧的地址 2 $\implies$ **`MAC_H1`**；
     - （注：AP 自身在有线以太网帧头中**隐身**，完全体现二层透明桥接！）。

---

#### 阶段二（下行回复：Server $\to$ H1）推导
1. **有线链路（Server $\to$ SW $\to$ AP）**：
   - 服务器 Server 发出标准的以太网 MAC 帧：
     - **目的 MAC 地址**：**`MAC_H1`**；
     - **源 MAC 地址**：**`MAC_SVR`**。
2. **无线链路（AP $\to$ H1）格式转换**：
   - AP 从有线网口接收到该以太网帧，查表得知 H1 关联在自己的无线 BSS 中；
   - AP 将其转换为 802.11 无线 MAC 帧并注入空中：
     - 该帧是从有线系统出来发给无线终端的，因此：
       - **`To DS = 0`**，**`From DS = 1`**；
     - **地址 1（RA，直接接收端）**：空中直接接收信号的是 H1 $\implies$ **`MAC_H1`**；
     - **地址 2（TA，直接发射端）**：空中发射无线电波的是 AP $\implies$ **`MAC_AP`**；
     - **地址 3（SA，最初源地址）**：该数据的最初发起者是服务器 $\implies$ **`MAC_SVR`**；
     - 地址 4：不使用。

## 五、考场诱惑性暗礁与秒杀口诀

### 1. 致命诱惑与错误路线踩刹车

> [!CAUTION]
> **陷阱 1：把 AP 的 MAC 地址当成了源 MAC 或目的 MAC**
> - **408 极高频大题失分点**：手机发数据给外网服务器，有考生把“目的 MAC”写成了 AP 的 MAC。
> - **铁律警示**：AP 只是**空中这一跳的中继转发者（RA/TA）**！最终的目的（DA）永远是外网服务器的 MAC，最初的源（SA）永远是手机的 MAC！绝不能把中继当终点！

> [!CAUTION]
> **陷阱 2：混淆上行与下行中地址 3 的含义**
> - **秒杀钥匙**：
>   - **上行（To DS = 1）**：前两个地址是当前无线跳（AP, H1），那么**剩下的地址 3 必定是最终目的地 DA**！
>   - **下行（From DS = 1）**：前两个地址是当前无线跳（H1, AP），那么**剩下的地址 3 必定是最初发信人 SA**！

### 2. 考场核心记忆桩
- **“一收二发是铁律，地址三补另一头”**：地址 1 永远是 RA，地址 2 永远是 TA，地址 3 填远端真实主体。
- **“去 DS，一 AP 二源三目的；来 DS，一目的二 AP 三源头”**：上行与下行地址映射终极通杀口诀。
- **“AP 连 AP 四地址，中间两中继两头原主”**：WDS 模式 4 地址口诀。
