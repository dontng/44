# 3.7.2 虚拟局域网VLAN的实现机制

IEEE 802.1Q 标准统一规范了 VLAN 的帧标记机制，定义了带有 VLAN 标签的以太网帧格式及交换机端口类型。

## 一、802.1Q 帧格式（VLAN Tag 结构）

IEEE 802.1Q 在标准以太网帧的**源 MAC 地址**与**类型/长度字段**之间插入一个 **4 字节的 VLAN 标记（Tag）**：



### 4 字节 VLAN Tag 组成（常考细节）
1. **TPID（标签协议标识符，2 字节）**：固定为 ，表示这是一个打上了 802.1Q 标签的以太网帧。
2. **TCI（标签控制信息，2 字节）**：
   - **PRI（优先级，3 bit）**：8 个服务优先级（0~7），用于 QoS 流量调度。
   - **CFI/DEI（1 bit）**：规范格式指示符/可丢弃指示符。
   - **VID（VLAN 标识符，12 bit）**：唯一标识该帧所属的 VLAN。
     - 12 bit 决定了理论取值范围为 bash \sim 4095$（^{12} = 4096$）。
     - 0 和 4095 保留，**有效可用 VLAN ID 范围为 1 ~ 4094**。

## 二、交换机端口类型及其处理规则

| 端口类型 | 连接对象 | 发送帧处理 | 接收帧处理 |
|---|---|---|---|
| **Access 端口** | 终端 PC、服务器（不支持标签） | **剥离 Tag**（转为普通帧发给主机） | 若为无 Tag 帧，打上本端口的 **PVID** 接收；若带 Tag 且与 PVID 相同则接收，不同则丢弃 |
| **Trunk 端口** | 交换机与交换机、交换机与路由器 | 若帧的 VID 等于 Trunk 的 Native VLAN（PVID），**剥离 Tag** 发送；否则**保留 Tag** 发送（需在允许列表中） | 若为无 Tag 帧，打上本端口 Native VLAN Tag；若带 Tag 且在允许列表中则接收 |
| **Hybrid 端口** | 兼具 Access 与 Trunk 特性 | 可根据配置灵活决定对特定 VLAN 帧是否剥离 Tag | 类似 Trunk |

> **名词解释 PVID**：Port Default VLAN ID，端口默认 VLAN ID。
