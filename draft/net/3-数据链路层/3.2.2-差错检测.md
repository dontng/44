# 3.2.2 差错检测

在实际物理信道中，噪声、衰减等因素会导致比特翻转，产生传输差错。数据链路层通过在帧中加入**冗余校验位**来检测差错，但通常不纠错（纠错靠重传）。

## 一、误码率（BER）

**误码率（Bit Error Rate，BER）** = 传输出错的比特数 / 总传输比特数。实际信道 BER 通常在 10⁻⁶ ~ 10⁻³ 之间；光纤信道 BER 可低至 10⁻¹²。

## 二、奇偶校验（Parity Check）

在数据后附加 1 个校验位，使整个编码中 1 的个数满足：
- **奇校验**：1 的个数为奇数；
- **偶校验**：1 的个数为偶数。

**缺点**：只能检测奇数个比特错误；偶数个错误（如同时翻转 2 位）无法检出。检错能力弱，实际数据链路层很少单独使用。

## 三、CRC 循环冗余检验（重点考点）

**CRC（Cyclic Redundancy Check）** 是数据链路层最常用的检错方法，以太网使用 CRC-32。

### 基本原理

1. **约定生成多项式 G(x)**（双方事先约定），其最高次项决定 FCS 位数（r 位）；
2. **发送方**：在数据 M 后面添加 r 个 0，然后除以 G(x)（模 2 除法，即 XOR 运算），得到余数 R（共 r 位），这就是 **FCS（帧校验序列）**；将 R 附在数据 M 后面发送；
3. **接收方**：收到 `M+FCS` 后，用 G(x) 除它，若余数为 0 则认为无差错，否则丢弃该帧并请求重传。

### 模 2 运算规则

模 2 加法（等同于 XOR）：无进位、无借位。
```
1 ⊕ 1 = 0    1 ⊕ 0 = 1    0 ⊕ 0 = 0
```

### 计算示例

设数据 M = `1101011011`，生成多项式 G(x) = `x⁴+x+1`，对应二进制 `10011`（5 位，r=4）。

1. M 后附 4 个 0：`11010110110000`
2. 用模 2 除法除以 `10011`，得余数 R = `1110`
3. 发送帧 = `11010110111110`（= M + R）
4. 接收方用 `10011` 除 `11010110111110`，余数为 `0000` → 无差错。

### CRC 的检错能力

- 可以检测出所有**单比特错误**；
- 可以检测出所有**奇数个比特错误**；
- 可以检测出所有**长度 ≤ r 的突发错误**（连续出错位数不超过生成多项式最高次数）；
- 漏检概率极低（约 2⁻ʳ）。

> 考点：CRC 是**检错**，不是纠错。检测到错误后，链路层丢弃该帧（不可靠传输模式，如以太网）或请求重传（可靠传输模式）。

## 四、检错码 vs 纠错码

| 类型 | 原理 | 代表 | 能否自动纠错 |
|---|---|---|---|
| 检错码 | 只能发现错误 | 奇偶校验、CRC | 否（需重传） |
| 纠错码 | 能定位并纠正错误 | 汉明码（Hamming） | 是 |

纠错码冗余位多、开销大，适用于误码率高且无法重传的场景（如深空通信）。数据链路层一般用检错+重传而不是纠错。

## 五、考点提醒

- **FCS 字段**：CRC 校验的结果，附在帧尾，以太网 FCS 为 4 字节（CRC-32）。
- 考试中 CRC 计算题步骤：①M 后补 r 个 0 →②模 2 除法 → ③余数即 FCS → ④验证接收方余数是否为 0。
- 模 2 除法每步不看大小直接 XOR，不借位——不要用普通长除法。
