# 3.2.2 差错检测

---

## 1. 常见差错检测方法的选择

实际通信信道并非理想信道，比特在传输过程中受到噪声干扰难免会出现差错。为了发现这些差错，通常在数据后添加冗余校验位：

| 校验方法 | 基本原理 | 检错能力与特点 | 常见应用层次 |
| :--- | :--- | :--- | :--- |
| **奇偶校验 (Parity Check)** | 附加 1 位校验位，使整个码字中 `1` 的总个数保持为奇数（奇校验）或偶数（偶校验） | 只能发现奇数个比特翻转，若偶数个位出错则完全失效，检错率仅约 50% | 计算机内部总线、低速串口外设 |
| **因特网检验和 (Checksum)** | 将数据按 16 位分组，进行二进制反码求和，将和取反填入首部 | 计算简单，软件易实现；但若多个比特对消翻转则无法检出 | 网络层（IPv4 首部）、传输层（TCP/UDP） |
| **循环冗余检验 (CRC)** | 将数据看作多项式，通过模 2 除法计算余数作为校验序列（FCS） | 硬件容易实现，能以极高概率检出突发离散差错 | **数据链路层标准**（以太网 CRC-32、PPP CRC-16） |

数据链路层之所以普遍采用 CRC，是因为通信线路上的噪声大多表现为**突发性差错（Burst Error）**（即瞬时干扰造成一连串连续比特损坏）。CRC 在数学上对长度小于等于校验码长度的突发差错具有 100% 的检出能力。

## 2. 循环冗余检验（CRC）的运算原理

### 2.1 模 2 运算规则

模 2 运算是一种不考虑进位和借位的特殊二进制代数运算：
- **模 2 加法和模 2 减法**：完全等同于**异或（XOR）**运算：
  $$0 \oplus 0 = 0, \quad 1 \oplus 1 = 0, \quad 0 \oplus 1 = 1, \quad 1 \oplus 0 = 1$$
- **模 2 除法**：
  - 商的选取**只看当前被除数（或中间余数）的最高位**：
    - 若最高位为 **`1`**，则当前商为 **`1`**，并用除数与当前部分做模 2 减法（异或）；
    - 若最高位为 **`0`**，则当前商为 **`0`**，并用全 `0` 与当前部分做模 2 减法（异或）；
  - 运算过程中**不比较数值大小**，只看首位是否为 1。

### 2.2 生成多项式 $G(X)$ 与除数的关系

通信双方必须预先约定一个**生成多项式 $G(X)$**。生成多项式各项的幂次对应二进制除数的位权：
- 例如约定生成多项式为 $G(X) = X^4 + X^2 + 1$：
  - 展开为完整形式：$1 \cdot X^4 + 0 \cdot X^3 + 1 \cdot X^2 + 0 \cdot X^1 + 1 \cdot X^0$；
  - 多项式的最高阶数（阶数）为 $r = 4$；
  - 对应的二进制除数长度为 $r + 1 = 5$ 位，序列为 `10101`；
- **基本数量关系**：
  - 生成多项式的最高阶数 = $r$；
  - 对应二进制除数的位数 = $r + 1$ 位；
  - 发送数据尾部添加的 0 的个数 = $r$ 位；
  - 最终计算得到的帧检验序列 FCS 的位数 = $r$ 位。

### 2.3 发送端与接收端的完整处理过程

1. **发送端计算帧检验序列（FCS）**：
   - 设待发送的数据为 $M$（共 $k$ 位），生成多项式最高阶数为 $r$；
   - 发送端先在数据 $M$ 的尾部添加 $r$ 个 0，构成被除数（共 $k + r$ 位）；
   - 用该被除数除以生成多项式对应的二进制除数 $G(X)$，进行模 2 除法；
   - 得到长度为 $r$ 位的余数 $R$。这个余数 $R$ 就是**帧检验序列（FCS, Frame Check Sequence）**；
   - 发送端将 $R$ 拼接到原数据 $M$ 的尾部，发送出去；
2. **接收端的差错检验**：
   - 接收端收到由数据和 FCS 拼接成的共 $k + r$ 位帧；
   - 用该帧直接除以相同的生成多项式除数 $G(X)$，进行模 2 除法：
     - 若**余数为 0**：判定传输过程很可能**没有发生差错**，予以接收；
     - 若**余数不为 0**：判定传输过程中**必定发生了比特差错**，直接将该帧丢弃。
