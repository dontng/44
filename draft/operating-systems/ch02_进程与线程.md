# ch02_进程与线程

## 2.1_进程与线程简介

### 上下文切换（2026-06-04）

**提纯问题：** 为了维持"每个进程独占 CPU"的幻觉，切换时需要完整保存和恢复进程的哪些状态？切换由谁、在什么时机触发？代价是什么？

**是什么：** 暂停当前进程，保存其运行状态，恢复另一个进程的状态并继续执行。本质是把CPU从"做A"切到"做B"，且保证A之后能从断点续上。

**有什么：**
- 硬件上下文：PC、PSW、通用寄存器
- 软件上下文：PCB中的进程ID、优先级、页表、文件描述符等
- 进程切换比线程切换开销大（进程需切换页表，线程共享内存空间）

**怎么做（王道7步模板）：**
1. 触发（时间片到 / I/O阻塞 / 主动yield）
2. 保存原进程CPU现场到PCB/内核栈
3. 更新原进程PCB状态（运行→就绪/阻塞）
4. 原进程PCB入对应队列
5. 调度器选新进程
6. 恢复新进程CPU现场
7. 跳转执行

**关键辨析：** 调度≠切换；模式切换≠进程切换；进程切换一定在内核态完成

**开销：** 寄存器保存/恢复 + 页表切换→TLB刷新 + 缓存冷启动
