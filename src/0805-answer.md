## 01｜平衡因子：每个结点都要左右高度差 ≤1

<img src="../bank/2009/q04.png" alt="2009-04" width="431" style="display:block; width:26.94em; max-width:100%; height:auto;">

**新增**：平衡二叉树的判定。**起手**：从叶向上，在每个结点旁写它的高度（叶 1，空 0），再算左右差。**答案**：**B**。

| 选项 | 图上结构 | 最先违规处 | 结论 |
| --- | --- | --- | --- |
| A | 根 → 左孩子 → 其右孩子，根无右孩子 | 根：左高 2、右高 0 | ✗ |
| B | 根有左右孩子，二者各带一个左孩子 | 根 2/2；两个孩子 1/0 | ✓ |
| C | 根左为叶，右支 c → 右孩子 d → d 的左孩子 | 根：左 1、右 3 | ✗ |
| D | 根右为叶，左孩子 L 的左支是三个结点的链，L 另有一个右叶 | L：左 3、右 1；根：左 4、右 1 | ✗ |

> 只看根还不够：C 的 c 也已 0/2。每个结点都要查，一处差 2 即不是。


## 03｜插入后找最低失衡点，做右左双旋

<img src="../bank/2010/q04.png" alt="2010-04" width="485" style="display:block; width:30.31em; max-width:100%; height:auto;">

**新增**：失衡后的双旋转（沿用 01 的高度标注）。**起手**：先按大小插 48，再标高度。**答案**：**C**。

48 < 53，48 > 37 → 接在 37 的右边。高度：48 为 1，37 为 2，53 为 3（左 2 右 1，仍合法）；24 左 1（13）、右 3 → **最低失衡点是 24**。路径 24→53→37→48 是 **右、左**。

```
插入后                ① 右旋 53                 ② 左旋 24
     24                   24                       37
    /  \                 /  \                    /    \
  13    53             13    37                24      53
       /  \                    \              /       /  \
     37    90                    53          13      48    90
       \                        /  \
        48                    48    90
```

①把 37 提到 53 的位置，37 原来的右孩子 48 转给 53 当左孩子；②把 37 再提到根，37 原来的左孩子（空）转给 24 当右孩子。最终 37 的左、右孩子是 24、53。

| 选项 | 与最终树不符之处 |
| --- | --- |
| A 13, 48 | 13 是 24 的左孩子，48 是 53 的左孩子 |
| B 24, 48 | 37 的右孩子是 53 |
| D 24, 90 | 90 是 53 的右孩子 |

## 04｜查找路径：每步更新一个边界，值必须落在区间内

<img src="../bank/2011/q07.png" alt="2011-07" width="473" style="display:block; width:29.56em; max-width:100%; height:auto;">

**新增**：祖先区间（二叉排序树里，走过的每次转向都继续约束后面的结点）。**起手**：对每个序列写出“当前区间”，走一步改一个边界。**答案**：**A**（问“不可能”）。

规则：向左走 → 上界变成该结点；向右走 → 下界变成该结点。下一个值必须落在区间里。

```
A 95 22 91 24 94 71
  22<95: (-∞,95)   91>22: (22,95)   24<91: (22,91)   94>24: (24,91) ← 94 不在内 ✗
B 92 20 91 34 88 35
  (-∞,92) 20 ✓ → (20,92) 91 ✓ → (20,91) 34 ✓ → (34,91) 88 ✓ → (34,88) 35 ✓
C 21 89 77 29 36 38
  (21,∞) 89 ✓ → (21,89) 77 ✓ → (21,77) 29 ✓ → (29,77) 36 ✓ → (36,77) 38 ✓
D 12 25 71 68 33 34
  (12,∞) 25 ✓ → (25,∞) 71 ✓ → (25,71) 68 ✓ → (25,68) 33 ✓ → (33,68) 34 ✓
```

> 只比相邻两个数：24→94 “向右变大”看似合法，但它还在 91 的左边。信号：新值撞出区间就停。

## 05｜给定每个非叶的平衡因子，用递推数结点

<img src="../bank/2012/q04.png" alt="2012-04" width="437" style="display:block; width:27.31em; max-width:100%; height:auto;">

**新增**：由高度关系列结点数递推。**起手**：写出高 1、2、3 的树各有几个结点。**答案**：**B**。

平衡因子取“左高 − 右高”，非叶结点都是 1 → 每个非叶的左子树比右子树高 1（两侧互换，个数不变）。设高度 h 的这种树有 F(h) 个结点，空树 F(0)=0：

```
F(h) = 1 + F(h-1) + F(h-2)
F(1)=1  F(2)=2  F(3)=4  F(4)=7  F(5)=12  F(6)=20
```

两棵子树各自仍是“所有非叶因子为 1”的树，所以递推可以连续用。结果恰为 20，A 10、C 32、D 33 都不等于它。

<details><summary>与“普通 AVL 最少结点数”的区别</summary>

普通 AVL 允许因子 0，题问最少时递推同样是 `1+F(h−1)+F(h−2)`，还须说明最瘦形状存在。本题是条件直接固定两侧高度，不需要“最少”。
</details>

## 06｜B 树删除：叶空了向兄弟借，要经过父结点

<img src="../bank/2012/q09.png" alt="2012-09" width="435" style="display:block; width:27.19em; max-width:100%; height:auto;">

**新增**：下溢与借位。**起手**：先写出 3 阶的结点键数范围，再看 78 删后的叶。**答案**：**D**。

3 阶：非根结点至少 `⌈3/2⌉−1=1` 个键、至多 2 个。删 78 后最右叶为空 → 下溢。左兄弟 `[60 62]` 有 2 个键，可以借一个（借走后仍剩 1 个）。

```
父 [55 65]，兄弟 [60 62]，空叶 []
① 兄弟最大键 62 上升到父，替下 65     父 [55 62]
② 65 下降到空叶                       叶 [65]  兄弟 [60]
```

顺序仍是 `60 < 62 < 65`。

| 选项 | 与结果不符之处 |
| --- | --- |
| A 60 | 叶里的键必须大于它左边的分隔键，而 60 小于 62 和 65 |
| B 60, 62 / C 62, 65 | 空叶只需补到 1 个键，一次借位只移动一个键 |

## 07｜顺序插入：右右失衡用单旋转，写出每一步

<img src="../bank/2013/q03.png" alt="2013-03" width="538" style="display:block; width:33.63em; max-width:100%; height:auto;">

**新增**：单旋转（RR）。**起手**：逐个插入，插完立即查平衡。**答案**：**D**。

```
插1,2     1→右2         3 插入后 1 右右失衡，左旋 1：  2(1,3)
插4       2(1,3(,4))
插5       3→4→5 右右失衡，左旋 3：  2(1,4(3,5))
插6       2 左1 右3 失衡，左旋 2：  4(2(1,3),5(,6))
插7       5→6→7 失衡，左旋 5：      4(2(1,3),6(5,7))
```

规律：失衡点的路径是 右、右，就把失衡点的下一个结点提为新根（2、4、4、6 依次如此）。最终树：根 4，左 2(1,3)，右 6(5,7)。分支结点 4、2、6 的左右高度都相等 → 因子 0，共 **3** 个；叶子（1,3,5,7）题面不算。

## 08｜删除再插入：新插入的结点一定是叶

<img src="../bank/2013/q06.png" alt="2013-06" width="539" style="display:block; width:33.69em; max-width:100%; height:auto;">

**新增**：插入的落点只能是叶（沿 04 的查找路径走到空位）。**起手**：分“v 是叶”“v 不是叶”两种情况各画一棵小树。**答案**：**C**（II、III）。

- **II（v 是叶）**：T2 就是 T1 去掉 v，其余结点没动。重新插入 v，沿的是同一条查找路径，落在同一个空位 → T3 = T1。所以 I 错、II 对。
- **III（v 不是叶）**：不管怎样删除，把 v 重新插入后它是**叶**；而 T1 里的 v 有孩子 → 两树不同。所以 III 对、IV 错。

例：T1 = 2(1,3)，v=2，删根后用 1 或 3 顶上，再插 2 只会落成叶，根不再是 2。

> 同一关键字集合 ≠ 同一棵树：这里比的是结构。

## 09｜B 树最少关键字：逐层取最少的分叉

<img src="../bank/2013/q10.png" alt="2013-10" width="399" style="display:block; width:24.94em; max-width:100%; height:auto;">

**新增**：用“最少孩子数”推“最少键数”。**起手**：写出 5 阶根与非根的最少子树数。**答案**：**A**。

```
5 阶：非根结点最少 ⌈5/2⌉ = 3 棵子树 → 至少 2 个键（k 键 ⇒ k+1 棵子树）
      根（非叶）最少 2 棵子树        → 至少 1 个键
```

高度为 2：根 + 一层叶。根 1 键、两个叶各 2 键：`1 + 2 + 2 = 5`，这个树合法（叶同层、键数达到下限），且每个结点都不能再少 → 最少 **5**。

高度读法：叶在第 2 层，不另算外部结点那一层。若把外部结点也算一层，高度 2 就只剩根，最少 1 键，不在选项中。B、C、D 都大于 5，不是最小值。

## 10｜最多结点数：每个结点只放一个键，并证明可行

<img src="../bank/2014/q09.png" alt="2014-09" width="425" style="display:block; width:26.56em; max-width:100%; height:auto;">

**新增**：求“最多”时反过来用下限，并给构造。**起手**：写 4 阶非根结点最少键数，再用 15 去除。**答案**：**D**。

4 阶：非根至少 `⌈4/2⌉−1=1` 个键，根也至少 1 个。15 个键、每个结点至少 1 个 → 结点不超过 **15**（上界）。

构造：每个结点 1 键、2 个孩子，四层全满，叶同层：`1+2+4+8=15` 个结点，共 15 键（内部结点 2 棵子树 ≥ ⌈4/2⌉，合法）→ 15 可以取到。

A 5、B 6、C 10 都小于已构造出的 15，不是最大值。

## 11｜中序降序：方向反过来，再用反例否定“一定”

<img src="../bank/2015/q04.png" alt="2015-04" width="525" style="display:block; width:32.81em; max-width:100%; height:auto;">

**新增**：中序降序 → 左大右小。**起手**：写“左子树 > 根 > 右子树”，再沿左链找最大值。**答案**：**D**。

中序是 左、根、右，要得到降序，左边必须更大。最大值是中序第一个，沿左孩子走到底，所以**无左子树**（D 对）。

其余三项各给一个反例（均为合法 AVL，左大右小）：

| 选项 | 反例 | 说明 |
| --- | --- | --- |
| A 根的度一定为 2 | 根 3、只有左孩子 4 | 度 1 |
| B 最小元素一定是叶 | 根 3，左 4，右 1，1 的左孩子 2 | 中序 4,3,2,1 降序；根 3 左高 1 右高 2，1 左 1 右 0，合法；最小元素 1 不是叶 |
| C 最后插入的一定是叶 | 依次插 3、1、2 | 2 在 1 的左边（2>1）→ 3 的右左失衡，旋后 2 成根 |

> C 靠 03 的双旋：插入后旋转可能把新结点转成内部结点。

## 13｜读出整张树，写中序，再比较大小

<img src="../bank/2018/q06.png" alt="2018-06" width="397" style="display:block; width:24.81em; max-width:100%; height:auto;">

> 题单在图上方加了文字标注（x₁右孩子 x₂、x₂左孩子 x₃、x₃右孩子 x₄、x₄左孩子 x₅）；这是题单标注，不是图上的字。本稿以图上的连线为准，二者一致。

**新增**：把一棵无数值的二叉排序树的大小关系用中序一次写出。**起手**：对每个结点写“左，根，右”。**答案**：**C**。

```
x1：无左孩子 → 输出 x1，进右子树 x2
x2：先左子树 x3：无左 → x3，进右子树 x4：先左 x5 → x5, x4
再输出 x2
中序 = x1, x3, x5, x4, x2   （二叉排序树中序升序）
```

即 `x1<x3<x5<x4<x2`。A 要 x2<x5，B 要 x4<x5，D 要 x4<x3，均与链矛盾；C 的 `x3<x5<x4` 在链上。

## 14｜三阶、高 5：逐层 1、2、4、8、16 个结点

<img src="../bank/2018/q08.png" alt="2018-08" width="425" style="display:block; width:26.56em; max-width:100%; height:auto;">

3 阶：非根最少 `⌈3/2⌉=2` 棵子树、至少 1 键；根至少 2 棵子树、1 键。

## 15｜AVL 的删除和插入会旋转：判断“可能”要找一个例子

<img src="../bank/2019/q04.png" alt="2019-04" width="492" style="display:block; width:30.75em; max-width:100%; height:auto;">

| --- | --- | --- | --- |

## 17｜B 树插入：满了就分裂，中间键上升

## 19｜已知某层的键数，反推下一层的结点数

<img src="../bank/2021/q09.png" alt="2021-09" width="526" style="display:block; width:32.88em; max-width:100%; height:auto;">

3 阶：每个结点 1–2 键。第 2 层共 4 键，每个第 2 层结点 ≥1 键：

## 20｜内部结点删键：替换后叶下溢，穷举出口

<img src="../bank/2022/q08.png" alt="2022-08" width="466" style="display:block; width:29.13em; max-width:100%; height:auto;">

**新增**：用前驱或后继顶替内部键，再对叶的下溢列出全部修复方式（用 06 的借位、17 的分隔键）。**起手**：写 5 阶的键数范围：非根 2–4。**答案**：**D**（问“不可能”）。

根 `[60 90 260 350]`，叶 `[30 50] [70 80 85] [100 110] [280 300] [400 500]`。删 260：

```
用前驱 110 顶替 → 根 [60 90 110 350]，叶 [100] 下溢
  左兄弟 [70 80 85] 可借：85 上到根换 90，90 下到叶 → 根 [60 85 110 350]  = C
  右兄弟 [280 300] 只有 2 键不能借；左兄弟合并会有 5 键超限
  与右兄弟合并（110 下来）→ [100 110 280 300]，根 [60 90 350]       = B
用后继 280 顶替 → 根 [60 90 280 350]，叶 [300] 下溢，两边兄弟都只有 2 键
  与左 [100 110] 合并 → 根 [60 90 350]                              = B
  与右 [400 500] 合并 → 根 [60 90 280]                              = A
```

D `[60,90,110,350]` 恰是“用 110 顶替但还没修复”的根：叶下溢后必须借（把 90 换成 85）或合并（根少一个键），根不能保持原样；用 280 顶替的根里则根本没有 110。
