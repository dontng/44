## 01｜2010-17：TLB 是页表项的缓存，命中则页必在主存

<img src="../bank/2010/q17.png" alt="2010-17 原题" width="367" style="display:block; width:22.94em; max-width:100%; height:auto;">

**新增**：页表放主存，记“虚页→页框”；TLB 缓存其近期项。TLB 命中问映射是否缓存，Page 命中问页是否在主存，Cache 命中问块是否在 Cache。
**起手**：路径 `虚拟地址→TLB（不中查页表）→物理地址→Cache`，逐项造情景 → **D**。

| 选项 | 情景 | 结论 |
|---|---|---|
| A TLB✗ Cache✗ Page✗ | 页不在主存，TLB 与 Cache 都无它 | 可能 |
| B TLB✗ Cache✓ Page✓ | 页在主存，TLB 项被挤掉；查页表得物理地址后，块早先已在 Cache | 可能 |
| C TLB✓ Cache✗ Page✓ | 映射有效，块不在 Cache | 可能 |
| D TLB✓ Cache✓ Page✗ | TLB 只缓存主存中有效页的映射，页不在主存则其项已失效 | **不可能** |

（D 依赖：换出页时 TLB 项同步作废。）

## 02｜2013-16：虚页号｜页内偏移，用整个虚页号去比 TLB 标记

<img src="../bank/2013/q16.png" alt="2013-16 原题" width="538" style="display:block; width:33.63em; max-width:100%; height:auto;">

**新增**：页 4KB＝2¹²，低 12 位（3 个十六进制位）是偏移，其余是虚页号；翻译只换虚页号。
**起手**：虚拟地址 4GB＝32 位，`03FFF180H` → `03FFF ｜ 180`（虚页号 20 位）。TLB 全相联，要拿 `03FFFH` 与四行标记逐个比 → **A**。

| 选项 | 题面依据 |
|---|---|
| A `0153180H` | 标记 `03FFFH` 的行有效位 1，页框 `0153H`，拼 `0153｜180`（主存 256MB＝28 位，页框 16 位） |
| B `0035180H` | 页框 `0035H` 属标记 `3FFF1H` 的行，与 `03FFFH` 不等 |
| C TLB 缺失 | 已有一行标记相等且有效，不缺失 |
| D 缺页 | TLB 命中说明页在主存（01） |

> 标记 `FF180H` 恰是地址末 5 位，但页号取高位；该行也无效。

## 03｜2015-16：数主存访问——页表、数据读、直写的写

<img src="../bank/2015/q16.png" alt="2015-16 原题" width="529" style="display:block; width:33.04em; max-width:100%; height:auto;">

**新增**：主存访问来源：TLB 缺失读页表（01）、Cache 缺失读块、写。**直写**即使写命中也同步写主存。
**起手**：`add xaddr,3` 对 x 一读一写；“至少”＝最省路径＋下限 → **B**。

```
读 x：TLB 命中 → 无页表读；Cache 命中 → 无主存读      0 次
写 x：Cache 命中，直写 → 同步写主存                   1 次
```

- 构造：TLB、读、写全命中，恰 1 次，故最小 ≤ 1。
- 下限：写 x 必到主存，≥ 1。A 0 违反直写；C 2、D 3 是读也要访存的情形，不是最小。
- 读法：只计 x 的数据访问，取指不计。

## 04｜2019-14：缺页异常处理完，回到原指令重做

<img src="../bank/2019/q14.png" alt="2019-14 原题" width="346" style="display:block; width:21.63em; max-width:100%; height:auto;">

**新增**：缺页是翻译时查页表发现页不在主存而产生的异常；该指令的访存没做成，处理完要**重新执行它**。
**起手**：画 `取指 → 翻译（缺页，停）→ 访存（未做）`。→ **D**。

| 选项 | 依据 |
|---|---|
| A | 缺页在地址转换（查页表）时被 CPU 检测到 |
| B | 题面是“操作系统提供的缺页处理程序”，调页要访问外存，由 OS 完成 |
| C | 以页故障地址（引发缺页的虚拟地址）定位所缺页，从外存读入 |
| D | 原指令的数据访问还没完成；跳到下一条会永远漏掉它。**错误** |

## 05｜2020-15：无新台阶——与 0815-09 同题，换成逐项找反例

<img src="../bank/2020/q15.png" alt="2020-15 原题" width="421" style="display:block; width:26.31em; max-width:100%; height:auto;">

与 [0815-09](0815-answer.md#q09) 同一道原题，无新台阶，把 TLB 加进来逐项核对 → **D**。

| 选项 | 依据 |
|---|---|
| A 命中率与局部性有关 | TLB 靠近期页再次出现，Cache 靠近期块；都依赖局部性 |
| B 缺失后都要访问主存 | TLB 缺失读主存页表（01），Cache 缺失去主存取块 |
| C 缺失处理都可由硬件实现 | 只说“可以”；Cache 控制器取块、MMU 查页表可由硬件完成（缺页才交 OS，04） |
| D 都由 DRAM 组成 | TLB 为省掉主存里的页表读（01），自己也是 DRAM 就失去意义；Cache 同理（0815-09）。**错误** |

## 06｜2022-15：页表按虚页号查存在位，先对齐进制

<img src="../bank/2022/q15.png" alt="2022-15 原题" width="466" style="display:block; width:29.13em; max-width:100%; height:auto;">

**新增**：页表项含页框号与**存在位**，0 即缺页（04）。查表前先把虚页号换成表头进制。
**起手**：`00082840H` → `00082 ｜ 840`；虚页号 `0x00082`＝8×16＋2＝**130**。→ **C**。

```
虚页 130：页框 018H，存在位 1
物理地址 = 018H ｜ 840H = 018840H （主存 24 位＝6 个十六进制位）
```

| 选项 | 依据 |
|---|---|
| A `024840H` | 页框 `024H` 属虚页 82，其存在位为 0 |
| B `180840H` | 页框 `180H` 属虚页 129，不是 130 |
| D 缺页 | 虚页 130 存在位为 1 |

读法：表头页号图上未标进制，按十进制读，`0x82＝130` 才对应表中的行；属约定读法。

## 08｜2024-17：组相联 TLB 的标记＝虚页号扣掉组索引位

<img src="../bank/2024/q17.png" alt="2024-17 原题" width="540" style="display:block; width:33.75em; max-width:100%; height:auto;">

**新增**：全相联标记是整个虚页号（02）；组相联用虚页号低几位选组，这几位不再存入标记（同 0815-11）。
**起手**：

```
页 1KB=2^10 → 偏移 10 位；虚页号 32−10 = 22 位
32 项 ÷ 4 路 = 8 组 → 组索引 3 位
标记 = 22 − 3 = 19 位
```

→ **C**。“至少”：少于 19 位，则只差在缺位上的两个虚页号会混为一页；19 位够用，故最小 19。

| 选项 | 依据 |
|---|---|
| A 17 | 即 30−10−3，用了 30 位主存地址；TLB 查的是虚页号 |
| B 18 | 即 22−4，需 16 组，与 8 组不符 |
| D 20 | 即 22−2，需 4 组，与 8 组不符 |

## 09｜2024-18：越权在翻译时查，Cache 缺失要等物理地址

<img src="../bank/2024/q18.png" alt="2024-18 原题" width="445" style="display:block; width:27.81em; max-width:100%; height:auto;">

**新增**：页表项还有**权限位**；翻译时与本次访问类型比对，不符即**访问越权**。
**起手**：把四个事件放到路径上，问“它需要物理地址吗”→ **B**。

```
查 TLB（✗ = TLB 缺失）→ 页表项：存在位（✗ = 页面缺失）、权限位（✗ = 访问越权）
→ 得物理地址 → 查 Cache（✗ = Cache 缺失）
```

| 选项 | 依据 |
|---|---|
| A 访问越权 | 比对页表项权限，在翻译中完成 |
| C 页面缺失 | 页表项存在位 0，翻译中发现（04） |
| D TLB 缺失 | 查 TLB 未比中，是翻译第一步（01） |
| B Cache 缺失 | Cache 按物理地址查（01 路径），在翻译完成后才知。**不是** MMU 翻译过程中检测的 |
