<a id="q01"></a>
## 01｜芯片规格“m×n”：单元数×位数，片数＝并宽×扩深

<img src="../bank/2009/q15.png" alt="2009-15 原题" width="504" style="display:block; width:31.50em; max-width:100%; height:auto;">

> **新增**：规格 `m×n` 表示 m 个单元、每单元 n 位。**起手**：ROM 要 4K×8，RAM 要 60K×8，除以各自规格 → **D（2、30）**。

| | 目标 | 每片 | 并宽 | 扩深 | 片数 |
|---|---|---|---|---|---|
| ROM | 4KB＝4K×8 | 2K×8 | 8/8＝1 | 4K/2K＝2 | 2 |
| RAM | 64−4＝60KB＝60K×8 | 4K×4 | 8/4＝2 | 60K/4K＝15 | 30 |

校验：每片 4K×4 位＝2KB，60/2＝30，与上表一致。选项里的 15 恰是扩深数，没乘并宽的 2；ROM 为 1 片只有 2KB，凑不够题面的 4KB。

<a id="q02"></a>
## 02｜并宽不增加地址个数：段长只看每片深度

<img src="../bank/2010/q15.png" alt="2010-15 原题" width="491" style="display:block; width:30.69em; max-width:100%; height:auto;">

> **新增**：两片 2K×4 并宽成 2K×8，仍只有 2K 个地址。**起手**：8K×8＝4 段×2 片并宽，写 4 段首址 → **D（0800H）**。

```
段0 0000-07FF   段1 0800-0FFF   段2 1000-17FF   段3 1800-1FFF   (2K=0800H)
0B1FH 落段1，该段芯片最小地址 0800H
```

A 0000H 是段 0 的首址，0B1FH 不在 0000–07FF。B 0600H、C 0700H 不是任何段的首址（段首只能是 0800H 的倍数）。

<a id="q03"></a>
## 03｜随机存取：访问时间与单元所在位置无关

<img src="../bank/2010/q16.png" alt="2010-16 原题" width="352" style="display:block; width:22.00em; max-width:100%; height:auto;">

> **新增**：随机存取＝任一单元按地址直接选到，耗时不随位置变。**起手**：四句各配一个性质，只需判 I、II、IV → **A**。

| 句 | 依据 | 真假 |
|---|---|---|
| I | RAM 掉电丢信息，ROM 不丢 | 真 |
| II | 二者都按地址直接选单元，符合上面的定义 | 真 |
| III | Cache 内容要不断被新块替换，ROM 内容不能这样写入 | 假 |
| IV | ROM 的信息固化，没有需要周期补充的电荷 | 假 |

I 真 → B、D 排除；IV 假 → C 排除；只剩 A。III 在这一步可不必判，但它也假，与结论一致。

<a id="q04"></a>
## 04｜复用 03：光盘靠转盘和寻道定位，访问时间随位置变

<img src="../bank/2011/q14.png" alt="2011-14 原题" width="436" style="display:block; width:27.25em; max-width:100%; height:auto;">

> 无新判据，沿用 03；**补一个事实**：CDROM 读数要让光头移到目标轨道并等扇区转到。**起手**：对四项逐个问“任意单元耗时一样吗” → **B**。

EPROM、DRAM、SRAM 都是半导体芯片，按地址直接选单元（03 的 II），符合随机存取；CDROM 的耗时取决于光头和碟片当前位置，不符合。

<a id="q05"></a>
## 05｜MAR 位数由地址空间决定，不由已装芯片决定

<img src="../bank/2011/q15.png" alt="2011-15 原题" width="535" style="display:block; width:33.44em; max-width:100%; height:auto;">

> **新增**：MAR 要能装下 CPU 可能发出的任一地址，位数＝log₂(地址空间字节数)。**起手**：圈出题面的“地址空间 64MB” → **D（26 位）**。

```
64MB = 2^6 · 2^20 = 2^26 字节 → 26 位
(32MB = 2^25 → 25 位；4MB×8 芯片 4M=2^22 → 22 位，是片内地址)
```

C 25 位是已装 32MB 的位数，A 22 位是单片单元数的位数，题问的“地址空间”都不是这两个数；B 23 位在题中没有对应的量。

读法说明：“至少”不是指按已装 32MB 去减，因为题面把地址空间 64MB 明确给了，若 MAR 只有 25 位，就表示不了 32MB–64MB 的地址；这是采用的读法。8 片 4MB×8 拼 32MB 只用来说明“已装”，按 01 的方法是并宽 1、扩深 8。

<a id="q06"></a>
## 06｜闪存：写前要擦除，读写不对称

<img src="../bank/2012/q16.png" alt="2012-16 原题" width="363" style="display:block; width:22.69em; max-width:100%; height:auto;">

> **新增**：闪存改写某位置前须先擦除（以块为单位），所以写慢于读。**起手**：逐句找“多加的断言” → **A（错误）**。

| 项 | 题面说法 | 判断 |
|---|---|---|
| A | 可读可写，**并且读写一样快** | “一样快”与擦除后再写矛盾 → 错 |
| B | MOS 管构成的半导体存储器 | 对 |
| C | 掉电不丢 | 对 |
| D | 随机访问，可替代外存 | 按本题的传统读法对（U 盘、固态盘） |

题问“错误”，且只有 A 多出一个速度断言，其余三项各自成立。

<a id="q07"></a>
## 07｜DRAM 行列分时复用地址引脚

<img src="../bank/2014/q15.png" alt="2014-15 原题" width="525" style="display:block; width:32.81em; max-width:100%; height:auto;">

> **新增**：DRAM 把地址分成行地址、列地址，先后从同一组引脚送入。**起手**：4M＝2²² → 阵列 2¹¹×2¹¹ → 引脚 11＋数据 8 → **A（19）**。

题面只给 4M×8，没给阵列形状；取行列各半的 11×11（引脚最少的读法）。

| 选项 | 对应的算式 | 与题面不符之处 |
|---|---|---|
| A 19 | 11＋8 | ✓ |
| B 22 | 22 位单元地址 | 不复用；也没算 8 根数据线 |
| C 30 | 22＋8 | 不复用地址 |
| D 36 | 28＋8 | 28 位是整机 256MB 的位数，题问单个芯片 |

<a id="q08"></a>
## 08｜DRAM 用电容存位，所以要周期刷新

<img src="../bank/2015/q17.png" alt="2015-17 原题" width="443" style="display:block; width:27.69em; max-width:100%; height:auto;">

> **新增**：电容会漏电，所以存位靠电容的存储器必须周期刷新。**起手**：四项各写“靠什么存位” → **B（SDRAM）**。

| 项 | 存位方式 | 工作期间要刷新吗 |
|---|---|---|
| SRAM | 触发器 | 否 |
| SDRAM | 电容（DRAM 单元），S 指同步时钟接口 | 是 |
| ROM | 固化信息 | 否 |
| FLASH | 浮栅，非易失 | 否 |

03 的 IV 判 ROM 不刷新，同一理由；SDRAM 名字里的 S 不改变存位的单元。

<a id="q09"></a>
## 09｜低位交叉：体号＝地址 mod 4，同体紧邻才冲突

<img src="../bank/2015/q18.png" alt="2015-18 原题" width="529" style="display:block; width:33.06em; max-width:100%; height:auto;">

> **新增**：4 体低位交叉，体号取地址低 2 位（即 mod 4）。**起手**：把九个地址写成“序号：体号” → **D**。

```
序号  1    2    3    4    5    6    7    8    9
地址  8005 8006 8007 8008 8001 8002 8003 8004 8000
体号  1    2    3    0    1    2    3    0    0
```

| 选项 | 体号 | 序号 | 结论 |
|---|---|---|---|
| A 8004、8008 | 0、0 | 8、4 | 同体，但隔 4 拍 |
| B 8002、8007 | 2、3 | 6、3 | 不同体 |
| C 8001、8008 | 1、0 | 5、4 | 不同体 |
| D 8000、8004 | 0、0 | 9、8 | 同体且紧邻 |

题面没给存取周期，读法：按 4 体交叉的设计，每个体周期正好等于轮完 4 个体的时间，所以隔 4 拍的 A 刚好不冲突，紧邻的 D 前一次尚未完成。这是采用的读法；依据是 A、D 同体，而只有 D 紧邻。

<a id="q10"></a>
## 10｜地址区间长度＝末址−首址＋1

<img src="../bank/2016/q16.png" alt="2016-16 原题" width="549" style="display:block; width:34.31em; max-width:100%; height:auto;">

> **新增**：十六进制端点都含在区间内，长度要 +1。**起手**：5FFF−4000+1 → **C（14）**。

```
ROM: 5FFF-4000+1 = 2000H = 8192 B = 8KB
RAM: 64-8 = 56KB（0000-3FFF 与 6000-FFFF 两段，不连续也照加）
8K×4 = 4KB/片 → 56/4 = 14   （并宽 2 × 扩深 7，见 01）
```

A 7 是 56K 除以 8K，把每片 8K 单元当成 8KB；B 8 与 D 16 在题面里都没有对应的算式（D 若是 64KB/4KB，则把 ROM 区也算成 RAM）。“位 ROM 区”是题面印刷错字，读作“为”。

<a id="q11"></a>
## 11｜非对齐的 8 字节跨几个 4 字节总线字

<img src="../bank/2017/q13.png" alt="2017-13 原题" width="525" style="display:block; width:32.81em; max-width:100%; height:auto;">

> **新增**：总线每次传一个 4 字节对齐的字，周期数＝所占字节覆盖的对齐字个数。**起手**：写出 1A…21，画 4 字节边界 → **C（3）**。

```
x = 0804001A，占 1A 1B | 1C 1D 1E 1F | 20 21        (1A mod 4 = 2)
对齐字: [18-1B] [1C-1F] [20-23]  → 3 次
```

首址 mod 4＝0 时才是 2 次（B）；A 1 次连 4 字节都装不下；D 4 次要求 8 字节各占一次，与每次传 4 字节矛盾。读法：每个周期读一个对齐的 32 位字；4 片 64M×8 就是并成这 32 位。

<a id="q12"></a>
## 12｜地址访问与内容访问：看凭什么定位

<img src="../bank/2017/q18.png" alt="2017-18 原题" width="454" style="display:block; width:28.38em; max-width:100%; height:auto;">

> **新增**：按地址＝给出单元号取内容；按内容＝给出内容去找它在哪。**起手**：每项问“凭什么定位” → **B（错误）**。

| 项 | 题面 | 判断 |
|---|---|---|
| A | MM 在 CPU 外，CS 在 CPU 内（控制器内） | 对 |
| B | MM 按地址，CS **按内容** | CS 取微指令靠微地址，也是按地址 → 错 |
| C | MM 存指令和数据，CS 存微指令 | 对 |
| D | MM 用 RAM、ROM，CS 用 ROM | 按本题的传统约定对 |

<a id="q13"></a>
## 13｜两级目标：先让引脚最少，再让刷新行最少

<img src="../bank/2018/q17.png" alt="2018-17 原题" width="523" style="display:block; width:32.69em; max-width:100%; height:auto;">

> **新增**：复用后引脚数＝行位数、列位数中较大者；刷新按行进行，行数少则开销小。**起手**：列 r×c＝2048 的各对 → **C（32、64）**。

| (r,c) | 引脚 | 行数 |
|---|---|---|
| 2048、1 | 11 | 2048 |
| 64、32 | 6 | 64 |
| 32、64 | 6 | 32 |
| 1、2048 | 11 | 1 |

引脚最少 6，有 B、C；再取行数少的 C。D 行数最少但引脚 11，第一级就被排除。“刷新开销”题面没有定义，读法：DRAM 逐行刷新，开销看行数；否则 B、C 无法分出。

<a id="q14"></a>
## 14｜按字编址：地址数是字数，不是字节数

<img src="../bank/2021/q15.png" alt="2021-15 原题" width="587" style="display:block; width:36.69em; max-width:100%; height:auto;">

> **新增**：按字编址时，单元＝一个字（32 位），区间含的单元数×32 位才是容量。**起手**：3FFFFF−0＋1＝4M 个字 → **C（32）**。

```
4M 字 × 32 位 = 16MB = 32 × 512KB（每片 512K×8 位＝512KB）
并宽 32/8 = 4；扩深 4M/512K = 8；4×8 = 32 片        （02：并宽不增地址）
```

读法依据：题面写“按字编址，字长 32 位”，24 位地址线共 2²⁴ 个字，其中 00 0000H–3F FFFFH 为 RAM。A 8 是只算了深度、没乘并宽的 4；B、D 与 4×8 不符。

## 15｜行缓冲＝一行的全部列；不正确项看引脚

<img src="../bank/2022/q17.png" alt="2022-17 原题" width="466" style="display:block; width:29.13em; max-width:100%; height:auto;">

> **新增**：DRAM 读出时整行进行缓冲，缓冲容量＝列数×每单元位数。**起手**：每片 8192×8192×8 位，列出 A、C、D 的算式 → **C（不正确）**。

| 项 | 算式 | 判断 |
|---|---|---|
| A | 8192×8192＝2²⁶ 字节/片，×8 片＝512MB | 对 |
| C | 单元 2²⁶ 需 26 位，复用后行、列各 13 位 → 引脚 13（07） | 26 位错 |
| D | 一行 8192 列，每列 8 位 | 对 |
| B | 8 片拼 64 位总线 | 题面没给地址如何分布，不能据此判错 |

B 严格说“并宽”与“交叉编址”不同，题面没有展开；单选“不正确”取与 07 直接矛盾的 C。这是我没有把握的一项，B 的措辞可争议。

<a id="q16"></a>
## 16｜按比例切分：RAM 在低端，ROM 在高端

<img src="../bank/2023/q15.png" alt="2023-15 原题" width="548" style="display:block; width:34.25em; max-width:100%; height:auto;">

> **新增**：地址空间＝2ⁿ 字节，按比例切成连续段，低端给 RAM。**起手**：2³⁰＝1GB，3:1 → 每份 256MB＝1000 0000H → **C**。

```
0000 0000 ~ 2FFF FFFF  RAM (768MB)
3000 0000 ~ 3FFF FFFF  ROM (256MB)   末址 = 2³⁰−1 = 3FFF FFFF
```

A 是最低 256MB（ROM 在低端，与题设相反）；B 长 512MB；D 的 4FFF FFFF 要 31 位地址，超出 30 位空间。
