## 01｜2010-08：拓扑序的个数＝逐轮零入度候选的分叉

<img src="../bank/2010/q08.png" alt="2010-08 原题" width="470" style="display:block; width:29.38em; max-width:100%; height:auto;">

**新增**：每轮只能选入度为 0 的点，选后删它的出边。**起手**：抄边 `a→e a→b a→c b→c c→d e→d`，逐轮写候选。→ **3 种，选 B**

```
第1轮 候选 {a}
第2轮 候选 {b,e}
  先 e：候选 {b} → {c} → {d}        a e b c d
  先 b：候选 {c,e}
        c → {e} → {d}               a b c e d
        e → {c} → {d}               a b e c d
```

d 要等 c 与 e 都已删；a→c 已被 a→b→c 蕴含，不添分叉。
核对：a 在首、d 在末，中间 b 先于 c，e 只能插到 b 前、b c 之间、c 后，恰 3 个位置，没有第 4 个，所以 A 不成立；C、D 少数了一个分叉。

## 02｜2012-06：邻接矩阵下三角为零，边只从小编号指向大编号

<img src="../bank/2012/q06.png" alt="2012-06 原题" width="436" style="display:block; width:27.25em; max-width:100%; height:auto;">

**新增**：`A[i][j]=1` 表示 `i→j`，下三角（i>j）全零＝不存在大号指向小号的边。**起手**：写 n=2 的两个合法矩阵。→ **存在，可能不唯一，选 C**

```
[[0,1],[0,0]]  只有 1→2          序列只有 1,2        唯一
[[0,0],[0,0]]  无边              1,2 与 2,1 都可    不唯一
```

- 存在：每条边 u→v 都有 u<v，按 1,2,…,n 排，每条边起点在前（沿用 0806-03）。
- A 错、B 错：上面两个矩阵都满足题设，一个唯一、一个不唯一。
- D 错：序已构造出来。

> 读法：“以下”不含主对角线，按图论默认无自环；若有自环则无拓扑序，题面未给此情形。若约定相反（`A[i][j]` 表 `j→i`），则按 n,…,1 排，结论不变。

## 03｜2012-07：Dijkstra 每轮取最小暂定距离，再松弛它的出边

<img src="../bank/2012/q07.png" alt="2012-07 原题" width="439" style="display:block; width:27.44em; max-width:100%; height:auto;">

**新增**：dist 是“已确定点的距离＋出边权”的最小暂定值；每轮取未确定点中最小者，用它松弛出边。**起手**：写一行 b c d e f 的暂定距离。→ 后续依次 **f, d, e，选 C**

```
边：ab2 ac5 bc1 bd3 cd3 ce4 cf1 de1 df4 ef1
初始           b2  c5  d∞  e∞  f∞
取 b(2)：c=3 d=5    →  c3  d5
取 c(3)：d 6≥5 不改，e=7，f=4  →  d5  e7  f4
取 f(4)：无出边
取 d(5)：e=6，f=9 不改          →  e6
取 e(6)：f=7 不改
```

| 选项 | 取 c 之后的最小暂定值 | 结论 |
|---|---|---|
| A d,e,f | 要先取 d(5)，但 f=4 更小 | ✗ |
| B e,d,f | 要先取 e，但 e=7 最大 | ✗ |
| D f,e,d | 取 f 后 d=5<e=7 | ✗ |
| C f,d,e | f4、d5、e6 | ✓ |

> 把边权 `ce4` 当 e 的距离，就得 e=4 而取错；应为 c 的 3 加 4＝7，此时看信号：写的是不是“到 a 的距离”。

## 04｜2012-08：最小生成树的总权唯一，树本身可以不唯一

<img src="../bank/2012/q08.png" alt="2012-08 原题" width="448" style="display:block; width:28.00em; max-width:100%; height:auto;">

**新增**：最小生成树＝生成树中总权最小者；总权由此唯一，等权边可使树不同。**起手**：画三边权均 1 的三角形（合法的连通无向图）。→ **仅 I，选 A**

三角形的生成树是任取 2 边：3 棵，总权都是 2。

| 命题 | 依据 | 结论 |
|---|---|---|
| I 代价唯一 | 凡最小生成树都等于那个最小值 | 真 |
| II 最小权边在所有树中 | 三边全是最小权边，每棵树只含 2 条 | 假 |
| III Prim 不同起点必同树 | 从 a 起第一步 ab、ac 等权可任取：取 ab 得含 ab 的树，取 ac 后再取 cb 得 `{ac,cb}`，不含 ab | 假 |
| IV 两算法总不同 | 图本身是树（如一条路径）时，最小生成树只有它自己，两法都得它 | 假 |

> III 用到“Prim 先取与起点相连的最小边”，规则在 [07](#q07) 完整讲；IV 只用“两法都得最小生成树”。

## 05｜2013-09：缩短工期要覆盖每一条并列最长路径

<img src="../bank/2013/q09.png" alt="2013-09 原题：含完整活动权值" width="537" style="display:block; width:33.56em; max-width:100%; height:auto;">

**新增**：AOE 网的工期＝源到汇的最长路径权和；缩短要让所有最长路径都变短。**起手**：列出 1 到 6 的全部路径和权和。→ **f 和 d，选 C**

```
1-2-4-6      a c g   3+9+6  = 18
1-2-5-6      a e h   3+6+9  = 18
1-3-2-4-6    b d c g 8+4+9+6= 27
1-3-2-5-6    b d e h 8+4+6+9= 27
1-3-5-6      b f h   8+10+9 = 27
```

三条 27 同时最长：只有同时碰到这三条的组合才能缩短工期。

| 选项 | 没被碰到的 27 路径 | 结论 |
|---|---|---|
| A c,e | `b f h` | ✗ |
| B d,c | `b f h` | ✗ |
| D f,h | `b d c g` | ✗ |
| C f,d | f 在 `bfh`，d 在另两条 | ✓ |

> 图上权全部可读，题单无补充标注。C 只说“能缩短”，不给缩短量；缩得很多时，18 的路径也可能成为新瓶颈，此处不涉及。


第二次确定的是 5，之后的松弛才得到 14，所以 14 与 2 的 21 同时出现；B 的 25 是只取 3 时的值，与 14 不能并存；A 无任何更新；D 的 15 是把 5→2 的权当成 dist(2)，漏了 dist(5)=6。

> 读法：“更新为”按松弛完 5 的出边后读；仅取 5 未松弛时是 (25,3,∞,6)，不在选项中。
