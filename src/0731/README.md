# 0731｜教学基准包

这组文件保存0731九道题的完整教学结果，以及这次真实教学现场反复纠偏后形成的讲解规则。它独立服务于后续 `src` 题目的互动教学，不套用其他分析模板。

## 文件

- [answers.md](answers.md)：九道题的完整讲解，包括第一步、推理过程、易错路线和可迁移动作。
- [teaching-protocol.md](teaching-protocol.md)：从本次分歧中确定的教学规则。讲解0801及以后日期前应先阅读。

## 使用顺序

后续开始某个日期时：

1. 先读 `teaching-protocol.md`，确定怎样讲。
2. 需要校准讲解力度时，再读 `answers.md` 中最相近的题，而不是照抄答案结构。
3. 每次只讲用户指定的一题；随对话补足真实卡点，不提前展开后续知识。

这套基准的目标不是把回答写得更像教材，而是在用户没有时间完整听课、代码基础不足的条件下，通过真题建立能在考场调用的思考动作，最终服务于408提分和上岸。
