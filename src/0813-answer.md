<a id="q01"></a>
## 01｜溢出＝数学结果超出目标范围

<img src="../bank/2010/q13.png" alt="2010-13 原题" width="492" style="display:block; width:30.75em; max-width:100%; height:auto;">

> **新增**：沿用 0812-21 的范围 [−128,127]，把“溢出”定为：真实乘积不在此范围。**起手**：FE、F2、90、F8 译成值再乘 → **B**。

```
FE=-2  F2=-14  90=-112  F8=-8
A r1×r2 = 28     B r2×r3 = 1568     C r1×r4 = 16     D r2×r4 = 112
```

只有 B 的 1568 > 127。D 的 112 是两负相乘里最接近的，但仍 ≤127，不溢出。两个负数相乘得正，符号对不代表装得下。

<a id="q02"></a>
## 02｜CF 是借位；无符号 a>b ⇔ 无借位且差非零

<img src="../bank/2011/q17.png" alt="2011-17 原题" width="534" style="display:block; width:33.38em; max-width:100%; height:auto;">

> **新增**：比较 a、b＝做 a−b 但不存差。**CF＝1 表示无符号时 a<b 需要借位**；ZF＝1 表示差为 0。无符号 a>b 恰好是 CF=0 且 ZF=0，即 C。**起手**：用两组数代入。

选项 B、D 的横线只盖 SF（B）或 CF+SF（D），C 的横线盖 CF+ZF 整体（读图所得）。8 位代入：

| 数据（无符号） | CF | ZF | SF | 应转移？ |
|---|---|---|---|---|
| 1−2＝FF | 1 | 0 | 1 | 否（1<2） |
| FF−01＝FE | 0 | 0 | 1 | 是（255>1） |

| 选项 | 在哪组数上失败 |
|---|---|
| A CF+OF=1 | 1−2：CF=1，式子成立而转移，但 1<2 |
| B ¬SF+ZF=1 | FF−01：SF=1、ZF=0，式子为 0 不转移，但 255>1 |
| C ¬(CF+ZF)=1 | 两组都与应有结果一致；等价于 CF=0 且 ZF=0 |
| D ¬(CF+SF)=1 | FF−01：SF=1，式子为 0 不转移，但 255>1 |

SF、OF 的含义见 07；这里只用到它们在反例中的取值，不影响 A、B、D 的裁决。

<a id="q03"></a>
## 03｜多步表达式：每一步的数学值都要装得下

<img src="../bank/2013/q14.png" alt="2013-14 原题" width="536" style="display:block; width:33.50em; max-width:100%; height:auto;">

> **新增**：z=2x+y/2 有三个结果（2x、y/2、和）。若任一步越出 [−128,127]，才选 D。**起手**：先译 x、y。

```
x = 1 1110100 = 11110100 → -12     y = 10110000 → -80
2x    = -24   在范围内
y/2   = -40   在范围内（-80 是偶数，除 2 无舍入）
z     = -64   在范围内
-64 → 256-64=192 → 1100 0000
```

对照选项：A 是 1100 0000，**选 A**；B 为正数，与两个负项相加矛盾；C 的值是 −86，≠ −64；D 要求某一步越界，三步都没有。本题只用数学值，移位怎样落到位串见 06。

## 04｜无新台阶：复用 01，边界在 −128

<img src="../bank/2014/q13.png" alt="2014-13 原题" width="498" style="display:block; width:31.13em; max-width:100%; height:auto;">

**起手**：x=103，y=−25，四个式子各算数学值 → **C**。

| 式 | 值 | 在 [−128,127] 内？ |
|---|---|---|
| A x+y | 78 | 是 |
| B −x+y | −128 | 是（1000 0000） |
| C x−y | 128 | 否，超出 127 |
| D −x−y | −78 | 是 |

B 绝对值最大，但 −128 正是负端多出的那个值（0812-21）。

<a id="q05"></a>
## 05｜无新台阶：复用 0812-27，模数换成 2¹⁶

<img src="../bank/2016/q13.png" alt="2016-13 原题" width="432" style="display:block; width:27.00em; max-width:100%; height:auto;">

**起手**：目标 unsigned short，范围 0..65535，−32767 加 2¹⁶ → **D**。

```
-32767 + 65536 = 32769 = 0x8001     （short 里 -32767 的位串就是 8001）
```

A 不是无符号可取的值；B 是绝对值，位串 8001 ≠ 7FFF；C 32768＝8000，与 8001 差 1。

<a id="q06"></a>
## 06｜逻辑右移补 0，算术右移补符号位

<img src="../bank/2018/q16.png" alt="2018-16 原题" width="524" style="display:block; width:32.75em; max-width:100%; height:auto;">

> **新增**：右移时原位向低位移一格，最高位空出，填什么由移位类型定。**起手**：写 `1101 1000`，右移后最高位记 `?`。

```
原       1 1 0 1 1 0 0 0
右移     ? 1 1 0 1 1 0 0
逻辑     ?=0  → 0110 1100
算术     ?=原符号位 1 → 1110 1100
```

题问“逻辑，算术”的顺序，故 **B**。核对：算术右移值 −40/2=−20，−20 的 8 位补码正是 1110 1100。A 两个都填 1，D 两个都填 0，C 顺序颠倒。

<a id="q07"></a>
## 07｜CF 看无符号借位，OF 看有符号数学差

<img src="../bank/2018/q19.png" alt="2018-19 原题" width="526" style="display:block; width:32.88em; max-width:100%; height:auto;">

> **新增**：同一次 R1−R2，OF 回答“按有符号，真实差是否出范围”。CF 沿用 02。**起手**：把两个操作数各按两种类型写成值。

| 读法 | R1 | R2 | 差 | 标志 |
|---|---|---|---|---|
| 无符号 | 2³²−1 | 2³²−16 | 15 | R1≥R2，无借位，CF=0 |
| 有符号 | −1 | −16 | 15 | 在 32 位范围内，OF=0 |

所以 **A**。两个操作数最高位都是 1，但有符号值相差只有 15，OF 并不因此置 1；B、D 要求 R1<R2（无符号），C、D 要求有符号差出范围，都与 15 不符。

## 08｜同一组位串：先按题设类型分组，再各自排序

<img src="../bank/2021/q13.png" alt="2021-13 原题" width="587" style="display:block; width:36.69em; max-width:100%; height:auto;">

> **新增**：A、B 讲无符号，C、D 讲带符号，先按选项分两组。**起手**：把 FFFD、FFDF、7FFC 各写成两列。

| 位串 | 无符号 | 带符号（16 位） |
|---|---|---|
| x＝FFFD | 65533 | −3 |
| y＝FFDF | 65503 | −33 |
| z＝7FFC | 32764 | 32764 |

无符号：z<y<x，与 A（z<x<y）、B（x<y<z）都不符。有符号：y<x<z，C（x<y<z）不符，**D** 相符。

<a id="q09"></a>
## 09｜无符号视角：减数是负数的位串，就是大数

<img src="../bank/2023/q16.png" alt="2023-16 原题" width="547" style="display:block; width:34.19em; max-width:100%; height:auto;">

> **新增**：减数 y 为负时，无符号读法里它是 2³²+y，必然大于小的被减数，所以借位。**起手**：先用题给例子确认 CF 的约定。

题给：100−200 得 OF=0、CF=1。100<200 需借位，与 02 的“CF＝借位”一致；若 CF 取加法进位，该例应是 0。

```
x=10, y=-20
有符号：10-(-20)=30，在 int 范围内 → OF=0
无符号：10 减 (2³²-20)，10 < 2³²-20 → 借位 → CF=1
```

**B**。A、C 的 CF=0 要求被减数不小于减数，不成立；C、D 的 OF=1 要求 30 出范围，不成立。

## 10｜乘法可写成“按乘数各位移位、累加”的循环

<img src="../bank/2024/q15.png" alt="2024-15 原题" width="397" style="display:block; width:24.81em; max-width:100%; height:auto;">

> **新增**：乘数按位读，某位为 1 就把当前被乘数加进部分积，然后被乘数左移、乘数右移。**起手**：手算 13×11（b=1011）。

```
a=13 b=1011 p=0
bit1: p=13   a=26
bit1: p=39   a=52
bit0: p=39   a=104
bit1: p=143  a=208     → 143
```

乘数 b 是变量也能这样做，所以 D“无法”是错的，**选 D**（题问错误项）。

| 选项 | 判断 |
|---|---|
| A | 阵列乘法器是组合逻辑，题说“可以”一个周期完成，成立 |
| B | 上面循环每轮用一次 ALU 加、一次移位，多轮才完成；按这一读法 B 成立。若硬件另有合并设计则超出题面 |
| C | 乘常数把常数拆成 2 的幂之和，如 ×11＝<<3＋<<1＋原值，成立 |
| D | 与上面的循环矛盾，错误 |

## 11｜越界后机器留下低 8 位，OF 单独报告

<img src="../bank/2025/q14.png" alt="2025-14 原题" width="495" style="display:block; width:30.94em; max-width:100%; height:auto;">

> **新增**：题问“通过补码加减运算器得到的值”，8 位只留数学值 mod 2⁸（0812-25 取低位）；OF 由数学值是否出范围决定。**起手**：先把 A3、75 译成值。

```
A3 → -93     75 → 117
x-y = -210 < -128      → OF=1
-210 + 256 = 46        → 2EH，运算器输出 46
```

核对位串：A3−75＝0x2E＝46。**D（46，1）**。A、B 的 24 与 0x2E 不符；C 的 OF=0 与 −210 出范围不符。结果位串首位为 0，是负减正得正的符号翻转，不影响 OF=1 的判断。
