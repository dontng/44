## 02｜用“第 k 趟后的特征”反查算法

<img src="../bank/2009/q10.png" alt="2009-10 原题" width="504" style="display:block; width:31.50em; max-width:100%; height:auto;">

**新增 / 起手 → 答案**：本题一次要用到四种排序“二趟后”的样子，只给最小定义（各自的完整过程见后文）。起手：列出每种算法第二趟后必有的特征。→ **B**。

| 算法（一趟的含义） | 第二趟后必有 | 对 `11,12,13,7,8,9,23,4,5` |
|---|---|---|
| 插入：把下一项插入已有序前缀 | 前 3 项互相有序 | `11,12,13` ✓ |
| 冒泡：相邻比较，大者向后沉 | 末 2 位是最大两个 | 末位 4,5，最大 23 不在末 ✗ |
| 选择：每趟选未排部分最小放前端 | 前 2 位是全局最小两个 | 前位 11,12 ✗ |
| 二路归并：一趟把有序段长翻倍（1→2→4） | 每 4 个一段有序 | `11,12,13,7` ✗ |

冒泡若改为小者前浮，则前 2 位应是 4,5，同样不符。

<details><summary>严谨性</summary>

只能说“与插入排序一致”，不能说它一定如此；题目的“只能是”由其余三项都被特征否定得到。7,8,9 碰巧有序，不构成别的算法的证据。
</details>

<img src="../bank/2010/q10.png" alt="2010-10 原题" width="462" style="display:block; width:28.88em; max-width:100%; height:auto;">


## 14｜小根堆删根：末项补根下沉，每层先比两孩子再比替补
