# Answer 重写规程｜一次一篇，独立执行

> 把已有 `src/MMDD-answer.md`（GPT 解析并审核过的旧稿）按 [answer-writing-rules.md](answer-writing-rules.md) 重写成新稿。本页只规定**怎样做才不写错、不写成同一个样子、不浪费开销**；教学要求以 answer-writing-rules.md 为准。

## 0. 原则

1. **旧稿是事实来源，不是版式来源，也不是结论来源。** 答案、选项理由、计算都要自己复核；讲法、结构、标题不继承。
2. **新稿不以任何已完成的 answer 为样板。** 每题的写法由这道题决定：指针题画前后图，计数题列表，证明题写推理链。跨篇只允许共享文件头的速览格式，题内展开不得雷同。
3. **一次只做一篇。** 做完、核对、提交、推送，再开下一篇。不批量，不为凑日期压缩后半篇。
4. **每篇用新会话，输入只取下面第 1 节列出的文件。** 不读 quality-gate、learning-system、0731-context、整本账本。

## 1. 开工前只读这些

## 2. 每篇的步骤

1. **读图、独立解题**：先自己得出每题答案与每个选项的裁决，再和旧稿、题单结果表对。不一致时先复查图和计算，再判断谁错。
2. **列事实卡（只在草稿里，不入库）**：每题一行：答案；各选项被排除的题面证据；承重计算。旧稿与自己不一致处标出来。
3. **排 i+1 链**：按题单顺序，每题只写一个新台阶；前面题已教的用回链调用；后面才讲的知识不得提前使用。
4. **逐题决定写法**：先问“一个没学过这块的人，第一笔写什么”，再决定用代码块、表格还是推理链。写完一题，检查它与相邻题的结构是否过于相像。
5. **写文件头**：已有 / 新增 / 折叠速览（起手、最易错→信号）；速览不放答案。
6. **复核**：重算全部数值；每个选项都有依据；锚点、图片路径与题单一致。
7. **更新 ledger 本日期那一段**，使“新增判断”与新稿一致。
8. **提交并推送**，提交信息按 AGENTS.md 的三段格式。

## 3. 实际遇到的错误类型（核对时优先查）

- **旧讲法漏了一类情形，结论碰巧仍对。** 例如枚举“可能取值”时少一种构造。要么补全，要么说明为什么不影响结论。
- **错误选项的“来历”写成对读者心理的猜测。** 只写客观的错误路线、它偷用的前提、该看的信号；写不出具体原因的选项，就只写它和题面哪里不符，不编造。
- **题图本身有不规范处**（括号不匹配、条件含糊）。写明所采用的读法，以及为什么这是唯一能得到确定答案的读法；不替出题人补答案。
- **含糊的“最小/至少”只给一边。** 下界与构造都要有。
- **定义依赖约定**（指向元素还是空位、先加后写还是先写后加）。先读约定，再写公式，不套另一题的公式。
- **解释越写越长。** 同一道题已经说清的内容不重复；折叠区只放严谨性细节，不放必要机制。

## 4. 交付前自检

- [ ] 我看了每一张原题图，答案与旧稿、题单一致，或分歧已查明？
- [ ] 每题只新增一个台阶，没有用到后面才讲的东西？
- [ ] 每个选项都有题面依据，没有编造的排除理由？
- [ ] 相邻两题的写法不是同一种结构？
- [ ] 数值逐项复算，锚点和图片路径无误？
- [ ] ledger 与新稿一致，且没有写成“用户已掌握”？

## 5. 与旧稿相比，什么情况下不该动

如果旧稿某题已经满足全部要求，保留其事实与讲法，不为“统一”而改写。重写的目标是教学质量，不是文字量；改动前后都要能说出读者因此少卡在哪一步。
