# 真实复盘事件

当前没有替用户预填的作答。每次事件为独立JSON，含实际日期、题号、独立/提示/不确定/失败、原题/迁移/混合、具体依据，可选实际耗时；通过 `tools/review.py record` 用唯一ID独占创建，绝不覆盖旧文件。

这里与历史 `data/answers`、`data/results`、`data/progress` 分开。旧首次证据不动，也不导入旧box/due作新的到期队列。完整使用见[复习入口](../../review/README.md)。测试只用临时目录，不写示例通过记录到这里。

填错记录时不要偷偷改历史；先说明错误，保留原记录并追加纠正说明。当前调度器没有自动撤销事件功能；需要撤销时须显式实现有引用ID的撤销事件后再重算，不能用伪造一次成功抵消。
