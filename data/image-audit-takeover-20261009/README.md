# 题图内容审核与接力

审核对象由当前 src/MMDD.md 的图片引用动态提取；当前59页、825个图片引用、798张去重题图。不要仅审核最近改动图片。

1. 用仓库 bank/YYYY/qNN.png 和 past_papers 原卷作为稳定输入；upload 路径只是临时附件。缺失图片必须重新读取，不能跳过后计为通过。
2. 将 PNG 解码及哈希核对、联系表目视筛查、原尺寸目视、原卷逐题比对分开记录。联系表筛查不等同逐字原卷验收。
3. 检查无前后题片段、页码、页眉及分节标题，同时保留完整题干、选项、代码、所有图表及所有小问。跨页续文和必要共用图须特别回查原卷。
4. 审核结论绑定仓库相对路径与 blob SHA。图片变化使旧审核结论失效。把已查、疑点、已修、未查范围及时写入记录。
5. 每批最多3张图片，附具体修复与验证记录；确认远端 main 更新成功后才标记已发布。禁止用全量重截数量当作缺陷数量。
6. 最新接力记录是 manifest.json；20261008旧记录保留历史用途，已标记由新复验替代。
