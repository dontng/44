## 可复用的排版经验

1. 先量原 PDF：本卷实际是 **514.56 × 742.08 pt**（约 181.53 × 261.79 mm），不是 A4。盲目指定 A4 会改变字号比例和分页。
2. 2023 逐行保存位置，题号悬挂约 20.6 pt；选项按原卷采用单列、双列、四列。跨页题目的选项和小问不重复题号。
3. 2026 使用同一尺寸与10 pt 正文、15.3 pt 行距。分页等待内嵌字体加载完成，依照实际浏览器高度决定；选择题整体移动，大题在完整段落、代码或图表之间分割。
4. 图像必须按纸面文字的可读性设置宽度，不能直接使用网页的 1200×800 占位尺寸；图表中的字体同样要内嵌并避免缺字。
5. 不让分值单占一行，不让表头换行撑高表格；章节标题与第一道题保持在一起。打印前检查题号 01–47、40×2+70=150 分、图数、代码字符、上下标及页脚。

## 文件管理和复现

- `data/2023-layout.txt`：人工对照扫描卷校定的逐行文字，坐标单位为 pt；`||` 代表原卷列间分隔。
- `data/2023-geometry.json`：OCR 仅提供位置测量，最终文字不取自未校对 OCR。
- `data/2023-figures.json`：原卷局部图像的页码和裁剪坐标。
- `data/2026.json`：结构化题文、选项与分值。
- `assets/`：局部原图、2026 SVG、字体子集及许可。
- `tools/build.py`：构建两个独立 HTML（Python 3 + lxml，运行时不联网）。
- `tools/paginate.js`：2026 大题段落分页。
- `tools/rebuild_fonts.py`：用仓库原卷内嵌的西文字形和外部 Fandol 字体目录重新构建字体子集。
- `data/font-match.json`：字体来源、恢复覆盖范围和局部字形比对记录。

在仓库根目录执行 `python paper_html/tools/build.py`。修改字体所未覆盖的新字符时，需要重新扩充字体子集；不要依赖操作系统的中文字体补缺。

打印使用页面自带的纸张尺寸、100% 缩放，并关闭浏览器页眉页脚。2023 为 8 页；2026 由于题文及配图不同，按内容自然分页，不强行压成 8 页。详见 `verification.json` 的实际检查记录。

字体再次生成：先从 <https://mirrors.ctan.org/fonts/fandol.zip> 取得 Fandol 字体，再运行 `python paper_html/tools/rebuild_fonts.py --fandol-dir /path/to/fandol`，随后执行普通构建命令。西文字形仅从本仓库已有 PDF 中读取，不下载完整商业字体。
