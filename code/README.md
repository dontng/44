<details>

在仓库根目录运行 `bash code/linear-list/run.sh` 可查看实验列表。`demo` 展示完整使用过程，`check` 运行维护者回归检查；`insert-wrong` 是故意交换接线顺序的反例，预期输出 FAIL、退出码为 1。需要 Bash 和 C 编译器。手动编译完整演示时，将 `demo.c` 和 `linked_list.c` 一起交给编译器。
