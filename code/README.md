# 408 数据结构代码母版

这里不做工程项目，也不收集大量“标准答案”。目标只有一个：用最少的、可运行的 C 代码，恢复读代码、改代码和写代码的能力，并把这种能力迁移到 408 的陌生代码题和算法设计题。

每个模块固定包含四样东西：

1. 一份最小完整实现；
2. 一页把语句翻译成动作的说明；
3. 从母版得到常见变体的方法；
4. 能自动判定对错的检查。

## 当前入口

- [线性表：顺序表与带头结点单链表](linear-list/README.md)
- `bash code/linear-list/check.sh`：编译并运行两份母版的断言检查

## 学习顺序

第一次只做三件事：运行代码；找到改变结构的核心语句；遮住核心语句重新补出。第二次再改变一个条件，例如把带头结点单链表改成不带头结点、循环链表或双链表。能通过新条件下的断言，才算完成迁移。

以后按“线性表 → 栈和队列 → 树与递归 → 图的遍历 → 排序和查找”扩展。每次只增加当前训练真正需要的母版，不提前建设庞大的代码库。
