# ch02 线性表：先掌握两种基本动作

顺序表和链表共同表达线性关系，但代码动作完全不同：顺序表靠移动数组元素腾位或补位；链表靠改写指针重接关系。`01`、`02` 是两份基本操作母版，`03` 把母版变为双链表、循环链表和静态链表，`04` 承担逆置与有序归并。

## 运行


## 一、顺序表怎样读

母版统一采用“位序从 1 开始、数组下标从 0 开始”。因此第 `i` 个元素是 `data[i - 1]`，而 `length` 既是元素个数，也是下一个空闲数组下标。

插入的核心是：

```c
for (int j = L->length; j >= i; --j)
    L->data[j] = L->data[j - 1];
L->data[i - 1] = e;
++L->length;
```

把代码翻译成动作：从后向前腾出第 `i` 个位置，写入新元素，最后增加表长。必须从后向前搬，否则尚未搬走的元素会被覆盖。

删除的核心是：

```c
*e = L->data[i - 1];
for (int j = i; j < L->length; ++j)
    L->data[j - 1] = L->data[j];
--L->length;
```

动作是：先保存被删值，再从前向后补空位，最后减少表长。顺序表的代码可以压缩为三个判断：位序怎样换算成下标、移动方向是什么、`length` 在什么时候改变。

## 二、单链表怎样读

母版使用带头结点的单链表。`L` 指向不存有效数据的头结点，空表条件是 `L->next == NULL`。第一个数据结点也因此拥有前驱，插入和删除首元结点不需要另写特殊分支。

先看等号左边，就能判断一句代码改变了什么：

| 代码 | 改变的对象 | 链表结构是否改变 |
|---|---|---|
| `p = p->next` | 指针变量 `p` | 否 |
| `p->data = x` | 当前结点的数据 | 逻辑连接不变 |
| `p->next = q` | 当前结点的后继字段 | 是 |

插入的两句核心代码是：

```c
s->next = p->next;
p->next = s;
```

先让新结点保存原后继，再让前驱指向新结点。如果交换顺序，`p->next` 中原后继的地址会先被覆盖，随后 `s` 会错误地指向自己。

删除的核心代码是：

```c
LNode *q = p->next;
*e = q->data;
p->next = q->next;
free(q);
```

依次是保存目标地址、取出结果、让前驱跨过目标、释放目标。`free(q)` 之后不能再读取 `q->data` 或 `q->next`。

## 三、从母版得到变体

### 不带头结点

此时 `L` 直接指向第一个数据结点，空表条件变为 `L == NULL`。第一个位置没有普通前驱，因此首元插入、首元删除需要单独修改 `L`。带头结点的价值不是“多一个结点”，而是用一个结构性哨兵消除首位置的特殊分支。

### 循环单链表

空表由 `L->next == NULL` 改为 `L->next == L`；尾结点由指向 `NULL` 改为指回头结点；遍历终点由 `p == NULL` 改为 `p == L`。结点类型以及插入时的两句改链都不需要改变。

### 双链表

结点增加 `prior`。在 `p` 后插入 `s` 时，单链表的两条关系扩展为四条：

```c
s->next = p->next;
if (p->next != NULL)
    p->next->prior = s;
s->prior = p;
p->next = s;
```

删除 `p` 的后继 `q` 时，要同时修复正向和反向关系：

```c
LNode *q = p->next;
p->next = q->next;
if (q->next != NULL)
    q->next->prior = p;
free(q);
```

### 哨兵的统一机制

哨兵不是链表专属技巧。它是人为放置一个保证存在的边界对象，把“是否到边界”的特殊判断吸收进普通操作。带头结点让首元操作拥有普通前驱；顺序查找设置哨兵，则让循环可以依靠必然命中结束。判断一个哨兵是否有价值，只问：它消除了哪个反复出现的边界分支。

## 四级验收

1. **会读**：能区分“指针变量移动”“数据改变”“连接改变”。
2. **会补**：遮住顺序表插入/删除循环和链表插入/删除改链，能补回核心代码。
3. **会变**：能说出改成无头、循环、双链表时，终止条件和连接维护分别改变什么。
4. **会证**：为首位、末位、空表、非法位序各增加一个 `assert`；修改代码后仍能通过检查。

当前不要追求一次默写整个文件。先让每一行都能还原成动作，再逐步减少提示，最终从函数骨架补出核心语句。
