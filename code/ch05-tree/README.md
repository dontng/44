# ch05 树与二叉树

阅读顺序是结构递归、遍历状态、树森林表示、典型应用。`01_binary_tree.c` 把“树由根和左右子树组成”落实为递归建树、计数和求高；`02_traversal_threading.c` 对比系统栈、显式栈、队列和线索；`03_tree_forest.c` 对比双亲数组与孩子兄弟链；`04_tree_applications.c` 用 Huffman 和并查集展示树如何服务于最优合并与集合管理。

验收重点是能说清递归函数返回时已经解决了哪棵子树，以及非递归代码中的栈或队列保存了哪些“尚未完成”的结点。线索指针只有在对应孩子不存在时才有效，不能把线索当成普通孩子继续递归。
